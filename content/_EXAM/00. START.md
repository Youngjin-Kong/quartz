# 00. START — 시험 시작하면 여기부터

> 모든 명령을 **풀어서** 쓴다. 보고서에 copy/paste 재현이 요건이라 헬퍼 스크립트·별칭·tmux 자동화를 쓰지 않는다.
> `nnmap` 별칭도 쓰지 마라 — 보고서에 `nnmap` 이라고 적으면 재현이 안 된다.

## 1. 변수 — 터미널마다 한 번

```bash
# ↓↓↓ 매 시험 이 두 줄만 바꾼다 ↓↓↓
export T=192.168.x.x       # 현재 타겟
export LHOST=192.168.x.x   # 아래로 확인
```
```bash
ip -4 addr show tun0 | grep -oP 'inet \K[\d.]+'    # LHOST 확인
mkdir -p ~/OSCP-EXAM/$T && cd ~/OSCP-EXAM/$T
```
> 타겟 바뀌면 `export T=` 만 다시. 작업 폴더도 타겟별로 나눠야 nmap 결과가 안 덮인다.

## 2. 첫 스캔 — 타겟마다

빠른 스캔 먼저 보고, 전체 스캔은 **터미널 탭을 따로 열어** 돌린다(백그라운드).

```bash
# 빠른 것 — 상위 포트 먼저 (탭 1)
nmap -sCV -T4 --top-ports 1000 -oN nmap-top.txt $T

# 전체 포트 — 새 탭에서, 결과는 끝나면 파일로 (탭 2)
nmap -p- -T4 --min-rate 2000 -oN nmap-allports.txt $T
# ↑ 끝나면 새로 열린 포트만 -sCV 재스캔:
#   nmap -sCV -p <새포트들> -oN nmap-extra.txt $T

# UDP 상위 (탭 3, 선택)
sudo nmap -sU -T4 --top-ports 100 -oN nmap-udp.txt $T
```
⛔ 스캔 끝나길 앞에 앉아 기다리지 마라. 탭 던져두고 빠른 결과부터 판다.
