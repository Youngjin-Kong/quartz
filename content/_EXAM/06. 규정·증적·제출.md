# 06. 규정·증적·제출

> [!danger] 기술이 돼도 문서 없으면 0점 · 웹셸 플래그도 0점
> 매 단계 스크린샷 + 명령 기록. 플래그는 «대화형 셸»에서 원위치 `cat`/`type`.

## 1. 도구 규정 (출처: OffSec OSCP+ Exam Guide)

| 판정 | 도구 |
|---|---|
| ⛔ 완전 금지 | **sqlmap · commix · NoSQLMap · Tplmap · SQLNinja** (자동 탐지+익스) · Nessus/OpenVAS/NeXpose 등 대량 스캐너 · `db_autopwn`/`browser_autopwn` |
| ⚠️ 1대 한정 | **Metasploit / meterpreter** (전 시험에서 «한 대»만). `msfvenom`·`multi/handler` 는 **전 대상 허용** |
| ✅ 허용 | nmap(+NSE)·rustscan·**AutoRecon**·ffuf·feroxbuster·gobuster·nikto·whatweb·wpscan·hydra·medusa·john·hashcat·netexec·evil-winrm·enum4linux-ng·smbmap·BloodHound·CrackMapExec·searchsploit·공개 PoC |
| 🟡 회색 | Nuclei (회피 권장) |

**판단 기준: 열거를 «도와주면» 허용, 알아서 «뚫어주면» 금지.**
Burp는 **Community만** (Pro 금지).

⚠️ **웹셸로 얻은 플래그 = 0점** — "this includes any type of web-based shell". `?cmd=whoami` 웹셸은 셸 안정화용일 뿐, 플래그는 nc/evil-winrm 대화형 셸에서 읽는다.

## 2. 플래그 증거 — 값만 따지 말고 «한 화면» 저장

셸이 죽으면 재현 불가다. 플래그 잡는 «즉시» 한 명령으로:

```bash
# 리눅스
echo "===$(whoami)@$(hostname)==="; id; ip a | grep inet; date; cat /root/proof.txt 2>/dev/null; cat local.txt
```
```cmd
:: Windows
whoami & hostname & ipconfig | findstr IPv4 & type C:\Users\Administrator\Desktop\proof.txt
```
→ 이 출력 «전체»가 화면에 보이는 상태로 스크린샷. **IP가 프레임에 들어가야 한다.**
⚠️ 7월 실측 실패: 플래그 값 33바이트만 저장해 «대화형 셸에서 얻었다»를 증명 못 한 사례 3연속. 위처럼 통째로 찍는다.

## 3. 스크린샷 — 무엇을 남기나

- 각 타겟 **local.txt · proof.txt (IP 함께 보이게)** — 필수, 이게 없으면 점수 0
- 진입점 화면(로그인·업로드·관리콘솔), 버전 드러난 화면, 익스 성공 직후
- AD: WS·SRV·DC 각 proof.txt + IP

## 4. 제출

- 컨트롤 패널에 각 플래그 제출 (제출해야 점수 인정)
- 보고서: 각 단계 명령을 **copy/paste 재현 가능**하게, 익스 링크/사본, 수정한 부분 명시
- AD는 **전체 도메인 장악 경로**를 한 흐름으로

## 5. 배점·합격

| 항목 | 점수 |
|---|---|
| 단독 3대 | 각 20 (local 10 + proof 10) |
| AD 세트 (WS+SRV+DC) | 40 |
| **합격** | **70** |

- 보너스 10점(과제) 폐지됐을 수 있음 — 컨트롤 패널 확인 `[가정]`
- **AD 40 + 단독 2대(40) = 80 → 합격.** AD 먼저 잡는 게 안전. 손절선은 [[00. START]] §4.

## 6. 호스트명 접속 (AD·일부 웹)
```bash
echo "$T dc01.oscp.exam oscp.exam" | sudo tee -a /etc/hosts   # IP 금지 서비스 대비
getent hosts dc01.oscp.exam                                    # 등록 확인
```

## 7. Rabbit hole 신호 (여기 빠지면 시간 날림)
- 온라인 브루트(hydra rockyou)가 «정답처럼» 보이면 → 대개 우리가 못 본 웹 취약점 신호. 웹 다시.
- 커널 익스 여러 개 연속 실패 → 커널이 답이 아님. 열거로 돌아가라(크리덴셜·서비스).
- 같은 익스를 조건 안 맞는데 반복 → 조건(버전·기능 활성) 먼저 확인.
- 5분 넘게 한 명령 출력만 노려봄 → 파일로 저장하고 다음 벡터 (병렬).
- ⚠️ **"막힘 = 다음 무기로 전환"** — 한 벡터에 매달리지 마라. 손절선 [[00. START]] §4.

## 8. 세션·재접속 (셸 죽었을 때)
- 셸 잡으면 «즉시» 안정 셸 확보 + 지속 경로 심기(SSH키·계정·태스크) — 재진입용
- evil-winrm/SSH는 재접속 쉬움. nc 셸은 죽으면 끝 → 안정 셸로 즉시 전환 [[09. 크랙·페이로드·전송]] 5절
- 플래그는 셸 잡은 «즉시» 한 화면으로 저장(2절) — 죽어도 스샷 남음
- 인스턴스 리버트하면 5~7분 대기, IP·플래그 값 바뀜

## 9. 보고서 체크리스트 (제출 전)
```
□ 각 타겟: local.txt + proof.txt 스샷 (IP 프레임 안)
□ 각 단계 명령 copy/paste 재현 가능 (별칭·헬퍼 없이 풀어씀)
□ 익스플로잇: 링크 또는 사본 첨부, 수정한 부분 명시
□ AD: 제공크리덴셜→WS→SRV→DC 전체 경로를 한 흐름으로
□ 스샷에 내 IP(tun0) 또는 타겟 IP 보이게
□ 웹셸 아닌 대화형 셸에서 플래그 읽음 (0점 방지)
□ 컨트롤패널에 플래그 «제출» 완료
```
