## 2. `112\ftp-pdf-추출.txt` — FTP 익명 PDF 추출본

112 의 FTP 익명 로그인으로 받은 **확장자 없는 20자 hex 이름 PDF 5개**를 텍스트 추출해 하나로 합친 것임.
원본 PDF 는 `파일보관\EXAM-old07-112-ftp-<원래해시이름>.pdf` 로 별도 보관함(§4).

⚠️ **추출 도구가 지시와 다름** — Kali 에 `pdftotext`(poppler-utils)가 **설치돼 있지 않아** `pypdf 5.4.0` 으로 대체함.

**5개 전부 mtime 2021-11-25** — 응시자가 받은 시각이 아니라 **박스 이미지 빌드 시각**임.

| `2d5ef5a0f0c9579458c9` | Staedtler Catalogue 2019 | 5 | 3.4MB | 미끼 |
| `4835e976619690ae006e` | Interstat Contents Guide 2014 | 5 | 1.2MB | 미끼 |
| `4e8cce46d6abec9a9d9a` | BIC #MADE Stationery Catalogue 2019 (독일어) | 5 | 1.5MB | 미끼 |

앞 두 개만 PDF `Title` 메타데이터가 살아 있고, 나머지 셋은 본문 1페이지로 판별함.

### ★ 패스워드 목록 위치

- **파일** — `77cfe070405f6ca327a5` (AuditorzRus Annual Report)
- **위치** — 8페이지 중 **5페이지** / 문서 내 표기 `Pg. 03`
- **절** — `Password Audit Findings` → 하위 `Findings` → `Password / Instances` 표 **10행**
- **성격** — 사내 패스워드 감사 결과를 가장한 「자주 쓰인 비밀번호 + 사용 계정 수」 표. 이 10개가 곧 이 박스의 워드리스트임
- **보조 단서** — 같은 문서 **6페이지**(`Pg. 04`, `Notes to Staff` 절)에 패스워드 정책 명시 — **최소 8자 + 숫자 1개 이상**. 위 10개에서 후보를 거르는 조건임
- 문서 **2페이지 목차**에 `Password Audit Findings ___ 3` 으로 항목이 노출돼 있어, 목차만 봐도 어느 파일인지 가려낼 수 있었음

> [!tip] 6장(시행착오) 재료
> 미끼 4개 합계 **7.27MB** vs 실제 재료 **0.43MB** — **제일 작은 파일이 정답**이었음.
