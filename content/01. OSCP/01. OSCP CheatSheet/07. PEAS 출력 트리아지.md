# 07. PEAS 출력 트리아지

> [!important] 이 노트가 있는 이유
> **PEAS 를 돌리는 것과 PEAS 출력을 읽는 것은 다른 작업임.** 2026-07-16 시험에서 winPEAS 를 돌렸고 권한상승 답이 그 출력 안에 평문으로 있었으나 읽지 못한 채 3시간을 다른 벡터에 씀. 도구 선택이 아니라 **출력 소비가 병목이었음.**

## 1. 실측된 실패 — 389KB 가 «한 줄»이었음

`~/OSCP-EXAM/111/a.txt` (2026-07-16 11:21 생성):

```
$ wc -lc a.txt
     0 389469 a.txt        ← 줄바꿈 0개. 389KB 전체가 한 줄
```

따라 나오는 것:

- `grep 패턴 a.txt` 가 **389KB 전체를 출력함** — 한 줄이 통째로 매치라서
- `-A` / `-B` / `-C` 전부 무력화
- 터미널 스크롤로는 읽을 방법이 없음

## 2. 원인 — PowerShell 리버스셸 원라이너가 개행을 지움

문제의 조각 (볼트 치트시트에 실린 그 원라이너임):

```powershell
$Output = try { Invoke-Expression ($Code) 2>&1 } catch { $_ }
$StreamWriter.Write("$Output`n")
```

`$Output` 은 **행 단위 객체 배열**임. 이걸 `"$Output"` 으로 문자열 보간하면 PowerShell 이 `$OFS`(기본값 = 공백 한 칸)로 join 함.

pwsh 실측:

```
$ pwsh -NoProfile -c '$a = @("line1","line2","line3"); Write-Output "AS-STRING:[$a]"'
AS-STRING:[line1 line2 line3]
```

→ **이 셸로 받은 모든 다중행 출력이 한 줄이 됨.** winPEAS 뿐 아니라 `systeminfo`·`net user`·`dir /s` 전부 해당.

## 3. 1순위 대응 — 애초에 뭉개지지 않게 함

**출력이 화면 한 장을 넘으면 읽지 말 것. 타겟에서 파일로 떨어뜨리고 회수할 것.**

```cmd
winPEASx64.exe > C:\Windows\Temp\peas.txt 2>&1
```

회수 경로는 이미 뚫려 있는 것을 재사용함. 2026-07-16 111 의 경우 `C:\Backups` 가 `Everyone [Allow: AllAccess]` 인 **동시에** 익명 접근 가능한 SMB 공유였음 — 그대로 썼으면 개행이 살아 있는 파일을 받을 수 있었음:

```bash
# 타겟
winPEASx64.exe > C:\Backups\peas.txt 2>&1
# Kali
smbclient //192.168.142.111/Backups -N -c 'get peas.txt'
```

대안 — 타겟에서 `curl`/`certutil` 로 Kali 웹서버에 PUT, 또는 base64 후 분할 전송.

## 4. 2순위 대응 — 이미 뭉개졌으면 줄을 복원함

winPEAS 는 섹션 구분자(`╔══════════╣`)와 4칸 이상 공백을 남기므로 그걸 개행으로 되돌림. **아래 두 줄은 실제 a.txt 로 검증됨:**

```bash
# A) 섹션 단위 — 어느 절에 있는지 찾는 용도 (389KB 한 줄 → 453줄)
sed 's/╔══════════╣/\n\n### /g; s/═\{20,\}/\n/g' peas.txt > peas.sec

# B) 최대 분해 — 사용자·그룹 같은 목록을 읽는 용도 (→ 10321줄)
sed 's/╔══════════╣/\n\n### /g; s/  \+/\n/g'      peas.txt > peas.line
```

- **A 는 key:value 절에 강하고 B 는 목록 절에 강함.** 둘 다 만들어 두고 골라 씀
- 둘로도 안 잡히면 창 추출로 감:

```bash
grep -aoP '.{0,200}패턴.{0,400}' peas.txt
```

- ⚠️ **`-a` 를 빼지 말 것.** 뭉개진 PEAS 출력은 grep 이 바이너리로 판정해 `Binary file matches` 만 뱉고 끝냄

## 5. winPEAS grep 배터리 — 실측 적중 수 포함

2026-07-16 `a.txt`(복원본 453줄) 기준 적중 줄 수임.

| 순위 | 패턴 | 적중 | 무엇을 잡나 |
|---|---|---|---|
| 1 | `/rp \|/ru ` | 5 | **schtasks 평문 비번.** 이번 답이 여기 있었음 |
| 2 | `4104` | 5 | PowerShell 스크립트블록 로그 — 명령줄에 박힌 비밀 |
| 3 | `Groups: Administrators` | 5 | 로컬 관리자 명단 = 스프레이 대상 |
| 4 | `Hash:` | 1 | NetNTLMv2 등 크랙 가능 해시 |
| 5 | `AllAccess` · `Everyone \[Allow` | 12 · 7 | 쓰기 가능한 파일·폴더 |
| 6 | `Scheduled Applications` | 1 | 남의 계정으로 도는 태스크의 바이너리 |
| 7 | `Modifiable Services` | 3 | 서비스 오설정 |
| 8 | `AutoLogon\|DefaultPassword` | 3 | 레지스트리 평문 자격증명 |
| 9 | `AlwaysInstallElevated` | 5 | MSI 권한상승 |
| 10 | `Unquoted and Space` | 3 | 따옴표 없는 서비스 경로 |
| 11 | `Se[A-Za-z]+Privilege: .*ENABLED` | 0 | 토큰 권한 — **0건이 곧 답이었음** |
| 12 | `unattend\|sysprep\|Groups.xml\|web.config\|.kdbx\|.ppk` | 1 | 자격증명 파일 |

한 번에 도는 형태:

```bash
for p in '/rp |/ru ' '4104' 'Groups: Administrators' 'Hash:' 'AllAccess' \
         'Scheduled Applications' 'Modifiable Services' 'AutoLogon|DefaultPassword' \
         'AlwaysInstallElevated' 'Unquoted and Space' 'Se[A-Za-z]+Privilege: .*ENABLED'; do
  echo "=== $p"; grep -aiE "$p" peas.sec | cut -c1-300
done
```

> [!warning] 적중 0 은 「패턴 고장」이 아니라 「그 벡터 없음」이라는 **답**임
> 11번이 0건이었던 것은 실제로 juicy 토큰 권한이 없었다는 뜻임. **0건도 노트에 기록할 것** — 「배제했다」와 「끝까지 못 해봤다」를 구분하는 근거가 됨.

> [!warning] 섹션 제목이 같이 잡힘 — 본문을 읽을 것
> 9번 `AlwaysInstallElevated` 5건 중 실제 판정은 `AlwaysInstallElevated isn't available` 였음. **패턴 적중 = 취약이 아님.**

## 6. linPEAS

- **개행 파괴는 PowerShell 원라이너 고유 문제임.** nc·ssh 셸은 개행을 유지하므로 리눅스 쪽은 대개 그냥 grep 됨
- 그래도 파일로 남기는 원칙은 동일: `./linpeas.sh -a > peas.txt 2>&1`
- ANSI 색이 섞이면 제거: `sed -r 's/\x1B\[[0-9;]*[mGKH]//g' peas.txt > peas.plain`
- 앵커 (`/usr/share/peass/linpeas/linpeas.sh` 2025-12 판에서 존재 확인):
  `sudo -l` · `Sudo version` · `SUID` · `Capabilities` · `Cron jobs` · `Writable` · `Interesting GROUP writable` · `Users with console` · `Possible private SSH keys`
- ⛔ **`PE:` 확률 마커는 이 버전에 없음.** 앵커로 쓰면 0건이 나오고 오판함

## 7. 시험장 절차

```
셸 획득
  → PEAS 를 «파일로» 저장          (화면으로 읽지 않음)
  → 회수                            (이미 뚫은 경로 재사용)
  → 줄 복원 (peas.sec / peas.line)
  → 배터리 실행
  → 적중 0건도 기록
```

**PEAS 를 돌렸다는 사실이 아니라 «배터리를 끝까지 돌렸는가» 가 체크 항목임.** → [[06. 시험 중 진짜 막혔을 때]]

⚠️ winPEAS·linPEAS 는 열거 전용이라 **시험에서 허용됨.** 금지 도구는 `sqlmap`·대량 취약점 스캐너 계열임.
