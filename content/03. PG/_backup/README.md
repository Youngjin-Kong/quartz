# 노트 백업 보관소

개작·이관 작업 전의 원본을 여기 모은다. `03. PG\` 본체에 `.bak` 이 섞여 있으면 **노트 목록이 읽히지 않는다** — 실제로 파일 탐색기와 Obsidian 양쪽에서 노트와 백업이 뒤엉켜 보였다(2026-08-20 사용자 지적).

## 규칙

- **파일명은 `<노트>.md.bak` 형태를 유지한다.** 어느 노트의 백업인지 이름만으로 알 수 있어야 한다. 작업 종류를 구분해야 하면 `<노트>.md.bak-<작업>` 으로 접미사를 붙인다.
- **작업 «전»에 여기로 복사한다.** 고치고 나서 만드는 백업은 백업이 아니다.
- **되살릴 때는** `_backup\<노트>.md.bak` 을 원위치로 복사한다.

## 언제 지워도 되는가

git 에 원본이 커밋돼 있으면 이 파일들은 **중복이다.** 커밋이 끝난 뒤에는 정리해도 된다.
반대로 **커밋 전에는 지우지 마라** — 개작 중인 노트의 유일한 원본일 수 있다.
