## 판정법 ② 손실 — 통과 (인과·수치·유보 전량 생존)

### 인과가 사라질 뻔한 문장 (실례)

**(1) §6 80 헛짚음 — 「~니 …줄 알고」**

```
전: FlaskBB 정적 자산이 뜨니 웹앱이 살아 있는 줄 알고 라우트·vhost·gobuster 를 돌렸다.
    동적 경로가 전부 6461 B 짜리 동일 404 였던 게 신호였다
후: FlaskBB 정적 자산이 뜨니 웹앱이 살아 있는 줄 알고 라우트·vhost·gobuster 를 돌림.
    동적 경로가 전부 6461 B 짜리 동일 404 였던 것이 신호
```
개조식의 자연스러운 유혹은 「FlaskBB 정적 자산 오인 → 라우트·vhost·gobuster 헛돌림」이었다.
그러면 **왜 오인했는지(정적 자산이 떴다)** 가 통째로 사라져 6장이 「무엇을 했다」 목록이 된다. 종결만 바꾸고 절 구조는 손대지 않았다.

**(2) §6 SMB — 「~로 보여 …기대했지만」**

```
전: `backups` 공유 DACL 이 Everyone-full 로 보여 쓰기를 기대했지만 PUT 은 `ACCESS_DENIED`.
    …트래버설도 `NO_SUCH_FILE`/`OBJECT_NAME_NOT_FOUND` 로 막혔다.
후: `backups` 공유 DACL 이 Everyone-full 로 보여 쓰기를 기대했으나 PUT 은 `ACCESS_DENIED`.
    …트래버설도 `NO_SUCH_FILE`/`OBJECT_NAME_NOT_FOUND` 로 막힘.
```
「DACL Everyone-full. PUT `ACCESS_DENIED`.」로 줄이면 **기대와 결과의 어긋남**이 사라지고, 그 어긋남이 바로 이 항목의 교훈이다.

**(3) §3 재실측 — 4단 인과 사슬**

```
전: `$` → `:` 치환으로 `curl …/UID:(id -u)` 가 되어 셸이 `(` 에서 죽으면
    curl 자체가 실행되지 않으므로 회신이 없는 것이 예상된 결과다.
후: `$` → `:` 치환으로 `curl …/UID:(id -u)` 가 되어 셸이 `(` 에서 죽으면
    curl 자체가 실행되지 않으므로 무회신은 예상된 결과.
```
치환→구문오류→미실행→무회신 4단이 전부 살아 있다. 마지막 명사구만 압축(`회신이 없는 것이`→`무회신은`).

### 6장 「~해서 실패함」의 「~해서」 — 전건 생존

표준이 ⛔ 로 지목한 지점. 6장의 인과 접속 전수 확인:

- `guest 계정 비활성으로 Access denied` — 무변경
- `SMB1 workgroup 리스팅 → NT_STATUS_IO_TIMEOUT(139 필터)` — 무변경
- `enum4linux-ng 는 닫힌 포트에서 오래 물고 늘어지니 타임아웃을 짧게 잡을 것` — 무변경
- `|` 가 `:` 로 바뀌**니** … 못 쓰고 → 바뀌**어** … 못 쓰고 (접속 유지, 어미만 조정)
- `문자 제약을 "필터링"으로 알고 있으면 … 오독하고 … 시간을 쓰게 된다` → `…쓰게 됨` (조건절 무변경, 84초 수치 유지)

### 유보(`[가정]`) 처리

9건 전부 마커 그대로. 주변 문장만 종결 전환했고, 유보의 **범위**를 좁히지 않았다. 예:
```
전: [가정] 그래도 "아웃바운드 80-only" 를 단정할 수는 없다. tun0 캡처는 …구분하지 못한다.
    확실한 것은 관측된 회선이 전부 80이라는 것뿐이다.
후: [가정] 그래도 "아웃바운드 80-only" 단정은 불가. tun0 캡처는 …구분하지 못함.
    확실한 것은 관측된 회선이 전부 80이라는 것뿐.
```

## 기계 치환으로 안 되는 지점 (자동화 판정의 근거)

| 유형 | 실례 | 왜 사람 판단이 필요한가 |
|---|---|---|
| 어미 접미가 비문 | `동시에 못 문다` → ✗`못 뭄` / ✅`물 수 없음` | 「물다」류는 명사형이 어색해 **어휘 교체**가 필요 |
| `~했다` 의 목적지가 셋 | `확인했다`→`확인` · `없었다`→`없었음` · `돌렸다`→`돌림` | 상(相)에 따라 갈린다. 일괄 규칙 없음 |
| 인용문 내부 | `"리버스셸이 안 온다"` | 인용은 대상이 아니다 |
| 노트 간 공유 라벨 | `"응답이 성공을 뜻하지 않는다" 패턴` | 한 노트만 고치면 4개 노트와 어긋난다 |
| 관형형 오탐 | `안 태운다는 뜻` | `다`로 끝나지만 종결이 아니다 |
| 헤더 | `### 1-2 … 주지 않는다` | 「문단」만 도는 스크립트는 못 잡는다 |
| 대비 구문 소실 위험 | `사라지는 게 아니라 :로 바뀐다는 것이다` | 「A가 아니라 B」를 「B」로 줄이면 §2 논지가 붕괴 |

→ **펜스 배제만 기계화 가능. 산문 전환은 문장 단위 판단.**
