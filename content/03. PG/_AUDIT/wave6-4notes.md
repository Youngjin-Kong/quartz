## 2. 관리자 교차검증 — 부하 보고 중 직접 되짚은 것

### 2-1. Wheels 의 타겟 pty 프롬프트 제거 (되돌릴 수 없는 판정이라 최우선 확인)

작성자가 `bob@wheels:~$` 4곳을 **제거**했다. `CLAUDE.md` §3 이 「감사자가 규칙을 거꾸로 적용해 타겟 pty 프롬프트를 지운 사고」를 명시하므로 관리자가 직접 재확인:

- `~/PG/Wheels/` 의 `pwn.sh`·`finish.sh`·`collect.sh`·`xml.sh` **네 스크립트 전부** `sshpass -p $P ssh -o StrictHostKeyChecking=no ... bob@192.168.248.202` **비대화형**
- pty·tmux 캡처 파일 **0건**
- `~/.zsh_history` 에 해당 타겟 문자열 **0건**

→ **제거가 옳다.** 그 프롬프트는 화면에 뜬 적이 없다.

### 2-2. 같은 검사를 Assignment 에 적용한 결과는 «정반대»였다

감사자가 차등 확인해 **10개 전부 실측 확정**: `proof_*.txt` 에 프롬프트 + **pty 로컬 에코 중복**이 남아 있고, `harvest_jane.txt` PROCS 에 `git-receive-pack .../pgtest.git` → 자손 `python3 -c import pty;pty.spawn("/bin/bash")` 가 찍혀 있다. **초고가 지웠던 에코 중복을 오히려 복원했다.**

두 박스가 정반대라는 것이 요점 — **「타겟 프롬프트」를 일괄 규칙으로 처리하면 반드시 한쪽을 틀린다.** 박스마다 접근 형태를 확인해야 한다.

### 2-3. Assignment 의 `---` 4개

관리자 지시가 「불필요하면 제거 가능」이라 했으나 작성자가 반증. 확인 결과 **265·389행은 코드펜스 «안»의 `echo ---` 실측 출력 구분자**, 나머지 2개는 frontmatter. 제거했으면 실측 파괴였다.

### 2-4. Fractal 의 삭제 1건

관리자 규율상 삭제가 일어나면 표본을 되짚는다. 감사 파일 38–45행에 **원문 전문이 인용 보존**돼 있고, 삭제 대상은 `sudo -i    → root@fractal:~#` — `→` 는 작성자 표기이고 실제 세션 출력은 같은 절 `proof_root.txt` 블록에 원문으로 이미 존재. **정보 손실 0.** 타당.

## 4. 감사자가 새로 잡은 것 — `_PLAYBOOK` 에 반영 완료

관리자가 이관을 마친 «뒤에» 감사에서 나온 정정이라, `_PLAYBOOK` 쪽을 관리자가 되돌아가 고쳤다.

1. **A-22 등급 과잉** — 「동시성 40→48 인데 938→215/min 으로 떨어진 것이 bcrypt 의 **직접 증거**」. 두 수치는 동시 워커가 아니라 **시각이 겹치지 않는 별개 run**(admin 03:05:47, bob 03:18:25). 통제된 비교가 아니므로 **「신호」로 강등 + `[가정]` 표시**.
2. **A-45 · B-22 의 원인 추정이 반증됨** — Gogs 0.12.9 에 **`ENABLE_GIT_HOOKS` 키 자체가 없다.** 훅 게이트는 설정을 안 보고 `CanEditGitHook() = u.IsAdmin || u.AllowGitHook` 뿐(v0.12.9 태그 직접 조회 — `internal/db/user.go:174-177` · `internal/context/repo.go:455-462` · `internal/cmd/web.go:448-452`). 「믿지 말 것」이라는 결론은 유지하되 「섹션 배치 오류」 추정을 삭제하고 **「설정 파일의 키가 그 소프트웨어가 «읽는» 키라는 보장이 없다」**는 더 강한 일반화로 교체.
3. **이관 누락 1건** — 「포털 브리핑이 포트 80 을 통째로 빠뜨렸다」가 `_PLAYBOOK` 에 없었음. **A-11 에 추가 완료.**
4. **Fractal PwnKit 판정이 거꾸로였음** — `.bak` 이 `policykit-1 0.105-26ubuntu1.3` 을 CVE-2021-4034 대상으로 적었으나 Ubuntu 20.04 수정판이 `0.105-26ubuntu1.2`(USN-5252-1)라 **이미 패치된 버전**. 볼트 내 [[Exghost]] 가 같은 기준을 독립적으로 쓰고 있어 교차 확인됨. 노트에서 정정.
