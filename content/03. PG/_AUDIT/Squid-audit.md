# Squid.md 적대적 검증 + 정정

대상: `03. PG\Squid.md`(개작본 387행) · 원문 `03. PG\_backup\Squid.md.bak`(1062행) · 제안서 `03. PG\_AUDIT\Squid-playbook.md`
결과: **387행 → 428행**. 정정 18건 · 이관 손실 3건 · 반증 5건.

## 근거 출처

- Kali 산출물 `~/PG/Squid/` 전량 — `nmap.log`·`full_tcp.nmap`·`pscan.sh`·`psweep.sh`·`proxyscan.txt`·`gobuster8080.txt`·`pma.py`·`sh.php`·`web.sh`·`revgen.py`·`revgen4444.py`·`mkbat.py`·`srv/{go.bat, FullPowers.exe, PrintSpoofer64.exe}`·`spose/`
- `~/.zsh_history` — `192.168.248.189`·`3128` 검색 **0건**(초기 지시의 "Squid 문자열 0건"을 IP·포트로 재검색해 확인)
- git: `03. PG/Squid.md` 는 `efe8cef` 에서 신규 생성 — **개작 전 baseline 없음**
- 1차 사료: squid 7.6-2 데비안 패키지 기본 `squid.conf`(Kali 에서 추출·확인 후 삭제) — `http_access deny to_localhost` 가 **활성 상태로 출하**되며 주석에 사유가 적혀 있음
- 직접 실행: hex 리터럴 디코드 → `sh.php` MD5 대조 · `proxyscan.txt` 403 집계

## 이관 손실 3건 (제안서에 보충)

제안서는 「이관 손실 0」이라 신고했으나 노트·제안서 양쪽에 없는 실측이 3건 있었다. `Squid-playbook.md` 에 반영함.

1. **구 §6④ MariaDB 3307** — 「설정은 의도이지 현실이 아니다」 → 제안 12(B-2-12 병합) 신설. 노트에도 한 줄 복원
2. **구 §6⑩ SMB/RPC 버린 경로** — 릴레이 무용·익명 열거 차단·동적 RPC 부산물 3행 판단표 → 제안 13(A-2-27 병합) 신설
3. **구 §2-2 503 판별 3가지** — `The system returned:` errno · 응답 지연 · `ERR_READ_TIMEOUT`=열림 → 제안 1 본문에 추가

## 반증한 것 (지적으로 올랐다가 뒤집힌 것 · 작성자 주장 중 깨진 것)

1. **작성자 「nmap raw 바이트 동일을 diff 로 확인」** — 행 단위로는 맞으나 `Not shown:` 행 누락 + 무표시 생략 + 후행 공백 소실이 있었음. **부분 반증**
2. **작성자 「이관 손실 0」** — 위 3건. **반증됨**
3. **작성자 「신규 3 · 병합 8」** — 세어 보면 신규는 제안 1·11 **2건**. `_PLAYBOOK` `### B-7` 절에 B-71 하나뿐임을 확인해 **제안 1 의 신규 판정 자체는 유지**(지시 ⓗ 의 「기존이 있으면 병합으로 고쳐라」는 여기서 해당 없음)
4. **작성자 「certutil 절대경로 필요가 진짜 원인」** — 산출물은 파일명 변경과 절대경로 지정이 **동시에** 일어났음만 보여줌. AV 이론의 반증은 유효하나 새 원인은 `[가정]` 등급. **오귀인의 방향만 바뀐 것**
5. **내 지적 「zsh_history 근거 부족이므로 프롬프트를 지우지 마라(레거시 보호)」 → 자기 반증** — Squid 는 레거시가 아님. ① `Squid.md` 가 `efe8cef` 에서 신규 생성돼 인간 작업 baseline 이 없고 ② IP·포트로 재검색해도 히스토리 0건이며 ③ `nmap.log` 가 `root` 소유(비대화형 `sudo ssh` 호출)임. **제거가 옳음**으로 결론
6. **내 지적 「MariaDB 3307 미기동은 부재 증거라 못 쓴다」 → 자기 반증** — `pscan.sh`/`psweep.sh` 가 503·000 을 **명시적으로 걸러내는** 스크립트이므로 부재는 「스캔 안 함」이 아니라 「503 을 받았음」의 양성 함의임. 사용 가능
