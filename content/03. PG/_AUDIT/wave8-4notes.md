## 3. 부하 보고 중 깨진 것 / 되짚은 것

- **관리자 지시가 틀린 것 1건** — Mice 프롬프트에 「`shell443.log` 가 `~/PG/Mice/` 목록에 없다」고 적어 감사자에게 강등을 유도했음. 실물은 **430,595B · 7,868행으로 존재**. 원인은 관리자가 `ls | head -40` 으로 잘린 목록을 확정 사실로 박은 것. 감사자가 이를 반증하고 강등하지 않아 오판이 노트에 반영되지 않음. **프롬프트에 산출물 목록을 박을 때 절단 여부를 확인할 것.**
- **관리자 지시가 과했던 것 1건** — Wombo 「익스플로잇 5분」 mtime 불일치를 「반증」으로 지목했으나, 감사자가 **`근거부족`이 정확**임을 보였다: 35분 3초는 «첫 시도→플래그 벽시계»이고 원문 「5분」은 «익스플로잇 단계 소요»라 같은 것을 재고 있지 않음. 타임존도 문제없었음(같은 KST 축, HTTP `Date:` GMT 가 +9 로 일치).
- **작성자 초고 오류 2건을 감사가 정정** — Mice 「서비스 바이너리 ACL 은 `SYSTEM:(I)(F)` 뿐」(실제 ACE 4개, `BUILTIN\Users:(I)(RX)` 존재) · CVE `export` 없는 대입 형태 단정(새 창작이라 삭제).
- **작성자 자기반증은 대체로 진짜였다** — CVE 3건 전량, Graph 3건 전량, Mice 4건 중 다수. Graph rockyou 승격(`[가정]`→확정)은 감사자가 산술을 Kali 에서 재검산해 정당성 확인.
- **감사가 노트를 되살린 것** — Graph 이관 손실 1건 복원(앱 소스 프로빙 404 + Express 배너 인과), Wombo 설명 없는 소실 2줄 복원.
- **감사가 «지시»를 반증한 것** — Mice CVE-2021-35448 의 `It binds to local ports…` 인용문이 NVD 렌더에 없어 날조로 의심됐으나 **MITRE 원본 `descriptions` 에 실재** — 노트가 옳았음.
