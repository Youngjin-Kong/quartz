## 3. 반증한 것 — 지적으로 올렸다가 확인 결과 노트가 옳았던 것

1. **`-p` 메커니즘 서술** — 「bash/dash 는 `euid ≠ uid` 를 감지하면 `setuid(getuid())` 로 특권을 되돌리고 `-p` 가 그것을 건너뛴다」를 반증하려 **Kali 에서 직접 SUID 셸을 만들어 실행**했다. 결과가 노트와 정확히 일치했다(nosuid 인 `/tmp` 를 피해 `/var/tmp` 에서 재실행):

   ```text
   dash (no -p): euid=1000 ruid=1000      dash -p: euid=0 ruid=1000
   bash (no -p): euid=1000 ruid=1000      bash -p: euid=0 ruid=1000
   ```
   → **노트가 옳다.** 첫 실행이 `/tmp`(`nosuid`)라 전부 1000 으로 나왔고 하마터면 「노트가 틀렸다」로 갈 뻔했다.

2. **`git hash-object` 값 3개** — `47fe3ffb…` / `f7923106…` / `37706b14…` 를 Kali 에서 재계산했고 `tree_1.10.6.json`·`tree_1.10.7.json` 의 blob·size 와도 전부 일치했다. 파일 크기(271946 / 515478 / 9800)까지 맞다.

3. **`err500.html` 스택 프레임 15개 + `Undefined index: path`** — 노트가 실은 `grep -oE … | sort -u` 를 그대로 돌린 결과가 **한 줄도 다르지 않았다.**

4. **`installed.json` = 51개 패키지 / 126903바이트** · **`admin.html` 의 nonce `93d260b5a6f8507c947d6124d1dd158f`** — 전부 실물과 일치.

5. **Grav 1.7.8 릴리스 태그 커밋 `2021-03-17T17:44:48Z`** — GitHub API `created_at` 과 정확히 일치(`published_at` 은 17:45:16Z 로 다르다. 직전판이 남긴 「published_at 에 속을 뻔했다」 교훈대로 개작본이 올바른 쪽을 골랐다).

6. **레거시 Kali 프롬프트 보존 3건** — `searchsploit grav` 는 스크린샷 `20260615134012.png` 이 프롬프트째 찍혀 있어 **실측 확정**이다. 제거 대상이 아니다. 직전판에 있던 `searchsploit grav cms`(히스토리·스크린샷 모두 `grav`)를 개작이 원문으로 되돌린 것도 옳다.
