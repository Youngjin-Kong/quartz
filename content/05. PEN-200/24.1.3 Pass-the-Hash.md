# 24.1.3 Pass-the-Hash

> **Pass the Hash** · PEN-200 §24.1.3

Pass-the-Hash(PtH)는 평문 비밀번호 대신 **사용자의 NTLM 해시 자체로 원격 시스템·서비스에 인증**하는 기법임. MITRE 에서는 Use Alternate Authentication Material 아래 하위 기법으로 분류됨.

⚠️ **NTLM 인증을 쓰는 대상에만 통함. Kerberos 인증 대상에는 안 통함** — 여기서 막히면 다음 절의 Overpass-the-Hash 로 넘어가는 것이 정석 흐름임.

구현 도구는 여럿임 — Metasploit 의 PsExec, Passing-the-hash toolkit, Impacket. 내부 동작은 대체로 같음 —

- SMB 로 대상에 접속해 NTLM 해시로 인증
- 코드 실행이 필요하면 **Service Control Manager API** 로 Windows 서비스(예: `cmd.exe`·PowerShell)를 띄우고 **Named Pipe** 로 통신
- 반대로 SMB 공유 접근처럼 코드 실행이 필요 없는 용도라면 서비스 생성 단계는 아예 없음

전제는 PsExec 과 사실상 같음 — **SMB 연결(보통 445)**, **File and Printer Sharing** 활성화, **`ADMIN$` 공유** 접근. 마지막 항목 탓에 결국 **로컬 관리자 권한이 필요**함. 앞의 둘은 기업 내부망의 흔한 기본값임.

여기서 취약한 것은 NTLM 프로토콜 자체가 아님 — PtH 는 해시를 **정상적인 방식대로** 쓰고 있음. 문제는 로컬 관리자의 해시를 우리가 손에 넣었다는 사실 쪽에 있음.

Impacket 의 `wmiexec` 로 Kali 에서 바로 시도하는 예 — `-hashes` 에 `:NT해시` 형식으로 넣고 `사용자@대상IP` 를 지정함.

```bash
kali@kali:~$ /usr/bin/impacket-wmiexec -hashes :2892D26CDF84D7A70E2EB3B9F05C425E
Administrator@192.168.50.73
Impacket v0.10.0 - Copyright 2022 SecureAuth Corporation
[*] SMBv3.0 dialect used
[!] Launching semi-interactive shell - Careful what you execute
[!] Press help for extra shell commands
C:\>hostname
FILES04
C:\>whoami
files04\administrator
```

대상이 초기 침투 호스트를 통해서만 닿는 곳에 있다면, 앞 모듈의 피벗·프록시를 얹어 같은 공격을 그대로 돌릴 수 있음.

⚠️ **적용 대상의 경계** — AD 도메인 계정과 **빌트인 로컬 Administrator** 계정에는 통하지만, **2014년 보안 업데이트 이후 그 외 로컬 관리자 계정으로는 인증할 수 없음.** 로컬 관리자 해시를 여러 개 확보했는데 안 붙는다면 이 제한을 먼저 의심할 것.
