# 6.2.2 Google 해킹

> **Google Hacking** · PEN-200 §6.2.2

「Google Hacking」은 2001년 Johnny Long 이 강연과 저서 *Google Hacking for Penetration Testers* 로 널리 퍼뜨린 용어임. 검색 엔진으로 중요 정보·취약점·오설정된 웹사이트를 찾아내는 기법이고, 핵심은 검색 문자열과 연산자를 조합해 질의를 다듬는 것임. 대부분의 연산자가 여러 검색 엔진에서 통함. 과정은 반복적임 — 넓게 시작해 연산자로 무관한 결과를 걸러내며 좁힘.

주요 연산자:

- `site:` — 검색을 한 도메인으로 한정. 조직의 웹 노출 범위를 개괄하는 데 씀
- `filetype:` (또는 `ext:`) — 지정한 파일 형식으로 한정. `site:megacorpone.com filetype:txt` 처럼 조합함. `ext:php`·`ext:xml`·`ext:py` 로 사이트가 쓰는 프로그래밍 언어를 짐작할 수도 있음
- `-` — 항목을 검색에서 제외. `site:megacorpone.com -filetype:html` 은 도메인과 서브도메인으로 좁히되 HTML 페이지를 빼서 비 HTML 페이지만 남김
- `intitle:` — 제목에 특정 문자열이 든 페이지. `intitle:"index of" "parent directory"` 는 제목에 「index of」가 있고 본문에 「parent directory」가 있는 페이지를 찾음

`filetype:txt` 조합으로 나온 robots.txt 의 내용:

```
User-agent: *
Allow: /
Allow: /nanites.php
```

robots.txt 는 검색 엔진 크롤러에게 특정 자원의 수집을 허용·차단하도록 지시하는 파일임. 여기서는 정책상 허용으로 적혀 있으면서도 일반 검색에는 잡히지 않던 PHP 페이지 하나가 드러남 — 숨겨진 경로를 알려주는 단서임.

`intitle:"index of" "parent directory"` 로는 인덱스 페이지가 없어 디렉터리 내용을 그대로 나열하는 디렉터리 리스팅 페이지가 나옴. 이런 오설정은 흥미로운 파일과 민감 정보를 노출함.

![[PEN200-Fig-020.png]]

*디렉터리 리스팅이 노출된 검색 결과 — 인덱스 페이지가 없어 파일 목록이 그대로 보임*

연산자를 조합한 검색어는 Google Hacking Database(GHDB)에 대량으로 정리돼 있음. DorkSearch 포털도 미리 만들어 둔 질의 묶음과 빌더 도구를 제공함.

![[PEN200-Fig-021.png]]

*Google Hacking Database(GHDB) — 조합된 검색어를 모아 둔 저장소*

연산자 숙달과 추론 감각이 검색 엔진 「해킹」의 핵심 역량임.
