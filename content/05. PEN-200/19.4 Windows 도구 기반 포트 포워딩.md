# 19.4 Windows 도구 기반 포트 포워딩

> **Port Forwarding with Windows Tools** · PEN-200 §19.4

학습 목표 — ssh.exe 와 Plink 로 Windows 에서 포트 포워드 만들기, Netsh 를 이용한 포트 포워딩 이해.

지금까지는 Linux 도구 기준이었으나, 큰 네트워크에서는 Windows 호스트를 거쳐 포워딩해야 하는 상황이 흔함.
