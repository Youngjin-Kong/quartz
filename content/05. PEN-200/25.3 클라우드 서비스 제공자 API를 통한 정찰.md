# 25.3 클라우드 서비스 제공자 API를 통한 정찰

> **Reconnaissance via Cloud Service Provider’s API** · PEN-200 §25.3

학습 목표는 셋 — 공개 공유된 리소스에서 정보 얻기, 공개 S3 버킷에서 계정 ID 얻기, 타 계정의 IAM 사용자 열거.

퍼블릭 CSP 는 고객에게 최소 두 접점을 줌 — 자격 증명(사용자명·비밀번호·MFA)으로 보호되는 웹 포털, 그리고 프로그래밍 방식 연동용 API. **API 는 공개돼 있지만 상호작용에는 인증이 필요함.**

공격자 수법의 전제가 여기서 나옴 — 대상의 자격 증명이 없어도 **CSP 에 자기 계정을 만들어** API 호출용 키를 받으면, 그것으로 대상의 내부 정보(사용자·역할)를 캘 수 있음.
