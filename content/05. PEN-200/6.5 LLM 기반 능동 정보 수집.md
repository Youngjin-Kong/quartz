# 6.5 LLM 기반 능동 정보 수집

> **LLM-Powered Active Information Gathering** · PEN-200 §6.5

앞서 수동 정보 수집에서 LLM 의 도움을 다뤘고, 이 유닛은 **능동 열거** 쪽 접근을 다룸. 목표는 대상 도메인 인프라에 관한 결정적 통찰을 더 효율적이고 정확하게 끌어내는 것임.

DNS 열거는 정찰의 기본 기법임 — DNS 서버에 질의해 서브도메인·메일 서버·네임 서버 같은 정보를 뽑아냄. 여기에 LLM 을 끼워 넣으면 **질의 결과를 분석하고, 명명 패턴을 식별하고, 여러 출처의 데이터를 상호 연관**시켜 오설정이나 숨은 자산을 드러낼 수 있음. 존 전송(zone transfer)·역방향 조회·WHOIS 데이터의 분석을 정리하고, 수작업보다 빠르게 실행 가능한 정보로 합성하는 데 씀.

⚠️ 수동 정보 수집 절에서 짚은 한계가 그대로 적용됨 — 복잡한 작업을 단순화하고 놓칠 연결을 짚어 주지만 **출력의 정확성과 관련성은 반드시 검증해야 함.** 능동 정찰에 AI 를 적용할 때 윤리적·법적 경계 안에 머무는 것도 중요함.
