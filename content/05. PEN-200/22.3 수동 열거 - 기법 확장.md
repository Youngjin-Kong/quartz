# 22.3 수동 열거 - 기법 확장

> **Manual Enumeration - Expanding our Repertoire** · PEN-200 §22.3

학습 목표 — 운영체제 열거, 권한과 로그인 사용자 열거, SPN 을 통한 열거, 객체 권한 열거, 도메인 공유 탐색.

LDAP 와 기본 도구를 갖췄으니 도메인을 더 파고들 차례임. 목표는 수집한 정보로 **도메인 지도**를 만드는 것 — 실제로 그림을 그릴 필요는 없으나, 도메인이 어떻게 구성돼 있고 객체끼리 어떻게 연결돼 있는지를 머릿속에 그려두는 것이 중요함. 환경을 시각화하면 잠재적 공격 경로를 찾기가 쉬워지기 때문임.
