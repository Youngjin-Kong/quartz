# 6.2.3 Netcraft

> **Netcraft** · PEN-200 §6.2.3

Netcraft 는 영국 소재 인터넷 서비스 회사로, 무료 웹 포털에서 정보 수집 기능을 제공함 — 사이트가 어떤 기술로 돌아가는지, 같은 IP 넷블록을 공유하는 호스트가 무엇인지 등. **대상과 직접 상호작용하지 않으므로 수동 기법으로 분류됨.**

DNS 검색 페이지에 도메인을 넣으면 서버 목록이 나오고, 각 사이트 URL 옆 파일 아이콘을 누르면 그 서버의 추가 정보와 이력을 담은 「site report」로 들어감. 앞부분은 등록 정보이고, 아래로 내리면 「site technology」 항목이 나옴.

![[PEN200-Fig-024.png]]

*site report 하단의 site technology — 서버가 쓰는 기술 스택이 나열됨*

여기서 얻은 서브도메인과 기술 목록은 이후 능동 정보 수집과 익스플로잇 단계에서 쓰이므로 노트에 남길 것.

⚠️ 2024년 중 Netcraft 는 이 부분의 서비스를 중단하기로 결정함. 같은 정보는 `https://www.wappalyzer.com/lookup/megacorpone.com/` 같은 살아 있는 사이트에서 확인할 수 있음.
