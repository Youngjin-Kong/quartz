# 2.1.4 PWK 랩 접속

> **Connecting to the PWK Lab** · PEN-200 §2.1.4

- 랩과 상당수의 연습문제는 VPN 을 거쳐야 닿으며, 접속마다 학습자 전용 세그먼트가 붙음 — 다만 랩은 적대적 환경으로 간주해 Kali 에 민감 정보를 두지 말 것. **client-to-client 트래픽은 접근 박탈 사유임**.

```
┌──(kali㉿kali)-[~]
└─$
```

```
┌──(ArtVandelay㉿kali)-[~]
└─$
```

```
kali@kali:~$
```

- 절차 — OLP 로그인 → PEN-200 코스 페이지 좌측 Connectivity 의 VPN 다운로드. 받은 `.ovpn` 의 위치를 모르면 `locate` 로 찾되, `locate` 가 참조하는 DB 를 먼저 갱신할 것 — `updatedb` 는 상승된 권한이 필요해 `sudo` 를 붙임:

```
kali@kali:~$ sudo updatedb
[sudo] password for kali:
```

```
kali@kali:~$ locate universal.ovpn
/home/kali/Downloads/universal.ovpn
```

- 찾은 디렉터리로 이동해 `ls` 로 파일 존재를 확인함:

```
kali@kali:~$ cd /home/kali/Downloads
kali@kali:~/Downloads$
```

```
kali@kali:~/Downloads$ ls
universal.ovpn
```

- `Downloads` 는 내용이 자주 바뀌므로 전용 디렉터리를 만들어 옮겨 두는 편이 나음:

```
kali@kali:~/Downloads$ mkdir /home/kali/offsec
kali@kali:~/Downloads$ mv universal.ovpn /home/kali/offsec/universal.ovpn
kali@kali:~/Downloads$ cd ../offsec
kali@kali:~/offsec$
```
