# 22.2.2 PowerShell과 .NET을 이용한 Active Directory 열거

> **Enumerating Active Directory using PowerShell and .NET** · PEN-200 §22.2.2

## 클래스

`Get-ADUser` 같은 PowerShell cmdlet 은 잘 돌지만 **RSAT(Remote Server Administration Tools)의 일부라 도메인 컨트롤러에만 기본 설치됨.** 도메인 클라이언트에 깔려 있는 경우는 드물고 설치하려면 관리자 권한이 필요함. 필요한 DLL 을 직접 import 하는 길도 원리상 있으나, 여기서는 **기본 권한만으로 돌고 실전에서도 유연하게 쓸 수 있는 도구를 직접 만드는** 쪽을 택함. AD 가 평상시 주고받는 질의를 그대로 흉내내는 것이라, 뒤에서 쓸 기성 도구가 내부에서 무엇을 하는지도 같이 이해됨.

AD 열거는 LDAP 에 기댐. 도메인 머신이 프린터 같은 객체를 찾을 때도, 우리가 사용자·그룹 객체를 질의할 때도 통신 채널은 LDAP 임. 즉 **LDAP 은 AD 와 대화하는 프로토콜**이며 AD 전용은 아니고 다른 디렉터리 서비스도 씀.

다만 AD 와의 LDAP 통신이 늘 직관적이지는 않아서, COM 기반 인터페이스 집합인 **ADSI(Active Directory Services Interface)** 를 LDAP 공급자로 삼음. Microsoft 문서상 AD 서비스와 통신하려면 특정 형식의 LDAP ADsPath 가 필요함.

```
LDAP://HostName[:PortNumber][/DistinguishedName]
```

*LDAP 경로 형식 — 호스트명·포트·DN 세 부분*

**HostName** — 컴퓨터명·IP 주소·도메인명 중 아무거나 됨. `corp.com` 을 그대로 넣어도 정보는 나오겠지만, 도메인에 DC 가 여럿이면 그중 아무 DC 의 IP 로 해석될 수 있어 최적이 아님. 열거를 정확히 하려면 **가장 최신 정보를 들고 있는 DC**, 즉 PDC(Primary Domain Controller)를 찾아야 함. PDC 는 도메인당 하나뿐이고, 찾는 방법은 `PdcRoleOwner` 속성을 쥔 DC 를 찾는 것임.

**PortNumber** — 문서상 선택 항목임. SSL 연결 여부에 따라 자동으로 정해지므로 여기서는 넣지 않음. 다만 비표준 포트를 쓰는 도메인을 만나면 스크립트에 직접 넣어야 함.

**DistinguishedName(DN)** — 도메인 자신을 포함해 AD 의 객체를 유일하게 식별하는 이름임. LDAP 이 동작하려면 객체가 정해진 명명 표준을 따라야 하고 DN 이 그 표현임. `stephanie` 사용자 객체의 DN 이라면 대략 아래 형태가 됨.

```
CN=Stephanie,CN=Users,DC=corp,DC=com
```

*Distinguished Name 예시*

`CN` 은 Common Name 으로 도메인 안에서 객체를 가리키는 식별자임. 주의할 점은 **DN 문맥의 `DC` 는 도메인 컨트롤러가 아니라 Domain Component** 라는 것 — LDAP 트리의 최상위를 나타내며 여기서는 도메인 자체의 DN 임. DN 은 **오른쪽에서 왼쪽으로** 읽음: `DC=corp,DC=com` 이 트리의 꼭대기, `CN=Users` 가 그 사용자 객체가 담긴 부모 컨테이너, 맨 왼쪽 `CN=Stephanie` 가 계층 최하단의 객체 자신임.

LDAP 경로에 필요한 것은 Domain Component 부분인 `DC=corp,DC=com` 뿐임. 여기에 `CN=Users` 까지 붙이면 **검색 범위가 그 컨테이너 안으로 갇혀** 손해임.

PDC 호스트명부터 얻음. AD 관련 .NET 클래스는 `System.DirectoryServices.ActiveDirectory` 네임스페이스에 있고 그중 Domain 클래스를 씀 — 속성에 `PdcRoleOwner` 가 있고, 메서드 중 `GetCurrentDomain()` 이 현재 사용자(여기서는 `stephanie`)의 도메인 객체를 반환하기 때문임.

```
PS C:\Users\stephanie>
[System.DirectoryServices.ActiveDirectory.Domain]::GetCurrentDomain()
Forest                  : corp.com
DomainControllers       : {DC1.corp.com}
Children                : {}
DomainMode              : Unknown
DomainModeLevel         : 7
Parent                  :
PdcRoleOwner        : DC1.corp.com
RidRoleOwner            : DC1.corp.com
InfrastructureRoleOwner : DC1.corp.com
Name                    : corp.com
```

*Domain 클래스 호출 결과 — PdcRoleOwner 가 DC1.corp.com 으로 드러남*

호스트명을 스크립트에 그대로 박아도 되지만 다음 평가에서도 재사용하려면 자동으로 뽑아야 함. 한 단계씩 감. 먼저 도메인 객체를 변수에 담고, 스크립트 안에서도 잘 도는지 확인하려고 그 변수를 출력함.

```
# Store the domain object in the $domainObj variable
$domainObj = [System.DirectoryServices.ActiveDirectory.Domain]::GetCurrentDomain()
# Print the variable
$domainObj
```

*1단계 — 도메인 객체를 변수에 저장*

스크립트를 돌리려면 실행 정책(execution policy)을 우회해야 함. 실수로 스크립트를 실행하는 것을 막으려고 있는 장치이며 `powershell -ep bypass` 로 넘김.

```
PS C:\Users\stephanie> powershell -ep bypass
Windows PowerShell
Copyright (C) Microsoft Corporation. All rights reserved.
Install the latest PowerShell for new features and improvements!
https://aka.ms/PSWindows
PS C:\Users\stephanie>
```

스크립트를 실행해 도메인 객체가 그대로 찍히는지 확인함.

```
PS C:\Users\stephanie> .\enumeration.ps1
Forest                  : corp.com
DomainControllers       : {DC1.corp.com}
Children                : {}
DomainMode              : Unknown
DomainModeLevel         : 7
Parent                  :
PdcRoleOwner            : DC1.corp.com
RidRoleOwner            : DC1.corp.com
InfrastructureRoleOwner : DC1.corp.com
Name                    : corp.com
```

*1단계 실행 결과 — `$domainObj` 에 도메인 객체가 담긴 것이 확인됨*

다음은 LDAP 경로에 필요한 `PdcRoleOwner` 의 이름만 뽑는 단계임. 도메인 객체에서 나중에 더 꺼낼 것이 있을 수 있어 `$domainObj` 는 그대로 두고 `$PDC` 변수를 새로 만듦.

```
# Store the domain object in the $domainObj variable
$domainObj = [System.DirectoryServices.ActiveDirectory.Domain]::GetCurrentDomain()
# Store the PdcRoleOwner name to the $PDC variable
$PDC = $domainObj.PdcRoleOwner.Name
# Print the $PDC variable
$PDC
```

*2단계 — PdcRoleOwner 의 name 값을 $PDC 로 추출*

```
PS C:\Users\stephanie> .\enumeration.ps1
DC1.corp.com
```

*Domain 클래스를 통해 PDC 를 동적으로 뽑아낸 결과*

DN 도 도메인 객체에서 얻을 수는 있으나 **LDAP 이 요구하는 명명 표준을 따르지 않음.** `Name` 속성의 `corp.com` 을 쪼개서 `DC=` 를 붙이게 시킬 수도 있지만, ADSI 를 PowerShell 에서 직접 써서 받는 쪽이 쉽고 형식도 확실함. 작은따옴표 두 개는 **AD 계층의 최상위에서 검색을 시작한다**는 뜻임.

```
PS C:\Users\stephanie> ([adsi]'').distinguishedName
DC=corp,DC=com
```

*ADSI 로 도메인의 DN 을 그대로 받아옴*

```
# Store the domain object in the $domainObj variable
$domainObj = [System.DirectoryServices.ActiveDirectory.Domain]::GetCurrentDomain()
# Store the PdcRoleOwner name to the $PDC variable
$PDC = $domainObj.PdcRoleOwner.Name
# Store the Distinguished Name variable into the $DN variable
$DN = ([adsi]'').distinguishedName
# Print the $DN variable
$DN
```

*3단계 — DN 을 담을 $DN 변수 추가*

```
PS C:\Users\stephanie> .\enumeration.ps1
DC=corp,DC=com
```

*스크립트가 출력한 도메인 DN*

이제 호스트명과 DN 을 둘 다 동적으로 얻으므로 조각을 합치기만 하면 됨 — `LDAP://` 접두사에 두 변수를 붙인 `$LDAP = "LDAP://$PDC/$DN"` 한 줄을 더하면 완성임.

```
$PDC =
[System.DirectoryServices.ActiveDirectory.Domain]::GetCurrentDomain().PdcRoleOwner.Nam
e
$DN = ([adsi]'').distinguishedName
$LDAP = "LDAP://$PDC/$DN"
$LDAP
```

*주석을 걷어낸 최종 스크립트 — `$domainObj` 를 거치지 않고 `$PDC` 에 PdcRoleOwner 이름을 바로 담음*

> [!warning] 위 블록은 교재 조판에서 줄이 접혀 있음
> `$PDC =` 다음 줄과 `...PdcRoleOwner.Nam` / `e` 는 원래 이어진 한 줄임. 그대로 옮겨 치면 동작하지 않으므로 접힌 줄을 이어 붙일 것.

```
PS C:\Users\stephanie> .\enumeration.ps1
LDAP://DC1.corp.com/DC=corp,DC=com
```

*완성된 전체 LDAP 경로*

.NET 클래스와 ADSI 로 열거에 필요한 LDAP 경로를 동적으로 얻어냈고, 도메인 이름을 하드코딩하지 않았으므로 다른 환경에도 그대로 가져다 쓸 수 있음.
