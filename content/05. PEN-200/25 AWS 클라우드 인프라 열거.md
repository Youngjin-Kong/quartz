# 25 AWS 클라우드 인프라 열거

> **Enumerating AWS Cloud Infrastructure** · PEN-200 §25

이 모듈이 다루는 학습 단위는 넷임 — 인터넷에 노출된 클라우드 리소스 정찰, 클라우드 서비스 제공자(CSP) API를 통한 정찰, 초기 IAM 정찰, IAM 리소스 열거. 실습 플랫폼은 AWS(Amazon Web Services).

정찰(reconnaissance)은 침투 테스트 방법론과 사이버 킬 체인 양쪽에서 첫 단계임. 대상에 관해 알아낼 수 있는 것을 전부 모아 **공격 표면을 넓히는 것**이 목적이라, 이후 모든 단계의 성패가 여기서 갈림. 그 안에서 열거(enumeration)는 대상 내부의 구성요소와 리소스를 식별·분류·나열하는 작업임.

**이 과정은 재귀적임.** 정찰·열거 도중 취약점을 찾아 환경에 더 깊이 들어가면, 새로 얻은 권한과 이해를 가지고 **새로 드러난 자산에 대해 정찰을 처음부터 다시** 돌려야 함. 한 번 훑고 끝나는 단계가 아님.

모듈의 진행 방향은 바깥 → 안임:

- **외부 관점** — 공개적으로 접근 가능한 것만 분석함. 대상이 클라우드에 리소스를 두고 있는지 판별하고, 밖에서 클라우드 리소스를 열거하는 기법을 익힘
- **내부 관점** — 이미 대상 환경에 접근한 상태를 가정함. CSP API를 통해 안에서 리소스를 나열함

공격 기법을 이해하는 것은 곧 클라우드 환경을 어떻게 방어해야 하는지의 기준이 되기도 함.
