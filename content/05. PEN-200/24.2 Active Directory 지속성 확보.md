# 24.2 Active Directory 지속성 확보

> **Active Directory Persistence** · PEN-200 §24.2

MITRE 는 지속성(persistence)을 **대상 네트워크의 발판을 계속 유지하기 위한** 기법 묶음으로 정의함. 판정 기준은 하나 — **재부팅을 넘기고, 나아가 자격 증명이 변경돼도 접근이 살아남는가.**

AD 환경에서도 일반적인 지속성 수법을 그대로 쓸 수 있지만, **AD 고유의 지속성**도 따로 존재함. 이 단위가 다루는 것 —

- 지속성 기법의 목적
- Golden Ticket 을 이용한 지속성
- Shadow Copy 악용

⚠️ **실무에서는 지속성이 스코프에서 빠지는 경우가 많음** — 평가 종료 후 심어둔 것을 완전히 제거하지 못할 위험 때문임. 계약 범위를 먼저 확인할 것.
