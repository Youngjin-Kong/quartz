# 3.4.5 관리적 분리

> **Administrative Segmentation** · PEN-200 §3.4.5

관리자가 역할과 업무 필요를 이유로 통제를 우회하는 것은 자연스러워 보이나, 위협이 내부에 있거나 공격자가 유효한 관리자 자격 증명을 쥐는 순간 그 구조가 그대로 약점이 됨.

- 대응은 통제를 분리해 «단일 권한자가 모든 통제를 우회하지 못하게» 만드는 것
- 애플리케이션 팀과 관리자 사이에 통제를 쪼개거나, 관리 권한을 여러 관리자에게 나누는 것
- Shamir's Secret Sharing (SSS) 이 후자의 수단임. 인가 요건을 여러 시스템·사람에게 나눠, 관리자 root 접근 한 건에 서로 다른 관리자 인가 3건을 요구하도록 설계할 수 있음 — root 자격 증명을 온전히 가진 사람이 아무도 없게 됨
