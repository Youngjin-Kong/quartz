# 3.6.4 그 밖의 역할

> **Additional Roles** · PEN-200 §3.6.4

사이버보안 분야에는 앞서 다룬 것 말고도 훨씬 많은 역할과 직함이 있음.

**Information Security Officer** — 보안 프로그램의 수장을 가리키는 직함은 CISO·CSO·PSO·ISO 등 여러 가지임. CISO 아래에는 보안 기능 안의 팀을 이끄는 관리 직책이 놓임 — Manager GRC(Governance, Risk & Controls), Manager SOC 등. 전부 **거버넌스 기능**이라 경험 있는 보안 전문가에게 적합함.

**Security Tester** — 직접 침투 테스트를 하는 것 말고도 여러 보안 어슈어런스 역할이 있음. Security Tester 는 통상 개발팀 소속으로, 제품에 보안 테스트 케이스를 돌려 **보안 기능이 문서대로 작동하는지 검증**함. Security Controls Assessor(SCA) 는 감사·컴플라이언스 점검에 앞서 통제의 작동을 확인하고, Common Criteria Security Evaluator 는 벤더 제품이 표방한 보안 기능과 보증 수준을 실제로 충족하는지 평가함.

**Security Assurance Officer** — 검토 대상 시스템에 통제가 존재하고 올바로 작동하는지 검증하는 역할. Security Compliance Officer, Cyber Security Auditor 등으로도 불림. 구체적 예가 PCI Qualified Security Assessor 로, PCI Council 인증을 받아 PCI DSS 기준 평가를 수행할 자격을 갖춘 사람임.

**Security Risk Analyst** — 사이버보안이 근본적으로 위험의 한 전문 영역이라, 어느 보안팀이든 상당 부분을 이 역할이 차지함(Security Risk and Controls Analyst, 넓게는 Cybersecurity Analyst 로도 불림). 사업에 대한 위협과 그것이 사업 활동에 미칠 영향을 이해하는 일이며, **보안 컨설팅 서비스의 핵심 업무 영역**이기도 함.

**Identity Analyst (IAM Security Analyst)** — 조직 내 여러 부서와 함께 접근 통제 이니셔티브를 추진해 내부 정책·규제 준수·업계 표준을 뒷받침함. 포괄 직함인 Cybersecurity Analyst 가 IAM 영역을 함께 맡기도 함.

**Security Assistant** — 어느 보안 프로그램이든 접근 자격 증명·2요소 토큰·출입 카드 발급 같은 기본 행정 프로세스를 포함함. 제품 벤더는 자사 제품의 보안 설정 관리·지원 담당자를 security administrator 로 규정하기도 함. 이런 지원 역할은 보안팀 안에 있을 수도, 자격 증명 발급처럼 IT 등 다른 팀에 배정될 수도 있음.
