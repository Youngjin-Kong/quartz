# 16.4 마무리

> **Wrapping Up** · PEN-200 §16.4

비밀번호 공격은 외부 평가에서는 노출된 네트워크 서비스를 통해 경계를 뚫는 데, 내부 평가에서는 평문 비밀번호를 회수하거나 확보한 해시로 다른 시스템에 붙는 데 쓰임 — 그래서 한 종류가 아니라 여러 갈래를 익혀 둬야 함.

이 모듈이 지나온 순서는 이렇게 됨.

- 네트워크 서비스에 대한 기본 사전 공격(dictionary attack)
- 크래킹 과정과 규칙 기반(rule-based) 공격 — KeePass 데이터베이스와 SSH 개인키에 적용
- NTLM 과 Net-NTLMv2 해시 — 크랙, pass-the-hash, Net-NTLMv2 릴레이로 다른 시스템 확보
- Mimikatz 로 도메인 사용자의 캐시된 해시 덤프, 그리고 Credential Guard 를 비롯한 최신 완화책과 그 우회(평문 비밀번호 회수)

도메인 계정 해시는 여기서는 맛만 봄 — 본격적인 것은 뒤의 Active Directory 모듈이고, 이 절의 내용이 그 전제가 됨.

실무 관점의 요점 하나 — 실제 침투 테스트에서 경계가 뚫리는 경로는 기술적 익스플로잇보다 **클라이언트 사이드 공격이나 비밀번호 공격**인 경우가 많음. 같은 지식이 방어를 설계하는 쪽에서도 그대로 쓰임.
