# 25.6 마무리

> **Wrapping Up** · PEN-200 §25.6

AWS 정찰은 공개된 서비스·리소스와 상호작용해 대상이 어떤 서비스 제공자와 클라우드 리소스를 쓰는지 알아내는 단계임. 외부 계정에서 공개 CSP API 를 악용해 대상 정보를 걷는 예도 다뤘음. 여기서 얻은 정보로 인프라·서비스의 약점을 짚고, 공격 벡터와 사회공학 전술을 대상에 맞춰 조정함.

초기 침해 이후의 정찰은 「확보한 접근 권한의 범위」를 확정하는 데서 시작함. 탈취한 자격 증명으로 인가 수준을 직접 조회할 수 있으면 그것이 최선이지만, 조회 권한조차 없으면 추측에 기대거나 브루트포스로 범위를 훑는 자동 도구를 써야 함 — 탐지를 피하는 것이 목표라면 권장되지 않는 방식임. 이어서 침해 계정에서 IAM 리소스를 추가 열거하며 수동 열거와 자동 열거의 차이를 봤고, 마지막으로 걷은 정보를 분석해 관리자 접근으로 가는 경로를 찾았음.
