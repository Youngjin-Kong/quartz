# 18.4 취약한 시스템 구성 요소

> **Insecure System Components** · PEN-200 §18.4

학습 목표 — SUID 프로그램과 capabilities 악용, 특수 sudo 권한 우회, 시스템 커널의 알려진 취약점 열거 후 악용. 잘못 설정된 시스템 애플리케이션과 권한 역시 권한 상승으로 이어짐.
