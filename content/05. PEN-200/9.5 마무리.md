# 9.5 마무리

> **Wrapping Up** · PEN-200 §9.5

이 모듈에서 다룬 웹 애플리케이션 공격들 — 디렉터리 트래버설로 웹 루트 밖 파일의 내용을 노출, 파일 인클루전으로 내용 노출을 넘어 애플리케이션의 실행 코드에 파일을 끌어들여 실행, 파일 업로드 취약점을 실행 파일과 실행 불가 파일 양쪽으로 악용, 명령어 인젝션으로 하부 시스템 접근.

이 공격들이 값을 하는 지점은 둘임 — **인터넷에 노출된 웹 애플리케이션**에서 터뜨리면 대상 네트워크의 최초 발판이 되고, **내부 웹 서비스**에서 찾으면 측면 이동 경로가 됨.

취약점 자체는 특정 프로그래밍 언어나 웹 프레임워크에 매이지 않지만 **악용 방법은 매임.** 그래서 공략에 들어가기 전에 대상이 쓰는 웹 기술을 짧게라도 파악해 두어야 함.
