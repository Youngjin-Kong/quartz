# 8 웹 애플리케이션 공격 입문

> **Introduction to Web Application Attacks** · PEN-200 §8

학습 단위 — 웹 애플리케이션 진단 방법론 · 웹 애플리케이션 열거 · XSS(Cross-Site Scripting).

프레임워크와 호스팅이 구축·배포를 쉽게 만든 대가로 공격 표면이 넓게 노출됨. 원인 넷 — 다수의 의존성, 안전하지 않은 서버 설정, 성숙하지 못한 애플리케이션 코드, 업무 로직 고유의 결함.

언어·프레임워크마다 고유한 취약점 유형이 생기지만, **흔한 취약점들은 개념이 서로 닮았고 프레임워크 동작도 기저 기술 스택과 무관하게 비슷해서** 유사한 익스플로잇 경로를 그대로 재사용할 수 있음.
