# 3.6.3 사이버보안 진로 - 구축

> **Cybersecurity Career Opportunities: Build** · PEN-200 §3.6.3

생애주기의 **Build 단계**에도 중요한 보안 활동이 있음. 구축 시점에 보안을 설계·구현하는 것이 **가장 효율적인 보안 수행 방식**이기 때문임.

**Enterprise Security Architect (ESA)** — 대규모 조직이 보안팀이나 아키텍처팀에 두는 자리. 사업 활동을 이해하고, 그 사업을 떠받치는 보안 서비스에 보안 솔루션을 연결하는 모델을 만듦. 온프레미스와 클라우드를 깊이 이해하고, 상위 수준의 사업 전략을 짜며 기술 개념을 여러 사업 영역에 걸쳐 전달하는 데 능한 사람에게 맞음.

**Cloud Architect** — 사업 목표·필요에 맞춘 클라우드 컴퓨팅 전략을 설계하고 구현을 감독하는 특화 아키텍처 역할. 클라우드 보안을 포함하거나 그쪽으로 특화하기도 함. CLD-100 이 클라우드 핵심 개념·기술과 안전한 클라우드 구축·보호를 다룸. 프로그래밍과 인프라 구축을 즐기고 클라우드 서비스 제공자 경험이 있는 사람에게 맞음.

**Security Solution Architect (SA)** — 애플리케이션 보안의 상위 아키텍처 솔루션을 만들고, 그것이 전사 보안 아키텍처와 정렬되도록 보장함. 특정 보안·IT 제품에 관여하지 않고, **제품의 보안 요구사항을 규정할 수 있는 일반화된 보안 모델을 만드는 데** 집중함. 가용한 보안 솔루션 유형을 폭넓게 알고 애플리케이션 주도의 보안 모델을 세울 수 있는 사람에게 맞음.

**Security Designer** — 애플리케이션과 IT 인프라의 사이버 방어 구조를 설계·구축하고 많은 경우 유지까지 함. 보안 어슈어런스팀에도 유사 역할이 있으나, 그쪽은 설계를 직접 하지 않고 외부 공급사나 내부 개발팀이 한 보안 설계를 **검토·승인**함. **Cloud Engineer** 는 클라우드 인프라의 설계·구축·유지를 맡는 특화 설계자임.

**Developer** — 컴퓨터 프로그램을 작성하는 역할로, 세부 직무에 따라 운영체제 핵심 구성요소부터 데스크톱·모바일·웹 애플리케이션까지 범위가 걸침. 문제에 대해 우아하고 효율적인 프로그램 해법을 설계하는 것을 즐기는 사람에게 맞음. 소프트웨어 취약점 전반은 PEN-200 에서, 웹 개발 쪽은 WEB 200·300 레벨에서 다루고, C 처럼 **메모리 안전하지 않은 언어**를 쓴다면 EXP-301·EXP-312 가 참고가 됨.

**DevSecOps** — 보안을 개발 생애주기의 마지막으로 미루지 않고 **전 단계에 통합하는** 개발 접근법(Development, Security, Operations). DevSecOps Engineer 는 보안 테스트를 비롯한 보안 프로세스의 자동화를 맡음. CI/CD 파이프라인과 도구를 이해하고, 보안 테스트 자동화에 관심이 있으며, 빠른 환경에서 일할 수 있는 사람에게 맞음. 자동화 대상이 되는 공격 벡터와 자동화 테스트 도구 유형은 WEB·PEN 200·300 레벨에서, DevSecOps 의 필수 도구인 Docker 와 Kubernetes 는 CLD-100 에서 다룸.

**Site Reliability Engineer (SRE)** — 소프트웨어 시스템의 가용성과 성능을 보장하고 개선함. 소프트웨어 개발 경험이 있고 자동화로 신뢰성 문제를 모니터링·알림·대응하는 데 관심 있는 사람에게 맞음. SRE 를 떠받치는 핵심 기술인 컨테이너와 Kubernetes 는 CLD-100 에서 배움.

**System Hardener (System Administrator)** — 시스템을 설정해 보안 위험을 줄이는 역할. 안전하지 않은 기본 설정을 바꾸고, 쓰지 않는 프로그램을 제거하고, 방화벽이 충분히 제한적인지 확인하는 일 등이 포함됨. 시스템 관리 경험이 있고 공격 기법에 익숙하며 시스템과 데이터를 더 안전하게 만드는 것을 즐기는 사람에게 맞음. PEN 트랙 100·200·300 이 필요한 기술 대부분을 다룸 — PEN-100 은 네트워킹·시스템 관리 기초, PEN-200 은 공격자가 쓰는 흔한 기법, PEN-300 은 방어를 우회하는 고급 기법.
