# 27.4 내부 네트워크 열거

> **Enumerating the Internal Network** · PEN-200 §27.4

CLIENTWK1 발판만 있고 로컬 시스템·내부 네트워크 정보가 전무함 → 로컬 열거 후 Active Directory 환경 열거로 넘어감. 목표는 측면 이동(lateral movement) 경로와 권한 상승 벡터의 식별임.
