# 28.2.2 머신 간 의존성

> **Machine Dependencies** · PEN-200 §28.2.2

다른 랩 머신에서 특정 정보를 먼저 모아야만 공략되는 타겟이 있고, 피벗을 거쳐야만 닿는 타겟도 있음. Student Mentor 는 의존성을 알려주지 않음 — 의존성 유무를 판별하는 것 자체가 정보 수집의 일부라 스스로 알아내야 함.

원문이 드는 예시는 이렇다. VANGUARD 라는 머신에 SENTINEL 용 자격 증명이 담긴 파일이 있고 VANGUARD 에는 (의도된) 외부 공격 벡터가 없다면, SENTINEL 을 먼저 침해해야 함. 두 이름은 설명용 가상 머신이라 실제 챌린지 랩에는 없음.

**챌린지 «사이»에는 의존성이 없음.** 챌린지 1 에서 얻은 정보가 챌린지 2~6 의 머신에 쓰이지 않음. OSCP 유사 챌린지(4~6)에서는 도메인 조인 3대와 독립 3대 사이에도, 독립 3대끼리도 의존성이 없음. 따라서 이 챌린지들과 시험은 **격리된 미니 환경 4개** — AD 세트 하나 + 독립 머신 3개 — 로 보는 것이 맞음.
