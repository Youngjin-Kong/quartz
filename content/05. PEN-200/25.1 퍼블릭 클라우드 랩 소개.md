# 25.1 퍼블릭 클라우드 랩 소개

> **About the Public Cloud Labs** · PEN-200 §25.1

이 모듈의 실습은 OffSec Public Cloud Labs 를 씀. 다른 모듈의 VM 랩(VPN 접속 또는 브라우저 내 VM)과 달리 **인터넷을 통해 클라우드 환경에 직접 접속**하는 형태임.

지켜야 할 것 셋:

1. 학습 자료에 기술·요청된 활동 외의 용도로 쓰지 말 것. 모듈 범위 밖 항목을 시험하는 놀이터가 아님
2. **랩 외부의 어떤 자산도 대상으로 삼지 말 것.** 일부 모듈이 취약한 클라우드 배포에 대한 공격을 설명하거나 시연하지만, 그것은 그 배포를 어떻게 보호할지 설명하기 위한 것임
3. OffSec 교육 자료 공유 금지 규정이 그대로 적용됨 — 랩의 자격 증명과 세부 정보는 공유 대상이 아님

OffSec 은 리소스 사용량을 포함해 랩 활동을 모니터링하고, 학습 모듈과 무관한 비정상 이벤트를 감시함. 의심스러운 활동은 조사로 이어지고, 위 가이드라인을 벗어났거나 고의로 남용한 것으로 판정되면 **랩 접근 회수 또는 계정 해지**까지 감.

운영상의 제약:

- **세션 간 진행 상태는 저장되지 않음.** 재시작한 랩은 원래 상태로 돌아감
- 1시간이 지나면 세션이 아직 활성인지 묻고, 응답이 없으면 종료됨. 수동 연장은 최대 10시간까지 가능함

학습 자료 자체가 이 제약을 전제로 설계돼 있어 한 세션 안에 모듈의 모든 활동을 끝낼 필요는 없음. 다만 **이전에 실행한 명령과 조치를 기록해 두면** 다음 세션에서 떠났던 상태로 복원하기 쉬움 — 여러 단계를 요구하는 복잡한 랩일수록 중요함.
