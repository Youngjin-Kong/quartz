# 6.4.5 SMTP 열거

> **SMTP Enumeration** · PEN-200 §6.4.5

취약한 메일 서버도 호스트·네트워크 정보의 출처가 됨. SMTP(Simple Mail Transport Protocol)는 `VRFY`·`EXPN` 같은 명령을 지원하는데, `VRFY` 는 서버에 이메일 주소의 검증을 요청하고 `EXPN` 은 메일링 리스트의 구성원을 요청함. 이를 악용해 **메일 서버에 실재하는 사용자를 확인**할 수 있으며, 침투 테스트에서 값이 큰 정보임.

```
kali@kali:~$ nc -nv 192.168.50.8 25
(UNKNOWN) [192.168.50.8] 25 (smtp) open
220 mail ESMTP Postfix (Ubuntu)
VRFY root
252 2.0.0 root
VRFY idontexist
550 5.1.1 <idontexist>: Recipient address rejected: User unknown in local recipient
table
^C
```

성공과 실패의 응답이 갈리는 것이 요점임. 응답 코드 `252` 는 root 사용자가 실재함을 검증해 주는 것이 아니라, **어떤 메시지든 받아 전달을 시도하겠다**는 뜻임. `550` 은 메일박스를 쓸 수 없다는 뜻임. 이 차이를 이용하면 유효 사용자명 추측을 자동화할 수 있음.

TCP 소켓을 열어 SMTP 서버에 접속하고 주어진 사용자명으로 `VRFY` 를 던지는 Python 스크립트로 자동화함 — 첫 인자에 검사할 사용자명, 둘째 인자에 대상 IP 를 줘서 실행함.

```
#!/usr/bin/python
import socket
import sys
if len(sys.argv) != 3:
        print("Usage: vrfy.py <username> <target_ip>")
        sys.exit(0)
# Create a Socket
s = socket.socket(socket.AF_INET, socket.SOCK_STREAM)
# Connect to the Server
ip = sys.argv[2]
connect = s.connect((ip,25))
# Receive the banner
banner = s.recv(1024)
print(banner)
# VRFY a user
user = (sys.argv[1]).encode()
s.send(b'VRFY ' + user + b'\r\n')
result = s.recv(1024)
print(result)
# Close the socket
s.close()
```

```
kali@kali:~/Desktop$ python3 smtp.py root 192.168.50.8
b'220 mail ESMTP Postfix (Ubuntu)\r\n'
b'252 2.0.0 root\r\n'
kali@kali:~/Desktop$ python3 smtp.py johndoe 192.168.50.8
b'220 mail ESMTP Postfix (Ubuntu)\r\n'
b'550 5.1.1 <johndoe>: Recipient address rejected: User unknown in local recipient
table\r\n'
```

*스크립트 실행 — 실재 사용자(252)와 없는 사용자(550)의 응답이 갈림*

같은 정보를 Windows 11 클라이언트에서도 얻을 수 있음. `Test-NetConnection -Port 25` 로 포트 도달 여부는 확인되지만 **그것만으로는 SMTP 서비스와 온전히 상호작용할 수 없음.** 그래서 Microsoft 판 Telnet 클라이언트를 (아직 없다면) 설치함.

```
PS C:\Users\student> Test-NetConnection -Port 25 192.168.50.8
ComputerName     : 192.168.50.8
RemoteAddress    : 192.168.50.8
RemotePort       : 25
InterfaceAlias   : Ethernet0
SourceAddress    : 192.168.50.152
TcpTestSucceeded : True
```

*25번 포트 도달 확인 — TcpTestSucceeded 만 알려 줌*

```
PS C:\Windows\system32> dism /online /Enable-Feature /FeatureName:TelnetClient
...
```

⚠️ **Telnet 설치에는 관리자 권한이 필요함** — 저권한 사용자로 돌고 있으면 걸림돌이 됨. 우회로는 보유한 다른 개발 머신의 `c:\windows\system32\telnet.exe` 바이너리를 가져다 테스트에 쓰는 Windows 머신으로 옮기는 것임. Telnet 이 준비되면 Kali 에서 하던 열거를 그대로 수행할 수 있음.

```
C:\Windows\system32>telnet 192.168.50.8 25
220 mail ESMTP Postfix (Ubuntu)
VRFY goofy
550 5.1.1 <goofy>: Recipient address rejected: User unknown in local recipient table
VRFY root
252 2.0.0 root
```

Kali 를 쓸 수 없을 때 **침해한 Windows 호스트에서 수행하는 열거**의 또 다른 예임.
