# 11.3.2 정상 웹사이트 복제

> **Cloning a Legitimate Website** · PEN-200 §11.3.2

자격 증명 탈취용 피싱 페이지는 직접 만드는 것보다 **원본을 통째로 복제**하는 쪽이 확실함 — 손으로 그린 화면은 사소한 차이로 들통나지만 복제본은 원본 자산을 그대로 씀. 여기서는 Zoom 로그인 페이지를 대상으로 삼음.

복제는 `wget` 한 줄로 끝남. 자산이 수천 개 쏟아지므로 전용 디렉터리를 만들고 그 안에서 실행할 것.

```
kali@kali:~$ mkdir ZoomSignin
kali@kali:~/ZoomSignin$ cd ZoomSignin
```

| 플래그 | 역할 |
|---|---|
| `-E` | 내려받은 파일의 MIME 타입에 맞게 확장자 교정 |
| `-k` | 문서 안 링크를 로컬 사본을 가리키도록 변환 |
| `-K` | 변환 전 원본을 `.orig` 로 함께 보존 |
| `-p` | 그 페이지를 보이게 하는 데 필요한 파일 전부 |
| `-e robots=off` | `robots.txt` 지시 무시 |
| `-H` | 외부 호스트의 자산까지 따라감 |
| `-Dzoom.us` | 단 `zoom.us` 도메인으로 한정 |
| `-nd` | 디렉터리 구조 없이 현재 위치에 평면 저장 |

`-H` 와 `-D` 는 한 쌍임 — 외부 호스트를 열어주되 도메인으로 묶지 않으면 수집 범위가 무한정 번짐. 이 명령 한 번으로 수천 개 파일이 회수됨.

*회수된 파일 목록 — `-K` 로 남긴 `.orig` 사본과 링크 변환본이 짝으로 보임*

내려받은 것은 `sudo python -m http.server 80` 으로 그 자리에서 서비스해 확인함.

```
kali@kali:~/ZoomSignin$ sudo python -m http.server 80
Serving HTTP on 0.0.0.0 port 80 (http://0.0.0.0:80/) ...
```

*복제본을 80 포트로 서비스*

![[PEN200-Fig-172.png]]

*외부 도메인에서 불러온 스크립트를 탐지한 OWASP CSRFGuard 경고 — 복제본에서만 뜨는 흔적이라 제거 대상임*

브라우저로 열면 두 가지가 먼저 뜸.

- **CSRFGuard 경고** — 외부 호스팅 JavaScript 를 남의 도메인에서 불러와 발생함. 예상된 부작용이고 §11.3.3 에서 제거함
- **쿠키 동의 모달** — 지우면 안 됨. 대다수 사이트가 띄우는 것이라 있는 쪽이 오히려 진짜처럼 보임

경고를 넘기면 원본과 구분되지 않는 화면이 나옴. 다만 가짜 계정으로 Sign In 을 누르면 화면이 회색으로 덮이고 스피너만 무한히 돔.

![[PEN200-Fig-175.png]]
