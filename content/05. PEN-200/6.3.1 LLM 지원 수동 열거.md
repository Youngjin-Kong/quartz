# 6.3.1 LLM 지원 수동 열거

> **Passive LLM-Aided Enumeration** · PEN-200 §6.3.1

이 절은 무료 버전 ChatGPT 로 열거 단계를 어떻게 돕는지 살펴봄. 무료 버전은 GPT-4 접근과 사용량이 제한되지만, 열거 전략을 브레인스토밍하고 계획하는 데는 충분히 쓸 수 있음.

⚠️ **LLM 의 답변은 매번 달라짐** — 목록이 더 짧게 나오는 식임. 원하는 출력이 안 나오면 요청을 반복할 것.

LLM 에 던지는 질의를 프롬프트(prompt)라고 부름. 프롬프트는 모델이 응답을 생성하도록 유도하는 텍스트 입력으로, 서술문·질문·지시·미완성 문장 어느 형태든 될 수 있음. 효과적인 프롬프트의 요건은 **명확성과 구체성** — 필요한 정보가 무엇인지 정확히 밝히고 모호함이 없는 표현을 쓸 것.

**WHOIS 조회.** 먼저 megacorpone 도메인의 whois 정보를 물음.

```
whois megacorpone.com
```

*WHOIS 프롬프트에 대한 응답 — 등록일·등록대행자·등록자 연락처·네임 서버*

응답에서 도메인 등록일·만료일, 등록대행자(Gandi SAS), 등록자 연락처(Alan Grofield, MegaCorpOne, 주소·전화), 네임 서버 3개, 그리고 무단 이전을 막는 `clientTransferProhibited` 상태를 얻음. 연락처 정보는 이후 OSINT 정찰의 실마리가 되고, 네임 서버는 능동 열거의 대상이 됨.

여기서 중요한 점 — 이 프롬프트는 모델이 **자기 학습 데이터에서 꺼내오게 한 것이 아니라 WHOIS 데이터베이스에 직접 질의하도록 지시한 것**임. WHOIS 데이터는 등록대행자·레지스트리가 자주 갱신하기 때문임.

*조직 정보 요청에 대한 응답 — 직책·이메일·소셜 핸들·총 직원 수*

**Google dork 생성.** ChatGPT 는 이용약관 위반 소지 때문에 Google dork 를 **직접 실행하지는 못하지만**, 대상에 맞춘 dork 목록을 즉석에서 만들어 주는 용도로는 매우 유용함.

```
can you provide the best 20 google dorks for megacorpone.com website tailored for a
penetration test?
```

*기술 스택 조회 응답 — 언어·프레임워크·CDN·웹서버·인프라 소프트웨어*

ChatGPT 는 Datanyze·6sense 처럼 Netcraft 와 비슷한 사이트 여러 곳을 조회해 최신 기술 스택을 가져옴. megacorpone.com 의 경우 프로그래밍 언어·프레임워크(jQuery, Bootstrap, Font Awesome, ECMAScript, JavaScript, HTML), CDN(Google Hosted Libraries), 웹·애플리케이션 서버(Apache HTTP Server), 기타 IT 인프라 소프트웨어(GitHub Pages)의 네 범주로 각각 짧은 설명과 함께 반환됨.

수동 정보 수집에서 LLM 이 전통적 도구보다 나은 지점은 **여러 출처의 비정형 데이터를 대규모로 종합**한다는 것임 — 집계가 빠르고, 미묘한 상관관계를 드러내며, 기존 방식이 놓치는 통찰을 보여 정찰이 더 정밀하고 효율적이 됨.
