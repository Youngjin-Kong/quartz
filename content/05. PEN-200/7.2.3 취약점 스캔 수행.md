# 7.2.3 취약점 스캔 수행

> **Performing a Vulnerability Scan** · PEN-200 §7.2.3

- Scans 탭의 New Scan 으로 시작해 Basic Network Scan 템플릿을 고름. 스캔 설정 화면은 BASIC·DISCOVERY·ASSESSMENT·REPORT·ADVANCED 로 나뉨.
- 기본 화면인 General 의 필수 인자는 둘 — 스캔 이름과 대상 목록. 대상 표기는 단일 IP, IP 범위, 쉼표로 구분한 FQDN, IP 목록을 지원함. 예시에서는 이름을 "Basic Vulnerability Scan" 으로, 대상을 POULTRY·JENKINS·WK01·SAMBA 의 IP 로 지정함.
- 템플릿이 대부분을 잡아 주지만 기본값이 늘 맞지는 않음 — 스캔 유형·환경·시간 제약·대상에 따라 조정할 것.
- 포트 한정 — 기본값은 흔한 포트 목록을 스캔함. 80·443 만 보려면 DISCOVERY 설정에서 드롭다운을 Custom 으로 바꿔야 추가 메뉴가 나타나며, 이 상태에서는 Basic Network Scan 을 Advanced Scan 처럼 DISCOVERY 범위에서 손볼 수 있음. Port Scanning 의 Port scan range 를 "80,443" 으로 두고, 나머지를 닫힌 것으로 취급하도록 Consider unscanned ports as closed 를 켬.

![[PEN200-Fig-052.png]]
*Port scan range 를 80,443 으로 한정하는 위치*

- UDP 는 이 템플릿의 기본값에서도 스캔되지 않음. 켜려면 수동 설정이 필요하며, 끈 채로 두면 UDP 서비스의 중요한 정보를 놓칠 수 있음. 다만 켜면 스캔 시간이 크게 늘고, UDP 특성상 열린 포트와 필터된 포트를 구분하기 어려운 경우가 많음.
- 호스트가 살아 있음을 이미 아는 상황이라 시간을 아끼고 조용히 가려고 호스트 발견을 끔 — Discovery > Host Discovery 에서 Ping the remote host 를 Off 로.
- 자격 증명을 넣지 않았으므로 이 스캔은 비인증임. ASSESSMENT 기본값도 그대로 두어 사용자 자격 증명 무차별 대입은 수행되지 않음. 그럼에도 여러 호스트를 대상으로 하는 만큼 트래픽이 많아 눈에 잘 띔.
- 실행은 Save 옆 화살표 → Launch. My Scans 에서 상태가 Running 으로 뜨고 중지·일시정지가 가능하며, 끝나면 Completed 로 바뀜.
