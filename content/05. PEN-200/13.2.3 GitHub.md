# 13.2.3 GitHub

> **GitHub** · PEN-200 §13.2.3

GitHub 은 버전 관리와 협업을 위한 코드 호스팅 플랫폼이라 누구나 코드를 만들고 공유할 수 있고, 익스플로잇도 그중 하나임.

바로 그 개방성이 위험이 됨 — 앞의 두 자료와 달리 **저장소를 누구나 만들어 감시 없이 배포할 수 있음.** 실제로 GitHub 에 올라온 특정 익스플로잇을 실행하면 백도어에 감염된다는 경고가 트윗된 사례가 있었음. 전부가 악성이라는 뜻은 아니지만 전부를 의심하고 다뤄야 함.

반대로 장점은 **속도**임. 새 취약점이 나오면 보안 커뮤니티가 개념 증명(PoC) 코드를 거의 즉시 만들어 공유함.

OffSec 계정에도 저장소가 여럿 있고, 그중 `exploitdb-bin-sploits` 는 미리 컴파일된 익스플로잇을 모아 둔 것이라 바로 실행할 수 있음.
