# 23.1 Active Directory 인증 구조 이해

> **Understanding Active Directory Authentication** · PEN-200 §23.1

- 학습 목표 셋 — NTLM 인증 이해, Kerberos 인증 이해, 캐시된 AD 자격 증명 파악
- AD 는 여러 인증 프로토콜을 지원함 — Windows 외에 Linux·macOS 컴퓨터 인증도 포함
- WDigest 같은 구형 프로토콜은 Windows 7·Server 2008 R2 급에서나 쓸모가 있어 제외함
- 다루는 것은 NTLM·Kerberos 의 동작 상세와, AD 자격 증명이 Windows 에 «어디에 어떻게» 캐시되는가임
