# 26.11 마무리

> **Wrapping Up** · PEN-200 §26.11

이 모듈의 경로를 되짚으면 — 애플리케이션이 잘못 설정된 S3 버킷의 파일을 쓰고 있었고, 그 버킷에서 발견한 git 저장소의 **이력**에 자격 증명이 남아 있었음. 그 자격 증명으로 Git 으로 이동해 파이프라인 정의 파일을 편집할 수 있음을 확인했고, 직접 만든 페이로드로 파이프라인을 오염시켜 시크릿을 탈취함. 한편 OSINT 로 애플리케이션이 **공개 Python 인덱스에 없는 의존성**을 쓴다는 것을 알아내, 그보다 높은 버전을 공개하면 대상이 그것을 내려받을 것이라 가정하고 실행에 옮겨 운영 환경에서 코드 실행을 얻음. 그 실행 권한으로 내부 네트워크를 스캔해 자체 가입이 열린 Jenkins 를 찾았고, 계정을 만들어 취약한 플러그인에서 AWS 키를 얻었으며, 그 키로 접근한 S3 버킷의 Terraform 상태 파일에서 관리자 자격 증명을 찾아 환경 전체를 장악함.

정리(cleanup)도 함께 해 둘 것 — 이 모듈에서 개인 Kali 의 설정을 여럿 바꿨기 때문임.

DNS 부터 되돌림. `nmcli connection modify` 로 해당 연결(여기서는 "Wired connection 1")의 `ipv4.dns` 를 비운 뒤 NetworkManager 를 재시작함. 선호하는 DNS 서버가 있다면 빈 값 대신 그것을 넣을 것.

```
kali@kali:~$ nmcli connection modify "Wired connection 1" ipv4.dns ""
kali@kali:~$ sudo systemctl restart NetworkManager
```

브라우저로 아무 공개 사이트에나 접속해 정상 동작을 확인함.

pip 의 기본 설정을 바꾸려고 만든 `~/.pypirc` 와 `~/.config/pip/pip.conf` 도 지워야 함 — 남겨 두면 이후 작업에서 문제를 일으킴.

```
kali@kali:~$ rm ~/.pypirc
kali@kali:~$ rm ~/.config/pip/pip.conf
```

마지막으로 Firefox 에 넣은 SOCKS 프록시 설정을 해제할 것. 프록시가 닫히므로 그대로 두면 브라우저가 먹통이 됨.
