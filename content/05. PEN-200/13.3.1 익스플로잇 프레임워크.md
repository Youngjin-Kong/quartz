# 13.3.1 익스플로잇 프레임워크

> **Exploit Frameworks** · PEN-200 §13.3.1

익스플로잇 프레임워크는 **신뢰성이 확인된 익스플로잇을 모아 대상에 쉽게 실행할 수 있게 만든 소프트웨어 패키지**임. 익스플로잇 설정 형식이 표준화돼 있고, 온라인·오프라인 양쪽에서 접근할 수 있는 것이 공통 특징임.

- **Metasploit** — 2003 년 H D Moore 가 만들었고 현재 Rapid7 소유. 사전 탑재된 익스플로잇을 소소한 설정만으로 실행할 수 있음. 무료 커뮤니티 에디션과 유료 pro 버전이 있음. 뒤 모듈에서 상세히 다룸
- **Core Impact** — HelpSystems 소유이며 무료판이 없음. 테스트 자동화, 취약점 스캐너 연동, 피싱 캠페인 수행, 그리고 침투 테스트 후 조치가 실제로 됐는지 확인하는 재시험까지 지원함
- **Canvas** — Immunity 제작. 유료이고 구매하면 익스플로잇이 매월 정기 갱신됨
- **BeEF**(Browser Exploitation Framework) — 웹 브라우저 안에서 실행되는 클라이언트 사이드 공격에 특화된 도구
