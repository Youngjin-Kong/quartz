# 25.2.2 도메인과 서브도메인 정찰

> **Domain and Subdomain Reconnaissance** · PEN-200 §25.2.2

공격자 시점에서 아는 것은 도메인 `offseclab.io` 하나임. 여기서 뽑을 수 있는 것 중 클라우드 관련 정보에 집중함.

먼저 해당 도메인의 모든 레코드를 쥔 권한 있는 네임서버를 조회함.

```
kali@kali:~$ host -t ns offseclab.io
offseclab.io name server ns-1536.awsdns-00.co.uk.
offseclab.io name server ns-512.awsdns-00.net.
offseclab.io name server ns-0.awsdns-00.com.
offseclab.io name server ns-1024.awsdns-00.org.
```

*출처: 원문 Listing 930 — offseclab.io 의 NS 레코드*

이름이 노골적이라 AWS 관리 도메인으로 추정됨. **추정을 그대로 두지 말고 검증할 것** — 그 네임서버 도메인의 등록 정보를 `whois` 로 확인하고 조직명 줄만 걸러냄.

```
kali@kali:~$ whois awsdns-00.com | grep "Registrant Organization"
Registrant Organization: Amazon Technologies, Inc.
```

*출처: 원문 Listing 931 — awsdns-00.com 의 등록자 조직*

등록자가 Amazon Technologies, Inc. 이므로 도메인은 AWS 가, 십중팔구 Route53 서비스로 관리함. ⚠️ **다만 이것이 나머지 인프라까지 AWS 라는 뜻은 아님** — 계속 파야 함.

다음은 `www.offseclab.io` 의 공인 IP 를 얻음. ⚠️ 이 값은 랩을 다시 시작할 때마다 바뀜.

```
kali@kali:~$ host www.offseclab.io
www.offseclab.io has address 52.70.117.69
```

그 IP 를 역방향 조회하고, `whois` 로는 `OrgName` 값을 봄.

```
kali@kali:~$ host 52.70.117.69
69.117.70.52.in-addr.arpa domain name pointer ec2-52-70-117-69.compute-1.amazonaws.com
kali@kali:~$ whois 52.70.117.69 | grep "OrgName"
OrgName:        Amazon Technologies Inc.
```

*출처: 원문 Listing 933 — 공인 IP 의 역방향 조회와 등록 정보*

여기서 두 가지가 드러남 — 응답의 `amazonaws.com` 이 AWS 호스팅임을 말하고, `ec2-...compute-1` 형태가 그 리소스가 **EC2 인스턴스**임을 말함. `whois` 의 `OrgName` 도 Amazon 이라 서로 맞음. EC2 는 AWS 클라우드의 가상 머신으로, 서버가 필요한 웹사이트·애플리케이션을 올리는 대표 서비스임.

대상이 퍼블릭 CSP 에 호스팅됐다는 것이 확정되면 이후 방법론과 도구를 그 클라우드에 맞춰 조정할 수 있음. 이 수동 정찰에는 OSINT 조사를 함께 붙이는 것이 정상임. 그리고 **재귀적으로** — 새로 찾은 도메인·서브도메인·공인 IP 에 같은 절차를 다시 돌림.

마지막으로 자동화 도구 `dnsenum` 을 돌림. 이미 얻은 정보를 재확인하면서 사전 공격으로 서브도메인을 추가 발견함. 필수 인자는 도메인 하나이고, `--threads` 로 DNS 요청 스레드를 늘려 스로틀링이 걸릴 때 속도를 보완함.


*출처: 원문 Listing 934 — dnsenum 으로 DNS 정찰 자동화*

네임서버와 공인 IP 가 앞의 수동 조회와 일치하고, zone transfer 는 네임서버 넷 모두에서 실패했으며, 브루트포스로 `mail`·`www` 서브도메인이 나옴. 나머지 사이트는 랩용 허구라 실제 취약점은 없음.

정찰로 확정된 것 정리:

- 도메인 서비스가 AWS 에 있고 Route53 사용이 유력함
- 도메인이 가리키는 공인 IP 도 AWS 것이며 구체적으로 EC2 서비스임
- 그 공인 IP 하나가 `www.offseclab.io` 를 포함한 여러 사이트를 서비스함 → 같은 EC2 인스턴스 안에서 돌고 있음
