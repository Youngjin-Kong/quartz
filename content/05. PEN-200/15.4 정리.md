# 15.4 정리

> **Wrapping Up** · PEN-200 §15.4

안티바이러스의 목적과 벤더가 쓰는 대표 탐지 방식을 살펴본 장. 우회는 디스크 상(on-disk) 회피와 메모리 내(in-memory) 셸코드 주입으로 갈리며, 실습에서는 Shellter 와 PowerShell 로 실제 우회를 성사시킴.

다만 두 예시가 통했다고 회피를 익힌 것은 아님 — 탐지·회피 영역의 표면만 건드린 수준임. 현대적 방어를 뚫는 데 드는 공은 Microsoft 의 "FinFisher exposed" 분석 글과 Emeric Nasi 의 고급 회피 기법 문서를 참고할 것.
