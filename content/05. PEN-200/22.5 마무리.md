# 22.5 마무리

> **Wrapping Up** · PEN-200 §22.5

이 모듈에서 다룬 Active Directory 열거 방법은 모두 LDAP 와 PowerShell 의 .NET 클래스를 바탕으로 함. AD 에 환경 정보가 집중돼 있어 그 열거가 침투 테스트의 결정적 단계가 됨.

익힌 것은 도메인 열거의 기본기임. 기법을 전부 다룰 수는 없으므로 랩에서 .NET 클래스·PowerView 함수·BloodHound 질의를 더 파볼 것.

이어지는 Attacking Active Directory Authentication·Lateral Movement in Active Directory 모듈에서 이 정보로 AD 인증을 공격하고 대상 사이를 측면 이동함.
