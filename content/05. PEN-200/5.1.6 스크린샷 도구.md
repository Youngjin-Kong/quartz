# 5.1.6 스크린샷 도구

> **Tools to Take Screenshots** · PEN-200 §5.1.6

스크린샷은 OS 기본 기능으로 찍을 수 있음. Windows·Linux·macOS 모두 도구를 제공하며 전용 도구를 쓸 수도 있음.

Windows 에서는 PrintScreen 키로 전체 화면을, Alt/PrtSc 로 현재 활성 창을 복사함. 이것을 Paint·Word·PowerPoint 문서에 붙여 넣어 원하는 대로 조작할 수 있고, 원치 않는 부분을 잘라내는 크롭도 이 애플리케이션들에서 함. Windows 키와 함께 눌러 Snipping Tool 을 부를 수도 있으며, 이 도구는 화면에서 고른 임의 영역을 강조해 촬영하게 해 줌.

macOS 는 Shift/Command 조합에 숫자 3·4·5 를 더해 촬영함 — 전체 화면 선택·저장은 3, 화면의 특정 영역을 강조해 선택하는 것은 4 또는 5 임.

Linux 에서는 PrintScreen 키로 전체 화면을 캡처해 사용자의 Images/ 디렉터리에 저장하고, 수식 키를 함께 누르면 영역을 강조해 선택할 수 있음. Kali Linux 에는 Screenshot 도구가 기본 설치돼 있고 활성 창 선택·영역 선택·촬영 전 지연 같은 옵션을 제공함.

Flameshot 은 OS 를 가리지 않는 오픈소스 화면 캡처 도구로 기능이 풍부함. 명령줄과 GUI 인터페이스를 모두 제공하고, 캡처한 이미지에 강조·픽셀화·텍스트 등을 넣는 그리기 도구가 내장돼 있음.

원문 추출에서 macOS·Windows·Linux 의 수식 키 기호(Command·Shift 등)가 알파벳으로 깨져 나오므로 조합의 정확한 키는 본 노트에서 특정하지 않음 `[가정]`.
