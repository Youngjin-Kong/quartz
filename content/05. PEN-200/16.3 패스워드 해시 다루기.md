# 16.3 패스워드 해시 다루기

> **Working with Password Hashes** · PEN-200 §16.3

이 학습 단원의 목표 — Net-NTLMv2 해시 획득·크래킹, NTLM 해시 패싱, Net-NTLMv2 릴레이, Windows Credential Guard.

실무에서는 특권 접근을 얻으면 운영체제에서 패스워드 해시를 뽑아낼 수 있음. 여기서 그치지 않고 Windows 네트워크 인증 요청을 «만들어 내고 가로채» pass-the-hash 나 릴레이로 잇는 길도 있음 — 즉 해시는 깨야만 쓸모가 생기는 것이 아님.

다루는 Windows 해시 구현은 둘이고, 이 구분이 이후 절의 뼈대임.
- **NTLM 해시** — 시스템에 «저장»되는 값
- **Net-NTLMv2** — 네트워크 인증 과정에서 «오가는» 값

저장되는 것과 오가는 것이 다르고, 그래서 활용법도 갈림.
