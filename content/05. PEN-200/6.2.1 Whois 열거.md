# 6.2.1 Whois 열거

> **Whois Enumeration** · PEN-200 §6.2.1

Whois 는 도메인 이름에 대한 정보(네임 서버, 등록대행자 등)를 제공하는 TCP 서비스이자 도구이자 데이터베이스임. 등록대행자가 비공개 등록에 비용을 매기는 구조라 이 정보는 대체로 공개돼 있음.

도메인 이름을 넘겨 정방향 조회를 수행함. `-h` 로 조회할 WHOIS 서버 IP 를 지정함.

```
kali@kali:~$ whois megacorpone.com -h 192.168.50.251
```

여기서 건질 것 — 도메인 등록자가 Alan Grofield 라는 사실. MegaCorp One 연락처 페이지에 따르면 이 인물은 「IT and Security Director」임. 함께 드러나는 네임 서버도 DNS 구성요소로서 노트에 적어 둘 것.

IP 주소를 이미 확보했다면 같은 whois 클라이언트로 역방향 조회를 걸어 그 IP 를 누가 호스팅하는지 알아낼 수 있음.

```
kali@kali:~$ whois 38.100.193.70 -h 192.168.50.251
...

CIDR:           38.0.0.0/8

...

StateProv:      DC

Country:        US

```

수집한 것은 전부 노트에 남길 것 — 지금 쓸모가 없어 보여도 뒤 단계에서 쓰임.
