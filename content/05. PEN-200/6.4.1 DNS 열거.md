# 6.4.1 DNS 열거

> **DNS Enumeration** · PEN-200 §6.4.1

DNS(Domain Name System) — 사람이 읽는 도메인명을 IP 주소로 바꿔 주는 분산 데이터베이스이자 인터넷에서 가장 중요한 시스템 중 하나임. 최상위 루트 존을 시작으로 여러 존으로 갈라지는 계층 구조로 동작함. 도메인마다 여러 유형의 레코드를 둘 수 있고, 그 안에 정보가 풍부하게 쌓여 있어 능동 정보 수집(active information gathering)의 값나가는 표적이 됨.

흔히 쓰이는 레코드 유형:

| 유형 | 담는 것 |
|---|---|
| NS | 그 도메인의 DNS 레코드를 보유한 권한 있는(authoritative) 네임서버의 이름 |
| A | 호스트명의 IPv4 주소. 호스트 레코드라고도 부름 |
| AAAA | 호스트명의 IPv6 주소 |
| MX | 도메인의 메일을 처리하는 서버 이름. 도메인 하나에 여러 개를 둘 수 있음 |
| PTR | 역방향 조회 존에서 IP 주소에 연결된 레코드를 찾는 데 씀 |
| CNAME | 다른 호스트 레코드의 별칭 |
| TXT | 임의 데이터. 도메인 소유권 검증 등 용도가 다양함 |

`host` 는 옵션을 주지 않으면 A 레코드를 찾음.

```
kali@kali:~$ host www.megacorpone.com
www.megacorpone.com has address 149.56.244.87
```

*`host` 로 A 레코드 조회*

`-t` 로 레코드 유형을 지정하면 MX·TXT 같은 다른 필드도 물어볼 수 있음.

```
kali@kali:~$ host -t mx megacorpone.com
megacorpone.com mail is handled by 10 fb.mail.gandi.net.
megacorpone.com mail is handled by 20 spool.mail.gandi.net.
megacorpone.com mail is handled by 50 mail.megacorpone.com.
megacorpone.com mail is handled by 60 mail2.megacorpone.com.
```

*MX 레코드 조회 — 앞의 숫자가 우선순위*

MX 응답 앞의 숫자(10·20·50·60)가 우선순위이고 **값이 가장 낮은 서버가 먼저** 메일을 받음(여기서는 `fb.mail.gandi.net`). TXT 는 아무 문자열이나 들어가므로 운영 흔적이 그대로 노출되기도 함.

```
kali@kali:~$ host -t txt megacorpone.com
megacorpone.com descriptive text "Try Harder"
megacorpone.com descriptive text "google-site-
verification=U7B_b0HNeBtY4qYGQZNsEYXfCJ32hMNV3GtC0wWq5pA"
```

*TXT 레코드 조회*

호스트명을 추측할 때의 판정 근거는 **응답의 차이**임. 유효한 이름은 IP 로 해석되지만, 공개 DNS 레코드가 없는 이름은 `NXDOMAIN` 오류가 돌아옴. 해석된다는 것은 동작 중인 서버가 있다는 신호임.

```
kali@kali:~$ host idontexist.megacorpone.com
Host idontexist.megacorpone.com not found: 3(NXDOMAIN)
```

*존재하지 않는 호스트명 — NXDOMAIN 응답*

이 차이를 이용해 정방향 조회(forward lookup)를 브루트포스로 자동화함. 브루트포스는 시행착오로 유효한 값(웹 디렉터리·계정과 비밀번호 조합, 여기서는 DNS 레코드)을 찾아내는 기법임. 흔한 호스트명 워드리스트를 만들어 Bash 한 줄로 돌림.

```
kali@kali:~$ cat list.txt
www
ftp
mail
owa
proxy
router
```

*시험해 볼 호스트명 목록*

```
kali@kali:~$ for ip in $(cat list.txt); do host $ip.megacorpone.com; done
www.megacorpone.com has address 149.56.244.87
Host ftp.megacorpone.com not found: 3(NXDOMAIN)
mail.megacorpone.com has address 51.222.169.212
Host owa.megacorpone.com not found: 3(NXDOMAIN)
Host proxy.megacorpone.com not found: 3(NXDOMAIN)
router.megacorpone.com has address 51.222.169.214
```

*Bash 반복문으로 정방향 DNS 브루트포스*

`www`·`mail`·`router` 는 해석됐고 `ftp`·`owa`·`proxy` 는 없었음. 실전용 대규모 워드리스트는 SecLists 프로젝트에 있고 `sudo apt install seclists` 로 `/usr/share/seclists` 에 설치됨.

```
/usr/share/seclists directory using the sudo apt install seclists command.
```

*원문에서 SecLists 설치 안내 한 줄이 리스팅으로 잡힌 조각*

정방향 결과에서 www 를 뺀 IP 가 한 대역(51.222.169.X)에 몰려 있으면 그 대역을 역방향 조회로 훑을 값이 있음 — 관리자가 PTR 레코드를 설정해 뒀다면 IP 마다 호스트명이 돌아옴. `grep -v "not found"` 로 실패 응답을 걷어냄.

*IP 대역을 역방향 조회로 훑기*

이런 스캔은 **순환적임** — 새로 나온 이름(`mail2`·`router` 등)을 다시 정방향에 넣고, 나온 IP 를 다시 역방향으로 돌리며 회차마다 탐색 범위를 넓힘.

Kali 에는 이 과정을 자동화하는 도구가 여럿 있음. DNSRecon 은 Python 으로 쓰인 DNS 열거 스크립트로, `-d` 로 도메인을 `-t` 로 열거 유형을 지정함(`std` 는 표준 스캔).

```
kali@kali:~$ dnsrecon -d megacorpone.com -t std
```

*dnsrecon 표준 스캔 — 주요 레코드 유형을 한 번에*

브루트포스는 `-t brt` 로 지정하고, 후보 서브도메인이 든 파일을 `-D` 로 넘김.

```
kali@kali:~$ dnsrecon -d megacorpone.com -D ~/list.txt -t brt
[*] Using the dictionary file: /home/kali/list.txt (provided by user)
[*] brt: Performing host and subdomain brute force against megacorpone.com...
[+]      A www.megacorpone.com 149.56.244.87
[+]      A mail.megacorpone.com 51.222.169.212
[+]      A router.megacorpone.com 51.222.169.214
[+] 3 Records Found
```

*dnsenum 기본 실행 — 브루트포스 결과, 클래스 C 대역 추출, 역방향 조회*

여기서 새로 드러난 호스트들은 다시 수동·능동 열거의 입력이 됨 — 정보 수집이 고리 모양으로 도는 것이 이 모듈의 전제임.

Windows 쪽에서는 `nslookup` 이 같은 역할을 함. LOLBAS 목록에 들어 있지는 않지만 'living off the land' 상황에서 흔히 쓰임(의도치 않은 코드 실행을 제공하는 응용프로그램이 보통 LOLBAS 에 정리돼 있음). Windows 11 클라이언트에는 `xfreerdp` 로 붙음 — `/u:` 사용자명, `/p:` 비밀번호, `/v:` IP.

```
kali@kali:~$ xfreerdp /u:student /p:lab /v:192.168.50.152
```

*xfreerdp 로 Windows 11 클라이언트 접속*

```
C:\Users\student>nslookup mail.megacorptwo.com
DNS request timed out.
    timeout was 2 seconds.
Server:  UnKnown
Address:  192.168.50.151
Name:    mail.megacorptwo.com
Address:  192.168.50.154
```

*nslookup 으로 A 레코드 조회 — 기본 DNS 서버가 응답*

`nslookup` 도 `host` 만큼 세밀한 조회가 됨. `-type=` 으로 레코드 유형을, 마지막 인자로 물어볼 DNS 서버를 지정함.

```
C:\Users\student>nslookup -type=TXT info.megacorptwo.com 192.168.50.151
Server:  UnKnown
Address:  192.168.50.151
info.megacorptwo.com    text =
        "greetings from the TXT record body"
```

*지정한 DNS 서버에 TXT 레코드를 조회*

PowerShell 이나 배치 스크립트로 감싸면 이 조회도 반복 자동화됨.
