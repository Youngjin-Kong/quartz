# 17.4 마무리

> **Wrapping Up** · PEN-200 §17.4

이 모듈이 다룬 Windows 권한 상승(privilege escalation) 경로 —

- 수동·자동 열거(enumeration)로 민감 정보를 찾고 상황 파악(situational awareness)을 확보
- Windows 서비스를 악용하는 세 가지 방법
- 예약 작업(scheduled tasks) 악용, 그리고 권한 상승으로 이어지는 익스플로잇 계열

여기 실린 것은 **가장 흔한 축**이지 전부가 아님. 권한 있는 파일 쓰기(privileged file writes) 같은 다른 벡터가 다수 있고, 새 벡터와 취약점이 계속 발견·개발되는 영역이라 목록이 고정되지 않음.

대상의 보안 태세나 보안 기술 때문에 **권한 상승 자체가 불가능한 상황도 만남.** 그때는 다른 모듈에서 배운 기법으로 방향을 틀어 다른 시스템·서비스를 노릴 것.
