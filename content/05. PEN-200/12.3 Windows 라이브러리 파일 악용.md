# 12.3 Windows 라이브러리 파일 악용

> **Abusing Windows Library Files** · PEN-200 §12.3

매크로 벡터가 어려워진 이유 셋 — 보안 제품의 악성 매크로 스캔, Microsoft 의 완화 가이드와 GPO(Group Policy Object) 템플릿, 사회공학 인식 교육의 집중 대상.

대안이 **Windows 라이브러리 파일**임 — 덜 알려졌을 뿐 효과는 대등하며, 바로가기와 엮어 코드 실행을 얻음.
