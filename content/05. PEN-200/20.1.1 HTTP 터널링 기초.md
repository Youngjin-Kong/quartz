# 20.1.1 HTTP 터널링 기초

> **HTTP Tunneling Fundamentals** · PEN-200 §20.1.1

시나리오 전제 — CONFLUENCE01 을 이미 장악해 HTTP 요청으로 명령을 실행할 수 있으나, 피벗 단계에서 빡빡한 네트워크 구성에 막힘.

제약 둘:

- DPI 장비가 **아웃바운드 트래픽 중 HTTP 만 남기고 전부 끊음**
- CONFLUENCE01 의 **인바운드는 TCP/8090 만 열림**

그래서 평범한 리버스셸이 안 됨 — HTTP 형식이 아니라 경계에서 잘림. 같은 이유로 SSH 원격 포트 포워딩도 못 씀. Kali 까지 닿는 것은 HTTP 뿐이라 `wget`·`curl` 정도가 남음.

⚠️ 이 DPI 제약은 **가정된 시나리오**임 — 랩에 실제로 구현돼 있지 않음. 제약을 상정해 보는 훈련임.

![[PEN200-Fig-289.png]]

*WAN 인터페이스에서 CONFLUENCE01 로 향하는 스트림을 감시하는 방화벽/DPI 구성*

단순 방화벽 자리를 FIREWALL/INSPECTOR 가 대체했고 MULTISERVER03 은 WAN 쪽에서 차단됨.

목표는 PGDATABASE01 — 자격 증명은 이미 있고 CONFLUENCE01 을 거쳐 SSH 할 경로가 필요함. 즉 내부망으로 들어가는 터널을 만들되 **겉모습이 CONFLUENCE01 에서 나가는 HTTP 연결이어야** 함.
