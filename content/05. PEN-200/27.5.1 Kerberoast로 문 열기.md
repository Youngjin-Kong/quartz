# 27.5.1 Kerberoast로 문 열기

> **Speak Kerberoast and Enter** · PEN-200 §27.5.1

INTERNALSRV1 의 WordPress 가 지금 가장 유망한 표적임. 새 정보를 얻을 때마다 이미 아는 것을 재평가해야 하는데, 여기서 걸리는 것이 「daniela 에게 `http/internalsrv1.beyond.com` SPN 이 매핑돼 있다」는 사실임.

인과 — SPN 이 걸린 계정의 서비스 티켓(TGS-REP)은 **그 계정의 비밀번호 해시로 암호화**되고 도메인 사용자면 누구나 그 티켓을 요청할 수 있음 → 받아서 오프라인 크래킹에 걸 수 있음. 이것이 daniela 가 kerberoastable 인 이유이고, SPN 이 문제의 웹앱을 가리키므로 **daniela 가 WordPress 에 로그인 가능한 계정일 것**이라는 가정이 성립함. 실패하면 WPScan 등 웹앱 열거로 돌아가거나 MAILSRV1 로 표적을 돌림.

Kerberoasting 은 Proxychains 를 통해 `impacket-GetUserSPNs` 로 수행함. TGS-REP 해시를 받으려면 유효한 도메인 사용자 자격 증명이 필요한데 가진 것은 john 뿐임.

*daniela 계정에 대한 Kerberoasting — SPN 이 `http/internalsrv1.beyond.com` 임을 재확인하고 `$krb5tgs$23$*daniela$BEYOND.COM$...` TGS-REP 해시를 회수함*

받은 해시를 `daniela.hash` 로 저장하고 Hashcat 으로 깸 — **TGS-REP 의 해시 모드는 `13100`**.

kali@kali:~/beyond$ sudo hashcat -m 13100 daniela.hash

*TGS-REP 해시 크래킹 — 해시 끝에 `:DANIelaRO123` 이 붙어 나오는 것이 크랙 성공의 표식임. 블록 안의 `...` 은 교재 자신의 생략 표시임*

평문 `DANIelaRO123` 확보 → `creds.txt` 에 기록. 도메인 컴퓨터에 로컬 관리자 권한이 없고 RDP 도 안 되는 것은 이미 배제했으나 WinRM 같은 프로토콜은 남아 있음. 우선은 포워딩해 둔 포트로 `/wp-admin` 에 daniela 로 로그인 → 성공.
