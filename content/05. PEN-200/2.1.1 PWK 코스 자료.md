# 2.1.1 PWK 코스 자료

> **PWK Course Materials** · PEN-200 §2.1.1

- 자료는 텍스트 모듈과 영상 둘 — 내용이 겹치나 서로 빈 곳을 메우므로 둘 다 볼 것.
- 연습문제는 단답형과 플래그형(`OS{random-hash}`) 두 종류이며 제출은 OLP 에서 받음.
- ⚠️ 플래그는 머신 부팅 시 생성되고 종료·리버트 시 만료됨 — **리버트 전에 제출해야 인정됨**.
- 연습문제 VM 은 같은 IP·포트가 재사용되어 known-hosts 가 깨지므로 SSH 접속 시 두 옵션을 붙일 것(보안 관점에서는 MITM 에 열리는 설정임):

```
ssh -o "UserKnownHostsFile=/dev/null" -o "StrictHostKeyChecking=no"
learner@192.168.50.52
```

- 공식 지원 대상은 x86-64 Kali — ARM 은 별도 안내를 따라야 하고 일부 제약이 있음.
