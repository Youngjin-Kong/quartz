# 2.2.1 불확실성 증가 모델

> **A Model of Increasing Uncertainty** · PEN-200 §2.2.1

- 침투테스트는 불확실성 아래의 추론임 — 정보가 양쪽에 다 드러난 체스가 아니라 상대의 패를 모르는 포커 쪽에 가까움.
- 대상을 전부 알면 침투에 시간이 걸릴 이유가 없음 — 소요 시간은 공격자가 모르는 것의 양임.
- 그래서 코스는 두 층을 같이 가르침 — 명시적 기법(정보 수집·경계 공격·권한 상승·측면 이동)과, 처음 보는 상황에서 어떻게 생각하고 행동할 것인가라는 방법론.
- 학습 양식은 불확실성이 낮은 순서로 나열됨 — 학습 모듈 → 시연 연습문제 → 응용 연습문제 → 캡스톤 랩 → Assembling the Pieces → 챌린지 랩 세 유형.
