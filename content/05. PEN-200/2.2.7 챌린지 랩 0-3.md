# 2.2.7 챌린지 랩 0-3

> **Challenge Labs 0-3** · PEN-200 §2.2.7

- 챌린지 랩은 세 유형이며, 0–3 은 배경 스토리가 붙은 **시나리오**형 — 목표는 Active Directory 도메인의 Domain Administrator 획득과 최대한 많은 머신 장악.
- 여러 모듈을 합쳐 묻는 구간이라 불확실성이 높음 — 어느 머신이 무엇에 취약한지는 물론 **그 머신이 단독으로 취약한지조차** 알 수 없음.
- 의존 구조가 핵심 — 다른 머신에서 얻은 자격 증명·정보가 있어야 열리는 머신, 도메인 컨트롤러 장악 후에야 끩이지는 머신이 섮임.
- 증거 파일은 `local.txt`·`proof.txt` 이고 값은 리버트마다 바뀜 — OLP 제출로 장악을 기록.
- 랩 0 은 모의시험은 아니나 OSCP+ 의 Assumed Breach 방식을 따라 초기 자격 증명(`Eric.Wallows` / `EricLikesRunning800`)이 주어짐.
