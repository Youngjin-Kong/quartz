# 23.3 마무리

> **Wrapping Up** · PEN-200 §23.3

이 모듈에서 다룬 것은 NTLM 과 Kerberos 인증임. 인증이 «어떻게» 도는지를 잡아두지 않으면 이 모듈의 공격들을 기술적 수준에서 이해할 수 없으므로, 개념이 먼저고 도구가 나중임.

실제 진단에서는 기법을 그대로 쓰기보다 환경에 맞게 변형해야 통하는 경우가 많음. 여기서 얻은 것은 유효한 사용자 자격 증명과 시스템·서비스 접근을 확보하는 수단이고, 다음 모듈 Lateral Movement in Active Directory 가 이를 발판으로 AD 환경 내 횡적 이동을 다룸.
