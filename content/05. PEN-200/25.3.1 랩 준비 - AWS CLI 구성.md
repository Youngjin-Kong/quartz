# 25.3.1 랩 준비 - AWS CLI 구성

> **Preparing the Lab - Configure AWS CLI** · PEN-200 §25.3.1

이후 절들은 랩 시작 시 받은 자격 증명으로 AWS CLI 를 통해 AWS API 를 호출함. 이 액세스 키는 실제로는 대상 계정 «안»의 사용자 것이지만, **외부 AWS 계정에 속한 공격자**인 것처럼 가정하고 진행함.

AWS 에서 사용자와 권한을 관리하는 서비스가 IAM(Identity and Access Management)이고, 그 사용자를 IAM 사용자라 부름. AWS CLI 가 없으면 Kali 패키지 관리자로 `awscli` 를 설치함.

```
kali@kali:~$ sudo apt update
...
kali@kali:~$ sudo apt install -y awscli
...
The following NEW packages will be installed:
  awscli docutils-common python3-awscrt python3-docutils python3-jmespath python3-
roman
(Reading database ... 461429 files and directories currently installed.)
...
```

자격 증명은 **명명 프로파일(named profile)** 로 넣음 — 랩 진행 중 여러 IAM 사용자로 갈아타야 하는데, 프로파일이 있으면 구분과 전환이 쉬워짐. `aws configure --profile attacker` 로 만들고 랩이 준 키 ID 와 시크릿을 넣음. ⚠️ 이후 **모든 AWS 명령에 `--profile attacker` 를 붙여야 함.**

검증은 `sts get-caller-identity` — 사용자 정보 JSON 이 오면 자격 증명이 유효하고 그 IAM 사용자로 API 를 쓰고 있다는 증거임.

```
kali@kali:~$ aws configure --profile attacker
AWS Access Key ID []: AKIAQO...
AWS Secret Access Key []: cOGzm...
Default region name []: us-east-1
Default output format []: json
kali@kali:~$ aws --profile attacker sts get-caller-identity
{
    "UserId": "AIDAQOMAIGYU5VFQCHOI4",
    "Account": "123456789012",
    "Arn": "arn:aws:iam::123456789012:user/attacker"
}
```
