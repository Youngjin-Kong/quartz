# 10.1.2 DB 유형과 특성

> **DB Types and Characteristics** · PEN-200 §10.1.2

웹앱 점검 시 뒤에 어떤 DB 가 있는지 모르는 상태로 시작하는 경우가 많음 → 변종별 문법·함수·기능 차이를 알고 있어야 함. 여기서는 가장 흔한 둘, MySQL 과 Microsoft SQL Server(MSSQL) 를 다룸. 온프레미스뿐 아니라 클라우드 배포에서도 그대로 만남.

MySQL(및 오픈소스 포크 MariaDB)에는 Kali 에서 `mysql` 클라이언트로 직접 붙음. 기본 포트는 3306.

```
kali@kali:~$ mysql -u root -p'root' -h 192.168.50.16 -P 3306
Copyright (c) 2000, 2018, Oracle, MariaDB Corporation Ab and others.
Type 'help;' or '\h' for help. Type '\c' to clear the current input statement.
MySQL [(none)]>
```

*원격 MySQL 인스턴스 접속*

접속 후 기본 열거(enumeration) 순서:

- `select version();` — 인스턴스 버전. MySQL 은 `@@version` 도 받음(§10.2.1)
- `select system_user();` — 현재 세션의 사용자@호스트. ⚠️ 여기 나오는 `root` 는 **DB 전용 root** 지 시스템 관리자 root 가 아님
- `show databases;` — 접근 가능한 DB 목록

```
MySQL [(none)]> select version();
+-----------+
| version() |
+-----------+
| 8.0.21    |
+-----------+
1 row in set (0.107 sec)
```

*버전 질의 결과 — 8.0.21*

```
MySQL [(none)]> select system_user();
+--------------------+
| system_user()      |
+--------------------+
| root@192.168.20.50 |
+--------------------+
1 row in set (0.104 sec)
```

*세션 사용자 확인 — 접속 출발지 IP 까지 같이 드러남*

```
MySQL [(none)]> show databases;
+--------------------+
| Database           |
+--------------------+
| information_schema |
| mysql              |
| performance_schema |
| sys                |
| test               |
+--------------------+
5 rows in set (0.107 sec)
```

*접근 가능한 DB 목록*

계정 정보는 `mysql` DB 의 `user` 테이블에 있음 — 사용자명은 `user`, 비밀번호는 `authentication_string` 컬럼임. `WHERE` 로 원하는 계정만 걸러 뽑음.

```
MySQL [mysql]> SELECT user, authentication_string FROM mysql.user WHERE user =
'offsec';
+--------+------------------------------------------------------------------------+
| user   | authentication_string                                                  |
+--------+------------------------------------------------------------------------+
| offsec | $A$005$?qvorPp8#lTKH1j54xuw4C5VsXe5IAa1cFUYdQMiBxQVEzZG9XWd/e6|
+--------+------------------------------------------------------------------------+
1 row in set (0.106 sec)
```

*사용자 비밀번호 해시 조회*

여기 저장된 값은 Caching-SHA-256 해시라 평문이 아님 — 크래킹은 별도 모듈 주제임.

MSSQL 은 Windows 생태계에 내장된 DBMS 로, Windows 에는 명령줄 도구 `SQLCMD` 가 기본 탑재돼 있어 명령 프롬프트에서 로컬로도, 다른 머신에서 원격으로도 질의를 던질 수 있음. Kali 쪽에서는 Impacket 이 MSSQL 의 통신 규약인 TDS(Tabular Data Stream)를 구현한 `impacket-mssqlclient` 로 붙음. `-windows-auth` 는 Kerberos 대신 NTLM 인증을 강제하는 옵션임.

```
kali@kali:~$ impacket-mssqlclient Administrator:Lab123@192.168.50.18 -windows-auth
Impacket v0.9.24 - Copyright 2021 SecureAuth Corporation
[*] Encryption required, switching to TLS
[*] ENVCHANGE(DATABASE): Old Value: master, New Value: master
[*] ENVCHANGE(LANGUAGE): Old Value: , New Value: us_english
[*] ENVCHANGE(PACKETSIZE): Old Value: 4096, New Value: 16192
[*] INFO(SQL01\SQLEXPRESS): Line 1: Changed database context to 'master'.
[*] INFO(SQL01\SQLEXPRESS): Line 1: Changed language setting to us_english.
[*] ACK: Result: 1 - Microsoft SQL Server (150 7208)
[!] Press help for extra shell commands
SQL (SQLPLAYGROUND\Administrator  dbo@master)>
```

*Impacket 으로 원격 MSSQL 접속*

버전 확인은 `SELECT @@version` — MSSQL 판올림뿐 아니라 **하부 Windows Server 버전과 빌드 번호까지** 같이 뱉음. ⚠️ DBMS 마다 열거 문법이 갈리므로 대상에 맞는 구문을 골라 던질 것.

```
SQL (SQLPLAYGROUND\Administrator  dbo@master)> SELECT @@version;
...
Microsoft SQL Server 2019 (RTM) - 15.0.2000.5 (X64)
    Sep 24 2019 13:48:23
    Copyright (C) 2019 Microsoft Corporation
    Express Edition (64-bit) on Windows Server 2022 Standard 10.0 <X64> (Build 20348:
) (Hypervisor)
```

*OS 버전까지 노출되는 MSSQL 버전 질의*

⚠️ `sqlcmd` 같은 로컬 도구에서는 문장 끝에 세미콜론을 붙이고 다음 줄에 `GO` 를 써야 실행됨. 반면 원격 TDS 로 붙었을 때는 `GO` 가 프로토콜의 일부가 아니라 생략함.

DB 목록은 시스템 카탈로그에서 뽑음. `master`·`tempdb`·`model`·`msdb` 는 기본 DB 라 눈여겨볼 것은 나머지(예제에서는 `offsec`)임.

```
SQL (SQLPLAYGROUND\Administrator  dbo@master)> SELECT name FROM sys.databases;
name
...
master
tempdb
model
msdb
offsec
SQL>
```

*접근 가능한 DB 목록*

해당 DB 의 테이블은 그 DB 의 `information_schema` 를 통해 확인함.

```
SQL (SQLPLAYGROUND\Administrator  dbo@master)> SELECT * FROM
offsec.information_schema.tables;
TABLE_CATALOG   TABLE_SCHEMA   TABLE_NAME   TABLE_TYPE
-------------   ------------   ----------   ----------
offsec          dbo            users        b'BASE TABLE'
SQL (SQLPLAYGROUND\Administrator  dbo@master)>
```

*offsec DB 의 테이블 목록*

레코드를 뽑을 때는 DB 명과 테이블명 사이에 **스키마(`dbo`)를 끼워** 지정해야 함 — MySQL 과 갈리는 지점임.

```
SQL>select * from offsec.dbo.users;
username     password
----------   ----------
admin        lab
guest        guest
```

*users 테이블 레코드 조회 — `username`·`password` 두 컬럼에 두 행*

이 예제의 비밀번호는 **평문**이라 해시 크래킹 없이 그대로 씀.
