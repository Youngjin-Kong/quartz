# 21.2 Metasploit 페이로드 활용

> **Using Metasploit Payloads** · PEN-200 §21.2

학습 목표 — 스테이지드/논스테이지드 페이로드의 차이 · Meterpreter 페이로드 · 실행 파일 페이로드 생성.

앞 단위에서는 exploit 모듈의 페이로드로 `linux/x64/shell_reverse_tcp` 를 썼음. Metasploit 에는 OS·아키텍처별 페이로드가 다수 있고 **기본 셸을 넘어 다른 동작을 수행하는 종류**도 있음. 나아가 리버스 셸 기동 같은 동작을 담은 파일을 여러 형식으로 생성하는 기능도 있음.
