# 9.2 파일 인클루전 취약점

> **File Inclusion Vulnerabilities** · PEN-200 §9.2

학습 목표 — 파일 인클루전과 디렉터리 탐색의 차이, 파일 인클루전 취약점의 이해, LFI(로컬 파일 인클루전)로 코드 실행 획득, PHP 래퍼(wrapper) 활용, RFI(원격 파일 인클루전) 공격 수행.

진행 순서 — 사례 연구로 LFI 익스플로잇을 시연하고 디렉터리 탐색과의 차이를 분석함. 이어서 필터와 기타 제약을 우회하는 데 쓰는 PHP 래퍼를 다루고, 마지막으로 공격자가 통제하는 시스템의 파일을 포함시키는 RFI 취약점을 살펴봄.
