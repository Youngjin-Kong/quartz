# 25.4.1 랩 접속

> **Accessing the Lab** · PEN-200 §25.4.1

시나리오 전제 — 초기 침투에 성공해 **AWS 환경에서 액션을 실행할 수 있는 자격 증명을 이미 확보한** 공격자 입장임.

도구는 AWS CLI. 여러 OS 에서 돌지만 여기서는 Kali 에서 쓰며, 공식 저장소에 있으므로 `sudo apt install awscli` 로 설치함.

랩을 배포하면 **세 사용자의 자격 증명**을 받고 각각 역할이 다름 —

- **target** — 탈취된 접근을 흉내내는 주 사용자. 이 단원의 기법 대부분을 이 자격 증명으로 실행함
- **challenge** — 접근 권한이 매우 제한된 보조 사용자. 개념 검증과 추가 과제용이며, **외부 계정에서 호출하는 상황을 재현할 때** 씀
- **monitor** — AWS 로깅 서비스인 Cloudtrail 에 접근 가능한 운영자 역할. 공격이 로그에 남았는지 방어자 시점에서 확인하는 데 씀

![[PEN200-Fig-322.png]]
*랩 배포 후 정보 상자에서 세 사용자의 자격 증명을 확인하는 화면*

받아 적어 둘 항목 — target 과 challenge 는 각각 ACCESS KEY ID · SECRET ACCESS KEY, monitor 는 관리 콘솔 로그인 URL · 사용자명 · 비밀번호. 다음 절에서 이 값들을 CLI 프로필로 구성해 사용함.
