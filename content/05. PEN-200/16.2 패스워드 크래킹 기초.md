# 16.2 패스워드 크래킹 기초

> **Password Cracking Fundamentals** · PEN-200 §16.2

학습 목표 — 크래킹의 원리 이해, 워드리스트 변형(mutation), 기본 크래킹 방법론, 패스워드 매니저 키 파일 공격, SSH 개인키 패스프레이즈 공격.

기초 개념(암호화 대 해시, 크래킹 시간 계산)에서 출발해, Rule 로 기존 워드리스트를 변형하는 방법과 방법론을 거쳐, 데이터베이스 파일과 SSH 개인키를 실제로 깨는 순서로 진행함.
