# 8.4.2 JavaScript 복습

> **JavaScript Refresher** · PEN-200 §8.4.2

JavaScript 는 현대 웹 애플리케이션의 주요 구성 요소이고, 모든 최신 브라우저가 자체 엔진으로 브라우저 안에서 코드를 실행함.

브라우저는 HTML 이 담긴 HTTP 응답을 처리할 때 **DOM 트리**를 만들어 렌더링함. DOM 은 그 페이지의 폼·입력·이미지 등 전부를 포함하고, JavaScript 의 역할은 이 DOM 에 접근·수정해 상호작용을 만드는 것임.

**이 성질이 그대로 공격력이 됨** — JavaScript 를 주입할 수 있으면 DOM 에 접근·수정할 수 있고, 그러면 로그인 폼을 다른 곳으로 돌리거나 비밀번호를 빼내거나 세션 쿠키를 훔칠 수 있음.

다른 언어처럼 JavaScript 도 명령 묶음을 함수로 만듦.

```
function multiplyValues(x,y) {
  return x * y;
}
let a = multiplyValues(3, 5)
console.log(a)
```

*간단한 JavaScript 함수*

1~3 행에서 정수 둘을 받아 곱을 반환하는 `multiplyValues` 를 선언하고, 5 행에서 `3`·`5` 로 호출해 반환값을 `a` 에 대입한 뒤 6 행에서 출력함. `a` 에 타입을 명시하지 않는 것은 JavaScript 가 **느슨한 타입(loosely typed) 언어**여서임 — 인자가 Number 이므로 `a` 도 Number 로 추론됨.

확인은 `about:blank` 에서 개발자 도구를 띄워 함 — 빈 페이지라 다른 라이브러리가 화면을 어지럽히지 않음. Web Developer 하위 Web Console 을 열거나 단축키를 씀. [가정] 원문의 단축키 표기는 PDF 추출에서 수식 키 기호가 알파벳으로 치환돼 조합을 특정할 수 없어 옮기지 않음.
