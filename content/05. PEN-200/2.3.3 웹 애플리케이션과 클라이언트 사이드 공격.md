# 2.3.3 웹 애플리케이션과 클라이언트 사이드 공격

> **Web Application and Client Side Attacks** · PEN-200 §2.3.3

- 여기부터 경계(perimeter) 공격 — 내부망 접근 없이 인터넷에서 시작할 수 있는 침투 경로를 다룸. 그중 웹을 먼저 놓는 이유는 둘 — 사용자 입력을 받는 구조라 공격면이 가장 흔하고, 시각적이라 공격이 왜 먹히는지 보기 쉽기 때문임.
- Introduction to Web Applications — 방법론·도구·열거 틀을 잡고 첫 취약점으로 XSS 를 다룸. 서버가 아니라 사용자를 공격하므로 웹 공격이자 클라이언트 사이드 공격임.
- Common Web Application Attacks — 네 가지: 디렉터리 트래버설, 파일 인클루전, 파일 업로드 취약점, 명령 삽입.
- SQL Injection 은 별도 모듈 — 흔해서만이 아니라 **웹 서버와 DB 가 섞이는 지점에서 약점이 생긴다**는 구조를 보여주는 사례임.
- Client-side Attacks — 정찰, Microsoft Office 악용, Windows Library 파일 악용.
