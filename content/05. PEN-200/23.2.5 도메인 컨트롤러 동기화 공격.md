# 23.2.5 도메인 컨트롤러 동기화 공격

> **Domain Controller Synchronization** · PEN-200 §23.2.5

운영 환경의 도메인은 이중화를 위해 도메인 컨트롤러를 여러 대 둠. 이들을 동기화하는 것이 DRS(Directory Replication Service) Remote Protocol 이고, 계정 같은 객체 하나의 갱신은 `IDL_DRSGetNCChanges` API 로 요청함.

결함은 여기 있음 — 갱신 요청을 받은 도메인 컨트롤러는 요청자가 «알려진 도메인 컨트롤러인지 확인하지 않음». 확인하는 것은 연결된 SID 가 적절한 권한을 가졌는지뿐임. 따라서 권한만 있으면 일반 사용자 계정으로 보낸 위장 복제 요청도 성공함.

필요한 권한은 셋임 — Replicating Directory Changes, Replicating Directory Changes All, Replicating Directory Changes in Filtered Set. 기본적으로 Domain Admins, Enterprise Admins, Administrators 그룹 구성원이 갖고 있음. 이 그룹에 속하거나 권한이 직접 부여된 계정을 잡으면 도메인 컨트롤러를 사칭하는 **dcsync** 공격으로 도메인의 «아무 사용자 자격 증명이나» 요청할 수 있음.

도메인 가입 Windows 에서는 Mimikatz 의 `lsadump::dcsync` 모듈을 쓰고, `/user:` 에 뽑고 싶은 도메인 사용자를 지정함.

얻은 NTLM 해시는 파일에 저장해 Hashcat 으로 깸 — NTLM 이므로 모드는 **1000** 임.

> [!warning] 아래 명령은 교재 지면 폭에 맞춰 줄이 접혀 있음 — `-r` 이하는 원래 같은 줄이므로 한 줄로 이어 칠 것

```
kali@kali:~$ hashcat -m 1000 hashes.dcsync /usr/share/wordlists/rockyou.txt -r
/usr/share/hashcat/rules/best64.rule --force
...
08d7a47a6f9f66b97b1bae4178747494:Flowers1
...
```

같은 방식으로 도메인 관리자 `Administrator` 를 포함해 도메인의 어떤 계정이든 해시를 뽑을 수 있음.

```
mimikatz # lsadump::dcsync /user:corp\Administrator
...
Credentials:
  Hash NTLM: 2892d26cdf84d7a70e2eb3b9f05c425e
...
```

*`Administrator` 를 표적으로 한 dcsync — 도메인 관리자 NTLM 해시 확보*

Linux 에서는 impacket-secretsdump 로 함. `-just-dc-user` 에 표적 사용자명을, 그 뒤에 필요한 권한을 가진 계정의 자격 증명과 도메인 컨트롤러 IP 를 `domain/user:password@ip` 형식으로 넘김. 도구 출력의 DRSUAPI 는 Directory Replication Service Remote Protocol 을 구현한 Microsoft API 임.

정리하면 dcsync 는 Windows·Linux 양쪽에서 쓸 수 있고 도메인의 임의 사용자 자격 증명을 얻는 강력한 기법이지만, **전제가 이미 무거움** — Domain Admins·Enterprise Admins·Administrators 소속이거나 위 복제 권한이 직접 부여된 계정이 필요함. 후자는 실전 침투에서 마주칠 확률이 훨씬 낮음.
