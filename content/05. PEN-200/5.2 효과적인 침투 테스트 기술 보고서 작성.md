# 5.2 효과적인 침투 테스트 기술 보고서 작성

> **Writing Effective Technical Penetration Testing Reports** · PEN-200 §5.2

학습 목표 — 기술 보고서의 목적, 독자에 맞춘 내용 조정, 경영진 요약 구성, 테스트 환경 고려사항 반영, 기술 요약 작성, 기술적 발견과 권고 기술, 부록·자료·참고문헌의 사용 시점 판단.
