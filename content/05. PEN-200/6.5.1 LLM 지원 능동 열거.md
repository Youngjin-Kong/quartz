# 6.5.1 LLM 지원 능동 열거

> **Active LLM-Aided Enumeration** · PEN-200 §6.5.1

DNS 열거의 첫 단계는 **탄탄한 워드리스트를 만드는 것**임. 대상 도메인에 딸린 서브도메인·서비스·디렉터리를 찾아내는 데 워드리스트의 질이 결정적인데, 전통적으로는 공개 정보를 사람이 일일이 훑어야 했음. 현대의 LLM 은 이 단계를 간소화하면서 **패턴까지 끌어내** 결과를 개선함.

megacorpone.com 을 예로, 회사의 공개 데이터를 가져와 그 출력을 걸러 서브도메인 후보 목록을 만들도록 ChatGPT 에 요청함.

```
Using public data from MegacorpOne's website and any information that can be inferred
about its organizational structure, products, or services, generate a comprehensive
list of potential subdomain names.
    •   Incorporate common patterns used for subdomains, such as:
    •   Infrastructure-related terms (e.g., "api", "dev", "test", "staging").
    •   Service-specific terms (e.g., "mail", "auth", "cdn", "status").
    •   Departmental or functional terms (e.g., "hr", "sales", "support").
    •   Regional or country-specific terms (e.g., "us", "eu", "asia").
    •   Factor in industry norms and frequently used terms relevant to MegacorpOne's
sector.
Finally, compile the generated terms into a structured wordlist of 1000  words,
optimized for subdomain brute-forcing against megacorpone.com
Ensure the output is in a clean, lowercase format with no duplicates, no bulletpoints
and ready to be copied and pasted.
Make sure the list contains 1000 unique entries.
```

```
I have generated a structured 1000-word subdomain wordlist optimized for brute-forcing
against megacorpone.com. You can download the file for use directly:
Download Subdomain Wordlist
```

*워드리스트 생성 응답 — 내려받을 파일 링크로 제공됨*

프롬프트에 **출력 형식과 워드리스트 크기까지 명시**한 것이 요점임. 응답 자체는 장황하지만 필요한 부분만 보면 됨 — 이 사례에서는 LLM 이 워드리스트를 응답에 첨부해 줘서 링크로 Kali 에 내려받아 `wordlist.txt` 로 저장함. 목록이 응답에 직접 실려 있으면 복사해 붙여도 됨.

⚠️ **LLM 의 답은 매번 달라짐** — 더 짧은 목록이 나오기도 함. 원하는 결과가 아니면 다시 요청할 것.

DNS 열거 속도를 올리려면 gobuster 를 씀. 여러 종류의 자원을 빠르고 효율적으로 브루트포스·열거하도록 만들어진 오픈소스 명령행 도구이며, 먼저 Kali 에 설치함.

```
sudo apt update
sudo apt install gobuster
```

이어 `gobuster dns -d megacorpone.com -w wordlist -t 10` 로 DNS 브루트포스를 실행함 — `dns` 는 Gobuster 의 DNS 모듈 사용, `-d` 는 열거 대상 도메인 지정, `-w` 는 LLM 이 만든 커스텀 워드리스트 공급, `-t 10` 은 동시성 수준(스레드 10개)임.


LLM 의 도움으로 만든 워드리스트로 유효 서브도메인들이 발견됨. 능동 열거에서 LLM 의 기여는 **대상 조직의 구조와 명명 패턴을 추론해 맞춤 워드리스트를 만들어 준 것**이고, 그만큼 유효 서브도메인을 찾을 확률이 크게 올라감. 예전 같으면 그런 목록을 손으로 모으거나 범용 데이터셋에 의존해야 했던 단계임.
