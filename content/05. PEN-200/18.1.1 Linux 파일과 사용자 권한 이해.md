# 18.1.1 Linux 파일과 사용자 권한 이해

> **Understanding Files and Users Privileges on Linux** · PEN-200 §18.1.1

Linux 및 UNIX 계열의 핵심 성질 — 파일·디렉터리·장치는 물론 네트워크 통신까지 대부분의 자원이 파일시스템에 표현됨("everything is a file"). 따라서 **모든 자원이 파일 권한 모델의 지배를 받음**.

권한은 세 속성 `r`(읽기)·`w`(쓰기)·`x`(실행)의 조합이며, **소유자(owner) · 소유 그룹(owner group) · 그 외(others)** 세 부류에 각각 부여됨.

같은 rwx 라도 파일이냐 디렉터리냐에 따라 의미가 다름 — 이 차이가 권한 상승 판단에서 자주 갈림:

| | 파일 | 디렉터리 |
|---|---|---|
| `r` | 내용 읽기 | 목록 조회 |
| `w` | 내용 변경 | 파일 생성·삭제 |
| `x` | 실행 | `cd` 등으로 통과해 하위 접근 |

`r` 없이 `x` 만 있으면 목록은 못 보지만 **정확한 이름을 알면 그 항목에 접근 가능**함. 열거로 파일명을 알아내면 읽을 수 없어 보이던 디렉터리를 뚫는 경로가 됨.

Kali(Debian 계열)에서 실제 권한 표기를 확인:

```
kali@kali:~$ ls -l /etc/shadow
-rw-r----- 1 root shadow 1751 May  2 09:31 /etc/shadow
```

읽는 법 — 맨 앞 하이픈은 파일 «종류»라 권한과 무관하므로 무시. 이어지는 세 글자씩이 순서대로 소유자·소유 그룹·others 임. 여기서는 소유자 root 가 `rw-`(실행 없음), `shadow` 그룹은 읽기만, others 는 아무 권한도 없음.
