# 6.4 능동 정보 수집

> **Active Information Gathering** · PEN-200 §6.4

학습 목표 — Netcat·Nmap 포트 스캐닝, DNS·SMB·SMTP·SNMP 열거, Living Off the Land 기법 이해.

이 유닛부터는 수동 수집을 넘어 **대상 서비스와 직접 상호작용**하는 기법을 다룸. 현장에서 노릴 서비스는 무수히 많고 Active Directory 처럼 별도 모듈에서 다루는 것도 있음. 여기서는 흔한 능동 기법 — 포트 스캐닝과 DNS·SMB·SMTP·SNMP 열거 — 을 살펴봄.

기본은 로컬 Kali 에 미리 깔린 도구로 수행하는 것임. 그러나 침투 테스트 중에는 **좋아하는 Kali 도구를 쓸 여유가 없는 경우**가 있음. 고객이 Windows 워크스테이션을 내주는 가정 침해(assumed breach) 시나리오에서는 Windows 에 있는 것으로 해결해야 함.

이때 「Living off the Land」로 미리 설치돼 신뢰받는 Windows 바이너리를 침해 후 분석에 활용함. 이런 바이너리를 LOLBins, 최근에는 스크립트·라이브러리까지 포함해 **LOLBAS** 로 줄여 부름.

⚠️ 엄밀히는 LOLBAS 가 **설계 의도와 다른 방식으로** 바이너리를 쓰는 것을 가리킴. 이 모듈에서는 정의를 느슨하게 잡아 표준 Windows 바이너리를 「있는 그대로」 써서 정보를 수집하는 것까지 포함함.
