# 11.3.3 복제본 다듬기

> **Cleaning Up the Clone** · PEN-200 §11.3.3

복제본에는 원본에 없는 흔적이 남음. 발송 전에 지울 것.

첫째는 §11.3.2 에서 본 CSRFGuard 경고임. 추적 순서는 **문자열 → 그것을 담은 파일 → 그 파일을 부르는 페이지**임. 경고 문구를 그대로 grep 함.

```
kali@kali:~/ZoomSignin$ grep "OWASP" *
csrf_js: * The OWASP CSRFGuard Project, BSD License
csrf_js: *    3. Neither the name of OWASP nor the names of its contributors may be
used
csrf_js:                    this.setRequestHeader("X-Requested-With", "OWASP CSRFGuard
Project");
csrf_js:        alert("OWASP CSRFGuard JavaScript was included from within an
unauthorized domain!");
```

*경고 문구가 `csrf_js` 파일에서 나옴*

경고는 `csrf_js` 에 있음. 이어서 그 파일을 임포트하는 쪽을 찾음.

```
kali@kali:~/ZoomSignin$ grep "csrf_js" *
csrf_js:        xhr.open("POST",
"/csrf_js"+(typeof(resourceAccountIdRoutingURl)!="undefined"?"?"+resourceAccountIdRout
ingURl:""), false);
csrf_js:            xhr.open("POST",
"/csrf_js"+(typeof(resourceAccountIdRoutingURl)!="undefined"?"?"+resourceAccountIdRout
ingURl:""), false);
signin.html:<script nonce="Sxwi1J4PRJSzTs4fu1bzvQ" src="csrf_js"></script>
signin.orig:<script nonce="Sxwi1J4PRJSzTs4fu1bzvQ" src="/csrf_js"></script>
```

*`csrf_js` 를 부르는 곳 — 렌더되는 진입점은 `signin.html` 임*

여러 파일에 이름이 나오지만 실제로 렌더되는 진입점은 `signin.html` 하나임. 그 `<script>` 줄을 지우고 다시 열면 경고가 사라짐.

둘째는 **`zoom.us` 를 그대로 가리키는 잔여 임포트**임. 그런 요청은 피해자 브라우저에서 진짜 Zoom 서버로 나가므로, 캠페인의 존재가 상대 쪽 로그에 남고 의심을 삼. 은밀성을 위해 남은 외부 참조를 훑어 줄여야 함 — 교재는 이 단계를 건너뛰지만 실전에서 생략하면 안 되는 부분임.
