# 22.4 Active Directory 자동화 열거

> **Active Directory - Automated Enumeration** · PEN-200 §22.4

학습 목표 둘 — SharpHound 로 도메인 데이터를 수집하고, BloodHound 로 분석하는 것.

수동 열거는 시간이 들고 정보량이 많아 정리하기 어려움. 개념 이해에는 반드시 거쳐야 하지만, 특히 대규모 환경에서는 자동화 도구가 열거를 앞당기고 공격 경로를 빠르게 드러냄. 실무에서는 대개 둘을 섞어 씀.

PingCastle 처럼 보기 좋은 보고서를 내는 도구도 있으나 상용 이용에는 유료 라이선스가 필요함. 여기서는 무료인 BloodHound 를 씀.

함정 — 자동화 도구는 네트워크 트래픽을 대량으로 만들어내므로 관리자가 트래픽 급증을 알아챌 가능성이 높음.
