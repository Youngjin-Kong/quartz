# 9.3 파일 업로드 취약점

> **File Upload Vulnerabilities** · PEN-200 §9.3

학습 목표 — 파일 업로드 취약점의 이해, 식별 방법, 익스플로잇 벡터의 종류.

파일 업로드 기능은 다수의 웹 애플리케이션이 제공함. 이 취약점은 크게 세 부류로 나뉨.

**첫째, 웹 애플리케이션이 «실행할 수 있는» 파일을 올릴 수 있는 경우.** PHP 가 활성화된 웹 서버에 PHP 스크립트를 올릴 수 있으면 브라우저나 `curl` 로 접근하는 것만으로 실행됨. 파일 인클루전 단위에서 본 것처럼 PHP 외의 프레임워크·서버측 스크립트 언어에서도 같은 부류가 성립함.

**둘째, 다른 취약점과 «결합»해야 성립하는 경우.** 애플리케이션에 디렉터리 탐색 취약점이 함께 있으면 업로드 요청에 상대 경로를 넣어 `authorized_keys` 같은 파일을 덮어쓸 수 있음. XXE(XML External Entity)나 XSS 와의 결합도 가능함 — 프로필 아바타를 SVG 로 올릴 수 있으면 SVG 안에 XXE 공격을 심어 파일 내용을 표시하거나 코드를 실행시킬 수 있음.

**셋째, 사용자 상호작용에 의존하는 경우.** 채용 지원서 업로드 폼을 찾았다면 악성 매크로를 넣은 `.docx` 이력서를 올리는 식임. 누군가 그 파일을 열어야만 성립하므로 이 단위에서는 앞의 두 부류에 집중함.
