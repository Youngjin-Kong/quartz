# 13.3.2 SearchSploit

> **SearchSploit** · PEN-200 §13.3.2

Exploit Database 는 올려 둔 익스플로잇 코드 전체를 아카이브 형태로 내려받을 수 있게 제공하고, Kali 에는 `exploitdb` 패키지로 기본 포함돼 있음. **평가 시작 전에 갱신할 것** — 로컬 사본이 낡으면 최신 익스플로잇을 아예 못 찾음.

```
kali@kali:~$ sudo apt update && sudo apt install exploitdb
[sudo] password for kali:
...
The following packages will be upgraded:
  exploitdb
...
Setting up exploitdb (20220526-0kali1) ...
...
```

*exploitdb 패키지 갱신*

아카이브는 `/usr/share/exploitdb/` 아래에 풀리고, `exploits` 와 `shellcodes` 두 갈래로 나뉨. 같은 위치의 CSV 파일 두 개가 각 디렉터리에 든 파일 정보를 담고 있으며, EDB-ID·제목·작성자·플랫폼 등 사이트에서 보던 것과 같은 항목이 들어 있음.

```
kali@kali:~$ ls -1 /usr/share/exploitdb/
exploits
files_exploits.csv
files_shellcodes.csv
shellcodes
```

*아카이브 최상위 구성*

`exploits` 아래는 OS·아키텍처·스크립트 언어 등으로 하위 디렉터리가 갈림(`linux`, `windows`, `php` 등).

```
kali@kali:~$ ls -1 /usr/share/exploitdb/exploits
aix
alpha
android
arm
ashx
asp
aspx
atheos
beos
bsd
bsd_x86
cfm
cgi
freebsd
freebsd_x86
...
```

*`exploits` 아래 하위 디렉터리 — 끝의 `...` 는 교재 자신의 생략 표기임*

양이 워낙 많아 손으로 뒤지는 것은 현실적이지 않음. 그 검색을 담당하는 것이 `searchsploit` 이고, 인자 없이 실행하면 사용법이 출력됨.

```
kali@kali:~$ searchsploit
  Usage: searchsploit [options] term1 [term2] ... [termN]
...
```

*인자 없이 실행했을 때 나오는 사용법 첫 줄*

사용 예시는 다음과 같음.

```
==========
 Examples
==========
  searchsploit afd windows local
  searchsploit -t oracle windows
  searchsploit -p 39446
  searchsploit linux kernel 3.2 --exclude="(PoC)|/dos/"
  searchsploit -s Apache Struts 2.0.0
  searchsploit linux reverse password
  searchsploit -j 55555 | json_pp
  For more examples, see the manual: https://www.exploit-db.com/searchsploit
```

*searchsploit 사용 예시*

기본 검색은 대소문자를 무시하고, 용어 순서를 따지지 않으며, 버전 범위까지 매칭함 — 그래서 **오탐이 잘 생김.** 옵션은 그 범위를 좁히거나 출력 형식을 바꾸는 데 씀.

```
=========
 Options
=========
## Search Terms
   -c, --case     [Term]      Perform a case-sensitive search (Default is inSEnsITiVe)
   -e, --exact    [Term]      Perform an EXACT & order match on exploit title (Default
is an AND match on each term) [Implies "-t"]
                                e.g. "WordPress 4.1" would not be detect "WordPress
Core 4.1")
   -s, --strict               Perform a strict search, so input values must exist,
disabling fuzzy search for version range
                                e.g. "1.1" would not be detected in "1.0 < 1.3")
   -t, --title    [Term]      Search JUST the exploit title (Default is title AND the
file's path)
       --exclude="term"       Remove values from results. By using "|" to separate,
you can chain multiple values
                                e.g. --exclude="term1|term2|term3"
## Output
   -j, --json     [Term]      Show result in JSON format
   -o, --overflow [Term]      Exploit titles are allowed to overflow their columns
   -p, --path     [EDB-ID]    Show the full path to an exploit (and also copies the
path to the clipboard if possible)
   -v, --verbose              Display more information in output
   -w, --www      [Term]      Show URLs to Exploit-DB.com rather than the local path
       --id                   Display the EDB-ID value rather than local path
       --colour               Disable colour highlighting in search results
...
```

*searchsploit 옵션*

사용법 끝의 Notes 절이 기본 검색 동작과 각 옵션을 언제 쓰는지 정리해 둠 —

```
=======
 Notes
=======
 * You can use any number of search terms
 * By default, search terms are not case-sensitive, ordering is irrelevant, and will
search between version ranges
   * Use '-c' if you wish to reduce results by case-sensitive searching
   * And/Or '-e' if you wish to filter results by using an exact match
   * And/Or '-s' if you wish to look for an exact version match
 * Use '-t' to exclude the file's path to filter the search results
   * Remove false positives (especially when searching using numbers - i.e. versions)
 * When using '--nmap', adding '-v' (verbose), it will search for even more
combinations
 * When updating or displaying help, search terms will be ignored
```

*Notes 절 — `-c`·`-e`·`-s`·`-t` 의 사용 시점이 여기 적혀 있음*

버전 번호로 검색할 때 특히 오탐이 심한데, `-t` 로 파일 경로를 빼고 제목만 검색하면 상당수가 걸러짐. 실제 검색은 `searchsploit remote smb microsoft windows` 처럼 서비스·OS·유형을 나열해 던지면 됨.

*검색 결과 형태 — 제목과 로컬 경로가 `|` 로 갈림 (원문 출력의 앞 33행)*

쓰기로 정한 익스플로잇은 `-m` 으로 현재 작업 디렉터리에 복사함. **원본을 그 자리에서 수정하면 안 되는 이유** — `exploitdb` 패키지가 새로 나오면 로컬 익스플로잇이 전부 덮어써져 수정분이 사라짐. 복사본으로 작업하면 어떤 시스템에 어떤 익스플로잇을 썼는지 정리하기도 쉬움. 대상은 경로로도 EDB-ID 로도 지정할 수 있음.

```
kali@kali:~$ searchsploit -m windows/remote/48537.py
  Exploit: Microsoft Windows - 'SMBGhost' Remote Code Execution
      URL: https://www.exploit-db.com/exploits/48537
     Path: /usr/share/exploitdb/exploits/windows/remote/48537.py
File Type: Python script, ASCII text executable, with very long lines (343)
Copied to: /home/kali/48537.py
kali@kali:~$ searchsploit -m 42031
  Exploit: Microsoft Windows 7/2008 R2 - 'EternalBlue' SMB Remote Code Execution
(MS17-010)
      URL: https://www.exploit-db.com/exploits/42031
     Path: /usr/share/exploitdb/exploits/windows/remote/42031.py
File Type: Python script, ASCII text executable
Copied to: /home/kali/42031.py
```

*앞은 경로로, 뒤는 EDB-ID 로 복사한 것*
