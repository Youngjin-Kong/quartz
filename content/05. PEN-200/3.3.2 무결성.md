# 3.3.2 무결성

> **Integrity** · PEN-200 §3.3.2

시스템이 무결성을 갖는다는 것은 저장된 정보와 기능이 «소유자가 의도한 것뿐»이라는 뜻임. 데이터와 서비스의 정확성·신뢰성 유지가 관심사임.

기밀성과의 경계 — 비밀번호를 추측해 «로그인만» 한 것은 무결성 공격이 아니고, 공격자가 글을 올리거나 정보를 삭제하기 시작하면 그 시점부터 무결성 공격이 됨. 흔한 공격 수단은 임의 코드 실행(arbitrary code execution).

**WhisperGate 사례(2022년 1월)** — 우크라이나 표적에 사용된 신종 와이퍼(wiper) 악성코드. 2단계 구조임.

1. MBR(Master Boot Record)을 덮어써 «가짜» 랜섬웨어 노트를 표시
2. 추가 악성코드를 내려받아 특정 확장자 파일들을 덮어써 복구 불가 상태로 만듦

파일을 복구 불가능하게 덮어써 사실상 삭제하는 것이라 데이터 «무결성»을 직접 침해함.

Microsoft 권고 — MFA 로 자격 증명 탈취 영향 완화, Microsoft Defender 의 CFA(Controlled Folder Access) 활성화로 MBR/VBR 변조 차단, 제공된 IoC 로 침해 탐색, 모든 원격 접근의 인증 활동 검토, 이상 활동 조사. 기술적 세부는 CrowdStrike 가 공개함.

무결성이 기업에 중요한 이유 — 다른 기업과 소비자가 그 기업이 보유한 정보를 «신뢰»할 수 있어야 하기 때문임.
