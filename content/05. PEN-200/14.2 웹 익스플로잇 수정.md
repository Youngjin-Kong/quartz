# 14.2 웹 익스플로잇 수정

> **Fixing Web Exploits** · PEN-200 §14.2

- 학습 목표 둘 — 웹 익스플로잇 수정, 흔한 문제 해결.
- 웹 취약점은 메모리 손상을 일으키는 일이 드물어 DEP·ASLR 같은 OS 보호기제의 영향을 안 받음 — 그만큼 고쳐 쓰기가 수월함.
- 그럼에도 파급은 큼 — DB 정보 유출이나 시스템 완전 장악까지 이어짐.
