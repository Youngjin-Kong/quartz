# 8.3 웹 애플리케이션 열거

> **Web Application Enumeration** · PEN-200 §8.3

학습 목표 — 웹 애플리케이션 소스 코드 디버깅 · 헤더·쿠키·소스 코드 열거와 검사 · API 테스트 방법론 습득.

앞 모듈에서 본 수동 정보 수집은 웹 애플리케이션 매핑에서 특히 값이 큼 — 공개 저장소나 Google dork 가 민감 정보를 흘리는 경우가 있음. 유출된 자격 증명이든 단순한 애플리케이션 문서든, **능동 테스트 중에도 수동 수집분을 계속 참조할 것.** 거기서 아직 안 밟아 본 경로가 나옴.

무작정 익스플로잇하기 전에 **애플리케이션을 이루는 구성 요소를 먼저 식별**해야 함. 웹 취약점 상당수는 기술과 무관하게 성립하지만, 일부 익스플로잇과 페이로드는 DB 소프트웨어나 OS 같은 기저 기술에 맞춰 만들어야 하기 때문임.

기술 스택은 보통 **호스트 OS · 웹 서버 소프트웨어 · DB 소프트웨어 · 프론트엔드/백엔드 언어**로 구성됨. 앞서 익힌 방법으로 스택을 열거한 뒤 애플리케이션 열거로 넘어감.

애플리케이션 정보는 브라우저에서 직접 캘 수 있음. 최신 브라우저는 대부분 개발자 도구를 내장하는데, 이름과 달리 공격자에게도 유용함 — **대상 애플리케이션의 내부 동작**을 그대로 보여주기 때문임. 이 과정은 Kali 기본 브라우저인 Firefox 기준으로 다루지만 다른 브라우저에도 비슷한 도구가 있음.
