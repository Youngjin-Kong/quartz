# 21 Metasploit Framework

> **The Metasploit Framework** · PEN-200 §21

이 모듈이 다루는 학습 단위 — Metasploit 기본 다루기 · 페이로드 활용 · 포스트 익스플로잇 · 자동화.

앞선 모듈들에서 공개 익스플로잇을 다루며 드러난 문제 — 시나리오마다 코드를 고쳐야 하고, 악성 코드가 섞였는지 검사해야 하며, 명령행 문법·언어·코딩 관례가 익스플로잇마다 제각각이라 표준이 없음. 가장 기본적인 공격에서도 포스트 익스플로잇 도구·보조 도구·기법을 매번 따로 골라야 함.

익스플로잇 프레임워크는 이 문제들을 통합·간소화하려는 시도임. 형태와 기능은 제각각이나 목표는 공통임 — 다양한 익스플로잇을 모아 두고, 사용법을 단순화하고, 측면 이동을 쉽게 하고, 장악한 인프라의 관리를 돕는 것.

**동적 페이로드(dynamic payload)가 핵심 이점임** — 프레임워크에 든 익스플로잇마다 배포할 페이로드를 골라 끼울 수 있음. 익스플로잇과 페이로드가 분리돼 있어야 성립하는 구조임.

주요 프레임워크는 Metasploit · Covenant · Cobalt Strike · PowerShellEmpire 임. Cobalt Strike 같은 상용 제품과 달리 **Metasploit Framework(MSF)는 오픈소스이고 갱신이 잦아** 이 모듈의 대상임.

Rapid7 이 유지보수하며 저자들은 "익스플로잇 코드를 개발·테스트·사용하는 고급 플랫폼"으로 설명함. 처음에는 이식형 네트워크 게임으로 출발했으나 침투 테스트·익스플로잇 개발·취약점 연구 도구로 발전했고, 보안 감사자용 무료 익스플로잇 수집·개발 프레임워크의 대표가 됨. Kali Linux 에는 `metasploit-framework` 패키지로 오픈소스 구성요소가 기본 포함돼 있음.

정보 수집, 취약점 연구·개발, 클라이언트 사이드 공격, 포스트 익스플로잇까지 범위가 넓어 처음에는 압도되기 쉬움. 다만 인터페이스가 일관되게 설계돼 있어 구조를 잡고 접근하면 길을 잃지 않음.

이 모듈의 목표는 도구 사용법 암기가 아니라 **이런 프레임워크가 실제 침투 테스트에서 무엇을 대신해 주는지 이해하는 것**임. Metasploit 을 다루지만 개념 상당수는 다른 프레임워크에도 그대로 통함.
