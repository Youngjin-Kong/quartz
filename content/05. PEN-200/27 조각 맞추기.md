# 27 조각 맞추기

> **Assembling the Pieces** · PEN-200 §27

개별 기법을 모두 다룬 뒤 그것들을 하나의 침투 테스트로 이어 붙이는 실전 워크스루임. PEN-200 모듈과 챌린지 랩 사이의 다리 역할이라 「챌린지 랩 0」으로 보면 됨. 머신을 먼저 켜고 스스로 뚫어 본 뒤 여기 적힌 방법론과 서사를 읽는 방식도 가능하며, 어느 쪽이든 이 사고방식을 챌린지 랩 1~6 에 그대로 가져갈 것을 권함.

시나리오 — 고객사 BEYOND Finances 의 IT 인프라가 대상임. 고객의 관심사는 「공격자가 경계를 뚫고 내부 Active Directory 에서 도메인 관리자 권한까지 갈 수 있는가」이고, 따라서 이번 평가의 목표는 도메인 관리자 권한 획득과 도메인 컨트롤러 접근임.

목표는 고객마다 다름. 위협 수준·데이터 인프라·비즈니스 모델에 따라 갈리며, 예컨대 데이터 보관이 주 사업인 고객이면 그 데이터 확보 자체가 목표가 됨 — 그런 침해가 사업에 가장 큰 타격이어서임. 대부분의 환경에서 도메인 관리자 권한이 그 목표에 이르는 경로이긴 하나 항상 그렇지는 않음.

다루는 학습 단위 — 공개 네트워크 열거 · 공개 머신 공격 · 내부 네트워크 접근 획득 · 내부 네트워크 열거 · 내부 웹 애플리케이션 공격 · 도메인 컨트롤러 접근 획득.

시뮬레이션 특성상 결과가 나오지 않을 단계는 시간을 아끼려 생략되며, 생략하는 지점마다 원문이 그 사실을 명시함.
