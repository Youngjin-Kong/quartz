# 28.3.3 Metasploit 사용 - 챌린지 랩과 시험

> **Metasploit Usage: Challenge Labs vs Exam** · PEN-200 §28.3.3

챌린지 랩, 특히 0~3 에서는 Metasploit 사용이 권장됨 — 기능 전반을 익혀둘 것.

**OSCP 인증 시험에서는 Metasploit 사용이 제한되나** 학습 단계에 임의의 제약을 걸지는 말 것 — 4~6 초회 탐색에 한해 «일시적으로» 걸어보는 정도. 상세 규정은 OSCP exam guide 참조.
