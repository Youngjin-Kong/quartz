# 22.2 Active Directory 수동 열거

> **Active Directory - Manual Enumeration** · PEN-200 §22.2

목표는 둘 — 레거시 Windows 애플리케이션으로 AD 를 열거하는 것, 그리고 PowerShell 과 .NET 으로 열거를 더 밀어붙이는 것.

순서는 얻기 쉬운 것부터임. Windows 에 이미 깔려 있는 도구로 빠르게 걷을 수 있는 정보를 먼저 훑고, 이후 PowerShell 로 .NET 클래스를 호출해 LDAP 으로 AD 와 직접 통신하는 쪽으로 넘어감.
