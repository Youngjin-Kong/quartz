# 27.1.2 WEBSRV1

> **WEBSRV1** · PEN-200 §27.1.2

이름으로 보아 웹 서버로 추정되는 두 번째 대상임. 실제 평가라면 MAILSRV1 과 동시에 스캔해 고객의 시간을 아낌 — 단 결과가 섞이거나 발견을 놓치지 않도록 구조를 잡고 진행해야 함.

```
kali@kali:~/beyond$ sudo nmap -sC -sV -oN websrv1/nmap 192.168.50.244
Starting Nmap 7.92 ( https://nmap.org ) at 2022-09-29 11:18 EDT

*WEBSRV1 스캔 결과 — 22·80 두 포트, 그리고 `http-generator` 줄이 WordPress 6.0.2 를 그대로 뱉음*

열린 포트는 22(OpenSSH 8.9p1 Ubuntu 3)와 80(Apache httpd 2.4.52 (Ubuntu), WordPress 6.0.2) 둘뿐임.

배너를 그냥 읽고 넘기지 말 것 — `OpenSSH 8.9p1 Ubuntu 3` 문자열을 검색하면 Ubuntu Launchpad 의 OpenSSH 버전↔릴리스 대응표가 나오고, 이 버전이 Jammy Jellyfish 곧 Ubuntu 22.04 에 매핑됨. 배너 한 줄에 수동 작업을 조금 더해 OS 세부 버전까지 좁힌 것임.

22 번은 지금 할 수 있는 것이 비밀번호 공격뿐인데 사용자명도 비밀번호도 없으므로 뒤로 미룸. 따라서 80 번을 먼저 팜. Apache 2.4.52 의 취약점 검색도 성과가 없어 생략함.

랜딩 페이지는 평범한 회사 소개 페이지이고 메뉴바도 다른 페이지 링크도 없어 겉으로는 건드릴 것이 없음. 이럴 때는 소스 보기(View Page Source)로 헤더·주석·링크를 훑음 — 대부분의 프레임워크와 CMS 는 소스에 흔적 문자열을 남김.

*페이지 소스 하단 링크에 `wp-content`·`wp-includes` 가 보임 — WordPress 판정의 근거*

```
kali@kali:~/beyond$ whatweb http://192.168.50.244
http://192.168.50.244 [301 Moved Permanently] Apache[2.4.52], Country[RESERVED][ZZ],
HTTPServer[Ubuntu Linux][Apache/2.4.52 (Ubuntu)], IP[192.168.50.244],
RedirectLocation[http://192.168.50.244/main/], UncommonHeaders[x-redirect-by]
http://192.168.50.244/main/ [200 OK] Apache[2.4.52], Country[RESERVED][ZZ], HTML5,
HTTPServer[Ubuntu Linux][Apache/2.4.52 (Ubuntu)], IP[192.168.50.244], JQuery[3.6.0],
MetaGenerator[WordPress 6.0.2], Script, Title[BEYOND Finances &#8211; We provide
financial freedom], UncommonHeaders[link], WordPress[6.0.2]
```

whatweb 이 WordPress 6.0.2 를 확인해 줌. 이 버전은 2022년 8월 릴리스로 작성 시점 최신판이고 코어는 패치가 빠름. 반면 테마와 플러그인은 커뮤니티가 작성해 패치가 부실하거나 아예 안 되는 경우가 많음 — 그래서 노릴 지점은 코어가 아니라 그쪽임.

WPScan 으로 그 구성요소를 훑음. `--url` 에 대상, 플러그인 탐지를 aggressive 로, `--enumerate` 에 `p` 를 줘 인기 플러그인 전수 열거, `-o` 로 결과 저장. 취약점 조회는 WordPress Vulnerability Database 를 참조하므로 API 토큰이 필요하고(계정 등록 시 제한된 무료 키 발급), 토큰이 없어도 열거 도구로는 충분히 쓸 만함.

```

detection aggressive -o websrv1/wpscan

*WPScan 플러그인 열거 결과 — 활성 플러그인 6개 중 duplicator 만 `[!] The version is out of date` 로 잡히고 `Version: 1.3.26 (80% confidence)` 까지 확정됨. 블록 안의 `...` 은 교재 자신의 생략 표시이고, 명령의 `--plugins-detection` 은 지면 폭 때문에 두 줄로 나뉜 것임*

나머지는 최신이거나(contact-form-7 · elementor · wordpress-seo) 버전 판정 자체가 안 됐으므로(akismet), 버전이 잡히면서 동시에 구버전인 유일한 항목인 duplicator 부터 봄. 취약점 조회는 API 토큰이 필요한 WPScan 의 DB 대신 searchsploit 을 씀.

이 버전에 걸리는 항목이 둘 — `php/webapps/50420.py`(Unauthenticated Arbitrary File Read)와 `php/webapps/49288.rb`(같은 취약점의 Metasploit 모듈)임.

정리 — WEBSRV1 은 Ubuntu 22.04, 포트 22·80 개방, 80 번에 WordPress 6.0.2 구동. 구버전 Duplicator 플러그인에 버전이 일치하는 익스플로잇 두 건 확보.
