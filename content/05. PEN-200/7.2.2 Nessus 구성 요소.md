# 7.2.2 Nessus 구성 요소

> **Nessus Components** · PEN-200 §7.2.2

- 첫 로그인 시 대상 입력을 권하는 환영 창이 뜨지만 그냥 닫아도 됨. Essentials 판의 대시보드 탭은 Scans 와 Settings 둘.
- Settings — 애플리케이션 설정. 결과를 메일로 받으려면 SMTP 서버 정보를 넣음. advanced 메뉴에서 UI·스캔·로그 동작부터 보안·성능 관련 항목까지 전역 설정을 다룸. About 메뉴는 Nessus 기본 정보와 라이선스, «남은 호스트 수»를 보여 줌.
- Scan 탭 → Policies — 정책은 Nessus 스캔 맥락에서 미리 정해 둔 설정 묶음임. 저장해 두면 새 스캔의 템플릿으로 쓸 수 있음.
- Scan Templates 는 Discovery·Vulnerabilities·Compliance 세 범주로 묶임. Compliance 범주와 Mobile Device Scan 템플릿은 기업판 전용임.
  - Discovery 범주의 유일한 템플릿은 Host Discovery — 살아 있는 호스트와 열린 포트 목록을 만드는 용도.
  - Vulnerabilities 범주에는 PrintNightmare·Zerologon 같은 개별 취약점(군) 템플릿과 Web Application Tests·Malware Scans 같은 일반 점검 영역 템플릿이 있음.
- 범용 취약점 스캔 템플릿 셋:
  1. Basic Network Scan — 설정 대부분이 미리 잡힌 전체 스캔. 다양한 취약점을 탐지해 Nessus 가 권장하는 템플릿이며 설정 변경도 가능함.
  2. Advanced Scan — 사전 설정이 전혀 없음. 스캔을 전면 커스터마이즈하거나 특수한 요구가 있을 때 씀.
  3. Advanced Dynamic Scan — 역시 사전 설정이 없으며, Advanced Scan 과의 결정적 차이는 플러그인을 손으로 고를 필요 없이 «동적 플러그인 필터»를 설정한다는 점임.
- Nessus 플러그인은 NASL(Nessus Attack Scripting Language)로 작성된 프로그램으로, 취약점 탐지에 필요한 정보와 알고리즘을 담음. 각 플러그인은 용도별 플러그인 패밀리에 배속됨.
