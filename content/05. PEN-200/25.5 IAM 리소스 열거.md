# 25.5 IAM 리소스 열거

> **IAM Resources Enumeration** · PEN-200 §25.5

앞 유닛에서는 대상을 침해해 제공자 API 를 호출할 자격 증명을 얻은 공격자 시점을 세우고, 침해 환경의 발자국을 수집했음 — 어떤 계정·액세스 키를 쥐었는지 확인하고 그 접근 수준을 쟀음. 외부 탐색으로 얻은 정보와 합쳐 계정이 접근하는 서비스의 윤곽까지 잡은 상태.

이 유닛은 그다음 단계 — 대상에서 데이터를 더 걷는 작업임. 정해진 정답 절차는 없음. 무엇을 노릴지는 대상의 클라우드 환경과 제공자에 따라 달라짐. 여기서는 AWS 환경의 IAM 리소스를 열거하지만 전술·절차 자체는 다른 제공자에도 대체로 그대로 적용됨.

다루는 것 — 수동/자동 열거의 선택, IAM 리소스 열거, JMESPath 로 API 응답 처리, Pacu 자동 열거, 수집 데이터에서 인사이트 추출.
