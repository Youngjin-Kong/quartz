# 17.1 Windows 열거

> **Enumerating Windows** · PEN-200 §17.1

OS 버전·패치 수준·시스템 설정이 제각각이라 모든 대상은 고유함. 따라서 권한 상승의 출발점은 대상 시스템에 관한 정보를 어떻게 얻고 어떻게 활용하는가임. 이 모듈의 공격 벡터를 온전히 이해하려면 Windows 의 권한 구조와 접근 제어 메커니즘부터 익혀야 함.

기술적 공격 벡터로 상승을 노리는 것이 일반적이지만, 사용자와 시스템이 남겨둔 정보를 훑어보는 것만으로 충분한 경우도 잦음 — 사용자가 텍스트 파일에 비밀번호를 저장해두거나 Windows 가 PowerShell 에 입력된 비밀번호를 기록해두는 식임. 공격자에게는 이것이 상위 권한으로 이어지는 금맥이 됨.

학습 목표 — Windows 권한과 접근 제어 메커니즘 이해, 상황 파악(situational awareness) 확보, Windows 시스템에서 민감 정보 탐색, PowerShell 이 만들어낸 민감 정보 확보, 자동 열거 도구 숙지.

단위 진행 순서 — 권한·접근 제어의 동작 → 시스템의 상황 파악 기법(존재하는 사용자, 활성 네트워크 연결, 실행 중인 애플리케이션 등 대상에 관한 핵심 정보를 제공함) → 민감 정보를 찾을 수 있는 Windows 내 영역들 → 자동화 도구.
