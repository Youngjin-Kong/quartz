# 20 심층 패킷 검사 우회 터널링

> **Tunneling Through Deep Packet Inspection** · PEN-200 §20

심층 패킷 검사(deep packet inspection, DPI)는 규칙 집합에 따라 트래픽을 감시하는 기술임. 주로 네트워크 경계에 놓여 침해를 시사하는 패턴을 드러냄.

DPI 장비는 특정 전송 프로토콜만 드나들도록 설정될 수 있음. 관리자가 아웃바운드 `SSH` 를 끊는 규칙 하나만 걸어도 SSH 를 전송로로 쓰는 연결이 전부 실패함 — 앞 모듈에서 익힌 SSH 포트 리다이렉션과 터널링이 통째로 죽음.

걸릴 수 있는 제약이 다양하므로 터널링 도구와 전략을 여러 벌 갖춰야 함. 이 모듈은 포트 리다이렉션·SSH 터널링 모듈의 연장선이라 그쪽을 먼저 끝내고 볼 것.

학습 단위는 둘 — HTTP 터널링, DNS 터널링.
