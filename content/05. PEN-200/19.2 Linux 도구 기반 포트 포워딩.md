# 19.2 Linux 도구 기반 포트 포워딩

> **Port Forwarding with Linux Tools** · PEN-200 §19.2

포트 포워딩(port forwarding)은 이 모듈에서 가장 기본이 되는 기법이고, 공격이 아닌 일반 네트워킹에서도 흔히 쓰임. 호스트 하나를 특정 포트에서 listen 하게 하고, 그 포트로 들어온 패킷을 전부 다른 목적지로 중계하도록 구성하는 것임.

정상 운영에서의 예 — 방화벽 뒤에 있는 웹 서버를 외부에 열어주려고 방화벽의 한 인터페이스에서 포트를 열고 받은 패킷을 뒤쪽 웹 서버로 넘김. 가정용 공유기의 포트 포워딩도 같은 것으로, 인터넷 쪽 포트에서 받은 연결을 내부 장비로 넘김.
