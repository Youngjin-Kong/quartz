# 26.7 의존성 체인 악용

> **Dependency Chain Abuse** · PEN-200 §26.7

**의존성 체인 악용** — 의존성을 가로채거나 흉내 내어 빌드 시스템이 악성 코드를 내려받게 만드는 것.

같이 엮이는 OWASP 위험 —

- **파이프라인 접근 통제 미흡** — 과도한 권한이 붙어 시스템 장악으로 이어짐. 권한은 최소 범위로 좁힐 것
- **안전하지 않은 시스템 구성** — 오설정·취약한 코드에서 오는 결함
- **아티팩트 무결성 검증 부재** — 검사가 없어 악성 코드를 파이프라인에 밀어 넣을 수 있음

서로 겹치는 일반 지침 성격임.

모듈 후반의 흐름 — 누락된 의존성에 관한 공개 정보로 악성 패키지를 배포해 운영 환경에서 실행시킴 → 내부 네트워크 스캔으로 추가 서비스 발견 → 자동화 서버로 터널링해 계정 생성 + 플러그인 취약점으로 AWS 키 획득 → 그 키로 열거를 이어가 S3 버킷의 Terraform 상태 파일에서 관리자 AWS 키까지 확보.
