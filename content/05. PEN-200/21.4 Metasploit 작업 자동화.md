# 21.4 Metasploit 작업 자동화

> **Automating Metasploit** · PEN-200 §21.4

학습 목표 — resource 스크립트 작성, Metasploit 에서 활용.

Metasploit 이 여러 작업을 대신해 주지만, 프레임워크 «안에서» 되풀이하는 명령 자체는 스크립트로 묶어 더 자동화할 수 있음. 그것이 resource 스크립트임.
