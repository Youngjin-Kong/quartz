# 23.2 Active Directory 인증 공격 수행

> **Performing Attacks on Active Directory Authentication** · PEN-200 §23.2

- 학습 목표 다섯 — 패스워드 공격으로 자격 증명 획득, 활성화된 계정 옵션 악용, Kerberos SPN 인증 메커니즘 악용, 서비스 티켓 위조, 도메인 컨트롤러 사칭으로 임의 도메인 사용자 자격 증명 회수
- 앞 단위의 NTLM·Kerberos 인증과 캐시 위치를 전제로, 그 메커니즘을 겨냥한 공격을 다룸
- 기법은 서로 독립적으로 소개됨 — 침투 테스트의 서로 다른 국면에서 각각 쓰이기 때문임
- 대부분 Windows·Linux 양쪽 수행법을 함께 다룸 — 실제 평가 환경에 맞춰 고르기 위함임
