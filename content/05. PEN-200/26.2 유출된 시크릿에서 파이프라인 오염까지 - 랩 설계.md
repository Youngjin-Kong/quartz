# 26.2 유출된 시크릿에서 파이프라인 오염까지 - 랩 설계

> **Leaked Secrets to Poisoned Pipeline - Lab Design** · PEN-200 §26.2

SCM·자동화 서버·저장소 서비스·애플리케이션과 받침 인프라가 한꺼번에 떠야 하므로 **완전 기동까지 5~10분** 걸림 — 바로 안 붙는다고 실패로 보지 말 것.

보조 구성요소 둘:

- **DNS 서버** — 랩 안의 호스트가 미리 등록돼 있음. 본인 Kali 에 설정해 써야 함
- **공인 IP 가 붙은 Kali 인스턴스** — 클라우드 상의 애플리케이션을 치므로 셸을 받으려면 인터넷에서 닿는 리스너가 있어야 해서임. SSH 사용자명 `kali`, 비밀번호는 랩마다 무작위. `kali-linux-headless` 라 기본 도구는 다 있으나 **GUI 가 없음** → 브라우저가 필요한 작업은 본인 Kali 에서. DNS 는 이미 설정돼 있음

랩 구성요소:

- **Gitea** — SCM. 자체 호스팅형이지만 GitHub·GitLab 같은 공개 SCM 이어도 공격 방식은 비슷함
- **Jenkins** — 자동화 서비스. 워크플로 문법은 전용이나 개념은 다른 자동화 서비스에도 그대로 적용됨
- **Application** — 공격 대상 애플리케이션

커스텀 DNS 에 질의하면 아래 서브도메인으로 접근됨:

| 구성요소 | 서브도메인 |
|---|---|
| Gitea | git.offseclab.io |
| Jenkins | automation.offseclab.io |
| Application | app.offseclab.io |
