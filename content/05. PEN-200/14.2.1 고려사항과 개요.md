# 14.2.1 고려사항과 개요

> **Considerations and Overview** · PEN-200 §14.2.1

- 웹 익스플로잇에는 hex 인코딩 페이로드가 거의 없지만 코드를 제대로 읽어야 하는 것은 같음. 수정 전에 던질 질문이 정해져 있음.
- HTTP 로 붙는가 HTTPS 로 붙는가.
- 특정 웹 애플리케이션 경로나 라우트에 접근하는가.
- 인증 전(pre-authentication) 취약점을 노리는가. 아니라면 애플리케이션에 어떤 방식으로 인증하는가.
- 취약점을 유발·악용하는 GET·POST 요청의 구성은 어떠한가. 특정 HTTP 메서드가 걸려 있는가.
- 설치 후 바뀌었을 수 있는 기본 설정값(웹 경로 등)에 의존하는가.
- 자체 서명 인증서 같은 변수가 익스플로잇을 깨뜨리지 않는가.
- 공개 웹 익스플로잇은 `.htaccess` 나 WAF 같은 추가 방어를 고려하지 않음 — 저자가 개발 시점에 알 도리가 없어 범위 밖임.
