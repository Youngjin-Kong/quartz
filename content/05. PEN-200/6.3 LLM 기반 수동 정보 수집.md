# 6.3 LLM 기반 수동 정보 수집

> **LLM-Powered Passive Information Gathering** · PEN-200 §6.3

이 유닛의 학습 목표는 **LLM 지원 수동 열거** 하나임.

수동 정보 수집은 대상 시스템에 직접 접촉하지 않고 공개 데이터에서 인프라·인력·정책·기술 스택에 대한 실마리를 캐는 작업임. 대규모 언어 모델(LLM, Large Language Model)은 이 단계에서 이점이 큼 — 자연어 처리로 여러 출처의 방대한 비정형 데이터를 분석해, 수작업으로는 놓치기 쉬운 패턴과 연결을 드러냄. 소셜 미디어 링크, 관련 사내 정책, 조직 환경의 단서가 되는 직원의 IT 관련 게시글 같은 것을 추적하는 데 쓸 수 있음.

이 단계가 LLM 에 특히 잘 맞는 이유는 **다루는 것이 대부분 텍스트**이기 때문임 — LLM 은 텍스트로 학습하고 텍스트 처리에 특화돼 있어 거기서 가치 있는 정보를 뽑아내기에 적합함.

⚠️ 그만큼 한계와 위험도 함께 안고 감:

- **사실 검증이 아니라 데이터의 패턴에 근거해 응답을 생성**하므로 정보가 낡거나 부정확하거나 불완전할 수 있음. 중요한 정보는 언제나 신뢰할 수 있는 출처와 교차 확인할 것
- 맥락이 부족하면 질의를 오해할 수 있음. 기술적·전문적 주제에서 특히 중요함
- **민감 데이터를 넣지 말 것** — 특히 클라우드 기반 모델은 그것을 무심코 노출하거나 안전하지 않게 처리할 수 있음
- 학습 데이터에 있는 편향이 응답에 반영될 수 있어 중립성·포용성이 떨어질 수 있음
- 규제 분야에서는 법적·규제 기준 준수를 스스로 보장하지 못하므로 별도로 확인해야 함

⚠️ 다수의 온라인 LLM 은 입력 정보를 **소유 기업 쪽으로 전송**함. 따라서 이런 도구의 사용이 합의된 교전 범위 안에 드는지 고객에게 확인하는 것이 좋음 — 윤리적으로도 계약상으로도 그렇게 해야 함.
