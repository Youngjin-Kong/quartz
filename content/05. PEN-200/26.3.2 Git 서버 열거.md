# 26.3.2 Git 서버 열거

> **Enumerating the Git Server** · PEN-200 §26.3.2

Git 서버 열거 방식은 **호스팅형이냐 자체 호스팅이냐로 갈림.**

- GitHub·GitLab 같은 호스팅형 — 공개 저장소·사용자 등을 훑는 OSINT 위주. 그쪽 서비스 자체에 취약점이 있을 수는 있으나, 윤리적 평가에서는 **대상 조직이 소유한 자산만** 다루고 제3자는 건드리지 않음
- 자체 호스팅이고 범위 안이면 SCM 소프트웨어 자체를 익스플로잇하는 것도 평가 항목이 됨

노출된 저장소 정보 수집은 양쪽 모두 범위에 드는 것이 보통임. 반면 **흔한 비밀번호 브루트포싱은 호스팅형에서 무의미함** — 대상 조직과 무관한 사용자가 수십만 명이라서임. 자체 호스팅 SCM 에서는 사용자·계정명 브루트포싱이 평가 항목이 될 수 있음. 여기서는 공개 정보 수집만 다루고 브루트포싱은 연습 과제로 남김.

`git.offseclab.io` 방문 — 홈은 정보가 적고 Explore 와 Sign In 버튼만 있음. **아래로 스크롤하면 Gitea 버전이 노출됨** → 공개 익스플로잇 검색용으로 기록해 둘 것.

Explore 로 들어가면 Repositories 탭이 비어 있음. 저장소가 없다는 뜻이 아니라 **전부 비공개라는 뜻**으로 읽는 것이 맞음. Users 탭에는 다섯 명이 노출됨 — Billy, Jack, Lucy, Roger, administrator.
