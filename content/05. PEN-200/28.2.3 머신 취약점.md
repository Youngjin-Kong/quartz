# 28.2.3 머신 취약점

> **Machine Vulnerability** · PEN-200 §28.2.3

챌린지 안에는 «애초에 해킹하도록 설계되지 않은» 머신도 섞여 있음. 실제 현장에서 침투 테스터가 마주치는 머신 상당수가 (쉽게) 뚫리지 않기 때문에 그 현실을 반영한 것임. 다만 수는 최소로 유지돼 챌린지당 몇 대뿐임.

그런 머신에도 `local.txt` 또는 `proof.txt` 는 최소 하나 들어 있음. 즉 권한 상승 경로가 없는 머신은 있어도, 도메인 조인 여부와 무관하게 각 챌린지의 Domain Administrator 권한을 얻으면 모든 머신에 접근할 수 있음.

⚠️ **OSCP 유사 챌린지와 실제 OSCP 시험에는 이런 머신이 없음.** 시험의 모든 머신은 공략 가능하도록 설계돼 있고, 모든 머신에 권한 상승 벡터가 존재함.
