# 26.9.2 악성 패키지 제작

> **Creating Our Malicious Package** · PEN-200 §26.9.2

패키지 이름·임포트 이름·노려야 할 버전이 모두 확보됐으므로 이제 패키지를 만들어 `pypi.offseclab.io` 에 올릴 차례임. Python 패키지의 최소 구성은 디렉터리 둘 + 파일 둘임.

```
└── hackshort-util
    ├── setup.py
    └── hackshort_util
        └── __init__.py
```

*최소 구성 — 루트는 배포명(대시), 하위 모듈 디렉터리는 임포트명(밑줄)*

- `hackshort-util/` — 배포용 패키지 이름. PyPI 쪽 이름이라 대시가 허용됨
- `setup.py` — setuptools 로 빌드·배포·설치를 정의하는 설정 스크립트. `pyproject.toml` 이나 `setup.cfg` 로 대신할 수도 있음
- `hackshort_util/` — 임포트할 때 쓰이는 모듈 이름. Python 문법이 대시를 못 받아 밑줄로 바뀜
- `__init__.py` — 이 디렉터리가 Python 모듈임을 표시함. 네임스페이스 패키지면 없어도 되나 여기서는 일반 패키지라 필요함

먼저 아무것도 안 든 골격을 만들어 로컬 설치가 되는지부터 확인함.

```
kali@kali:~$ mkdir hackshort-util
kali@kali:~$ cd hackshort-util
kali@kali:~/hackshort-util$ nano setup.py
kali@kali:~/hackshort-util$ cat -n setup.py
01  from setuptools import setup, find_packages
02
03  setup(
04      name='hackshort-util',
05      version='1.1.4',
06      packages=find_packages(),
07      classifiers=[],
08      install_requires=[],
09      tests_require=[],
10  )
kali@kali:~/hackshort-util$ mkdir hackshort_util
kali@kali:~/hackshort-util$ touch hackshort_util/__init__.py
```

*골격 생성 — 디렉터리 구조보다 `setup.py` 가 실질적 본체임*

`setup()` 인자 중 공격에 직결되는 것 둘 —

- `name` — **PyPI 서버에서 참조되는 이름**이라 대상 패키지명과 정확히 일치해야 함. 임포트명이 아니므로 대시를 씀
- `version` — 설치 시점의 버전 비교에서 **로컬 저장소에 이미 설치된 것보다 높아야** 내려받아짐. ⚠️ 그렇다고 너무 높으면 요구 조건 범위를 벗어나 역시 안 받아짐. 그 사이를 노린 값이 1.1.4 임

`packages=find_packages()` 는 디렉터리 구조를 훑어 포함할 패키지를 자동으로 찾아줌. 여기까지가 오류 없이 빌드·사용되는 최소치임.

빌드는 `sdist` 인자로 함 — 패키지를 구성하는 파일 전부를 묶은 **소스 배포판**이 `dist/hackshort-util-1.1.4.tar.gz` 로 떨어짐. 설치 검증은 원격 저장소를 거치지 않고 그 파일 경로를 `pip install` 에 직접 넘겨서 함.

*로컬 `tar.gz` 를 경로로 직접 설치 — 저장소를 거치지 않고 빌드 결과물만 시험함*

⚠️ **임포트 테스트는 패키지 디렉터리 «밖에서» 할 것.** 현재 디렉터리에서 `import hackshort_util` 하면 설치본이 아니라 옆에 있는 소스 디렉터리가 잡힘. 새 터미널을 열어 홈에서 실행해야 `~/.local/lib/python3.11/site-packages/` 아래 설치본이 잡힘 — 빌드가 잘못 구성된 경우를 걸러내려면 항상 «빌드 결과»를 시험해야 함.

```
kali@kali:~$ python3
Python 3.11.2 [GCC 12.2.0] on linux
Type "help", "copyright", "credits" or "license" for more information.
>>> import hackshort_util
>>> print(hackshort_util)
<module 'hackshort_util' from '/home/kali/.local/lib/python3.11/site-
packages/hackshort_util/__init__.py'>
```

*임포트 확인 — `print` 로 드러난 경로가 `site-packages` 쪽이면 설치본이 잡힌 것임*

이어서 페이로드를 넣고 다시 설치할 것이므로 `pip uninstall` 로 제거해둠. 제거할 때 넘기는 것은 임포트명이 아니라 **패키지명(대시)**임.


*패키지 제거 — 다음 설치가 갱신본을 받도록 미리 지움*
