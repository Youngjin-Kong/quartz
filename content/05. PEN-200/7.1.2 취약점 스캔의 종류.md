# 7.1.2 취약점 스캔의 종류

> **Types of Vulnerability Scans** · PEN-200 §7.1.2

- 스캔을 «어디서» 수행하느냐가 대상 가시성을 결정함.
- 외부(external) 스캔 — 인터넷에서 접근 가능한 시스템을 분석함. 대상은 주로 웹 애플리케이션, DMZ 안의 시스템, 공개 서비스임. 목적은 외부 공격자가 닿을 수 있는 범위의 보안 상태를 훑는 것.
  - 보통 고객이 IP 목록을 주지만 외부 노출 자산을 직접 매핑해 달라는 경우도 있음. 회사가 자기 공개 자산을 늘 파악하고 있지는 않아, 고객이 모르는 노출 시스템·서비스를 발견하는 일이 잦음.
- 내부(internal) 스캔 — 내부망 전체나 일부에 직접 접근해 수행함. VPN 을 받거나 현장에서 진행함. 목적은 내부망의 보안 상태 파악이고, 특히 «경계를 뚫은 뒤» 공격자가 쓸 수 있는 벡터가 무엇인지를 보는 것.
- 비인증(unauthenticated) 스캔 — 자격 증명 없이 수행. 원격 접근 가능한 서비스의 취약점을 찾는 것이 목적이라, 열린 포트를 매핑해 취약점 DB 와 대조한 공격 표면을 줌. 반면 누락된 패치·구버전 소프트웨어·설정 취약점 같은 «로컬» 결함은 알 수 없음.
  - 예 — Windows 대상에 비인증 스캔을 걸어서는 비권한 사용자가 민감한 시스템 파일을 읽는 HiveNightmare 취약점의 패치 여부를 판단할 수 없음.
- 인증(authenticated) 스캔 — 대부분의 스캐너가 지원하며, 스캐너가 유효한 자격 증명으로 대상에 로그인함. 가시성을 최대로 하려고 대개 권한 있는 계정을 씀. 목적은 취약한 패키지, 누락된 패치, 설정 취약점 점검임.
