# 16.1 네트워크 서비스 로그인 공격

> **Attacking Network Services Logins** · PEN-200 §16.1

학습 목표 — SSH·RDP 로그인 공격, HTTP POST 로그인 폼 공격.

**브루트포스(brute-force)와 딕셔너리(dictionary) 공격의 차이가 이 유닛의 전제임.**

- **브루트포스** — 문자·숫자·특수문자의 모든 조합을 체계적으로 전수 시도함. 길이와 프로토콜에 따라 시간이 폭증하지만, 이론상 보호가 부실한 패스워드 인증은 **전부** 뚫림
- **딕셔너리** — 흔한 단어 목록(워드리스트)만 시도함. 빠른 대신 **정답이 목록에 없으면 무조건 실패함**

SSH·RDP·VNC 와 웹 로그인 폼은 공개 노출 시 **기동 몇 초 만에** 공격받을 만큼 표적이 됨. 이 유닛은 그중 딕셔너리 공격으로 유효 자격 증명을 찾는 쪽을 다룸.
