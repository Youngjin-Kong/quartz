# 28.2.1 클라이언트 사이드 시뮬레이션

> **Client-Side Simulations** · PEN-200 §28.2.1

내부 VPN 랩망에는 클라이언트 사이드 공격으로 공략 가능한 시뮬레이션 클라이언트가 다수 있음. 사내 사용자 활동을 흉내내며, 랩의 미묘한 힌트와 침해 후 정보 수집(클라이언트 간 통신)으로 위치를 찾음. 동작 주기는 제각각이나 **3분 간격이 가장 흔함**.
