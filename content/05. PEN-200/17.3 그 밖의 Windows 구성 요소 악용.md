# 17.3 그 밖의 Windows 구성 요소 악용

> **Abusing Other Windows Components** · PEN-200 §17.3

앞 유닛은 Windows 서비스에 붙은 권한 상승 벡터만 다뤘음. 악용 대상이 서비스뿐인 것은 아니어서, 이 유닛은 **예약 작업(Scheduled Tasks)** 과 **Windows 자체를 겨냥한 익스플로잇**으로 범위를 넓힘.

학습 목표 셋 —

- 예약 작업을 지렛대 삼아 권한을 올리는 법
- 권한 상승으로 이어지는 익스플로잇의 유형 구분
- 보유 권한(privilege)을 악용해 고권한 계정으로 코드를 실행하는 법
