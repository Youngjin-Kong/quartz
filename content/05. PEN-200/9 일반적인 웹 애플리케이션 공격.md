# 9 일반적인 웹 애플리케이션 공격

> **Common Web Application Attacks** · PEN-200 §9

이 모듈이 다루는 학습 단위 — 디렉터리 탐색(directory traversal), 파일 인클루전(file inclusion) 취약점, 파일 업로드 공격 취약점, 명령 주입(command injection).

숙련된 웹 개발자의 부족·프로젝트 일정 압박·빠르게 바뀌는 기술이 겹쳐, 특정 부류의 취약점이 광범위한 웹 애플리케이션에서 반복해 나타남. 기반 기술 스택과 무관하게 몇몇 공통 취약점이 다수의 운영 중인 애플리케이션에서 발견됨.

진행 순서 — 디렉터리 탐색과 파일 인클루전 → 실행 가능 파일과 실행 불가 파일을 이용한 파일 업로드 취약점 악용 → 명령 주입 공격.
