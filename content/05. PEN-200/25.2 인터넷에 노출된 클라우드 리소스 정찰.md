# 25.2 인터넷에 노출된 클라우드 리소스 정찰

> **Reconnaissance of Cloud Resources on the Internet** · PEN-200 §25.2

학습 목표는 둘 — 도메인·서브도메인 정찰 수행, 서비스별 도메인 식별.

NIST 의 클라우드 컴퓨팅 정의는 "구성 가능한 컴퓨팅 자원의 공유 풀에 언제 어디서나 편리하게 온디맨드로 네트워크 접근"하는 모델로 시작하고, 필수 특성으로 **광범위한 네트워크 접근(broad network access)** 을 둠. "언제 어디서나(ubiquitous)"·"편리한(convenient)" 이라는 표현과 이 특성이 맞물려, 클라우드 리소스에는 **공개 접근성이 내재적으로 따라붙음.**

이후 모델이 진화하면서 기본적으로 공개되지 않거나 애초에 공개용이 아닌 것들도 생김 — 네트워크 인터페이스, 가상 디스크 등. 인터넷을 향한 더 큰 리소스의 내부 구성요소지만 그 자체로 클라우드 리소스이고, 일부는 사용자 간 공유까지 됨.

따라서 공격자가 노리는 것은 둘임 — 공개적으로 접근 가능한 리소스, 그리고 **공개될 의도가 없었는데 대개 오설정으로 노출된 리소스.**

이 단위가 다루는 것은 **CSP API 와의 인증된 상호작용 없이** 공개망에서 클라우드 리소스를 찾아내는 기법임.
