# 5.1.4 알맞은 노트 도구 선택

> **Choosing the Right Note-Taking Tool** · PEN-200 §5.1.4

무료·유료 노트 도구가 매우 많아 계약에 맞는 도구를 고르려면 요구사항부터 파악해야 함. 정보를 어디에도 업로드하지 않고 로컬에만 두어야 하는 경우가 많아 일부 도구는 애초에 배제되고, 소스코드 비중이 큰 계약이면 코드 블록을 넣을 수 없는 도구는 부적합함. 바람직한 속성을 전부 열거하기는 어렵지만 중요한 것들:

- **Screenshots** — 스크린샷이 많이 필요하면 인라인 삽입이 되는 도구를 고를 것
- **Code blocks** — 빠르고 정확하게 읽히려면 서식이 필요함
- **Portability** — OS 를 넘나들며 쓰거나 다른 곳으로 쉽게 옮길 수 있어야 함
- **Directory Structure** — 도메인·애플리케이션이 여럿인 계약에서는 일관된 구조가 필수임. 수동 구성도 되지만 자동으로 잡아주는 도구가 편함

Sublime 은 표준 텍스트 에디터에 여러 기능을 더한 것으로, 가장 중요한 것은 유연한 구문 강조임 — 코드 블록을 넣으면 그 언어의 문법 규칙에 맞춰 강조됨. 다만 한 파일에서 두 언어를 강조할 수 없고, 작성 시점 기준으로 스크린샷 인라인 삽입도 불가함. 코드 종류가 하나인 계약이면 문제가 아니지만 그 외에는 다른 선택지를 볼 만함.

CherryTree 는 Kali 에 기본 포함돼 있고 노트 작성에 필요한 기능을 대부분 갖춤. 노트를 SQLite 데이터베이스에 저장하고 HTML·PDF·평문·CherryTree 문서로 내보낼 수 있으며, 내장 서식이 풍부하고 「node」와 「subnode」라 부르는 트리 구조로 문서를 보관함.

![[PEN200-Fig-010.png]]

*CherryTree 의 트리 구조로 정리한 침투 테스트 노트*

Obsidian 은 마크다운 에디터로 노트 작성에 필요한 기능을 모두 갖춤. snap 이나 Flatpak 으로 설치할 수 있고 AppImage 형태로도 제공돼, 복사한 뒤 실행 권한을 주고 실행하기만 하면 됨.

```
kali@kali:~$ wget https://github.com/obsidianmd/obsidian-
releases/releases/download/v0.14.2/Obsidian-0.14.2.AppImage
....
2022-03-31 15:38:53 (1.28 MB/s) - 'Obsidian-0.14.2.AppImage' saved
[113102744/113102744]
kali@kali:~$ chmod +x Obsidian-0.14.2.AppImage
kali@kali:~$ ./Obsidian-0.14.2.AppImage
```

*Obsidian AppImage 를 내려받아 실행*

실행하면 welcome 화면이 뜨고 거기서 Obsidian vault 를 열거나 새로 만들 수 있음. vault 는 시스템의 폴더이고 그 안에 마크다운 파일과 폴더를 만들 수 있음. 기능으로는 마크다운 라이브 프리뷰, 이미지 인라인 배치, 코드 블록, 커뮤니티가 만든 CSS 확장 같은 다수의 애드온이 있음.

![[PEN200-Fig-012.png]]

*마크다운으로 직접 입력하는 노트*

vault 는 다른 컴퓨터로 옮겨 welcome 메뉴에서 열 수 있고, 마크다운 파일을 vault 폴더에 넣기만 하면 자동 인식됨. 마크다운이라 대부분의 보고서 생성 도구로 서식이 그대로 복사되며 Obsidian 자체에서 PDF 를 뽑을 수도 있음.

도구 선택은 개인·상황에 달린 취향의 문제이고 완벽한 도구는 없음. 시간을 들여 직접 써 보고 문서를 읽어 익숙해진 뒤 정할 것을 권함. 추가 도구 목록은 nil0x42 의 웹사이트에서 참조할 수 있음.
