# 7.3.1 NSE 취약점 점검 스크립트

> **NSE Vulnerability Scripts** · PEN-200 §7.3.1

- Nessus 대신 NSE 로도 자동 취약점 스캔이 가능함. NSE 스크립트는 Nmap 의 기본 기능을 확장해 다양한 네트워크 작업을 수행하며, 취약점 탐지·무차별 대입·네트워크 발견 같은 용도로 범주가 묶임. 버전 탐지와 정보 수집 능력도 확장함.
- 한 스크립트가 여러 범주를 가질 수 있음 — safe + vuln 이거나 intrusive + vuln 인 식임. safe 는 안정성에 영향이 없고, intrusive 는 대상 서비스나 시스템을 죽일 수 있음.
- ⚠️ 그래서 스크립트가 어느 범주인지 «먼저» 확인할 것. 함의를 이해하지 못한 채 스크립트나 범주를 통째로 돌려서는 안 됨. 범주는 NSE 문서나 로컬 스크립트 디렉터리에서 확인함.
- Kali 의 NSE 스크립트는 `/usr/share/nmap/scripts/` 에 `.nse` 확장자로 있고, 같은 디렉터리의 `script.db` 가 전체 스크립트 색인임. 여기서 vuln 범주 목록을 뽑을 수 있음.

```
kali@kali:~$ cd /usr/share/nmap/scripts/
kali@kali:/usr/share/nmap/scripts$ cat script.db  | grep "\"vuln\""
Entry { filename = "afp-path-vuln.nse", categories = { "exploit", "intrusive", "vuln",
} }
Entry { filename = "broadcast-avahi-dos.nse", categories = { "broadcast", "dos",
"intrusive", "vuln", } }
Entry { filename = "clamav-exec.nse", categories = { "exploit", "vuln", } }
Entry { filename = "distcc-cve2004-2687.nse", categories = { "exploit", "intrusive",
"vuln", } }
Entry { filename = "dns-update.nse", categories = { "intrusive", "vuln", } }
...
```
*`script.db` 의 각 항목은 파일명과 범주로 이뤄짐*

- 표준 NSE 스크립트 중에는 낡은 것이 적지 않음. 대신 통합된 vulners 스크립트가 탐지된 서비스 버전에 대한 최신 취약점 정보를 Vulners Vulnerability Database 에서 가져옴. 이 스크립트의 범주는 safe·vuln·external 임.
- `--script` 파라미터가 어떤 스크립트를 실행할지 결정함. 인자로는 범주, 불리언 식, 쉼표로 구분한 범주 목록, `script.db` 안 스크립트의 전체 이름이나 와일드카드 이름, 특정 스크립트의 절대 경로를 받음.
- vuln 범주 전체를 돌리는 예 — `-sV` 로 서비스 탐지를 켜고 `-p` 로 443 만 봄.

```
kali@kali:~$ sudo nmap -sV -p 443 --script "vuln" 192.168.50.124
[sudo] password for kali:
Starting Nmap 7.92 ( https://nmap.org )
...
PORT    STATE SERVICE VERSION
443/tcp open  http    Apache httpd 2.4.49 ((Unix))
...
| vulners:
|   cpe:/a:apache:http_server:2.4.49:
...
        https://vulners.com/githubexploit/DF57E8F1-FE21-5EB9-8FC7-5F2EA267B09D
*EXPLOIT*
|       CVE-2021-41773 4.3 https://vulners.com/cve/CVE-2021-41773
...
|_http-server-header: Apache/2.4.49 (Unix)
MAC Address: 00:0C:29:C7:81:EA (VMware)
```
*vuln 범주 스크립트 실행 결과 — 출력 대부분이 vulners 스크립트에서 나옴*

- Nmap 이 Apache 2.4.49 를 탐지하고 vuln 범주 스크립트를 전부 시도한 결과임. vulners 는 탐지된 서비스·버전 정보를 바탕으로 CVE 와 CVSS 점수, 추가 정보 링크를 제시하며, 여기서는 대상이 CVE-2021-41773 에 취약함이 드러남.
- 유용한 점 하나 더 — 발견된 취약점의 PoC 를 `*EXPLOIT*` 표시로 함께 나열함.
- ⚠️ 단 서비스 탐지가 성공하지 못하면 vulners 는 아무 결과도 내놓지 않음.
