# 8.2 웹 애플리케이션 진단 도구

> **Web Application Assessment Tools** · PEN-200 §8.2

학습 목표 — 웹 애플리케이션 열거 기법 수행 · 웹 프록시 이론 이해 · Burp Suite 프록시의 동작 파악.

세부로 들어가기 전에 쓸 도구부터 익힘 — 웹 서비스 열거용 Nmap, 기술 스택을 알려주는 온라인 서비스 Wappalyzer, 파일·디렉터리 탐색 도구 Gobuster, 그리고 이후 모듈 내내 크게 의존할 Burp Suite 프록시.
