# 8.4 XSS

> **Cross-Site Scripting** · PEN-200 §8.4

학습 목표 — XSS 취약점 유형 이해 · 기본 XSS 익스플로잇 · XSS 를 통한 권한 상승.

잘 방어된 웹 애플리케이션의 핵심 기능 하나가 **데이터 새니타이즈(sanitization)** 임 — 입력에서 위험한 문자·문자열을 제거·변환하는 처리임. 새니타이즈되지 않은 데이터는 공격자가 악성 코드를 주입·실행할 여지를 줌.

XSS 는 **사용자가 웹사이트에 두는 신뢰를 악용**함 — 브라우저가 렌더링하는 페이지에 내용을 동적으로 주입함. 한때 저위험으로 여겨졌으나 지금은 다른 사용자가 방문하는 페이지에 JavaScript 같은 클라이언트 측 스크립트를 심는 **고위험·광범위** 취약점임.
