# 27.6.2 측면 이동

> **Lateral Movement** · PEN-200 §27.6.2

beccy 의 도메인 관리자 권한으로 도메인 컨트롤러 DCSRV1 에 접근 — 침투 테스트의 두 번째 목표 달성.

평문과 해시 둘 다 있으나 해시를 씀. `-hashes` 는 `<LM>:<NT>` 형식이라 LM 자리를 0 32개로 채움. psexec 는 쓰기 가능한 `ADMIN$` 에 실행 파일을 올린 뒤 서비스로 등록·기동해 SYSTEM 셸을 얻음.
