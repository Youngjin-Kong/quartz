# 26.3.1 Jenkins 열거

> **Enumerating Jenkins** · PEN-200 §26.3.1

대상은 애플리케이션·Git 서버·자동화 서버 셋. 먼저 자동화 서버 `automation.offseclab.io` 부터.

홈페이지가 로그인 페이지로 자동 리다이렉트됨. Jenkins 에 자체 가입(self-registration)이 켜져 있으면 여기에 등록 옵션이 보이는데 그것이 없음 → **자동화 자산 대부분이 인증 뒤에 있다**고 결론. 그래도 인증 없이 걷을 수 있는 것은 걷음.

Metasploit 의 Jenkins 열거 모듈로 기본선을 잡음. `sudo msfdb init` 로 DB 를 먼저 초기화함.

```
kali@kali:~$ sudo msfdb init
[+] Starting database
[+] Creating database user 'msf'
[+] Creating databases 'msf'
[+] Creating databases 'msf_test'
[+] Creating configuration file '/usr/share/metasploit-framework/config/database.yml'
[+] Creating initial database schema
```

*Metasploit DB 초기화 — 모듈을 쓰기 전에 한 번만 하면 됨*

`msfconsole --quiet` 로 배너 없이 띄운 뒤 `auxiliary/scanner/http/jenkins_enum` 을 선택하고 `show options` 로 설정 항목을 확인함.

```
kali@kali:~$ msfconsole --quiet
msf6 > use auxiliary/scanner/http/jenkins_enum
msf6 auxiliary(scanner/http/jenkins_enum) > show options
Module options (auxiliary/scanner/http/jenkins_enum):
   Name       Current Setting  Required  Description
   ----       ---------------  --------  -----------
   Proxies                     no        A proxy chain of format
type:host:port[,type:host:port][...]
   RHOSTS                      yes       The target host(s), see
https://docs.metasploit.com/docs/using-metasploit/basics/
                                         using-metasploit.html
   RPORT      80               yes       The target port (TCP)
   SSL        false            no        Negotiate SSL/TLS for outgoing connections
   TARGETURI  /jenkins/        yes       The path to the Jenkins-CI application
   THREADS    1                yes       The number of concurrent threads (max one per
host)
   VHOST                       no        HTTP server virtual host
View the full module info with the info, or info -d command.
```

*모듈 옵션 — 채울 것은 `RHOSTS` 와 `TARGETURI` 둘임*

**`TARGETURI` 기본값이 `/jenkins/` 인데 이 랩의 Jenkins 는 루트에서 돌므로 `/` 로 바꿔야 함** — 이걸 놓치면 아무것도 안 나옴.

```
msf6 auxiliary(scanner/http/jenkins_enum) > set RHOSTS automation.offseclab.io
RHOSTS => automation.offseclab.io
msf6 auxiliary(scanner/http/jenkins_enum) > set TARGETURI /
TARGETURI => /
```

```
msf6 auxiliary(scanner/http/jenkins_enum) > run
[+] 198.18.53.73:80      - Jenkins Version 2.385
[*] /script restricted (403)
[*] /view/All/newJob restricted (403)
[*] /asynchPeople/ restricted (403)
[*] /systemInfo restricted (403)
[*] Scanned 1 of 1 hosts (100% complete)
[*] Auxiliary module execution completed
```

인증에 막혀 나머지 스캔은 전부 403 이고 얻은 것은 **버전 2.385** 뿐임. 그래도 버전은 공개 익스플로잇을 검색할 근거가 되므로 소득임.

열거는 무한히 늘릴 수 있으나 한 대상에 시간을 몰지 말 것 — Git 서버로 넘어감.
