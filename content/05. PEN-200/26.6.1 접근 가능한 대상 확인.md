# 26.6.1 접근 가능한 대상 확인

> **Discovering What We Have Access To** · PEN-200 §26.6.1

권한 경계를 알아내는 길은 둘임. 계정 자신의 정보·정책을 조회하는 쪽이 쉬우나 **그 조회 권한이 있어야만** 통함. 모든 API 호출을 브루트포스해 성공한 것만 기록하는 방법도 있으나 소음이 매우 커서 피할 것.

먼저 확보한 키로 AWS 프로파일을 만듦 — `aws configure` 에 `--profile` 로 이름을 주고 키를 넣음. 리전은 지금까지 관측된 `us-east-1`, 출력 형식은 기본값.

```
kali@kali:~$ aws configure --profile=CompromisedJenkins
AWS Access Key ID [None]: [REDACTED-AWS-KEY-ID]
AWS Secret Access Key [None]: [REDACTED-AWS-SECRET]
Default region name [None]: us-east-1
Default output format [None]:
```

*탈취한 자격 증명을 `CompromisedJenkins` 프로파일로 등록*

이어서 `sts get-caller-identity` 로 내가 누구인지 확인함. 이후 모든 호출에 `--profile CompromisedJenkins` 를 붙여 탈취 자격 증명을 씀.

```
kali@kali:~$ aws --profile CompromisedJenkins sts get-caller-identity
{
    "UserId": "AIDAUBHUBEGILTF7TFWME",
    "Account": "274737132808",
    "Arn": "arn:aws:iam::274737132808:user/system/jenkins-admin",
}
```

*ARN 에서 사용자명이 `jenkins-admin` 임을 확인*

다음은 권한 범위임. ⚠️ 정책이 사용자에게 붙는 경로가 **셋**이라 하나만 봐서는 안 됨 — ①**인라인 정책**(단일 사용자 전용으로 직접 붙인 것) ②**사용자에 연결된 관리형 정책**(고객·AWS 관리형을 한 명 이상에게 붙인 것) ③**그룹에 붙은 정책**(인라인·관리형을 그룹에 붙이고 그 그룹을 사용자에게 배정).

셋을 각각 `iam list-user-policies`, `iam list-attached-user-policies`, `iam list-groups-for-user` 로 열거함(`--user-name jenkins-admin`).

```
kali@kali:~$ aws --profile CompromisedJenkins iam list-user-policies --user-name
jenkins-admin
{
    "PolicyNames": [
        "jenkins-admin-role"
    ]
}
kali@kali:~$ aws --profile CompromisedJenkins iam list-attached-user-policies --user-
name jenkins-admin
{
    "AttachedPolicies": []
}
kali@kali:~$ aws --profile CompromisedJenkins iam list-groups-for-user --user-name
jenkins-admin
{
    "Groups": []
}
```

*세 경로 중 인라인 정책 하나(`jenkins-admin-role`)만 존재*

이름만으로는 권한을 모르므로 문서를 꺼냄 — `iam get-user-policy` 에 `--user-name` 과 `--policy-name` 을 줌.

```
kali@kali:~$ aws --profile CompromisedJenkins iam get-user-policy --user-name jenkins-
admin --policy-name jenkins-admin-role
{
    "UserName": "jenkins-admin",
    "PolicyName": "jenkins-admin-role",
    "PolicyDocument": {
        "Version": "2012-10-17",
        "Statement": [
            {
                "Sid": "",
                "Effect": "Allow",
                "Action": "*",
                "Resource": "*"
            }
        ]
    }
}
```

*`Action: "*"` · `Resource: "*"` — 탈취 자격 증명이 전권 관리자였음*
