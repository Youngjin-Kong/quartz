# 8.4.4 기본 XSS

> **Basic XSS** · PEN-200 §8.4.4

대상은 OffSec WordPress 의 **Visitors** 플러그인이고 저장형(stored) XSS 가 있음. 방문자의 IP·source·User-Agent 를 기록하는 플러그인이며 소스는 배포 사이트에서 받을 수 있음. `database.php` 의 저장 함수:

```
function VST_save_record() {
    global $wpdb;
    $table_name = $wpdb->prefix . 'VST_registros';
    VST_create_table_records();
    return $wpdb->insert(
                $table_name,
                array(
                    'patch' => $_SERVER["REQUEST_URI"],
                    'datetime' => current_time( 'mysql' ),
                    'useragent' => $_SERVER['HTTP_USER_AGENT'],
                    'ip' => $_SERVER['HTTP_X_FORWARDED_FOR']
                )
            );
}
```

*User-Agent 헤더(`$_SERVER['HTTP_USER_AGENT']`)를 가공 없이 `useragent` 컬럼에 삽입*

관리자가 플러그인을 열 때마다 `start.php` 가 저장된 레코드를 다시 그림:

```
$i=count(VST_get_records($date_start, $date_finish));
foreach(VST_get_records($date_start, $date_finish) as $record) {
    echo '
        <tr class="active" >
            <td scope="row" >'.$i.'</td>
            <td scope="row" >'.date_format(date_create($record->datetime),
get_option("links_updated_date_format")).'</td>
            <td scope="row" >'.$record->patch.'</td>
            <td scope="row" ><a href="https://www.geolocation.com/es?ip='.$record-
>ip.'#ipresult">'.$record->ip.'</a></td>
            <td>'.$record->useragent.'</td>
        </tr>';
    $i--;
}
```

*DB 에서 꺼낸 `useragent` 가 `td` 태그 안에 무가공으로 들어감*

XSS 성립 전제 셋 — ① 값의 출처가 User-Agent 라 **공격자 통제 하** ② 출력 컨텍스트가 HTML 본문(`td` 안)이라 `<script>` 태그를 그대로 넣을 수 있음 ③ 새니타이즈 없음. 그래서 `alert()` 를 부르는 스크립트 태그로 팝업을 띄울 수 있고, 시각적 확인이 즉각적이라 XSS 검증에 흔히 쓰는 방법임. 여기서는 소스를 읽는 화이트박스로 찾았으나 HTTP 헤더 퍼징(블랙박스)으로도 같은 것을 발견할 수 있음.

절차 — Burp 를 프록시로 두고 Intercept 는 끈 채 Firefox 로 `http://offsecwp/` 접속 → Proxy > HTTP History 에서 요청을 우클릭해 Send to Repeater → Repeater 에서 User-Agent 기본값을 `<script>alert(42)</script>` 로 교체해 전송.

![[PEN200-Fig-116.png]]

*Repeater 에서 User-Agent 를 스크립트 태그로 교체*

200 OK 면 페이로드가 DB 에 저장된 것으로 봄. `http://offsecwp/wp-login.php` 에 `admin`/`password` 로 로그인하고 Visitors 콘솔(`http://offsecwp/wp-admin/admin.php?page=visitors-app%2Fadmin%2Fstart.php`)로 이동하면 42 팝업이 뜸.

![[PEN200-Fig-117.png]]

*42 팝업 — 주입 성공의 증거*

저장형이라 페이로드는 플러그인을 여는 **모든 관리자**에게 제공됨. `alert` 창은 영향이 사소한 시연이고 실제로 노릴 것은 관리 계정 생성임.
