# 13.2.4 Google 검색 연산자

> **Google Search Operators** · PEN-200 §13.2.4

검색 엔진을 쓰면 개별 사이트 바깥의 익스플로잇 호스팅처까지 넓게 훑을 수 있음. 기본형은 **소프트웨어의 특정 버전 + `exploit` 키워드**이고, 여기에 검색 연산자를 붙여 범위를 좁힘 — 예로 Microsoft Edge 관련 결과를 Exploit Database 안으로 한정함.

```
kali@kali:~$ firefox --search "Microsoft Edge site:exploit-db.com"
```

*Google 로 exploit-db.com 내 Microsoft Edge 익스플로잇 검색*

결과를 다듬는 연산자로 `inurl`·`intext`·`intitle` 등도 있음.

⚠️ 이렇게 닿는 곳은 대개 검수를 거치지 않은 자료라 극도로 주의할 것.
