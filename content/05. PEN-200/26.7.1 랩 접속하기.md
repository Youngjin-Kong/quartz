# 26.7.1 랩 접속하기

> **Accessing the Labs** · PEN-200 §26.7.1

랩을 시작하면 DNS 서버 IP, Kali IP, Kali 비밀번호를 받음. 서비스에 닿으려면 **클라우드 인스턴스가 아니라 개인 Kali** 에서 DNS 와 pip 클라이언트를 설정해야 함.

DNS 부터 처리함. 이 예시의 DNS 서버는 `203.0.113.84` 임. 먼저 `nmcli` 로 활성 연결 이름을 확인함 — Wi-Fi·VM 등 연결 방식에 따라 출력이 다름.

```
kali@kali:~$ nmcli connection
NAME                UUID                                  TYPE      DEVICE
Wired connection 1  67f8ac63-7383-4dfd-ae42-262991b260d7  ethernet  eth0
lo                  1284e5c4-6819-4896-8ad4-edeae32c64ce  loopback  lo
```

*주 연결 이름이 "Wired connection 1" 임 — 다음 명령에 그대로 쓸 값*

연결 이름을 알았으면 `nmcli connection modify` 로 `ipv4.dns` 를 DNS 서버 IP 로 지정하고 NetworkManager 를 재시작함.

```
kali@kali:~$ nmcli connection modify "Wired connection 1" ipv4.dns "203.0.113.84"
kali@kali:~$ sudo systemctl restart NetworkManager
```

*DNS 지정 후 NetworkManager 재시작*

⚠️ 이 DNS 서버는 `offseclab.io` 도메인에만 응답함. 일반 인터넷 조회가 필요하면 `"203.0.113.84, 1.1.1.1, 8.8.8.8"` 처럼 쉼표로 이어 추가 서버를 지정할 것.

적용 여부는 `/etc/resolv.conf` 의 `nameserver` 값으로 확인하고, `nslookup` 으로 실제 응답까지 봄.

```
kali@kali:~$ cat /etc/resolv.conf
# Generated by NetworkManager
search localdomain
nameserver 203.0.113.84
...
kali@kali:~$ nslookup git.offseclab.io
Server:         203.0.113.84
Address:        203.0.113.84#53
Non-authoritative answer:
Name:   git.offseclab.io
Address: 198.18.53.73
```

*설정 반영 확인 — `nameserver` 가 바뀌었고 `git.offseclab.io` 가 해석됨*

⚠️ **랩을 재시작할 때마다 DNS IP 가 새로 발급**되므로 위 명령을 다시 돌려야 함. 랩 종료 시 DNS 서버도 파괴되므로 `nmcli` 를 빈 문자열로 다시 실행해 설정을 지워야 함(마무리 절에서 다룸).

다음은 pip 설정임. pip 명령을 클라우드 Kali 에서도 쓸 것이라면 그쪽에도 같은 설정을 해야 함. 설정 파일은 `~/.config/pip/pip.conf` 이고, 상위 디렉터리는 `mkdir -p` 로 한 번에 만듦.

```
kali@kali:~$ mkdir -p ~/.config/pip/
kali@kali:~$ nano ~/.config/pip/pip.conf
kali@kali:~$ cat -n  ~/.config/pip/pip.conf
1  [global]
2  index-url = http://pypi.offseclab.io
3  trusted-host = pypi.offseclab.io
```

*pip 설정 — 공식 PyPI 대신 랩 내부 인덱스를 바라보게 함*

`[global]` 은 이 사용자가 pip 를 쓸 때마다 적용되게 하는 최상위 설정임. `index-url` 로 공식 PyPI 를 대체할 `http://pypi.offseclab.io` 를 지정하고, HTTPS 가 아닌 HTTP 라서 `trusted-host` 로 신뢰 호스트에 등록해야 함.
