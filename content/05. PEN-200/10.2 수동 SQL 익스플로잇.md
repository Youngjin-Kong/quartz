# 10.2 수동 SQL 익스플로잇

> **Manual SQL Exploitation** · PEN-200 §10.2

학습 목표 — SQLi 취약점의 수동 식별, UNION·오류 기반·블라인드 페이로드(payload) 이해.

실무에서는 `sqlmap` 같은 자동 도구로 찾고 터는 경우가 많지만, **수동으로 취약점을 유발하는 법을 먼저 익혀야** 동작 원리를 잡을 수 있음.
