# 9.1.1 절대 경로와 상대 경로

> **Absolute vs Relative Paths** · PEN-200 §9.1.1

이 모듈의 취약점들은 전부 «표시·업로드·포함·실행할 파일의 경로를 지정하는 것»으로 성립함. 애플리케이션과 취약점에 따라 절대 경로와 상대 경로 중 하나를 쓰게 되므로 둘의 차이를 먼저 정리함.

**절대 경로** — 하위 디렉터리를 전부 포함한 전체 파일 시스템 경로. 파일 시스템 어느 위치에서든 같은 대상을 가리킴. 리눅스에서는 루트 파일 시스템을 뜻하는 슬래시(`/`)로 시작함. `/etc/passwd` 처럼 `etc` 앞에 슬래시를 붙이면 루트에서 출발하므로 현재 디렉터리와 무관하게 동작함. 반대로 앞의 슬래시를 빼면 셸은 «현재 디렉터리 안»에서 `etc` 를 찾음 — 절대와 상대를 가르는 것이 이 한 글자임.

```
kali@kali:~$ pwd
/home/kali
kali@kali:~$ ls /
bin   home            lib32       media  root  sys  vmlinuz
boot  initrd.img      lib64       mnt    run   tmp  vmlinuz.old
dev   initrd.img.old  libx32      opt    sbin  usr
etc   lib             lost+found  proc   srv   var
kali@kali:~$ cat /etc/passwd
root:x:0:0:root:/root:/usr/bin/zsh
daemon:x:1:1:daemon:/usr/sbin:/usr/sbin/nologin
bin:x:2:2:bin:/bin:/usr/sbin/nologin
sys:x:3:3:sys:/dev:/usr/sbin/nologin
...
king-phisher:x:133:141::/var/lib/king-phisher:/usr/sbin/nologin
kali:x:1000:1000:Kali,,,:/home/kali:/usr/bin/zsh
```

*절대 경로로 `/etc/passwd` 출력 — 현재 디렉터리와 무관하게 동작*

**상대 경로** — 현재 위치를 기준으로 지정함. 한 단계 뒤로 가는 것이 `../` 이고, 여러 단계는 `../` 를 이어 붙임. `/home/kali` 에서 `../` 하나면 `/home`, 둘이면 루트 파일 시스템에 도달함.

```
kali@kali:~$ pwd
/home/kali
kali@kali:~$ ls ../
kali
kali@kali:~$ ls ../../
bin   home            lib32       media  root  sys  vmlinuz
boot  initrd.img      lib64       mnt    run   tmp  vmlinuz.old
dev   initrd.img.old  libx32      opt    sbin  usr
etc   lib             lost+found  proc   srv   var
```

*상대 경로로 루트 파일 시스템까지 거슬러 올라가기*

루트에 도달한 뒤로는 평소처럼 내려가면 됨 — `../../etc/passwd` 가 `/etc/passwd` 와 같은 결과를 냄.

```
kali@kali:~$ ls ../../etc
adduser.conf            debian_version  hostname        logrotate.d     passwd
...
logrotate.conf  pam.d           rmt          sudoers       zsh
kali@kali:~$ cat ../../etc/passwd
root:x:0:0:root:/root:/usr/bin/zsh
daemon:x:1:1:daemon:/usr/sbin:/usr/sbin/nologin
bin:x:2:2:bin:/bin:/usr/sbin/nologin
sys:x:3:3:sys:/dev:/usr/sbin/nologin
...
king-phisher:x:133:141::/var/lib/king-phisher:/usr/sbin/nologin
kali:x:1000:1000:Kali,,,:/home/kali:/usr/bin/zsh
```

*루트까지 올라간 뒤 상대 경로로 `etc` 진입 — 절대 경로와 같은 결과*

**`../` 개수는 루트에 도달할 때까지만 의미가 있음.** `/` 보다 위가 없으므로 그 뒤로는 몇 개를 더 붙여도 결과가 같음. 이 성질이 공격에서 중요함 — **현재 작업 디렉터리를 모를 때 `../` 를 넉넉히 붙이면 상대 경로 관점에서 루트 도달이 보장됨.**

```
kali@kali:~$ cat ../../../../../../../../../../../etc/passwd
root:x:0:0:root:/root:/usr/bin/zsh
daemon:x:1:1:daemon:/usr/sbin:/usr/sbin/nologin
bin:x:2:2:bin:/bin:/usr/sbin/nologin
sys:x:3:3:sys:/dev:/usr/sbin/nologin
...
king-phisher:x:133:141::/var/lib/king-phisher:/usr/sbin/nologin
kali:x:1000:1000:Kali,,,:/home/kali:/usr/bin/zsh
```

*`../` 를 과도하게 붙여도 결과가 같음*
