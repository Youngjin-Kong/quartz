# 20.3 마무리

> **Wrapping Up** · PEN-200 §20.3

이 모듈에서 다룬 것은 HTTP 터널링(Chisel)과 DNS 터널링(dnscat2) 두 가지임. 심층 패킷 검사(deep packet inspection)나 트래픽 분석을 하는 강화된 네트워크 환경을 통과해야 할 때 쓰는 수단이고, 실습에서 양쪽의 장단점을 함께 확인함.
