# 7.2.6 Nessus 플러그인 다루기

> **Working with Nessus Plugins** · PEN-200 §7.2.6

- 기본 템플릿은 뒤에서 여러 플러그인을 알아서 켬. 반대로 «플러그인 하나만» 빠르게 돌리도록 좁힐 수도 있으며, 앞선 발견을 검증하거나 특정 취약점에 노출된 대상을 환경 전체에서 골라내는 데 씀.
- 예시 목표 — DESKTOP 이 CVE-2021-3156 에 취약한지 확인. 비권한 사용자가 root 로 권한 상승할 수 있는 로컬 취약점임.
- 템플릿은 Advanced Dynamic Scan — 플러그인을 손으로 켜고 끄는 대신 동적 필터를 쓸 수 있음. 이름·대상을 넣고, 앞 절과 같은 SSH·sudo 자격 증명을 넣어 이번에도 인증 스캔으로 돌림.
- 필터 설정 — Dynamic Plugins 탭에서 왼쪽 드롭다운을 CVE 로, 가운데는 매칭 방식, 오른쪽에 CVE 번호를 넣음. "CVE-2021-3156" 입력 후 Preview Plugins 를 누르면 해당 CVE 를 다루는 플러그인 패밀리 목록이 나옴. 몇 분 걸릴 수 있음.
- 필터는 여러 개를 조합할 수 있음. 대상이 Ubuntu 리눅스임을 알고 있으므로 첫 필터 옆 플러스 버튼으로 필터를 추가해 왼쪽을 Plugin Family, 오른쪽을 Ubuntu Local Security Checks 로 지정함.

![[PEN200-Fig-078.png]]
*CVE 필터와 플러그인 패밀리 필터를 결합한 상태*

- Nessus 버전에 따라 오른쪽 드롭다운이 비어 있을 수 있음 — 이때는 두 번째 필터를 지우고 그대로 진행할 것.
- 다시 Preview Plugins 를 돌린 뒤 Ubuntu Local Security Checks 를 펼치면 영향받는 Ubuntu 버전, 짧은 설명, 패치 번호, Plugin ID 가 표시되고, 플러그인을 클릭하면 상세가 나옴.
- 스캔을 실행하고 Vulnerabilities 탭을 보면 지정한 플러그인이 잡아낸 HIGH 심각도 발견 하나가 나오며, 상세에서 대상이 CVE-2021-3156 에 취약함이 확인됨.
- ⚠️ 다만 플러그인 출력에는 Nessus 가 «보고된 버전 번호만» 사용했고 익스플로잇으로 취약함을 확인하지는 않았다는 안내가 함께 붙음. 실제 평가에서는 이런 결과를 별도로 검증해 실제 익스플로잇 가능한 취약점인지 확인할 것.
