# 22.2.1 레거시 Windows 도구를 이용한 Active Directory 열거

> **Active Directory - Enumeration Using Legacy Windows Tools** · PEN-200 §22.2.1

침해 가정 시나리오이므로 확보한 `stephanie` 자격 증명으로 Windows 11 클라이언트(CLIENT75)에 붙어 도메인에 인증함. `xfreerdp` 로 RDP 접속하되 사용자명은 `/u`, 도메인명은 `/d` 로 넘기고 비밀번호(`LegmanTeamBenzoin!!`)는 접속 후 입력함.

```
kali@kali:~$ xfreerdp /u:stephanie /d:corp.com /v:192.168.50.75
```

*확보한 도메인 계정으로 Windows 11 클라이언트에 RDP 접속*

> [!warning] 자격 증명이 있으면 가급적 RDP 를 쓸 것
> PowerShell Remoting·winrm 으로 붙으면 **Kerberos Double Hop** 때문에 도메인 열거 도구를 더는 못 돌리게 될 수 있음. 회피는 RDP 접속이 가장 간단함(Double-Hop 상세는 PEN-300).

AD 는 정보량이 많아 시작점을 잡기 어려운데, **모든 AD 설치에 사용자와 그룹은 반드시 있으므로** 거기서 출발함.

도구는 모든 Windows 에 기본 탑재된 `net.exe`, 그중 `net user` 하위 명령임. 로컬 계정 열거에도 쓰지만 여기서는 `/domain` 을 붙여 도메인 사용자를 출력함.

```
C:\Users\stephanie>net user /domain
The request will be processed at a domain controller for domain corp.com.
User accounts for \\DC1.corp.com
-------------------------------------------------------------------------------
Administrator            dave                     Guest
iis_service              jeff                     jeffadmin
jen                      krbtgt                   pete
stephanie
The command completed successfully.
```

*도메인 사용자 목록 — 요청은 DC1.corp.com 에서 처리됨*

출력 길이는 조직 규모에 따라 달라짐. 목록을 쥐었으면 개별 사용자를 파고들 수 있는데, 관리자가 계정의 기능을 접두사·접미사로 표시해 두는 경향이 있어 `jeffadmin` 이 우선 확인 대상임.

```
C:\Users\stephanie>net user jeffadmin /domain
The request will be processed at a domain controller for domain corp.com.
User name                    jeffadmin

*특정 사용자 조회 — Global Group memberships 에 Domain Admins 가 보임*

`jeffadmin` 이 `Domain Admins` 소속임이 확인됨 — 장악하면 그대로 도메인 관리자로 올라서는 것이라 반드시 기록해 둘 것.

그룹 열거도 같은 도구로 함 — `net group /domain`.

```
C:\Users\stephanie>net group /domain

*도메인 그룹 목록 — 기본 설치 그룹과 관리자가 만든 커스텀 그룹이 섞여 있음*

`Development Department`·`Management Department`·`Sales Department` 처럼 기본 설치분이 아닌 것이 관리자가 만든 커스텀 그룹이라 여기부터 구성원을 확인함.

```
PS C:\Tools> net group "Sales Department" /domain
The request will be processed at a domain controller for domain corp.com.
Group name     Sales Department
Comment
Members
-------------------------------------------------------------------------------
pete                     stephanie
The command completed successfully.
```

*특정 그룹의 구성원 조회 — Sales Department 에 pete 와 stephanie*

당장 소득이 없어 보여도 **열거로 얻는 조각 하나하나가 나중에 값을 함.** 실제 평가에서는 그룹마다 돌려 목록화함. 다만 `net.exe` 보다 유연한 대안이 있어 다음 절로 넘어감.
