# 17.2 Windows 서비스 이용

> **Leveraging Windows Services** · PEN-200 §17.2

Windows 서비스 = Service Control Manager 가 관리하는 상시 백그라운드 실행 파일. Unix 데몬에 대응함. 관리 수단은 서비스 스냅인·PowerShell·`sc.exe`.

갈리는 지점은 **어느 계정으로 도는가**임. Windows 자체 서비스는 LocalSystem·Network Service·Local Service 로 돌고, LocalSystem 은 토큰에 `NT AUTHORITY\SYSTEM` 과 `BUILTIN\Administrators` SID 를 함께 담음. 서비스를 만드는 쪽은 이 셋 중 하나나 도메인·로컬 사용자를 지정할 수 있음.

즉 서비스 실행 흐름에 끼어들면 그 계정 권한을 그대로 얻으므로, 권한 상승 벡터를 찾을 때 반드시 분석하는 주요 영역 중 하나임. 다루는 경로는 셋 — 실행 파일 하이재킹, DLL 하이재킹, 따옴표 없는 서비스 경로.
