# 3.6.1 사이버보안 진로 - 공격

> **Cybersecurity Career Opportunities: Attack** · PEN-200 §3.6.1

**Network Penetration Tester** — 대상 네트워크에 존재하는 취약점을 발견하고 익스플로잇하는 역할. 네트워킹과 시스템 이해가 탄탄하고 그 보안 조치를 무력화하는 방법을 찾는 것을 즐기는 사람에게 맞음. **명확한 기술 문서 작성 능력**이 크게 작용함. 학습 경로는 PEN 100·200·300 레벨.

**Web Application Tester** — 웹 애플리케이션의 보안 약점을 시험하는 역할. 웹 취약점 지식이 탄탄하고 애플리케이션이 갖춘 보안 조치를 우회하는 것을 즐기는 사람이 적합함. WEB 트랙 100·200·300 레벨에서 웹 애플리케이션의 동작 원리와 블랙박스·화이트박스 접근법을 다룸.

**Cloud Penetration Tester** — 클라우드 인프라를 대상으로 침투 테스트를 수행함. 클라우드 인프라 지식·경험과 침투 테스트 경험이 함께 필요하고, 다른 침투 테스트 직무처럼 인프라를 찔러 약점을 찾고 악용 방법을 궁리하는 데 재미를 느껴야 함. CLD-100 이 클라우드 기술의 시험·공격·익스플로잇을 다룸.

**Exploit Developer** — 소프트웨어 취약점의 익스플로잇을 발견하고 개발함. 애플리케이션을 리버스 엔지니어링해 동작을 파악하고, 저수준 코드를 읽고, 보안 완화 기법을 우회하는 일을 즐기는 사람에게 맞음. EXP-301 이 Windows 바이너리 익스플로잇을, EXP-312 가 macOS 논리 익스플로잇을 다룸.

**Vulnerability Researcher** — 새 소프트웨어 취약점과 익스플로잇 기법을 연구해 영향도를 판정하고 PoC(Proof of Concept)를 개발한 뒤 이해관계자에게 결과를 전달함. 리버스 엔지니어링과 신규·부상 중인 취약점 연구를 즐기는 사람에게 맞음. Windows·macOS 각각의 리버스 엔지니어링과 익스플로잇 개발은 EXP-301·EXP-312 에서 배움.
