# 2.3.1 시작하기 - 선택 준비 모듈

> **Getting Started: Optional Ramp-up Modules** · PEN-200 §2.3.1

- Fundamentals 계열의 선택 모듈 3종 — 완만한 진입을 원하는 학습자용이라 건너뛰어도 무방.
- Introduction to Cybersecurity — 보안 분야 전반 개관(위협·위협 행위자, 보안 원칙과 통제, 법규·프레임워크).
- Effective Learning Strategies — OffSec 교수법의 근거가 되는 학습 이론과 실천 전술.
- Report Writing for Penetration Testers — 진행 중 노트 작성과 보고서 구성법. **OSCP+ 는 시험 보고서 제출이 필수**이므로 연습문제 단계부터 쓰는 연습을 해둘 것.
