# 26.2.1 랩 접속하기

> **Accessing the Labs** · PEN-200 §26.2.1

랩을 시작하면 넷을 받음 — DNS 서버 IP, Kali IP, Kali 비밀번호, **권한이 하나도 없는 AWS 계정**.

서비스에 닿으려면 **본인 Kali**(클라우드 인스턴스가 아님)가 제공된 DNS 를 쓰도록 설정해야 함. 예시 DNS 는 `203.0.113.84`. AWS 랩 DNS 에 닿는 데 별도 VPN 팩은 필요 없으므로 **Kali 의 VPN 연결을 끊어 둘 것.**

`nmcli connection` 으로 활성 연결 목록을 먼저 확인함 — 이름은 접속 방식(유선·Wi-Fi·VM)에 따라 다름.

```
kali@kali:~$ nmcli connection
NAME                UUID                                  TYPE      DEVICE
Wired connection 1  67f8ac63-7383-4dfd-ae42-262991b260d7  ethernet  eth0
lo                  1284e5c4-6819-4896-8ad4-edeae32c64ce  loopback  lo
```

*활성 연결 목록 — 예시에서는 유선 연결 `Wired connection 1` 이 주 연결임*

그 이름을 `modify` 서브커맨드에 넘겨 `ipv4.dns` 를 설정하고 NetworkManager 를 재시작함.

```
kali@kali:~$ sudo nmcli connection modify "Wired connection 1" ipv4.dns "203.0.113.84"
kali@kali:~$ sudo systemctl restart NetworkManager
```

이 DNS 는 `offseclab.io` 도메인에만 응답함. 나머지 이름 해석까지 살리려면 위 명령의 값에 `"203.0.113.84, 1.1.1.1, 8.8.8.8"` 처럼 쉼표로 이어 붙이면 됨.

반영 확인은 `/etc/resolv.conf` 의 nameserver 값과 `nslookup` 응답 둘 다로 함.

```
kali@kali:~$ cat /etc/resolv.conf
# Generated by NetworkManager
search localdomain
nameserver 203.0.113.84
...
kali@kali:~$ nslookup git.offseclab.io
Server:         203.0.113.84
Address:        203.0.113.84#53
Non-authoritative answer:
Name:   git.offseclab.io
Address: 198.18.53.73
```

**랩을 재시작할 때마다 DNS IP 가 새로 발급되므로 위 설정을 매번 다시 해야 함.** 랩 종료 시 DNS 서버가 파괴되므로, 같은 `nmcli` 명령에 IP 대신 빈 문자열을 줘서 설정을 지워야 함 — 안 지우면 죽은 DNS 를 계속 물고 감.
