# 21.5 마무리

> **Wrapping Up** · PEN-200 §21.5

이 모듈에서 다룬 것 — 프레임워크 사용법, auxiliary·exploit 모듈, Metasploit·msfvenom 의 페이로드 종류, Meterpreter 포스트 익스플로잇, 피벗팅, 리스너와 프로세스 이주를 자동화하는 resource 스크립트.

익스플로잇 프레임워크가 침투 테스트에서 값을 하는 이유는 셋임 — ① 여러 셸과 세션을 손으로 관리하는 것은 금세 번거롭고 실수를 부름 ② 프레임워크의 모듈은 공개 익스플로잇 코드를 고쳐 쓰는 과정 없이 상황에 맞게 조정할 수 있음 ③ 클라이언트 사이드·웹 애플리케이션 공격에 쓸 실행 파일 생성 기능을 함께 제공함.

특히 Metasploit 의 대표 페이로드인 Meterpreter 를 쓰면 포스트 익스플로잇과 피벗팅 기법을 폭넓게 확보하게 됨.
