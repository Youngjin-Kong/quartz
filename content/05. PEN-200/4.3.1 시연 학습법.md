# 4.3.1 시연 학습법

> **The Demonstration Method** · PEN-200 §4.3.1

시연 학습법(Demonstration Method) — 학습자가 할 수 있게 되길 바라는 것을 **직접 보여주는(실연하는)** 방식. 파일 이름 바꾸기 예로 다시 돌아감. 그냥 직접적으로 알려주는 방법은 이렇게 됨:

```
Use the "mv" command.
```

*시연 학습법을 쓰지 않은 경우 — 기술적으로 맞지만 활용법이 안 잡힘*

시연 학습법을 쓰는 교수자는 **학습자가 밟아야 할 단계를 그대로 따라가고 실행 결과까지 함께 보여줌.** 코드 블록을 내놓기 전에 먼저 계획을 세우고 새로 쓰는 명령을 설명함 — 여기서는 `ls *.txt` 로 디렉터리의 `.txt` 파일을 나열하고, `mv oldfilename.txt newfilename.txt` 로 이름을 바꾸고, 다시 `ls *.txt` 로 결과를 확인한다는 순서를 미리 밝힘.

```
kali@kali:~$ ls *.txt
oldfilename.txt
kali@kali:~$ mv oldfilename.txt newfilename.txt
kali@kali:~$ ls *.txt
newfilename.txt
```

*이름을 바꾸고 결과를 확인하는 전체 흐름*

블록 뒤에는 결과를 설명함 — `.txt` 파일은 `oldfilename.txt` 하나뿐이었고, 이름 바꾸기 명령은 **예상대로 아무 출력도 내지 않았으며**, 다시 나열하니 `newfilename.txt` 만 남음. 더 나아가 내용이 그대로이고 이름만 바뀌었는지까지 확인할 수도 있음.

이런 군더더기처럼 보이는 절차가 실은 **학습자가 익혀야 할 사고 과정을 드러내는 부분**임. 결과를 검증하는 것은 파일 이름 바꾸기의 필수 단계가 아니지만, **작업을 확인하는 습관** 자체가 갖춰야 할 태도임.

그래서 교재가 일부러 먼 길로 돌아가 새 기술과 그 맥락을 함께 보여주기도 하고, 교수자의 「실수」와 방향 전환을 드러내 놓고 논의하기도 함. 이렇게 사고 과정을 시연하는 것을 **모델링(modeling)** 이라 하며, 비판적 사고를 가르치기 위해 고안된 방법임.
