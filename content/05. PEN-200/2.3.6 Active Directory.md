# 2.3.6 Active Directory

> **Active Directory** · PEN-200 §2.3.6

- 기업 환경에 편재해 침투테스터가 반드시 다뤄야 하는 영역이라 PWK 가 모듈 셋을 할애함.
- Active Directory Introduction and Enumeration — Windows 머신을 「도메인의 일원」으로 보는 관점과 정보 수집.
- Attacking Active Directory Authentication — 인증 프로토콜을 공격하거나 우회해 내부 장악력을 넓히는 기법.
- Lateral Movement in Active Directory — 앞서 배운 피보팅 개념을 복잡한 AD 환경에 적용.
