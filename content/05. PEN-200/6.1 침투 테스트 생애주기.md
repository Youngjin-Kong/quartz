# 6.1 침투 테스트 생애주기

> **The Penetration Testing Lifecycle** · PEN-200 §6.1

학습 목표 — 침투 테스트의 단계 이해, 각 단계에서 정보 수집이 하는 역할, 능동·수동 정보 수집의 차이.

보안 태세를 통제된 상태로 유지하려면 정기적으로, 그리고 대상 IT 아키텍처가 크게 바뀔 때마다 테스트를 수행해야 함.

전형적인 침투 테스트의 단계:

- 스코프 정의(Defining the Scope)
- 정보 수집(Information Gathering)
- 취약점 탐지(Vulnerability Detection)
- 초기 발판(Initial Foothold)
- 권한 상승(Privilege Escalation)
- 측면 이동(Lateral Movement)
- 보고/분석(Reporting/Analysis)
- 교훈 정리/조치(Lessons Learned/Remediation)

스코프는 어떤 IP 대역·호스트·애플리케이션이 시험 대상이고 무엇이 대상 밖(out-of-scope)인지를 규정함. 고객과 스코프·기간에 합의하면 두 번째 단계인 정보 수집으로 넘어감.

정보 수집의 목표는 대상에 대한 데이터를 가능한 한 많이 모으는 것이고, 출발점은 대상 조직의 인프라·자산·인력을 알아내는 정찰(reconnaissance)임. 정찰은 수동·능동 양쪽으로 가능함 — 수동은 직접 상호작용을 거의 하지 않고 정보를 얻는 방식, 능동은 인프라를 직접 탐침하는 방식임. 능동 쪽이 공격자 흔적(footprint)을 크게 남기므로 노출을 피하고 싶으면 수동을 택함.

정보 수집(열거, enumeration)은 초기 정찰로 끝나지 않음. 발판을 잡거나 머신 사이를 측면 이동하면서 새 정보가 계속 나오므로, 테스트가 진행되는 내내 데이터를 모아 공격 표면에 대한 지식을 키워야 함.
