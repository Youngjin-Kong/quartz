# 9.3.1 실행 파일 활용

> **Using Executable Files** · PEN-200 §9.3.1

파일 업로드 취약점 중 **업로드한 파일을 웹 서버가 실행해 주는** 경우를 다룸. 디렉터리 탐색·파일 인클루전과 마찬가지로 출발점은 **업로드 지점을 찾아내는 것**임.

업로드 기능이 있을 만한 곳은 애플리케이션의 성격에서 추론 가능함 — CMS 라면 프로필 아바타나 게시글·페이지의 첨부 파일, 회사 사이트라면 채용 지원 섹션이나 업종별 용도(예: 법률 사무소의 사건 파일 접수). 사용자 눈에 잘 띄지 않는 업로드 지점도 있으므로 **열거(enumeration) 단계를 건너뛰지 말 것**.

실습 대상은 MOUNTAIN VM 의 "Mountain Desserts" 애플리케이션(`http://192.168.50.189/meteor/`).

![[PEN200-Fig-137.png]]

*Admin 링크가 사라지고 사진 업로드 폼이 들어선 새 버전 — 탭의 XAMPP 아이콘이 스택을 노출함*

개편된 화면은 콘테스트용 사진을 올리라고 안내함. 탭에 표시된 XAMPP 아이콘으로 스택을 추정할 수 있고, 본문이 Windows 로 전환했다고 밝히므로 **Windows + XAMPP** 로 가정하고 접근함.

먼저 이미지가 아닌 텍스트 파일이 올라가는지 확인함.

```
kali@kali:~$ echo "this is a test" > test.txt
```

*업로드 시험용 텍스트 파일 생성*

`test.txt` 가 그대로 올라가므로 **업로드가 이미지 전용이 아님**이 드러남. 이어서 앞 절에서 쓰던 `simple-backdoor.php` 웹셸을 올려 봄.

![[PEN200-Fig-139.png]]

*PHP 확장자는 블랙리스트에 걸려 업로드 거부됨*

필터 구현을 모르는 상태이므로 **시행착오로 우회**를 찾음. 두 가지 접근이 있음.

- **덜 쓰이는 PHP 확장자로 교체** — `.phps`·`.php7` 등. `.php`·`.phtml` 만 검사하는 단순 필터를 넘김. 구버전·특수 용도의 확장자지만 현대 PHP 도 호환을 위해 계속 지원함
- **확장자를 대문자로 변형** — 블랙리스트가 소문자 문자열 목록과 비교하는 방식이면 대소문자를 섞어 통과 가능

여기서는 두 번째 방법으로 `simple-backdoor.php` 를 `simple-backdoor.pHP` 로 바꿔 업로드했고 그대로 통과함. 업로드 응답에 저장 위치가 나와 `uploads` 디렉터리를 알 수 있으므로, 웹셸의 `cmd` 파라미터에 `dir` 을 넘겨 실행을 확인함.


*업로드한 웹셸로 `dir` 실행 — 원격 명령 실행 확립*

단순해 보이는 우회지만 실전에서 자주 통하는 부류임. 이어서 리버스 셸까지 진행함. 4444 포트로 리스너를 띄움.

```
kali@kali:~$ nc -nvlp 4444
listening on [any] 4444 ...
```

*리스너에 셸 연결 — `whoami` 가 `nt authority\system` 을 반환*

대상이 PHP 가 아니라 ASP 였다면 ASP 웹셸을 올리는 것만 다를 뿐 절차는 동일함. Kali 에는 프레임워크·언어별 웹셸이 `/usr/share/webshells/` 에 이미 들어 있음.

```
kali@kali:~$ ls -la /usr/share/webshells
total 40
drwxr-xr-x   8 root root  4096 Feb 11 02:00 .
drwxr-xr-x 320 root root 12288 Apr 19 09:17 ..
drwxr-xr-x   2 root root  4096 Feb 11 01:58 asp
drwxr-xr-x   2 root root  4096 Apr 25 07:25 aspx
drwxr-xr-x   2 root root  4096 Feb 11 01:58 cfm
drwxr-xr-x   2 root root  4096 Apr 25 07:06 jsp

drwxr-xr-x   2 root root  4096 Feb 11 01:58 perl
drwxr-xr-x   3 root root  4096 Feb 11 01:58 php
```

웹셸의 구현은 언어에 따라 다르지만 **사용 절차는 사실상 같음** — ①대상의 언어·프레임워크 식별 ②접근 가능한 위치에 업로드 ③명령 전달. 웹셸의 파일 형식이 필터나 업로드 로직에서 차단될 수 있는데, 이 절의 확장자 우회 외에 **파일 이름 변경·수정 기능**을 노리는 방법도 있음 — `.txt` 처럼 무해한 형식으로 올린 뒤 이름을 바꿔 원래 확장자로 되돌리는 것임.
