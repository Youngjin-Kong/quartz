# 24.1 Active Directory 측면 이동 기법

> **Active Directory Lateral Movement Techniques** · PEN-200 §24.1

측면 이동(lateral movement)은 **대상 네트워크 안에서 접근 범위를 넓히는** 기법들의 묶음임. MITRE 정의대로 지금 쥔 유효 계정을 쓰거나, 앞 단계에서 확보한 인증 자료(비밀번호 해시·Kerberos 티켓·앱 액세스 토큰)를 재사용함.

다루는 것 —

- WMI · WinRS · WinRM 원격 실행
- PsExec 악용
- Pass-the-Hash 와 Overpass-the-Hash
- DCOM 악용

⚠️ **AD 열거는 이 단계에서도 계속 유효함** — 측면 이동으로 안 보이던 네트워크에 닿기 때문임.
