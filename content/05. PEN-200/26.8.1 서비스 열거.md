# 26.8.1 서비스 열거

> **Enumerating the Services** · PEN-200 §26.8.1

대상 애플리케이션 `app.offseclab.io` 에 직접 접속해 동작부터 파악함. 이름은 HackShort 이고 긴 URL 을 짧게 줄여주는 서비스임. 페이지에 API 문서(HackShort's API) 링크가 있음.

문서의 첫 단계는 API 사용을 위한 액세스 토큰 발급임 — 토큰 생성기에 임의 이메일을 넣고 Get API Key 를 누르면 토큰이 발급됨.

일반적인 평가였다면 API 문서 발견과 토큰 확보만으로 공격면이 크게 넓어졌을 것이고, Burp 같은 도구로 애플리케이션 자체를 훨씬 오래 공략했을 것임. ⚠️ 다만 **이번 대상은 애플리케이션이 아니라 파이프라인**이므로 그쪽은 접고 열거를 이어감.

Firefox 에서 우클릭 → Inspect (Q) 로 개발자 도구를 열고 Network 탭에서 페이지를 새로고침해 첫 요청·응답을 봄.

![[PEN200-Fig-345.png]]

*개발자 도구 Network 탭 — 응답 헤더에서 스택이 드러남*

눈에 띄는 것은 `Server` 헤더임. 값이 `Caddy` 인 헤더가 **두 개** 있다는 것은 앞단에 Caddy 리버스 프록시가 두 겹 있다는 뜻임. 그리고 `Werkzeug/1.0.1 Python/3.11.2` 값을 가진 `Server` 헤더가 하나 더 있어 대상 애플리케이션이 Python 으로 작성됐음을 알 수 있음.
