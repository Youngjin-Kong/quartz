# 7.2.1 Nessus 설치

> **Installing Nessus** · PEN-200 §7.2.1

- 랩 접속에 쓰는 Kali VM 에 설치함. 다운로드와 활성화에 인터넷 연결과 «업무용» 이메일 주소가 필요함.
- Tenable 권장 최소 사양은 4 코어·8GB 지만 이 실습은 2 코어·4GB 로 충분함.
- Nessus 는 Kali 저장소에 없어 수동 설치임. Tenable 사이트에서 Kali 용 64비트 `.deb` 를 받고 같은 페이지에서 SHA256·MD5 체크섬도 얻음. 플랫폼은 `Linux - Debian - amd64` 를 고르고, ARM 칩 Apple 사용자는 `Linux - Ubuntu - arch64` 설치본으로 Kali VM 에 설치함.
- 체크섬 검증 — Checksum 버튼의 복사 아이콘은 «해시만» 복사하므로 파일명은 직접 붙여야 함. 해시와 파일명을 `sha256sum_nessus` 로 저장하되 설치본과 «같은 디렉터리»에 두고 `-c` 로 대조함.

```
kali@kali:~$ cd ~/Downloads
kali@kali:~/Downloads$ echo
"4987776fef98bb2a72515abc0529e90572778b1d7aeeb1939179ff1f4de1440d Nessus-10.5.0-
debian10_amd64.deb" > sha256sum_nessus
kali@kali:~/Downloads$ sha256sum -c sha256sum_nessus
Nessus-10.5.0-debian10_amd64.deb: OK
```
*체크섬이 일치하면 설치를 진행함*

- 버전이 올라가면 위 해시는 달라지므로 그때 받은 값으로 교체할 것.
- 패키지 설치는 `apt` 의 `install` 옵션으로 함.

```
kali@kali:~/Downloads$ sudo apt install ./Nessus-10.5.0-debian10_amd64.deb
...
Preparing to unpack .../Nessus-10.5.0-debian10_amd64.deb ...
Unpacking nessus (10.5.0) ...
Setting up nessus (10.5.0) ...
...
Unpacking Nessus Scanner Core Components...
 - You can start Nessus Scanner by typing /bin/systemctl start nessusd.service
 - Then go to https://kali:8834/ to configure your scanner
```
*설치가 끝나면 서비스 시작 명령과 접속 주소가 안내됨*

```
kali@kali:~/Downloads$ sudo systemctl start nessusd.service
```
*`nessusd` 서비스 기동*

- 기동 후 브라우저로 `https://127.0.0.1:8834` 에 접속함. 자체 서명 인증서라 발급자 불명 경고가 뜨는 것이 정상이며, Advanced… → Accept the Risk and Continue 로 수락함.
- 이후 설치 전 설정 화면에서 Continue 로 기본값 설치를 시작하고, 제품 선택에서 Register for Nessus Essentials 를 고른 뒤 정보를 입력해 Register 로 활성화 코드를 받음.
- 마지막으로 로컬 Nessus 계정을 만듦 — 스캔 결과를 보호해야 하므로 사용자명 `admin` 에 강한 암호를 지정하고, 이 자격 증명으로 로그인함.
- 계정 생성 뒤 Nessus 가 플러그인 전체를 내려받아 컴파일함. 상당한 시간이 걸림.
