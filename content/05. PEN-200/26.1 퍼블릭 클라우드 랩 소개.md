# 26.1 퍼블릭 클라우드 랩 소개

> **About the Public Cloud Labs** · PEN-200 §26.1

이 모듈은 OffSec 의 Public Cloud Labs 를 씀. 다른 모듈의 VM 랩은 VPN 으로 붙지만, 퍼블릭 클라우드 랩은 **인터넷을 통해 클라우드 환경에 직접** 접속함.

지켜야 할 것 셋:

1. 학습 자료에 기술·요청된 활동 «외의» 용도로 쓰지 말 것. 범위 밖 실험용 놀이터가 아님
2. 랩 «외부» 자산을 향해 행위하지 말 것. 취약한 클라우드 배포를 공격하는 시연이 나오더라도 그것은 방어 방법을 설명하려는 것임
3. OffSec 교육 자료 공유 금지 규정이 그대로 적용됨 — 랩 자격 증명과 세부 정보도 공유 대상이 아님

OffSec 은 리소스 사용량을 포함해 랩 활동을 모니터링하고, 학습 모듈과 무관한 이상 이벤트를 탐지함. 의심 활동으로 표시되면 조사가 들어가고, 가이드라인 밖 행위나 고의적 남용으로 판정되면 **랩 접근 회수 또는 계정 종료**로 이어질 수 있음.

**세션 간 진행 상태는 저장되지 않음.** 랩을 재시작하면 초기 상태로 돌아감. 시작 후 1시간이 지나면 세션이 아직 활성인지 묻고, 응답이 없으면 종료됨. 수동 연장은 최대 10시간까지 가능함.

한 세션에 모듈 전체를 끝내도록 설계돼 있지 않으므로 여러 세션으로 쪼개도 됨. 다만 **앞서 실행한 명령과 동작을 메모해 둘 것** — 재시작 시 원래 상태로 복원하는 비용이 그만큼 줄어듦. 여러 단계를 거치는 복잡한 랩일수록 중요함.
