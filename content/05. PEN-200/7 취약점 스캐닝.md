# 7 취약점 스캐닝

> **Vulnerability Scanning** · PEN-200 §7

- 취약점 발견은 모든 보안 평가의 필수 요소임. 소프트웨어·시스템·네트워크의 공격 표면(attack surface)을 식별하는 과정이 취약점 스캐닝(vulnerability scanning)임.
- 스캐너의 폭이 넓음 — 취약점 하나만 짚는 단일 스크립트부터 다양한 취약점을 훑는 상용 솔루션까지.
- 자동 스캐너의 값은 「기준선을 빨리 세우는 것」에 있음 — 수동 정밀 분석으로 커버리지를 채우기 «전» 단계용임.
- 흔한 분류는 웹 애플리케이션 스캐너와 네트워크 스캐너 둘. 이 모듈이 다루는 것은 자동 네트워크 취약점 스캐닝이고, 이론 → Nessus → Nmap 순으로 진행함.
