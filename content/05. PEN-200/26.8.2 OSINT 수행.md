# 26.8.2 OSINT 수행

> **Conducting Open Source Intelligence** · PEN-200 §26.8.2

애플리케이션·파이프라인 열거만큼 **공개 인터넷 검색**도 중요함 — Stack Overflow·Reddit 같은 포럼에서 대상 이름을 찾는 식임. ⚠️ 일치 항목이 너무 많으면 현실성이 없으나, 널리 쓰이는 공개 도구가 아니면 성과가 나옴.

여기서는 "hackshort" 로 검색해 포럼 글 하나를 찾았다고 가정함.

![[PEN200-Fig-346.png]]

*컨테이너 빌드 실패를 호소하는 글 — 질문자가 내부 정보를 그대로 노출함*

글쓴이가 도움을 청하며 결정적 정보를 흘렸음 — `hackshort-util` 이라는 Python 모듈의 존재. 개발자 워크스테이션이나 각 환경에서 코드 실행을 얻는 실마리임.

판정 흐름 — 공개 저장소에 있으면 내부 소스를 엿볼 수 있고, **없으면 의존성 체인 공격이 성립**함. `pip download` 로 확인함.

```
kali@kali:~$ pip download hackshort-util
Looking in indexes: http://pypi.offseclab.io
ERROR: Could not find a version that satisfies the requirement hackshort-util (from
versions: none)
ERROR: No matching distribution found for hackshort-util
```

*공개 인덱스에 그 패키지가 없음 — 어떤 버전도 매칭 안 됨*

없다는 것이 확인됐으므로 의존성 체인 공격을 시도할 차례임.
